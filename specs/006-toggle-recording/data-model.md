# Data Model: Toggle Recording

## Entity Modifications

### `TrainingSession` (Existing)
*Table*: `training_sessions` (or equivalent SQLAlchemy model)

We need to persist the trainer's decision to record the session.

**New Field**:
- `keep_recording` (Boolean): Default `False`. Indicates whether the recording file generated by the media server should be retained and transcoded (True), or deleted (False) at the end of the session.

## State Transitions

1. **Session Created**: `keep_recording` defaults to `False`.
2. **Trainer clicks "Record"**: UI calls API to set `keep_recording = True`.
3. **Trainer clicks "Stop Recording"**: UI calls API to set `keep_recording = False`.
4. **Session Ends (`end_session`)**:
   - If `keep_recording == True`: Backend keeps the file in MinIO and triggers transcoder.
   - If `keep_recording == False`: Backend deletes the file from MinIO.
