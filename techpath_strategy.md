## 🔍 SEO OPTIMIZATION BLUEPRINT

### **On-Page SEO Elements**

#### **1. URL Structure**
```
/courses/                          (Main training page)
/courses/[course-slug]/            (Individual course pages)
```

#### **2. Meta Tags**
```
Title (60 chars): 
"Online Tech Courses | Certificate Programs | TechPath"

Description (160 chars):
"Learn AI, Cloud, Web Dev with live instructors. ₹7K-65K. 
94% job placement. 30-day money-back guarantee."
```

#### **3. Heading Structure**
```
<h1>Master In-Demand Tech Skills - Live Training Courses</h1>

<h2>Why Choose TechPath Training</h2>
<h2>Explore Our Course Catalog</h2>
<h2>Student Success Stories</h2>
<h2>Frequently Asked Questions</h2>
```

#### **4. Image Optimization**
- File names: "data-science-live-class.jpg" (NOT "image1.jpg")
- Alt Text: "Live data science instructor teaching Python classes"
- Format: WebP with fallback
- Lazy load: Load below-fold images on scroll

#### **5. Schema Markup (JSON-LD)**
```json
{
  "@context": "https://schema.org",
  "@type": "Course",
  "name": "Full Stack MERN Development",
  "price": "24999",
  "priceCurrency": "INR",
  "aggregateRating": {
    "ratingValue": "4.9",
    "ratingCount": "450"
  }
}
```

#### **6. Internal Linking**
- Link to individual course pages
- Link to student success stories
- Link to testimonials page

## 📱 MOBILE + UX OPTIMIZATION

### **Mobile-First Design**
```
Desktop: 4-column course grid
Tablet:  2-column course grid
Mobile:  1-column course grid (full width)

CTAs:
- Desktop: Inline CTAs + bottom sticky bar

```

### **Core Web Vitals (For SEO)**
```
LCP (Largest Contentful Paint): < 2.5s
FID (First Input Delay): < 100ms
CLS (Cumulative Layout Shift): < 0.1
```
