# Module 13 — Assignment: Build and Deploy a Complete Website

**Deadline:** End of Week 22
**Submission:** GitHub repo link + live deployed URL

---

## Build: Business Website for a Local Business

Pick a real or fictional local business (training institute, restaurant, gym, clinic, clothing store) and build a complete responsive website.

### Task 1: Design & Plan — 10 marks
- Create a simple wireframe (pen-paper or Figma sketch)
- List all sections and content needed
- Choose a color palette (use Coolors)
- Document your AI prompts (which tool, what you asked)

### Task 2: Build with AI Assistance — 40 marks
Use AI tools (Claude, ChatGPT, v0.dev) to generate the initial code, then customize it.

**Required pages/sections (single-page or multi-page):**
- Hero section with business name, tagline, and CTA
- About section (business story, mission)
- Services/Products section (at least 4 cards)
- Testimonials (at least 3 reviews)
- Contact section with form and map embed
- Footer with links, social media, copyright

**Technical requirements:**
- HTML + CSS (Tailwind CDN or custom CSS)
- Mobile responsive (works on phone)
- Smooth scroll for single-page navigation
- At least 3 images (from Unsplash)
- Meta tags for SEO (title, description, Open Graph)
- Favicon

### Task 3: Customization Beyond AI — 20 marks
Make changes that prove you understand the code (not just AI copy-paste):
- Change the color scheme to match the business brand
- Add a section that AI didn't generate (e.g., FAQ accordion, pricing table, team section)
- Fix any responsive issues on mobile
- Add hover animations or transitions
- Optimize images (compress, use proper sizes)

### Task 4: Deploy — 30 marks
- Push to GitHub with proper README
- Deploy to GitHub Pages or Vercel
- Submit the live URL
- Test on: desktop, tablet, mobile
- Run Lighthouse audit — aim for 80+ on all scores

**Document your process:**
- Screenshots of AI prompts and generated code
- What you changed manually and why
- Lighthouse scores (screenshot)

| Criteria | Excellent (Full) | Good (75%) | Needs Work (50%) |
