## What is Figma?

**Figma** is a free, web-based design tool used to create app and website designs. It runs in your browser — no download needed!

| Feature | Detail |
|---------|--------|
| **Price** | Free for students (up to 3 projects) |
| **Platform** | Works in browser (Chrome, Edge) + desktop app |
| **Collaboration** | Multiple people can design at the same time (like Google Docs) |
| **Used by** | Google, Microsoft, Uber, Netflix, Airbnb |

> **Why Figma over Photoshop?** Figma is built for UI/UX design. Photoshop is for photo editing. Different tools for different jobs.

---

## Getting Started

1. Go to **figma.com** → Sign up (free)
2. Click **"New Design File"**
3. You're in the Figma editor!

## Essential Tools

### 1. Frame Tool (F)

A **frame** is like a container or artboard. It represents a screen.

| Frame Preset | Size | Use For |
|-------------|------|---------|
| iPhone 14 | 390 × 844 | Mobile app design |
| Desktop | 1440 × 900 | Website design |
| iPad | 820 × 1180 | Tablet design |
| Custom | Any size | Specific needs |

> **Always start with a frame.** Press **F**, then select a preset or draw custom size.

### 2. Rectangle Tool (R)

Draw rectangles for buttons, cards, backgrounds, input fields.

**Rounded corners:** Select rectangle → change "Corner Radius" in properties panel.

### 3. Text Tool (T)

Click and type. Use properties panel to change:
- Font family (Inter, Roboto, Poppins)
- Font size (headings: 24-48px, body: 14-18px)
- Font weight (Regular, Medium, Bold)
- Color

### 4. Ellipse Tool (O)

Draw circles for profile pictures, icons, decorative elements.

### 5. Pen Tool (P)

Draw custom shapes and paths. For advanced users.

## Working with Colors

### Setting Colors

1. Select any element
2. In right panel, click the color square next to **Fill**
3. Use color picker or type hex code

### Common Hex Codes

| Color | Hex Code |
|-------|----------|
| White | #FFFFFF |
| Black | #000000 |
| Red | #FF0000 |
| Blue | #0000FF |
| Green | #00FF00 |
| Light Gray (bg) | #F5F5F5 |
| Dark Gray (text) | #333333 |

### Color Styles

Save colors you use often:
1. Select element → Click fill color
2. Click the **4 dots** icon → "Create Style"
3. Name it (e.g., "Primary Blue") → Save
4. Now reuse it everywhere — change once, updates all

## Layout & Alignment

### Auto Layout (Most Powerful Feature!)

Auto Layout automatically arranges elements in a row or column with equal spacing.

1. Select multiple elements
2. Press **Shift + A** (or right-click → Add Auto Layout)
3. Elements auto-arrange with spacing

| Property | What It Does |
|----------|-------------|
| **Direction** | Horizontal (row) or Vertical (column) |
| **Gap** | Space between items |
| **Padding** | Space inside the container |
| **Alignment** | Left, Center, Right |

> **Use Auto Layout for:** Navigation bars, button groups, card lists, form fields, footers.

### Alignment Tools

Select multiple elements → use alignment icons in the toolbar:
- Align left / center / right
- Align top / middle / bottom
- Distribute spacing evenly

## Components (Reusable Design Pieces)

A **component** is a reusable design piece. Change the main one → all copies update.

### Creating a Component

1. Design a button (rectangle + text)
2. Select both → **Ctrl + Alt + K** (Create Component)
3. Main component has a **purple diamond** icon
4. Copy-paste to create **instances** (copies)

### Variants

One component with multiple versions:
- Button: Default, Hover, Disabled
- Input: Empty, Filled, Error

## Prototyping (Making It Clickable)

1. Switch to **Prototype** tab (right panel, top)
2. Select a button
3. Drag the blue circle to the **target frame** (destination page)
4. Set interaction: "On Click" → "Navigate To"
5. Press **Play button** (top-right) to test

| Setting | Options |
|---------|---------|
| **Trigger** | On Click, On Hover, On Drag |
| **Action** | Navigate To, Open Overlay, Back |
| **Animation** | Instant, Dissolve, Slide In, Smart Animate |
| **Duration** | 300ms (recommended) |

## Exporting Designs

### Export for Developers

1. Select element
2. Bottom of right panel → **Export**
3. Choose format:

| Format | Use For |
|--------|---------|
| **PNG** | Images, screenshots (most common) |
| **SVG** | Icons, logos (scalable, never blurry) |
| **JPG** | Photos (smaller file size) |
| **PDF** | Documents, presentations |

### Export Sizes

- **1x** = Normal size
- **2x** = Double size (for retina/high-res screens)
- **3x** = Triple size (for mobile)

### Dev Mode

Figma's **Dev Mode** shows developers the exact CSS, spacing, and sizes of your design. Developers can inspect your file directly!

## Design Tips for Beginners

| Tip | Why |
|-----|-----|
| Copy good designs first | Learn by recreating existing apps |
| Use 8px grid | All spacing in multiples of 8 (8, 16, 24, 32, 48) |
| Stick to 2 fonts | Too many fonts = messy |
| Use real content | "Lorem ipsum" hides layout problems |
| Name your layers | "hero-section" not "Frame 47" |
| Use Auto Layout | Keeps things aligned and responsive |
| Check on mobile | Always preview your design at mobile size |

## Summary

- **Figma** = free, browser-based design tool for UI/UX
- Start with a **Frame** (screen preset)
- Use **Auto Layout** (Shift+A) for spacing
- Create **Components** (Ctrl+Alt+K) for reusable pieces
- **Prototype** tab makes designs clickable
- Export as **PNG** (images), **SVG** (icons), **PDF** (documents)
- Follow the **8px grid** and limit to **2 fonts, 3 colors**
