# Module 05 — Assignment: Design a Mobile App in Figma

**Deadline:** End of Week 6
**Submission:** Figma share link (view access) + exported screenshots

---

## Task 1: Design System Setup (20 marks)

Create a Figma file with a page called **"Design System"** containing:

1. **Color palette**: Define 5 colors (primary, secondary, accent, success, danger) as Figma color styles
2. **Typography scale**: Create text styles for H1, H2, H3, Body, Small, Caption
3. **Button component**: Create a button with 3 variants — Default, Hover, Disabled
4. **Input component**: Create a text input with 3 variants — Empty, Filled, Error
5. **Card component**: Create a card with image, title, subtitle, and CTA button

---

## Task 2: Mobile App Design (50 marks)

Design a **Food Delivery App** with 5 screens:

| Screen | Required Elements |
|--------|------------------|
| **1. Splash/Login** | Logo, email input, password input, Login button, "Sign up" link |
| **2. Home** | Search bar, category chips (Pizza, Burger, etc.), restaurant cards with ratings |
| **3. Restaurant Menu** | Restaurant header image, menu items with price and "Add" button, cart badge |
| **4. Cart** | Cart items with quantity +/-, subtotal, delivery fee, total, "Place Order" button |
| **5. Order Tracking** | Order status steps (Confirmed → Preparing → On the Way → Delivered), map placeholder, delivery time |

Requirements:
- Use **iPhone 14 frame** (390 × 844)
- Apply your Design System (colors, typography, components)
- Use **Auto Layout** on at least 3 screens
- Include bottom navigation bar on screens 2-5
- Use realistic content (not Lorem Ipsum)
- Indian context (₹ prices, Indian restaurant names)

---

## Task 3: Prototype (15 marks)

Connect your screens with interactions:
1. Login → Home (on button click)
2. Home → Restaurant Menu (on card click)
3. Menu → Cart (on cart icon click)
4. Cart → Order Tracking (on "Place Order" click)
5. Add at least one **Smart Animate** transition

Test in Presentation mode (Ctrl+P) and screen record a walkthrough.

---

## Task 4: Design Handoff Notes (15 marks)

Create a page called **"Handoff"** with:
1. All color hex codes listed
2. All font names and sizes used
3. Spacing values (padding, gap, margins)
4. Asset export — export at least 3 icons/images as PNG/SVG
5. Write a short note for the developer explaining the navigation flow

---

## Rubric

| Criteria | Excellent | Good | Needs Work |
|----------|----------|------|------------|

| Prototype | All 5 connections + Smart Animate | 3-4 connections | No prototype |
