# Cheat Sheet: Figma & UI/UX Design

**Module 05 — Quick Reference**

---

## UI vs UX

| UI | UX |
|----|----|
| What user **sees** | How user **feels** |
| Colors, fonts, buttons | Easy? Confusing? Fast? |
| Visual design | Experience design |

---

## Design Thinking (5 Steps)

1. **Empathize** — Understand the user
2. **Define** — State the problem
3. **Ideate** — Brainstorm solutions
4. **Prototype** — Build quick version
5. **Test** — Get user feedback

## Design Rules

- **2-3 colors** max
- **2 fonts** max
- **16px** min body text
- **8px grid** for spacing (8, 16, 24, 32, 48)
- **Mobile first** design

---

## Design Process

Wireframe → Mockup → Prototype → Code

| Type | Detail |
|------|--------|
| Wireframe | Basic skeleton (B&W) |
| Mockup | Realistic design |
| Prototype | Clickable version |

---

## Color Contrast

- Min **4.5:1** ratio for text (WCAG AA)
- Dark text on light bg = usually safe
- Always test readability
