# Quiz: Figma & UI/UX Design

**Module 05 | 12 Questions | Pass Mark: 60%**

---

## Q1. What does UI stand for?

- A) User Integration
- B) User Interface ✅
- C) Universal Internet
- D) Useful Information

> **Explanation:** UI = User Interface — the visual elements users see and interact with (buttons, colors, fonts, icons).

---

## Q2. What is the first step in the Design Thinking process?

- A) Prototype
- B) Define
- C) Empathize ✅
- D) Test

> **Explanation:** Empathize is step 1 — understand the user's needs and problems before designing anything.

---

## Q3. In Figma, what keyboard shortcut creates a Frame?

- A) R
- B) T
- C) F ✅
- D) V

> **Explanation:** Press F for the Frame tool. Frames are like artboards that represent screens (mobile, desktop, etc.).

---

## Q4. How many main colors should a website design use?

- A) 1
- B) 2-3 ✅
- C) 5-6
- D) As many as you want

> **Explanation:** Best practice is 2-3 colors: one primary, one background, one accent. Too many colors looks messy.

---

## Q5. What is the difference between a wireframe and a mockup?

- A) No difference
- B) Wireframe is basic layout, mockup has real colors and fonts ✅
- C) Mockup is on paper, wireframe is digital
- D) Wireframe is the final product

> **Explanation:** A wireframe is a basic skeleton (boxes and lines). A mockup is a realistic design with actual colors, fonts, and images.

---

## Q6. What does Auto Layout do in Figma?

- A) Auto-saves your file
- B) Automatically arranges elements with equal spacing ✅
- C) Creates layouts from AI
- D) Auto-generates code

> **Explanation:** Auto Layout (Shift+A) automatically arranges elements in rows or columns with consistent spacing and padding.

---

## Q7. What is the minimum recommended font size for body text on screens?

- A) 8px
- B) 12px
- C) 16px ✅
- D) 24px

> **Explanation:** 16px is the minimum recommended size for body text on screens to ensure readability.

---

## Q8. What export format should you use for icons and logos?

- A) PNG
- B) JPG
- C) SVG ✅
- D) GIF

> **Explanation:** SVG (Scalable Vector Graphics) is best for icons and logos — it scales to any size without getting blurry.

---

## Q9. What does UX focus on?

- A) Making things look pretty
- B) How users feel when using the product ✅
- C) Writing code
- D) Choosing colors

> **Explanation:** UX = User Experience — focuses on how easy and pleasant the product is to use, not just how it looks.

---

## Q10. What is a Figma component?

- A) A type of export
- B) A reusable design piece that updates all copies when changed ✅
- C) A plugin
- D) A color palette

> **Explanation:** A component is a reusable design piece. Change the main component and all instances (copies) update automatically.

---

## Q11. Why design for mobile first?

- A) Mobile phones are cheaper
- B) Over 60% of internet traffic comes from mobile devices ✅
- C) Mobile design is easier
- D) Mobile screens are bigger

> **Explanation:** Over 60% of internet traffic is mobile. Designing for the smallest screen first ensures your design works everywhere.

---

## Q12. What is the WCAG minimum contrast ratio for readable text?

- A) 2:1
- B) 3:1
- C) 4.5:1 ✅
- D) 10:1

> **Explanation:** WCAG AA standard requires at least 4.5:1 contrast ratio between text and background for readability.
