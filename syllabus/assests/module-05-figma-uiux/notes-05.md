# Module 05 — Figma & UI/UX — Quick Revision Notes

---

## UI vs UX
- **UI (User Interface)** = How it looks (colors, fonts, buttons, layout)
- **UX (User Experience)** = How it feels (easy to use? intuitive? frustrating?)
- Good UI + bad UX = beautiful but confusing app
- Bad UI + good UX = ugly but functional app

## Design Principles
| Principle | Meaning | Example |
|-----------|---------|---------|
| **Contrast** | Different elements should look different | Dark text on light background |
| **Alignment** | Elements should be visually connected | Left-aligned text, not scattered |
| **Repetition** | Consistent styles throughout | Same button color everywhere |
| **Proximity** | Related items grouped together | Form label close to its input |
| **Hierarchy** | Important things should be prominent | Bigger headings, bold CTAs |
| **White Space** | Empty space = breathing room | Don't cram everything together |

## Color Theory
- **Primary color**: Brand identity (1 main color)
- **Secondary**: Complement or support the primary
- **Accent**: Call-to-action buttons, highlights
- **Neutral**: Backgrounds, text (grays, whites, blacks)
- **60-30-10 rule**: 60% neutral, 30% primary, 10% accent
- **Contrast ratio**: Text must be readable — 4.5:1 minimum (WCAG)

## Typography
- **Sans-serif** for screens (Inter, Poppins, Roboto)
- **Serif** for print/formal (Georgia, Merriweather)
- **Max 2 fonts** per design
- **Font sizes**: H1=32-48px, H2=24-32px, Body=16px, Small=14px
- **Line height**: 1.5× font size for body text

## Figma Essentials
| Tool | Shortcut | Purpose |
|------|----------|---------|
| Frame | F | Create artboard/screen |
| Rectangle | R | Shapes |
| Text | T | Add text |
| Move | V | Select and move |
| Scale | K | Resize proportionally |
| Pen | P | Custom shapes |
| Hand | H / Space+drag | Pan around canvas |
| Zoom | Ctrl+scroll | Zoom in/out |

## Auto Layout (Most Important Figma Feature)
- Select elements → Shift+A → adds Auto Layout
- **Direction**: Horizontal or Vertical
- **Gap**: Space between items
- **Padding**: Space around items
- **Hug**: Container shrinks to fit content
- **Fill**: Container expands to fill parent

## Components & Variants
- **Component**: Reusable design element (button, card, input)
- Create: Select element → Ctrl+Alt+K
- **Instance**: Copy of a component (updates when master changes)
- **Variants**: Different states of one component (default, hover, active, disabled)

## Prototyping
- Connect frames with **interactions** (click → navigate)
- Transitions: Smart Animate, Dissolve, Move In
- Preview: Ctrl+P or Present button

## Design Handoff
- Share with developers → click Share → copy link
- Developers see: exact colors (#hex), fonts, sizes, spacing
- Export assets: Select → Export → PNG/SVG

## Mobile vs Desktop
| | Mobile | Desktop |
|--|--------|---------|
| Width | 375px (iPhone) | 1440px |
| Touch target | 44×44px minimum | Smaller OK (mouse) |
| Navigation | Bottom tab bar, hamburger | Top navbar, sidebar |
| Content | Single column | Multi-column |
