**Module 01 — Computer Fundamentals | Topic 3**

## What Happens Inside a Computer?

When you use a computer, 4 main parts work together:

1. **CPU** — Does the thinking (brain)
2. **RAM** — Remembers things temporarily (short-term memory)
3. **ROM** — Stores permanent startup instructions
4. **Storage** — Saves your files permanently (hard disk, SSD)

---

## 1. CPU — Central Processing Unit

The **brain** of the computer. It does all the calculations and decision-making.

### CPU has 3 parts:

| Part | Full Name | What It Does |
|------|-----------|-------------|
| **ALU** | Arithmetic Logic Unit | Does math (+, -, x, /) and comparisons (>, <, =) |
| **CU** | Control Unit | Controls all other parts, tells them what to do and when |
| **Registers** | — | Tiny super-fast memory inside CPU for current work |

### How CPU works (simple steps):

1. **Fetch** — Gets the next instruction from memory
2. **Decode** — Understands what the instruction means
3. **Execute** — Does the work (calculate, compare, move data)
4. **Store** — Saves the result

This is called the **Fetch-Decode-Execute Cycle**. It happens billions of times per second!

### CPU Speed

- Measured in **GHz** (Gigahertz)
- 1 GHz = 1 billion cycles per second
- More GHz = faster processing
- Modern CPUs: 2.5 GHz to 5+ GHz

> **Example:** Intel Core i5, AMD Ryzen 5, Apple M2 — these are all CPUs.

---

## 2. RAM — Random Access Memory

**Temporary memory** — stores data only while computer is ON.

| Feature | Detail |
|---------|--------|
| Type | Volatile (data lost when power off) |
| Speed | Very fast (nanoseconds) |
| Size | Usually 4 GB, 8 GB, 16 GB, or 32 GB |
| Purpose | Stores currently running programs and data |

### Real Life Example

When you open Chrome browser:
- The browser program loads from storage into **RAM**
- While you browse, all tabs and data stay in **RAM**
- When you shut down computer, RAM is emptied — that's why unsaved work is lost!

### Why more RAM is better?

- More RAM = you can run more apps at the same time
- 4 GB = basic use (1-2 apps)
- 8 GB = normal use (multiple apps)
- 16 GB = heavy use (coding, design, gaming)

---

## 3. ROM — Read Only Memory

**Permanent memory** — data stays even when computer is OFF.

| Feature | Detail |
|---------|--------|
| Type | Non-volatile (data stays without power) |
| Speed | Slower than RAM |
| Size | Very small (few MB) |
| Purpose | Stores BIOS/startup instructions |

### What does ROM store?

- **BIOS** (Basic Input Output System) — the first program that runs when you press power button
- It checks if keyboard, mouse, screen, and hard disk are working
- Then it loads the Operating System (Windows/Linux) from storage

> **Simple way to remember:** ROM = Rules Of Machine. It has the basic rules to start the computer.

---

## 4. Storage — Hard Disk & SSD

**Permanent storage** for all your files, apps, photos, videos.

| Type | Full Name | Speed | Noise | Price | Life |
|------|-----------|-------|-------|-------|------|
| **HDD** | Hard Disk Drive | Slow | Has noise (spinning disk) | Cheap | Good |
| **SSD** | Solid State Drive | Very fast (5-10x faster) | No noise (no moving parts) | More expensive | Very good |

### Storage sizes common today:

- 256 GB — Basic (budget laptops)
- 512 GB — Standard (most laptops)
- 1 TB (1000 GB) — Good for lots of files
- 2 TB+ — Heavy storage (videos, games)

### External Storage Devices

| Device | Common Size | Use |
|--------|------------|-----|
| Pendrive (USB) | 8 GB to 128 GB | Carry files between computers |
| External Hard Disk | 500 GB to 4 TB | Backup, extra storage |
| Memory Card (SD) | 16 GB to 512 GB | Phones, cameras |
| Cloud Storage | Unlimited | Google Drive, OneDrive, Dropbox |

---

## RAM vs ROM vs Storage — Comparison

| Feature | RAM | ROM | Storage (HDD/SSD) |
|---------|-----|-----|-------------------|
| **Full Name** | Random Access Memory | Read Only Memory | Hard Disk / Solid State Drive |
| **Data stays without power?** | No (volatile) | Yes (non-volatile) | Yes (non-volatile) |
| **Speed** | Very fast | Medium | Slow (HDD) / Fast (SSD) |
| **Size** | 4-32 GB | Few MB | 256 GB - 4 TB |
| **Can you change data?** | Yes, constantly | No (read only) | Yes |
| **What it stores** | Running programs | BIOS/startup | Files, apps, OS |
| **Real life analogy** | Desk (current work) | Rules on the wall | Cupboard (stored items) |

---

## Summary

- **CPU** = Brain, does all thinking (ALU + CU + Registers)
- **RAM** = Temporary memory, fast, lost when power off
- **ROM** = Permanent startup instructions (BIOS)
- **Storage** = Permanent file storage (HDD/SSD)
- More RAM = run more apps, bigger storage = save more files
- SSD is faster than HDD but costs more
