# Hardware vs Software

**Module 01 — Computer Fundamentals | Topic 7**

---

## Simple Difference

| | Hardware | Software |
|---|---------|----------|
| **What is it?** | Physical parts you can touch | Programs and apps you can see on screen |
| **Can you touch it?** | Yes | No |
| **Examples** | Keyboard, mouse, monitor, CPU | Windows, Chrome, MS Word, WhatsApp |
| **Breaks how?** | Physical damage (drop, water, heat) | Bugs, virus, crash, corrupt files |
| **Fix how?** | Repair or replace the part | Reinstall, update, or debug |

> **Easy way to remember:**
> - **Hard**ware = **hard** to touch (physical)
> - **Soft**ware = **soft** (just code, no physical form)

---

## Types of Hardware

### 1. Input Devices (send data TO computer)

| Device | What It Does |
|--------|-------------|
| Keyboard | Type letters, numbers, commands |
| Mouse | Click, scroll, drag items on screen |
| Microphone | Send your voice/sound |
| Scanner | Convert paper documents to digital |
| Webcam | Capture video/photo |
| Touchscreen | Touch to give commands |
| Barcode Reader | Read barcodes on products |
| Joystick | Control games |

### 2. Output Devices (show results FROM computer)

| Device | What It Does |
|--------|-------------|
| Monitor | Shows text, images, video on screen |
| Printer | Prints documents on paper |
| Speaker | Plays sound/music |
| Headphones | Sound output to your ears |
| Projector | Shows screen on wall/big screen |

### 3. Processing Devices

| Device | What It Does |
|--------|-------------|
| CPU | Processes all data (brain) |
| GPU | Processes graphics/video (gaming, design) |

### 4. Storage Devices

| Device | What It Does |
|--------|-------------|
| Hard Disk (HDD) | Stores files permanently |
| SSD | Faster permanent storage |
| RAM | Temporary fast memory |
| Pendrive | Portable storage |
| Memory Card | Storage for phones/cameras |

---

## Types of Software

### 1. System Software

Software that **manages the computer** itself. Without this, computer cannot work.

| Software | Example |
|----------|---------|
| Operating System (OS) | Windows 11, Linux, macOS, Android |
| Device Drivers | Printer driver, graphics driver |
| BIOS / Firmware | Starts the computer |

### 2. Application Software

Software **you use for your tasks**. Runs on top of the OS.

| Category | Examples |
|----------|---------|
| Office Work | MS Word, Excel, PowerPoint, Google Docs |
| Internet | Chrome, Firefox, Edge |
| Communication | WhatsApp, Zoom, Gmail, Teams |
| Entertainment | Spotify, VLC, Netflix |
| Design | Figma, Photoshop, Canva |
| Coding | VS Code, PyCharm |

### 3. Utility Software

Software that **helps maintain** the computer.

| Software | What It Does |
|----------|-------------|
| Antivirus | Protects from viruses (Quick Heal, Windows Defender) |
| Disk Cleanup | Removes unnecessary files |
| File Manager | Organize files and folders |
| Backup Software | Makes copies of important files |
| Compression Tools | Makes files smaller (WinRAR, 7-Zip) |

---

## How Hardware and Software Work Together

Think of it like a **car**:

| Car Part | Computer Equivalent |
|----------|-------------------|
| Engine | CPU (does the work) |
| Fuel | Electricity (power supply) |
| Steering wheel | Keyboard/Mouse (input) |
| Dashboard | Monitor (output) |
| Driver | Operating System (controls everything) |
| Google Maps app | Application Software (specific task) |

Without the engine (hardware), the car can't move.
Without the driver (software), the car doesn't know where to go.
**Both are needed!**

## Open Source vs Closed Source Software

| Feature | Open Source | Closed Source |
|---------|-----------|--------------|
| Source code visible? | Yes, anyone can see | No, hidden by company |
| Free? | Usually free | Usually paid |
| Can modify? | Yes | No |
| Examples | Linux, Firefox, VLC, LibreOffice | Windows, MS Office, Photoshop |
| Who makes it? | Community of developers | Companies |

---

## Summary

- **Hardware** = physical parts, **Software** = programs
- Hardware has 4 types: Input, Output, Processing, Storage
- Software has 3 types: System, Application, Utility
- Both hardware and software are needed — one cannot work without the other
- **Open source** = free and editable, **Closed source** = paid and locked
