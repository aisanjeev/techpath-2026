# Cheat Sheet — Computer Fundamentals

**Module 01 | Quick Reference Card**

---

## IPOS Cycle

```
INPUT → PROCESS → OUTPUT → STORAGE
(keyboard)  (CPU)    (monitor)  (hard disk)
```

---

## Computer Generations

| Gen | Period | Technology | Size | Language |
|-----|--------|-----------|------|----------|
| 1st | 1940-56 | Vacuum Tubes | Room-sized | Machine (binary) |
| 2nd | 1956-63 | Transistors | Smaller | Assembly, FORTRAN |
| 3rd | 1963-71 | ICs (Chips) | Desk-sized | BASIC, C |
| 4th | 1971-now | Microprocessors | Personal | C++, Java, Python |
| 5th | Now+ | AI, Quantum | Pocket-sized | AI/NLP |

---

## CPU Parts

- **ALU** = Arithmetic + Logic (math and comparisons)
- **CU** = Control Unit (boss — tells other parts what to do)
- **Registers** = Tiny fast memory inside CPU

---

## Memory Quick Reference

| Type | Volatile? | Speed | Size | Stores |
|------|-----------|-------|------|--------|
| RAM | Yes (lost on power off) | Very fast | 4-32 GB | Running programs |
| ROM | No (stays) | Medium | Few MB | BIOS/startup |
| HDD | No (stays) | Slow | 256 GB-4 TB | Files, apps |
| SSD | No (stays) | Fast | 256 GB-2 TB | Files, apps |

---

## Data Sizes

```
1 Bit    = 0 or 1
1 Byte   = 8 Bits
1 KB     = 1,024 Bytes
1 MB     = 1,024 KB
1 GB     = 1,024 MB
1 TB     = 1,024 GB
```

## Logic Gates

| Gate | Rule | 0,0 | 0,1 | 1,0 | 1,1 |
|------|------|-----|-----|-----|-----|
| AND | Both must be 1 | 0 | 0 | 0 | **1** |
| OR | At least one is 1 | 0 | **1** | **1** | **1** |
| NOT | Flip the input | **1** | 0 | — | — |
| NAND | Opposite of AND | **1** | **1** | **1** | 0 |
| NOR | Opposite of OR | **1** | 0 | 0 | 0 |
| XOR | Inputs must differ | 0 | **1** | **1** | 0 |

---

## Hardware vs Software

- **Hardware** = Physical (touch kar sakte ho) → Keyboard, CPU, RAM
- **Software** = Programs (screen pe dikhta hai) → Windows, Chrome, Word
- **System Software** = Manages computer (OS, drivers)
- **Application Software** = Your tasks (Word, Chrome, WhatsApp)
- **Utility Software** = Maintenance (Antivirus, Cleanup)
