# What is a Computer?

**Module 01 — Computer Fundamentals | Topic 1**

---

## Simple Definition

A **computer** is an electronic machine that:

1. Takes **input** (data from you)
2. **Processes** it (follows instructions)
3. Gives **output** (shows you result)
4. **Stores** it (saves for later)

Think of it like a very fast and obedient worker — you give it work, it follows your instructions exactly, and gives you the answer.

> **Fun Fact:** The word "computer" was first used for **humans** who did math calculations by hand. During World War II, women called "computers" calculated missile paths for the military!

---

## Real Life Example

When you type something in a calculator app on your phone:

| Step      | What Happens            | Example           |
| --------- | ----------------------- | ----------------- |
| **Input** | You press buttons       | You type `5 + 3`  |
| **Process** | Phone calculates      | CPU adds 5 and 3  |
| **Output** | Result shows on screen | Screen shows `8`  |
| **Storage** | Saved in history      | You can see it later |

This is called the **IPOS Cycle** (Input → Process → Output → Storage). Every computer follows this — from a small calculator to a big server.

---

## Key Parts of a Computer

| Part           | What It Does                          | Real Life Example           |
| -------------- | ------------------------------------- | --------------------------- |
| **CPU**        | Thinks and calculates (brain)         | Like your brain doing math  |
| **RAM**        | Short-term memory (temporary)         | Like remembering a phone number for 1 minute |
| **Storage**    | Long-term memory (permanent)          | Like writing in a notebook  |
| **Input devices**  | Send data to computer            | Keyboard, mouse, mic        |
| **Output devices** | Show results from computer       | Monitor, speaker, printer   |

---

## Hardware vs Software — Quick Difference

| Feature        | Hardware                     | Software                      |
| -------------- | ---------------------------- | ----------------------------- |
| What is it?    | Physical parts you can touch | Programs/apps you can see on screen |
| Examples       | Keyboard, mouse, CPU, RAM    | Windows, Chrome, MS Word      |
| Can you touch? | Yes                          | No                            |
| Breaks how?    | Physical damage              | Bugs, virus, crash            |

> **Remember:** Hardware is **hard** to touch (physical). Software is **soft** (just code running inside).

---

## Types of Software

### 1. System Software
- Manages the computer itself
- Examples: Windows, Linux, macOS, Android
- Without this, computer cannot start

### 2. Application Software
- Software you use for your work
- Examples: MS Word, Chrome, WhatsApp, Calculator
- Runs on top of system software

### 3. Utility Software
- Helps maintain the computer
- Examples: Antivirus, Disk Cleanup, File Manager

---

## Summary

- A computer is an **electronic machine** that takes input, processes it, gives output, and stores data
- Every computer follows the **IPOS cycle**
- Computer has **hardware** (physical parts) and **software** (programs)
- CPU is the **brain**, RAM is **temporary memory**, Storage is **permanent memory**
- Software has 3 types: **System**, **Application**, **Utility**
