# Module 01 — Resources & Installation Links

## Software to Download

### System Information Tools
- **CPU-Z** — See detailed CPU, RAM, motherboard info
  https://www.cpuid.com/softwares/cpu-z.html
- **CrystalDiskInfo** — Check hard drive / SSD health
  https://crystalmark.info/en/software/crystaldiskinfo/
- **HWiNFO** — Complete hardware analysis
  https://www.hwinfo.com/download/

### Learning Tools
- **Cisco Packet Tracer** — Network simulation (used later in Module 04)
  https://www.netacad.com/courses/packet-tracer
- **Logisim Evolution** — Logic gates simulator (free)
  https://github.com/logisim-evolution/logisim-evolution/releases

### Utilities
- **7-Zip** — Free file compression (better than WinRAR)
  https://www.7-zip.org/
- **Notepad++** — Better text editor than Notepad
  https://notepad-plus-plus.org/downloads/
