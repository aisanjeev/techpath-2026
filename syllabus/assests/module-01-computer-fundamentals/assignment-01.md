# Module 01 — Assignment: Know Your Machine

**Deadline:** End of Week 1
**Submission:** Document (Word/PDF) or handwritten with photos

---

## Task 1: System Report (30 marks)

Open your own computer/laptop and find the following information. Write each answer clearly.

| # | Find This | Where to Look |
|---|-----------|---------------|
| 1 | Processor name and speed | Settings → System → About |
| 2 | Number of CPU cores | Task Manager → Performance → CPU |
| 3 | Total RAM installed | Settings → System → About |
| 4 | RAM currently in use (%) | Task Manager → Performance → Memory |
| 5 | System type (32-bit or 64-bit) | Settings → System → About |
| 6 | Windows version and edition | Settings → System → About |
| 7 | Total storage capacity | Settings → System → Storage |
| 8 | Free storage space | Settings → System → Storage |
| 9 | Storage type (SSD or HDD) | Task Manager → Performance → Disk |
| 10 | Graphics card name | Task Manager → Performance → GPU |

**Take a screenshot of the "About" page and paste it in your document.**

## Task 2: Number System Conversions (30 marks)

Convert the following manually (show your working):

1. (25)₁₀ to Binary
2. (11010)₂ to Decimal
3. (255)₁₀ to Binary
4. (10110011)₂ to Decimal
5. (FF)₁₆ to Decimal
6. (45)₁₀ to Hexadecimal
7. (1010)₂ to Octal
8. (7)₈ to Binary
9. (192)₁₀ to Binary (hint: this is part of an IP address)
10. (01000001)₂ to Decimal (hint: this is the ASCII code for 'A')

## Task 3: Hardware Identification (20 marks)

Look at your computer/laptop physically and identify:

1. How many USB ports does it have? What types (USB-A, USB-C)?
2. Does it have an HDMI port?
3. Does it have an Ethernet (RJ45) port?
4. Does it have a 3.5mm audio jack?
5. Does it have an SD card slot?

**Take a photo of the ports on your laptop/computer and label each one.**

## Task 4: Short Answer Questions (20 marks)

Answer in 2-3 sentences each:

1. What is the difference between RAM and ROM?
2. Why is an SSD faster than an HDD?
3. What does the CPU's ALU do?
4. Why do computers use binary (0s and 1s) instead of decimal?
5. What happens to the data in RAM when you shut down your computer?
