# Quiz: Computer Fundamentals

**Module 01 | 15 Questions | Pass Mark: 60%**

---

## Q1. What is a computer?

- A) A machine that only plays games
- B) An electronic device that takes input, processes it, gives output, and stores data ✅
- C) A device used only for internet
- D) A type of calculator

> **Explanation:** A computer is a programmable electronic device that follows the IPOS cycle — Input, Process, Output, Storage.

---

## Q2. What does IPOS stand for?

- A) Internet, Program, Output, Software
- B) Input, Process, Output, Storage ✅
- C) Input, Print, Open, Save
- D) Install, Process, Open, Store

> **Explanation:** IPOS = Input → Process → Output → Storage. This is the basic working cycle of every computer.

---

## Q3. Which of these is an input device?

- A) Monitor
- B) Printer
- C) Keyboard ✅
- D) Speaker

> **Explanation:** Keyboard sends data TO the computer (input). Monitor, printer, and speaker show results FROM the computer (output).

---

## Q4. CPU stands for?

- A) Computer Personal Unit
- B) Central Processing Unit ✅
- C) Central Program Utility
- D) Computer Processing Unit

> **Explanation:** CPU = Central Processing Unit. It is called the "brain" of the computer because it does all the thinking and calculating.

---

## Q5. RAM is which type of memory?

- A) Permanent memory
- B) Temporary memory (data is lost when power off) ✅
- C) External memory
- D) Read-only memory

> **Explanation:** RAM (Random Access Memory) is volatile — it loses all data when computer is turned off. It is used for temporary storage while computer is running.

---

## Q6. Which one is an example of system software?

- A) MS Word
- B) Google Chrome
- C) Windows 11 ✅
- D) WhatsApp

> **Explanation:** Windows 11 is an operating system = system software. It manages the computer hardware. Word, Chrome, WhatsApp are application software.

---

## Q7. Who is called the "Father of Computers"?

- A) Alan Turing
- B) Charles Babbage ✅
- C) Bill Gates
- D) Steve Jobs

> **Explanation:** Charles Babbage designed the Analytical Engine (1837) which had the basic design of modern computers — CPU, memory, and input/output.

---

## Q8. First generation computers used which technology?

- A) Transistors
- B) Integrated Circuits (ICs)
- C) Vacuum Tubes ✅
- D) Microprocessors

> **Explanation:** First generation (1940-1956) used vacuum tubes. They were very large (room-sized), generated a lot of heat, and used a lot of electricity.

---

## Q9. 1 Byte = how many Bits?

- A) 4 bits
- B) 16 bits
- C) 8 bits ✅
- D) 2 bits

> **Explanation:** 1 Byte = 8 Bits. A bit is the smallest unit of data (0 or 1). With 8 bits, you can make 256 different combinations.

---

## Q10. Which is the correct order from smallest to largest?

- A) KB → Byte → MB → GB
- B) Bit → Byte → KB → MB → GB → TB ✅
- C) Byte → Bit → KB → GB
- D) MB → KB → GB → TB

> **Explanation:** Bit → Byte (8 bits) → KB (1024 bytes) → MB (1024 KB) → GB (1024 MB) → TB (1024 GB).

---

## Q11. What does an AND gate output when both inputs are 1?

- A) 0
- B) 1 ✅
- C) 2
- D) Cannot determine

> **Explanation:** AND gate = both inputs must be 1 to get output 1. Think of it like: "Both conditions must be true." If any input is 0, output is 0.

---

## Q12. OR gate gives output 0 only when:

- A) Both inputs are 1
- B) Both inputs are 0 ✅
- C) One input is 1
- D) One input is 0

> **Explanation:** OR gate = at least one input must be 1 for output 1. Only when ALL inputs are 0, the output is 0.

---

## Q13. Convert binary 1101 to decimal.

- A) 11
- B) 15
- C) 13 ✅
- D) 12

> **Explanation:** 1101 = (1×8) + (1×4) + (0×2) + (1×1) = 8 + 4 + 0 + 1 = 13.

---

## Q14. Which type of computer processes continuous data (like temperature)?

- A) Digital Computer
- B) Analog Computer ✅
- C) Hybrid Computer
- D) Supercomputer

> **Explanation:** Analog computers work with continuous data like temperature, speed, pressure. Digital computers work with discrete data (0s and 1s).

---

## Q15. ROM is used to store:

- A) Temporary data while running programs
- B) User files and documents
- C) Permanent instructions like BIOS/startup program ✅
- D) Internet data

> **Explanation:** ROM (Read-Only Memory) stores permanent instructions that don't change — like the BIOS program that starts your computer. Data stays even when power is off.
