# Quiz: Operating Systems — Windows & Linux

**Module 02 | 12 Questions | Pass Mark: 60%**

---

## Q1. What is an Operating System?

- A) A hardware device
- B) Software that manages computer hardware and lets you run apps ✅
- C) A type of programming language
- D) An internet browser

> **Explanation:** An OS is the main software that manages your computer's hardware, memory, files, and runs other programs.

---

## Q2. Which shortcut opens File Explorer in Windows?

- A) Ctrl + E
- B) Win + E ✅
- C) Alt + E
- D) Shift + E

> **Explanation:** Win + E opens File Explorer. One of the most useful Windows shortcuts.

---

## Q3. What does Task Manager help you do?

- A) Create new files
- B) Browse the internet
- C) See running programs and close stuck apps ✅
- D) Install new software

> **Explanation:** Task Manager (Ctrl+Shift+Esc) shows running programs, CPU/RAM usage, and lets you end stuck apps.

---

## Q4. Which Linux command lists files in the current folder?

- A) dir
- B) ls ✅
- C) list
- D) show

> **Explanation:** `ls` shows all files and folders in the current directory.

---

## Q5. What does the 'cd' command do in Linux?

- A) Create a directory
- B) Copy a file
- C) Change directory (go to a folder) ✅
- D) Clear the screen

> **Explanation:** cd = Change Directory. Example: `cd Documents` moves you into the Documents folder.

---

## Q6. Which shortcut copies selected text or files?

- A) Ctrl + V
- B) Ctrl + X
- C) Ctrl + C ✅
- D) Ctrl + Z

> **Explanation:** Ctrl + C = Copy, Ctrl + V = Paste, Ctrl + X = Cut.

---

## Q7. Which OS is free and open source?

- A) Windows 11
- B) macOS
- C) Linux (Ubuntu) ✅
- D) Chrome OS

> **Explanation:** Linux is free and open source — anyone can see, modify, and share the code.

---

## Q8. What does Ctrl + Z do?

- A) Zoom in
- B) Close the window
- C) Undo the last action ✅
- D) Save the file

> **Explanation:** Ctrl + Z = Undo. It reverses your last action.

---

## Q9. What does 'mkdir' command do in Linux?

- A) Move a file
- B) Make a new directory (folder) ✅
- C) Delete a file
- D) Show file content

> **Explanation:** mkdir = Make Directory. Example: `mkdir myproject` creates a new folder.

---

## Q10. To make computer start faster, what should you do in Task Manager?

- A) End all processes
- B) Disable unnecessary Startup programs ✅
- C) Delete System files
- D) Increase RAM in Task Manager

> **Explanation:** Go to Startup tab in Task Manager and disable apps you don't need at startup.

---

## Q11. Which shortcut locks your Windows computer?

- A) Ctrl + L
- B) Win + L ✅
- C) Alt + L
- D) Shift + L

> **Explanation:** Win + L instantly locks your computer. Always lock when leaving your desk!

---

## Q12. What is the Linux command to delete a file?

- A) del
- B) remove
- C) rm ✅
- D) delete

> **Explanation:** rm = Remove. Be careful — Linux doesn't have a Recycle Bin by default!
