# Keyboard Shortcuts — Become 3x Faster

**Module 02 — Operating Systems | Topic 2 — The Skill That Gets You Noticed on Day One**

---

## Why This Matters

> Your first day at an IT job. Your manager sits next to you and watches you work. You reach for the mouse to copy text... click Edit... click Copy... click somewhere else... click Edit... click Paste. Your manager is already thinking "this person is slow."
>
> The person who gets promoted? They hit Ctrl+C, Ctrl+V without thinking. They snap windows with Win+Arrow. They switch apps with Alt+Tab. **Speed = competence** in every IT workplace.

## Windows — Core Shortcuts

### Editing (Used 100+ Times/Day)

| Shortcut | Action | When You'll Use It |
|----------|--------|-------------------|
| `Ctrl + C` | Copy | Copying text, files, images — everything |
| `Ctrl + X` | Cut (copy + delete original) | Moving files between folders |
| `Ctrl + V` | Paste | After copy or cut |
| `Ctrl + Z` | Undo (go back one step) | Made a mistake? Undo instantly |
| `Ctrl + Y` | Redo (undo the undo) | Went too far back? Redo |
| `Ctrl + A` | Select all | Select all text in a document, all files in a folder |
| `Ctrl + S` | Save | EVERY 2 MINUTES while working. Muscle memory. |
| `Ctrl + Shift + S` | Save As | Save a copy with a different name |
| `Ctrl + F` | Find / Search | Search for text in any app, any document |
| `Ctrl + H` | Find & Replace | Replace all instances of a word |
| `Ctrl + P` | Print | Print current document/page |
| `Ctrl + N` | New | New file, new window (depends on app) |

**Speed test:** Open Notepad, type a paragraph. Now select a word (double-click), copy (Ctrl+C), go to end (Ctrl+End), paste (Ctrl+V) — all without touching the mouse. Time yourself. Under 3 seconds = good.

---

### Text Navigation (The Secret Weapon)

Most beginners click with the mouse to move the cursor. Professionals use these:

| Shortcut | What It Does | Speed Gain |
|----------|-------------|-----------|
| `Home` | Jump to beginning of line | Instead of clicking at the start |
| `End` | Jump to end of line | Instead of clicking at the end |
| `Ctrl + Home` | Jump to beginning of document | Instant, no scrolling |
| `Ctrl + End` | Jump to end of document | Instant, no scrolling |
| `Ctrl + Left/Right` | Jump one word at a time | 5x faster than arrow keys |
| `Ctrl + Backspace` | Delete entire word backward | One key vs hitting backspace 8 times |
| `Ctrl + Delete` | Delete entire word forward | Same, forward direction |

### Text Selection (Combine with Shift)

| Shortcut | What It Does |
|----------|-------------|
| `Shift + Arrow` | Select character by character |
| `Shift + Home` | Select from cursor to beginning of line |
| `Shift + End` | Select from cursor to end of line |
| `Ctrl + Shift + Left/Right` | Select word by word |
| `Ctrl + Shift + Home` | Select from cursor to beginning of document |
| `Ctrl + Shift + End` | Select from cursor to end of document |
| `Shift + Click` | Select everything between cursor and where you click |

**Scenario:** Your boss says "Change all the dates in this report from 2025 to 2026."
- Slow way: Find each date manually, select, retype (5 minutes)
- Fast way: `Ctrl + H` → Find: 2025 → Replace: 2026 → Replace All (5 seconds)

## VS Code Shortcuts (For Coding)

VS Code is your primary tool as a developer. These shortcuts make you code 3x faster:

### File & Navigation

| Shortcut | Action | Why It's Essential |
|----------|--------|-------------------|
| `Ctrl + P` | Quick Open file (type filename) | Find any file instantly — no clicking through folders |
| `Ctrl + Shift + P` | Command Palette | Access EVERY VS Code feature by typing |
| `Ctrl + B` | Toggle sidebar | More screen space when coding |
| `Ctrl + `` ` | Toggle terminal | Open terminal without leaving VS Code |
| `Ctrl + Tab` | Switch between open files | Jump between files you're editing |
| `Ctrl + \` | Split editor | View two files side by side |

### Editing

| Shortcut | Action | Use Case |
|----------|--------|---------|
| `Ctrl + D` | Select next occurrence of word | Rename a variable in multiple places |
| `Ctrl + Shift + L` | Select ALL occurrences | Rename everywhere at once |
| `Alt + Up/Down` | Move line up/down | Reorder code without cut-paste |
| `Alt + Shift + Up/Down` | Copy line up/down | Duplicate a line instantly |
| `Ctrl + Shift + K` | Delete entire line | Faster than selecting + deleting |
| `Ctrl + /` | Toggle comment | Comment/uncomment code |
| `Ctrl + ]` / `Ctrl + [` | Indent / Un-indent | Fix code formatting |
| `Ctrl + Enter` | Insert line below | New line without moving to end first |
| `Ctrl + Shift + Enter` | Insert line above | New line above current |

### Multi-Cursor (Power Feature)

| Shortcut | Action |
|----------|--------|
| `Alt + Click` | Add cursor at clicked position |
| `Ctrl + Alt + Up/Down` | Add cursor above/below |
| `Ctrl + D` (repeatedly) | Add cursors at next matching word |

**Scenario:** You have a list of 20 names and need to add quotes around each:
```
Rahul
Priya
Amit
```
1. Click at the start of "Rahul"
2. Press `Ctrl + Alt + Down` two times (now you have 3 cursors)
3. Type `"` — all three lines get a quote
4. Press `End` — all cursors jump to end
5. Type `"` — done!

Result:
```
"Rahul"
"Priya"
"Amit"
```

## Workplace Scenarios — Shortcuts in Action

### Scenario 1: "Can You Send Me That Report?"
Your colleague asks for a report file.

| Step | Action | Shortcut |
|------|--------|----------|
| 1 | Open File Explorer | `Win + E` |
| 2 | Navigate to file | Type path in address bar: `Alt + D` |
| 3 | Select the file | Click or arrow keys |
| 4 | Copy | `Ctrl + C` |
| 5 | Open email/Slack | `Alt + Tab` |
| 6 | Paste in chat/email | `Ctrl + V` |

**Total time:** 10 seconds (vs 30 seconds with mouse)

### Scenario 2: "The App is Frozen"
An app stops responding.

| Step | Action | Shortcut |
|------|--------|----------|
| 1 | Open Task Manager | `Ctrl + Shift + Esc` |
| 2 | Find the frozen app | It'll say "Not Responding" |
| 3 | End it | Select → click "End Task" |

### Scenario 3: "Show Me Your Screen"
Boss walks by during a presentation prep.

| Step | Action | Shortcut |
|------|--------|----------|
| 1 | Snap your presentation to full screen | `Win + Up` |
| 2 | After they leave, get your windows back | `Win + Left` + `Win + Right` (snap two side by side) |

### Scenario 4: "You Have 5 Minutes to Leave for Lunch"
Secure your work fast.

| Step | Action | Shortcut |
|------|--------|----------|
| 1 | Save everything | `Ctrl + S` (in each app) |
| 2 | Lock your computer | `Win + L` |
| Done | Walk away | 3 seconds total |

**NEVER leave your work computer unlocked.** At some companies, if someone finds your PC unlocked, they send a joke email from your account. It's called "getting toasted."

## Practice Challenges

### Challenge 1: Zero Mouse Challenge (15 minutes)
Open Notepad and do this WITHOUT touching the mouse:
1. Type 3 paragraphs of text
2. Select the second paragraph (`Shift + Down` or `Ctrl + Shift + Down`)
3. Move it to the top (`Ctrl + X`, `Ctrl + Home`, `Ctrl + V`)
4. Find a specific word (`Ctrl + F`)
5. Replace it with another word (`Ctrl + H`)
6. Save (`Ctrl + S`) with the name "practice.txt"
7. Close Notepad (`Alt + F4`)

### Challenge 2: Window Master (5 minutes)
1. Open 4 apps: Chrome, File Explorer, Notepad, Calculator
2. Snap Chrome to the left half (`Win + Left`)
3. Snap File Explorer to the right half (`Win + Right`)
4. Switch between all apps using `Alt + Tab`
5. Minimize all with `Win + D`, then bring them back with `Win + D` again
6. Take a screenshot of the snapped layout (`Win + Shift + S`)

### Challenge 3: Browser Speed Run (5 minutes)
1. Open Chrome
2. Open 5 tabs (`Ctrl + T` × 5)
3. Go to 5 different websites (type URLs with `Ctrl + L`)
4. Close the 3rd tab (`Ctrl + W` after `Ctrl + 3`)
5. Reopen it (`Ctrl + Shift + T`)
6. Zoom in on a page (`Ctrl + +`), reset (`Ctrl + 0`)
7. Open DevTools (`F12`), close it (`F12`)
8. Open incognito (`Ctrl + Shift + N`), close it (`Ctrl + W`)

### Challenge 4: VS Code Sprint (10 minutes)
1. Open VS Code
2. Create a new file (`Ctrl + N`)
3. Type 10 lines of any text
4. Move line 5 above line 4 (`Alt + Up`)
5. Duplicate line 7 (`Alt + Shift + Down`)
6. Delete line 3 (`Ctrl + Shift + K`)
7. Comment out lines 2-4 (select → `Ctrl + /`)
8. Open the terminal (`` Ctrl + ` ``)
9. Split the editor (`Ctrl + \`)
10. Use `Ctrl + P` to open any file in the project
