# Module 02 — Resources & Installation Links

## Essential Downloads

### WSL (Windows Subsystem for Linux)
- **Pre-installed in Windows 11** — just run `wsl --install` in PowerShell (admin)
- Docs: https://learn.microsoft.com/en-us/windows/wsl/install

### VirtualBox (Run full Linux desktop in a window)
- Download: https://www.virtualbox.org/wiki/Downloads
- Choose "Windows hosts"

### Ubuntu ISO (For VirtualBox or Live USB)
- Download: https://ubuntu.com/download/desktop

### Windows Terminal (Better than CMD)
- Microsoft Store: search "Windows Terminal"
- Or: https://aka.ms/terminal

### Rufus (Create bootable USB drives)
- Download: https://rufus.ie/
- Use to create Ubuntu Live USB from ISO file
