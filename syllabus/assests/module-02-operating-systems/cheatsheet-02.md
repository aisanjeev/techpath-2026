## Windows Shortcuts — Top 20

| Shortcut | Action |
|----------|--------|
| `Ctrl+C / X / V` | Copy / Cut / Paste |
| `Ctrl+Z / Y` | Undo / Redo |
| `Ctrl+S` | Save |
| `Ctrl+A` | Select all |
| `Ctrl+F` | Find |
| `Win+E` | File Explorer |
| `Win+I` | Settings |
| `Win+L` | Lock computer |
| `Win+D` | Show desktop |
| `Win+S` | Search |
| `Win+Shift+S` | Screenshot |
| `Alt+Tab` | Switch apps |
| `Alt+F4` | Close window |
| `Ctrl+Shift+Esc` | Task Manager |
| `F2` | Rename |
| `F5` | Refresh |
| `Ctrl+T` | New browser tab |
| `Ctrl+W` | Close tab |
| `Ctrl+Shift+T` | Reopen closed tab |
| `Win+V` | Clipboard history |

## Linux Commands — Top 15

| Command | What It Does |
|---------|-------------|
| `ls` | List files |
| `cd folder` | Go to folder |
| `cd ..` | Go back |
| `pwd` | Show current path |
| `mkdir name` | Create folder |
| `touch file` | Create file |
| `cp a b` | Copy a to b |
| `mv a b` | Move/rename a to b |
| `rm file` | Delete file |
| `cat file` | Show file content |
| `clear` | Clear screen |
| `sudo` | Run as admin |
| `apt install` | Install software |
| `apt update` | Update package list |
| `chmod` | Change permissions |

## Task Manager — When to Use

| Problem | Action |
|---------|--------|
