# Quiz: Spec-Kit Development

**Module 15 | 10 Questions | Pass Mark: 60%**

---

## Q1. What is a Spec-Kit?
- A) A programming language
- B) A complete project delivery package with docs and config ✅
- C) A type of database
- D) A testing framework

> **Explanation:** Spec-Kit = README + tech spec + setup guide + .env.example + screenshots.

---

## Q2. What should you NEVER commit to GitHub?
- A) README.md
- B) .gitignore
- C) .env file with real secrets ✅
- D) package.json

> **Explanation:** .env has passwords and API keys. Use .env.example (with placeholder values) instead.

---

## Q3. Best platform for deploying React/Next.js frontend for free?
- A) Render
- B) Vercel ✅
- C) PythonAnywhere
- D) Docker Hub

> **Explanation:** Vercel auto-deploys frontend apps from Git — built for React/Next.js/Astro.

---

## Q4. What is Docker used for?
- A) Writing CSS
- B) Packaging an app with its dependencies into a portable container ✅
- C) Creating databases
- D) Designing UI

> **Explanation:** Docker = code + dependencies in one container that runs the same everywhere.

---

## Q5. What does CI/CD stand for?
- A) Code Integration / Code Delivery
- B) Continuous Integration / Continuous Deployment ✅
- C) Computer Interface / Computer Design
- D) Cloud Integration / Cloud Deployment

> **Explanation:** CI = auto-test on push. CD = auto-deploy after tests pass.

---

## Q6. What is a Dockerfile?
- A) A text file with passwords
- B) Instructions to build a Docker image ✅
- C) A database backup file
- D) A JavaScript file

> **Explanation:** Dockerfile has FROM, COPY, RUN, CMD — step-by-step image build recipe.

---

## Q7. What does SSL/HTTPS do?
- A) Makes websites load faster
- B) Encrypts data between browser and server ✅
- C) Adds colors to a website
- D) Compresses images

> **Explanation:** SSL = encryption. HTTPS = HTTP + SSL. The padlock icon in your browser.

---

## Q8. Which file tells Git which files to ignore?
- A) .env
- B) README.md
- C) .gitignore ✅
- D) package.json

> **Explanation:** .gitignore lists files Git should skip — .env, node_modules, __pycache__, etc.

---

## Q9. What DNS record points a domain to an IP address?
- A) CNAME
- B) MX
- C) A record ✅
- D) TXT

> **Explanation:** A record = domain → IP address (e.g., example.com → 76.76.21.21).

---

## Q10. What does 'docker-compose up' do?
- A) Deletes all containers
- B) Starts all services defined in docker-compose.yml ✅
- C) Pushes code to GitHub
- D) Installs Python

> **Explanation:** docker-compose up starts everything — web app, database, etc. — in one command.
