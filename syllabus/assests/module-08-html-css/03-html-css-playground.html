1. Create a Navigation Bar

Make a horizontal nav bar with 4 links: Home, About, Courses, Contact. Blue background, white text, centered links with padding.

<nav style="background:#3b82f6; display:flex; justify-content:center; gap:24px; padding:16px;"> <a href="#" style="color:white; text-decoration:none;">Home</a> <a href="#" style="color:white; text-decoration:none;">About</a> <a href="#" style="color:white; text-decoration:none;">Courses</a> <a href="#" style="color:white; text-decoration:none;">Contact</a> </nav>

2. Build a Profile Card

Create a card with: rounded corners, shadow, a heading (your name), a paragraph (about you), a blue "Follow" button.

<div style="max-width:300px; background:white; border-radius:12px; padding:24px; box-shadow:0 2px 12px rgba(0,0,0,0.1); font-family:Arial;"> <h2 style="color:#1a1a2e;">Your Name</h2> <p style="color:#666;">Web Developer | TechPath Student</p> <button style="background:#3b82f6; color:white; border:none; padding:10px 24px; border-radius:8px; cursor:pointer;">Follow</button> </div>

3. Create a 3-Column Layout

Use Flexbox to create 3 equal columns with different colored backgrounds and text. Add gap between them.

<div style="display:flex; gap:16px;"> <div style="flex:1; background:#dbeafe; padding:20px; border-radius:8px;">Column 1</div> <div style="flex:1; background:#dcfce7; padding:20px; border-radius:8px;">Column 2</div> <div style="flex:1; background:#fef3c7; padding:20px; border-radius:8px;">Column 3</div> </div>

4. Style a Simple Form

Create a login form with: email input, password input, and a "Login" button. Style with rounded inputs and a blue submit button.

<form style="max-width:300px; font-family:Arial;"> <input type="email" placeholder="Email" style="width:100%; padding:12px; border:1px solid #ddd; border-radius:8px; margin-bottom:12px; font-size:14px;"> <input type="password" placeholder="Password" style="width:100%; padding:12px; border:1px solid #ddd; border-radius:8px; margin-bottom:12px; font-size:14px;"> <button style="width:100%; background:#3b82f6; color:white; border:none; padding:12px; border-radius:8px; font-size:16px; cursor:pointer;">Login</button> </form>
