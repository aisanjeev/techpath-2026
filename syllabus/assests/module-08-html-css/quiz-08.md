# Quiz: HTML & CSS — Web Foundations

**Module 08 | 12 Questions | Pass Mark: 60%**

---

## Q1. What does HTML stand for?

- A) Hyper Text Markup Language ✅
- B) High Tech Modern Language
- C) Home Tool Markup Language
- D) Hyper Transfer Method Language

> **Explanation:** HTML = HyperText Markup Language — the standard language for creating web pages.

---

## Q2. Which HTML tag creates the largest heading?

- A) `<h6>`
- B) `<heading>`
- C) `<h1>` ✅
- D) `<head>`

> **Explanation:** `<h1>` is the largest heading. Headings go from `<h1>` (biggest) to `<h6>` (smallest).

---

## Q3. What does CSS stand for?

- A) Computer Style Sheets
- B) Cascading Style Sheets ✅
- C) Creative Style System
- D) Coded Style Syntax

> **Explanation:** CSS = Cascading Style Sheets — controls how HTML elements look (colors, fonts, layout).

---

## Q4. Which CSS property changes text color?

- A) text-color
- B) font-color
- C) color ✅
- D) text-style

> **Explanation:** The `color` property changes text color. Example: `color: blue;` or `color: #3b82f6;`

---

## Q5. What is the CSS Box Model order from inside to outside?

- A) Margin → Border → Padding → Content
- B) Content → Padding → Border → Margin ✅
- C) Border → Margin → Content → Padding
- D) Padding → Content → Margin → Border

> **Explanation:** Box Model (inside to outside): Content → Padding → Border → Margin.

---

## Q6. Which CSS display value is used for modern layouts?

- A) block
- B) inline
- C) flex ✅
- D) hidden

> **Explanation:** `display: flex` (Flexbox) is the modern way to create layouts — easy alignment and spacing.

---

## Q7. What does the `<a>` tag create in HTML?

- A) An image
- B) A heading
- C) A hyperlink ✅
- D) A paragraph

> **Explanation:** `<a href="url">Link text</a>` creates a clickable hyperlink to another page or section.

---

## Q8. Which attribute makes an image accessible for screen readers?

- A) src
- B) title
- C) alt ✅
- D) name

> **Explanation:** The `alt` attribute provides text description of an image for screen readers and when image fails to load.

---

## Q9. How do you select an element with class "card" in CSS?

- A) `card { }`
- B) `#card { }`
- C) `.card { }` ✅
- D) `*card { }`

> **Explanation:** Use a dot (.) for classes: `.card { }`. Use # for IDs: `#card { }`.

---

## Q10. What CSS property adds space between flex items?

- A) margin
- B) spacing
- C) gap ✅
- D) padding

> **Explanation:** The `gap` property adds space between flex items. Example: `gap: 16px;`

---

## Q11. Which unit is relative to the root font size?

- A) px
- B) em
- C) rem ✅
- D) %

> **Explanation:** `rem` = relative to root element font size. If root = 16px, then 1.5rem = 24px. Better for responsive design.

---

## Q12. What is the purpose of @media queries in CSS?

- A) Add images
- B) Play videos
- C) Make designs responsive for different screen sizes ✅
- D) Import fonts

> **Explanation:** `@media` queries apply different CSS rules based on screen size — essential for responsive design.
