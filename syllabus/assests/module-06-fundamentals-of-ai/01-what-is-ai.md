## Simple Definition

**Artificial Intelligence (AI)** = Making computers do things that normally need human intelligence.

Things like:
- Understanding language (Alexa, Google Assistant)
- Recognizing faces (phone unlock)
- Making decisions (recommending movies on Netflix)
- Creating content (ChatGPT writing text, DALL-E making images)

> **AI does NOT mean the computer is "thinking" like a human.** It's following patterns learned from massive amounts of data.

## Types of AI

### By Capability

| Type | What It Can Do | Exists Today? |
|------|---------------|---------------|
| **Narrow AI (Weak AI)** | Good at ONE specific task | Yes! (all current AI) |
| **General AI (Strong AI)** | Good at ANY task like a human | No (still research) |
| **Super AI** | Smarter than all humans combined | No (theoretical) |

> **All AI today is Narrow AI** — ChatGPT is amazing at language but can't drive a car. Self-driving cars can drive but can't write poems.

### By Learning Approach

| Type | How It Learns | Example |
|------|-------------|---------|
| **Machine Learning (ML)** | Learns from data | Spam filter learns from spam/not-spam emails |
| **Deep Learning (DL)** | ML with neural networks (brain-inspired) | Face recognition, voice assistants |
| **Generative AI (GenAI)** | Creates new content from learned patterns | ChatGPT, DALL-E, Midjourney |

## How AI Learns — Machine Learning Basics

### The Simple Idea

Instead of giving the computer **rules**, you give it **examples** and it finds the rules itself.

```
Traditional Programming:
  Input: Data + Rules → Output: Answers

Machine Learning:
  Input: Data + Answers → Output: Rules (patterns)
```

### Types of Machine Learning

| Type | What Happens | Example |
|------|-------------|---------|
| **Supervised** | Learn from labeled examples | 1000 photos labeled "cat" or "dog" → AI learns to tell them apart |
| **Unsupervised** | Find hidden patterns in data | Group customers by shopping behavior (no labels given) |
| **Reinforcement** | Learn by trial and error + rewards | Game AI — wins = reward, loses = try different strategy |

## Key AI Concepts (Simple Explanations)

| Concept | What It Means | Analogy |
|---------|--------------|---------|
| **Dataset** | Collection of examples used to train AI | Textbook for studying |
| **Training** | Teaching the AI using data | Student studying for exam |
| **Model** | The trained AI ready to use | Student after studying |
| **Prediction** | AI's answer for new data | Student answering exam |
| **Accuracy** | How often AI gets it right | Exam score percentage |
| **Neural Network** | AI structure inspired by human brain | Layers of connected decision-makers |
| **Overfitting** | AI memorizes training data, fails on new data | Student memorizes answers, can't solve new problems |
| **Bias** | AI learns unfair patterns from biased data | If trained only on men's resumes, may reject women |

## Neural Networks — The Brain Analogy

A **neural network** has layers of "neurons" (math functions) that process data.

```
Input Layer        Hidden Layers       Output Layer
(receive data)    (find patterns)     (give answer)

  Image →  [●]──[●]──[●]──[●]       → "Cat" (92%)
           [●]──[●]──[●]──[●]       → "Dog" (8%)
           [●]──[●]──[●]
```

- **Input layer:** Receives raw data (image pixels, text words)
- **Hidden layers:** Find patterns (edges, shapes, meanings)
- **Output layer:** Gives the answer (category, number, text)

> More hidden layers = "deeper" network = **Deep Learning**

## AI Ethics — Important Issues

| Issue | Problem | Example |
|-------|---------|---------|
| **Bias** | AI can be unfair if trained on biased data | Hiring AI that favors one gender |
| **Privacy** | AI needs lots of personal data to work | Face recognition tracking people |
| **Job Displacement** | AI may replace some jobs | Chatbots replacing call center workers |
| **Deepfakes** | AI can create fake videos/audio | Fake celebrity videos |
| **Misinformation** | AI can generate fake news | AI-written fake articles |
| **Transparency** | Hard to explain WHY AI made a decision | "Black box" problem |

### What You Should Know

- AI is a **tool** — it's not good or bad by itself
- **Humans are responsible** for how AI is used
- Always **verify AI output** — it can be wrong or hallucinate
- Don't blindly trust AI for important decisions

## Summary

- **AI** = Making computers do tasks that need human intelligence
- You already use AI daily (Google, YouTube, phone camera, etc.)
- All current AI is **Narrow AI** (good at one task only)
- **Machine Learning** = AI learns patterns from data, not rules
- **Deep Learning** = ML with neural networks (layers like brain)
- **Generative AI** = Creates new content (text, images, code)
- AI has ethical challenges: bias, privacy, deepfakes, job impact
- Always verify AI output — it can be wrong
