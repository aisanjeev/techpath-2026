# Module 04 — Resources & Installation Links

## Tools
- **Wireshark** — Network packet analyzer (see real network traffic)
  https://www.wireshark.org/download.html
- **Cisco Packet Tracer** — Network simulation for learning
  https://www.netacad.com/courses/packet-tracer
- **Advanced IP Scanner** — Scan your local network for all devices
  https://www.advanced-ip-scanner.com/
- **Angry IP Scanner** — Fast, cross-platform network scanner
  https://angryip.org/

## Online Tools
- **Speedtest** — Check your internet speed
  https://www.speedtest.net/
- **What Is My IP** — Find your public IP address
  https://whatismyipaddress.com/
- **DNS Checker** — Check DNS propagation globally
  https://dnschecker.org/
- **MX Toolbox** — Email/DNS/network diagnostics
  https://mxtoolbox.com/
- **Shodan** — Search engine for internet-connected devices
  https://www.shodan.io/
