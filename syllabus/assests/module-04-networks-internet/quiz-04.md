# Quiz: Computer Networks & Internet

**Module 04 | 15 Questions | Pass Mark: 60%**

---

## Q1. What is a computer network?

- A) A single computer connected to a printer
- B) Two or more computers connected to share data and resources ✅
- C) A website on the internet
- D) A type of software

> **Explanation:** A network is two or more computers connected together to share data, files, and resources like printers.

---

## Q2. Which network type covers a single building like an office or school lab?

- A) PAN
- B) LAN ✅
- C) MAN
- D) WAN

> **Explanation:** LAN (Local Area Network) covers a small area like one building — office, school lab, or home.

---

## Q3. What does DNS stand for?

- A) Data Network System
- B) Domain Name System ✅
- C) Digital Network Service
- D) Direct Name Server

> **Explanation:** DNS (Domain Name System) converts website names like google.com into IP addresses that computers understand.

---

## Q4. Which network topology is most commonly used today?

- A) Bus
- B) Ring
- C) Star ✅
- D) Mesh

> **Explanation:** Star topology is most common — all devices connect to a central switch or router. Easy to add/remove devices.

---

## Q5. How many layers does the OSI model have?

- A) 4
- B) 5
- C) 6
- D) 7 ✅

> **Explanation:** The OSI model has 7 layers: Physical, Data Link, Network, Transport, Session, Presentation, Application.

---

## Q6. Which protocol is used to securely browse websites?

- A) HTTP
- B) HTTPS ✅
- C) FTP
- D) SMTP

> **Explanation:** HTTPS (HTTP Secure) encrypts data between your browser and the website. Always look for the lock icon.

---

## Q7. What does a router do?

- A) Stores files
- B) Connects your network to the internet and directs traffic ✅
- C) Converts digital signals to sound
- D) Only works as a printer

> **Explanation:** A router connects your local network to the internet and decides which path data should take.

---

## Q8. What is the difference between TCP and UDP?

- A) TCP is faster, UDP is slower
- B) TCP confirms delivery, UDP just sends without confirmation ✅
- C) TCP is for WiFi, UDP is for cables
- D) TCP is old, UDP is new

> **Explanation:** TCP confirms every packet is received (reliable but slower). UDP just sends data without checking (faster, used for video calls and gaming).

---

## Q9. What is an IP address?

- A) A website name
- B) A unique number assigned to every device on a network ✅
- C) A type of cable
- D) A password for WiFi

> **Explanation:** An IP address (like 192.168.1.5) is a unique number that identifies each device on a network.

---

## Q10. Which cyber attack tricks you into giving your password through a fake email?

- A) Ransomware
- B) Phishing ✅
- C) Brute Force
- D) Spyware

> **Explanation:** Phishing uses fake emails or websites that look real to trick you into entering your password or personal info.

---

## Q11. What is the memory trick for OSI layers (top to bottom)?

- A) Please Do Not Throw Sausage Pizza Away
- B) All People Seem To Need Data Processing ✅
- C) Application Protocol Standard Transfer
- D) Always Practice Simple Testing

> **Explanation:** "All People Seem To Need Data Processing" = Application, Presentation, Session, Transport, Network, Data Link, Physical.

---

## Q12. What does a firewall do?

- A) Increases internet speed
- B) Blocks unauthorized network access ✅
- C) Stores website data
- D) Creates WiFi signals

> **Explanation:** A firewall monitors network traffic and blocks unauthorized access — like a security guard for your network.

---

## Q13. What is a VPN used for?

- A) Making internet faster
- B) Creating a secure, encrypted connection over the internet ✅
- C) Connecting a printer
- D) Blocking ads

> **Explanation:** A VPN (Virtual Private Network) encrypts all your internet traffic and hides your IP address. Important on public WiFi.

---

## Q14. Which OSI layer handles encryption?

- A) Application (Layer 7)
- B) Presentation (Layer 6) ✅
- C) Network (Layer 3)
- D) Physical (Layer 1)

> **Explanation:** The Presentation layer (Layer 6) handles encryption, compression, and data format conversion (SSL/TLS, JPEG, etc.)

---

## Q15. What is a CDN?

- A) A type of cable
- B) A network that stores website copies in servers around the world for faster loading ✅
- C) A company that makes routers
- D) A security protocol

> **Explanation:** CDN (Content Delivery Network) stores copies of websites on servers worldwide. Your request goes to the nearest server for faster loading.
