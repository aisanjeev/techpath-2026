# Cheat Sheet: Networks & Internet

**Module 04 — Quick Reference**

---

## Network Types

| Type | Area | Example |
|------|------|---------|
| PAN | Around one person | Bluetooth |
| LAN | One building | Office WiFi |
| MAN | One city | Cable TV network |
| WAN | Worldwide | The Internet |

---

## OSI Model (7 Layers)

| # | Layer | Job | Remember |
|---|-------|-----|----------|
| 7 | Application | User apps | **A**ll |
| 6 | Presentation | Encrypt/format | **P**eople |
| 5 | Session | Open/close connections | **S**eem |
| 4 | Transport | TCP/UDP delivery | **T**o |
| 3 | Network | IP + routing | **N**eed |
| 2 | Data Link | MAC + switches | **D**ata |
| 1 | Physical | Cables + signals | **P**rocessing |

---

## Key Protocols

| Protocol | Port | Job |
|----------|------|-----|
| HTTP | 80 | Web (not secure) |
| HTTPS | 443 | Web (secure) |
| FTP | 21 | File transfer |
| SSH | 22 | Remote access |
| SMTP | 25 | Send email |
| DNS | 53 | Name → IP |
| DHCP | 67/68 | Auto-assign IP |

---

## TCP vs UDP

| TCP | UDP |
|-----|-----|
| Reliable (confirms) | Fast (no confirm) |
| Web, email, files | Video, gaming, live |

---

## Network Devices

| Device | Job |
|--------|-----|
| Router | Connects to internet |
| Switch | Connects LAN devices |
| Modem | ISP signal → digital |
| Firewall | Blocks threats |
| Access Point | Extends WiFi |

---

## IP Addresses

- **IPv4:** 192.168.1.1 (4 billion addresses)
- **IPv6:** 2001:0db8::7334 (unlimited)
- **Private:** Inside your network (192.168.x.x)
- **Public:** Your router on internet
- **Subnet Mask:** 255.255.255.0 (separates network/device part)

---

## Cybersecurity Top Rules

1. Strong password (12+ chars, mixed)
2. Enable 2FA everywhere
3. Check for HTTPS before entering passwords
4. Don't click links in suspicious emails (phishing)
5. Use VPN on public WiFi
6. Keep software updated
7. Backup: 3 copies, 2 media, 1 cloud
