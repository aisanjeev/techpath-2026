## Why This Matters

> In every Indian company — from TCS to a 5-person startup — you'll present in meetings. A bad PowerPoint can kill a great idea. A great PowerPoint can make an average idea look brilliant. This isn't about animations — it's about clear communication.

## The 5 Rules of Professional Slides

### Rule 1: One Idea Per Slide

**Bad:** 8 bullet points crammed on one slide
**Good:** Break it into 3 slides with visuals

> 🖼️ **IMAGE:** Side-by-side comparison — left slide crammed with 8 bullet points (labeled "Bad"), right side showing the same content split into 3 clean slides with icons (labeled "Good")
> `ppt-one-idea-per-slide.png`

### Rule 2: 6×6 Rule — Max 6 Lines, Max 6 Words Per Line

People read slides, not listen to you. If your slide has too much text, they'll read it and ignore your voice.

```
❌ BAD SLIDE:
"Our company has been working in the IT sector for more than
15 years and we have delivered over 200 projects across
multiple industries including healthcare, finance, education,
and retail. We have a team of 500+ professionals..."

✅ GOOD SLIDE:
• 15+ years in IT
• 200+ projects delivered
• 500+ professionals
• 4 industries: Healthcare, Finance, Education, Retail
```

### Rule 3: Use Visuals, Not Walls of Text

| Instead of... | Use... |
|---------------|--------|
| List of numbers | Bar chart or pie chart |
| Process steps | Flow diagram with arrows |
| Comparison | Table or side-by-side layout |
| Timeline | Horizontal timeline graphic |
| Statistics | Big number + icon |

> 🖼️ **IMAGE:** A slide showing a big statistic "92%" in large bold font with a small icon and one-line caption below, versus a slide with the same stat buried in a paragraph — showing how visual impact works
> `ppt-visual-vs-text.png`

### Rule 4: Consistent Design

- Same font throughout (max 2 fonts)
- Same color palette (3-4 colors max)
- Same alignment (left-align body text)
- Same spacing between elements
- Same style for all icons/images

### Rule 5: The 10-20-30 Rule (Guy Kawasaki)

- **10 slides** maximum
- **20 minutes** maximum presentation
- **30pt font** minimum size

## Design & Color Theory for Slides

### Color Palettes That Work

| Palette | Colors | When to Use |
|---------|--------|-------------|
| Corporate Blue | Dark blue + white + light gray | Business presentations |
| Modern Dark | Dark gray + white + accent teal | Tech/startup presentations |
| Warm Professional | Navy + gold/amber + white | Finance/consulting |
| Clean Minimal | White + black + one accent color | Any presentation |

> 🖼️ **IMAGE:** Four color palette strips showing the above combinations — each strip has 3-4 color swatches with hex codes labeled, arranged in a 2x2 grid
> `ppt-color-palettes.png`

### Fonts That Work Together

| Heading Font | Body Font | Style |
|-------------|-----------|-------|
| Calibri Bold | Calibri Regular | Safe, corporate |
| Poppins Bold | Open Sans Regular | Modern |
| Georgia Bold | Arial Regular | Traditional |
| Montserrat Bold | Lato Regular | Clean, startup |

**Rule:** Never use more than 2 fonts in one presentation.

## Animations & Transitions — Less is More

### Good Use of Animation

| Animation | Use For |
|-----------|---------|
| Fade | Revealing bullet points one by one |
| Appear | Showing images/charts on click |
| Grow/Shrink | Highlighting a key number |

### Bad Use of Animation

| Animation | Why It's Bad |
|-----------|-------------|
| Fly in from all directions | Distracting, looks childish |
| Spin/Bounce | Not professional |
| Sound effects | Annoying |
| Automatic timing | Audience can't keep up |

**Rule:** If you're not sure about an animation, don't use it. No animation is better than bad animation.

### Slide Transitions

- Use ONE transition type for the entire presentation
- Recommended: **Fade** or **Push** (subtle)
- Set duration to 0.5-0.7 seconds
- Never use: Blinds, Checkerboard, Dissolve, Airplane, Origami

## Presenter Mode — How to Actually Present

### Setup

1. Connect projector/second screen
2. Slide Show → Set Up Slide Show → "Presented by a speaker"
3. Slide Show → Use Presenter View ✅

### What You See (Presenter View)

```
┌─────────────────────────────────────────────────────┐
│ Current Slide        │  Next Slide Preview          │
│ (what audience sees) │  (only you see this)         │
│                      │                              │
│                      ├──────────────────────────────│
│                      │  Your Notes                  │
│                      │  "Mention that revenue       │
│                      │   grew 23% because of the    │
│                      │   new marketing campaign"    │
│                      │                              │
├──────────────────────┴──────────────────────────────│
│  ← Previous    Slide 3 of 12    Next →     Timer   │
└─────────────────────────────────────────────────────┘
```

> 🖼️ **IMAGE:** Screenshot of PowerPoint Presenter View showing current slide on left, next slide preview on top-right, speaker notes on bottom-right, and navigation bar at bottom with timer
> `ppt-presenter-view.png`

### Speaker Notes

- Add notes for each slide (View → Notes)
- Don't write a script — write key points
- Example: "Mention the 23% growth, pause for reaction, ask if questions"

## SmartArt — Quick Professional Diagrams

Insert → SmartArt — choose a layout, type your text, done.

### Best SmartArt Types

| Type | Use For | Example |
|------|---------|---------|
| Process | Steps/workflow | "How our app works" |
| Cycle | Repeating process | "Development lifecycle" |
| Hierarchy | Org chart | "Team structure" |
| Relationship | Venn diagram | "Skills overlap" |
| List | Categorized items | "Our services" |
| Pyramid | Priority/levels | "Maslow's hierarchy" |

## Practice Exercises

### Exercise 1: Company Introduction (10 slides)

Create a presentation introducing a fictional company:
1. Title slide (company name, tagline, logo placeholder)
2. Agenda
3. About Us (mission, vision)
4. Our Services (use SmartArt)
5. Our Team (org chart)
6. Key Numbers (use big statistics + icons)
7. Client Testimonials
8. Our Process (use process SmartArt)
9. Contact Us
10. Thank You

Requirements: Consistent color scheme, max 2 fonts, no more than 6 lines per slide, at least 2 charts/SmartArt.

### Exercise 2: Monthly Sales Report (8 slides)

Using data you create in Excel:
1. Title slide
2. Executive Summary (3 key metrics in big numbers)
3. Revenue trend (line chart from Excel)
4. Revenue by city (bar chart)
5. Top 5 products (horizontal bar)
6. Challenges (icons + short text)
7. Next month plan (table)
8. Q&A

### Exercise 3: Personal Portfolio Presentation (12 slides)

For job interviews — present yourself:
1. Title (Your name + role)
2. About Me
3. Education & Certifications
4. Technical Skills (icons/progress bars)
5-9. Projects (one slide per project with screenshot, tech stack, outcome)
10. Achievements
11. What I Bring (value proposition)
12. Contact + Thank You
