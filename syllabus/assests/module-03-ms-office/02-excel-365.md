## What is Excel?

Excel is a **spreadsheet** program — it organizes data in rows and columns. Used for calculations, data analysis, charts, budgets, and reports.

---

## Excel Basics

### Structure

| Term | What It Means |
|------|-------------|
| **Workbook** | The entire Excel file (.xlsx) |
| **Worksheet / Sheet** | One tab/page inside the workbook |
| **Cell** | One box where row and column meet (e.g., A1, B5) |
| **Row** | Horizontal line (numbered 1, 2, 3...) |
| **Column** | Vertical line (lettered A, B, C...) |
| **Cell Reference** | Address of a cell (e.g., C3 = Column C, Row 3) |
| **Range** | A group of cells (e.g., A1:A10 = A1 to A10) |

### Data Types

| Type | Example | How Excel Shows |
|------|---------|----------------|
| Number | 100, 3.14 | Right-aligned |
| Text | "Hello", "John" | Left-aligned |
| Date | 15/07/2026 | Special format |
| Formula | =A1+B1 | Shows result, not formula |

## Essential Formulas

### Basic Math

| Formula | What It Does | Example |
|---------|-------------|---------|
| `=A1+B1` | Add | =5+3 → 8 |
| `=A1-B1` | Subtract | =10-3 → 7 |
| `=A1*B1` | Multiply | =4*5 → 20 |
| `=A1/B1` | Divide | =20/4 → 5 |

### Most Used Functions

| Function | What It Does | Example |
|----------|-------------|---------|
| `=SUM(A1:A10)` | Add all numbers in range | Total of A1 to A10 |
| `=AVERAGE(A1:A10)` | Average of numbers | Mean of values |
| `=COUNT(A1:A10)` | Count cells with numbers | How many numbers |
| `=COUNTA(A1:A10)` | Count non-empty cells | How many filled cells |
| `=MAX(A1:A10)` | Highest number | Maximum value |
| `=MIN(A1:A10)` | Lowest number | Minimum value |
| `=LEN(A1)` | Count characters in text | Length of text |
| `=UPPER(A1)` | Convert to UPPERCASE | "hello" → "HELLO" |
| `=LOWER(A1)` | Convert to lowercase | "HELLO" → "hello" |
| `=TRIM(A1)` | Remove extra spaces | "  hello  " → "hello" |
| `=TODAY()` | Today's date | Auto-updates daily |
| `=NOW()` | Current date and time | Auto-updates |

### Conditional Functions

| Function | What It Does | Example |
|----------|-------------|---------|
| `=IF(A1>50,"Pass","Fail")` | If-then-else logic | Check if marks > 50 |
| `=SUMIF(A:A,"Maths",B:B)` | Sum only matching rows | Sum marks where subject = "Maths" |
| `=COUNTIF(A:A,">50")` | Count matching cells | Count how many > 50 |

### Lookup Functions

| Function | What It Does | Example |
|----------|-------------|---------|
| `=VLOOKUP(value, table, col, FALSE)` | Find value in a table | Look up student marks by roll number |
| `=HLOOKUP(value, table, row, FALSE)` | Horizontal lookup | Look across columns |
| `=INDEX(range, row)` | Get value at position | Get 5th item from list |
| `=MATCH(value, range, 0)` | Find position of value | Which row has "John"? |

> **VLOOKUP Tip:** The value you're looking up MUST be in the **first column** of your table range. Use `FALSE` for exact match.

## Formatting Data

| Action | How |
|--------|-----|
| Format as Currency | Select → Home → Number Format → Currency |
| Format as Percentage | Select → Home → Number Format → Percentage |
| Format as Date | Select → Home → Number Format → Date |
| Conditional Formatting | Home → Conditional Formatting (highlight cells by rules) |
| Data Validation | Data → Validation (limit what can be typed in a cell) |
| Freeze Top Row | View → Freeze Panes → Freeze Top Row |

## Pivot Tables — Summarize Big Data

Pivot Tables let you summarize thousands of rows into a simple summary.

### How to Create

1. Select your data range
2. Insert → PivotTable
3. Drag fields to Rows, Columns, Values areas
4. Excel creates automatic summary

### Example

Raw data: 1000 rows of sales (Date, Product, City, Amount)

Pivot Table can instantly show:
- Total sales per product
- Total sales per city
- Monthly sales trend

> **Pivot Tables are the #1 skill employers look for in Excel.**

## Charts — Visualize Data

| Chart Type | Best For |
|-----------|---------|
| Column/Bar | Comparing categories |
| Line | Showing trends over time |
| Pie | Showing parts of a whole (percentages) |
| Scatter | Showing relationship between two variables |

### How to Create

1. Select your data
2. Insert → Chart → Choose type
3. Customize with Chart Design tab

## Important Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl + ;` | Insert today's date |
| `Ctrl + Shift + ;` | Insert current time |
| `Ctrl + D` | Fill down (copy cell above) |
| `Ctrl + R` | Fill right (copy cell left) |
| `Ctrl + ~` | Show/hide formulas |
| `Alt + =` | Auto SUM |
| `F4` | Toggle absolute reference ($) |
| `Ctrl + Shift + L` | Toggle filter |
