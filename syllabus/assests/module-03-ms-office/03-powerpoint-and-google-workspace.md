## Part 1: MS PowerPoint 365

### What is PowerPoint?

PowerPoint is for creating **presentations** — slideshows used for teaching, business meetings, project demos, and more.

---

### Slide Design Basics

| Principle | Rule | Why |
|-----------|------|-----|
| **Less text** | Max 6 lines per slide, max 6 words per line | Audience reads slides, doesn't listen to you |
| **Big font** | Minimum 24pt for text, 32pt+ for headings | Must be readable from back of room |
| **One idea per slide** | Don't put everything on one slide | Keeps audience focused |
| **Consistent design** | Same fonts, colors, layout throughout | Looks professional |
| **High quality images** | Use good images, not blurry ones | Bad images = bad impression |

---

### Key Features

| Feature | Where to Find | What It Does |
|---------|-------------|-------------|
| **Slide Master** | View → Slide Master | Edit the template for all slides at once |
| **Transitions** | Transitions tab | Animation between slides (Fade, Push, etc.) |
| **Animations** | Animations tab | Animate elements within a slide |
| **Speaker Notes** | Bottom of slide | Notes only you see while presenting |
| **Presenter View** | Slide Show → Presenter View | See notes + next slide while audience sees current |
| **Designer** | Design → Designer (AI) | AI suggests better layouts automatically |

### Animations — Use Wisely

| Animation Type | Use For | Example |
|---------------|---------|---------|
| **Appear** | Show bullet points one by one | Present key points step by step |
| **Fade** | Smooth entrance | Professional look |
| **Emphasis** | Highlight important item | Make a number pulse/grow |
| **Exit** | Remove item from slide | Clear space for next content |

> **Rule:** Use 1-2 animation types max. Too many animations = unprofessional.

### PowerPoint Copilot AI

| What It Can Do | How |
|---------------|-----|
| Create entire presentation | Type topic → Copilot generates slides |
| Summarize document into slides | Paste text → "Create slides from this" |
| Add images | Copilot suggests relevant images |
| Redesign slide | Select slide → "Make this look better" |

---

### Presentation Tips for Students

1. **Start** with a strong opening (question, fact, or story)
2. **Practice** your speech — don't just read slides
3. Use **Presenter View** so you can see your notes
4. Keep a **backup** on USB drive + email to yourself
5. Save final version as **PDF** too (in case PowerPoint doesn't work)

## Part 2: Google Workspace

Google Workspace is Google's free alternative to MS Office. Everything works in the **browser** — no software to install.

### Google Workspace vs MS Office

| Feature | Google Workspace | MS Office 365 |
|---------|-----------------|---------------|
| **Documents** | Google Docs | MS Word |
| **Spreadsheet** | Google Sheets | MS Excel |
| **Presentation** | Google Slides | MS PowerPoint |
| **Email** | Gmail | Outlook |
| **Storage** | Google Drive (15 GB free) | OneDrive (5 GB free) |
| **Price** | Free for personal use | Paid (free for students with school email) |
| **Collaboration** | Excellent (real-time) | Good (real-time in online version) |
| **Works offline?** | Limited | Full offline support |
| **Advanced features** | Basic | More powerful |

### Why Google Workspace Matters

1. **Real-time collaboration** — Multiple people edit same document at same time
2. **Auto-save** — Never lose work (saves every few seconds to cloud)
3. **Share easily** — Just share a link, no need to email attachments
4. **Works anywhere** — Any device with a browser
5. **Free** — No license cost

### Google Docs — Key Differences from Word

| Feature | Google Docs | MS Word |
|---------|-----------|---------|
| Saving | Auto-saves to Drive | Must press Ctrl+S |
| Sharing | Share link with view/edit permission | Share file or use SharePoint |
| Comments | Click text → Add Comment (Ctrl+Alt+M) | Review → New Comment |
| Version History | File → Version History | File → Version History |
| Offline | Need to enable | Works offline by default |

### Google Sheets — Key Differences from Excel

| Feature | Google Sheets | MS Excel |
|---------|-------------|----------|
| Formulas | Same syntax (SUM, IF, VLOOKUP) | Same |
| Pivot Tables | Insert → Pivot Table | Same |
| Charts | Insert → Chart | Same |
| Macros | Uses Google Apps Script (JavaScript) | Uses VBA |
| Import data | =IMPORTDATA(url) — pull live data | Power Query |

### Google Drive — File Management

| Action | How |
|--------|-----|
| Upload file | Drive → New → File Upload |
| Create folder | Drive → New → Folder |
| Share file | Right-click → Share → Add email or get link |
| Share permission | Viewer / Commenter / Editor |
| Offline access | Right-click → Available offline |

## PDF — Portable Document Format

### Why PDF?

- Looks the **same on every computer** (formatting doesn't change)
- Cannot be easily edited (good for final documents)
- Can be read on any device
- Standard for resumes, contracts, official documents

### How to Create PDF

| From | How |
|------|-----|
| MS Word | File → Save As → PDF |
| Google Docs | File → Download → PDF |
| Any app | Ctrl + P → "Save as PDF" as printer |
| Online | smallpdf.com, ilovepdf.com |

### Digital Signatures in PDF

- Used to sign documents electronically
- Tools: Adobe Acrobat, DocuSign, SmallPDF
- Legally valid in most countries

## Summary

- **PowerPoint** = presentations with slides, keep text minimal
- Use **Slide Master** for consistent design, **Presenter View** while presenting
- **Google Workspace** = free, browser-based alternative to MS Office
- Google Docs/Sheets/Slides work like MS Office with real-time collaboration
- Always save final documents as **PDF** for sharing
- **AI Copilot** in Office 365 can generate and redesign content
