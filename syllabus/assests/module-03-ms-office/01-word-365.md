# MS Word 365 — Complete Guide

**Module 03 — MS Office | Topic 1**

---

## What is MS Word?

MS Word is used to create **documents** — letters, reports, resumes, assignments, books. It's the most used document software in the world.

---

## Word Interface — Important Parts

| Part | Where It Is | What It Does |
|------|-----------|-------------|
| **Ribbon** | Top of screen | All tools organized in tabs (Home, Insert, Layout, etc.) |
| **Quick Access Toolbar** | Very top left | Save, Undo, Redo — always visible |
| **Ruler** | Below ribbon | Set margins and indents |
| **Status Bar** | Bottom | Page number, word count, zoom |
| **Navigation Pane** | Left side (View → Navigation) | Jump between headings |

## Essential Formatting

### Text Formatting

| Action | Shortcut | What It Does |
|--------|----------|-------------|
| Bold | `Ctrl + B` | **Makes text bold** |
| Italic | `Ctrl + I` | *Makes text italic* |
| Underline | `Ctrl + U` | Underlines text |
| Font Size | Select text → Change size | Make text bigger/smaller |
| Font Color | Home → Font Color button | Change text color |
| Highlight | Home → Highlight button | Yellow highlight on text |
| Clear Format | `Ctrl + Space` | Remove all formatting |

### Paragraph Formatting

| Action | How To |
|--------|--------|

| Align Center | `Ctrl + E` |
| Align Right | `Ctrl + R` |
| Justify | `Ctrl + J` |
| Line Spacing | Home → Line Spacing button |
| Bullet List | Home → Bullets button |
| Numbered List | Home → Numbering button |

## Styles — Make Documents Look Professional

Instead of manually formatting every heading, use **Styles**:

| Style | Use For | How to Apply |
|-------|---------|-------------|
| Normal | Regular body text | Already default |
| Heading 1 | Main heading (chapter title) | Home → Styles → Heading 1 |
| Heading 2 | Sub-heading | Home → Styles → Heading 2 |
| Heading 3 | Sub-sub-heading | Home → Styles → Heading 3 |
| Title | Document title | Home → Styles → Title |

> **Why use Styles?** They make your document consistent, let you create a Table of Contents automatically, and look professional.

## Important Features

### Page Setup (Layout Tab)

| Setting | What It Does |
|---------|-------------|
| Margins | Space between text and page edge (Normal = 1 inch) |
| Orientation | Portrait (tall) or Landscape (wide) |
| Size | A4, Letter, Legal |
| Columns | Split text into 2-3 columns (like newspaper) |

### Insert Tab — Add Things

| Item | How | Use For |
|------|-----|---------|
| Table | Insert → Table | Data in rows/columns |
| Image | Insert → Pictures | Add photos |
| Header/Footer | Insert → Header/Footer | Page numbers, title on every page |
| Page Number | Insert → Page Number | Auto page numbering |
| Hyperlink | `Ctrl + K` | Add clickable link |
| Page Break | `Ctrl + Enter` | Start new page |

### Track Changes (Review Tab)

Used when multiple people edit the same document:

1. Go to **Review** tab → Turn on **Track Changes**
2. Every edit shows in a different color
3. Others can **Accept** or **Reject** each change
4. Add **Comments** with Review → New Comment

### Mail Merge

Send personalized letters/emails to many people using one template:

1. Create letter template with placeholders (Dear {Name})
2. Connect to data source (Excel file with names, addresses)
3. Word fills in each person's info automatically
4. Print or email all letters at once

## Copilot AI in Word (New Feature)

| What Copilot Can Do | How to Use |
|---------------------|-----------|
| Draft a document | Type a prompt like "Write a leave application" |
| Summarize long document | Select text → Ask Copilot to summarize |
| Change tone | "Make this more formal" or "Make this simpler" |
| Rewrite text | Select text → Ask Copilot to rewrite |
| Generate table | "Create a table comparing X and Y" |

---

## Professional Resume Tips in Word

1. Use a **clean template** (File → New → Search "Resume")
2. Keep to **1 page** for freshers
3. Use **Heading styles** for sections
4. Add **bullet points** not paragraphs
5. Save as **PDF** for sending (File → Save As → PDF)

---

## Summary

- Word is for creating documents — letters, reports, resumes
- Use **Styles** for professional formatting
- **Track Changes** for team editing
- **Mail Merge** for bulk personalized letters
- **Copilot AI** can draft, summarize, and rewrite text
- Always save important documents as **PDF** before sharing
