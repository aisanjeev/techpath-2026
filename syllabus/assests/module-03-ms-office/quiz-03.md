## Q1. Which MS Office app is used to create documents like letters and reports?

- A) Excel
- B) PowerPoint
- C) Word ✅
- D) Outlook

> **Explanation:** MS Word is used for creating text documents like letters, reports, resumes.

---

## Q2. What does the Excel formula =SUM(A1:A5) do?

- A) Averages cells A1 to A5
- B) Adds all values from A1 to A5 ✅
- C) Counts cells A1 to A5
- D) Finds maximum in A1 to A5

> **Explanation:** SUM adds all the numbers in the given range.

## Q3. What is the shortcut to save a file?

- A) Ctrl + P
- B) Ctrl + S ✅
- C) Ctrl + N
- D) Ctrl + Z

> **Explanation:** Ctrl + S = Save. Works in almost every application.

## Q4. In PowerPoint, what is the recommended maximum lines per slide?

- A) 2 lines
- B) 6 lines ✅
- C) 15 lines
- D) No limit

> **Explanation:** Keep slides to 6 lines or less. Audience should listen to you, not read slides.

## Q5. What does VLOOKUP do in Excel?

- A) Counts cells
- B) Looks up a value in a table and returns matching data ✅
- C) Adds numbers vertically
- D) Creates a chart

> **Explanation:** VLOOKUP finds a value in the first column and returns data from another column in same row.

## Q7. What does the IF function do in Excel?

- A) Adds numbers if condition is met
- B) Checks a condition and returns different values for true/false ✅
- C) Imports data from another file
- D) Formats cells automatically

> **Explanation:** =IF(A1>50, "Pass", "Fail") returns Pass if A1 > 50, otherwise Fail.

## Q11. Which Excel formula gives today's date?

- A) =DATE()
- B) =TODAY() ✅
- C) =NOW()
- D) =CURRENT()

> **Explanation:** =TODAY() returns today's date. =NOW() returns date + time.
