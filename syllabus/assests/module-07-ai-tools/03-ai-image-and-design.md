## How AI Image Generation Works

AI image generators are trained on billions of images. You describe what you want in text, and the AI creates a new image matching your description.

```
Your text prompt → AI model → Generated image
"A sunset over mountains" → DALL-E → [Beautiful sunset image]
```

## Writing Better Image Prompts

### The Formula

```
[Subject] + [Style] + [Details] + [Mood/Lighting] + [Camera angle]
```

### Examples

| Level | Prompt | Quality |
|-------|--------|---------|
| **Basic** | "A dog" | Generic, boring |
| **Good** | "A golden retriever puppy playing in autumn leaves" | Better but simple |
| **Great** | "A golden retriever puppy playing in orange autumn leaves, soft afternoon sunlight, shallow depth of field, warm colors, photo-realistic, Canon EOS R5" | Professional quality |

### Style Keywords

| Category | Keywords to Use |
|----------|----------------|
| **Photography** | photo-realistic, DSLR, 4K, bokeh, macro, portrait |
| **Art** | watercolor, oil painting, digital art, sketch, anime |
| **3D** | 3D render, isometric, clay render, low-poly |
| **Design** | flat design, minimalist, vector, infographic |
| **Mood** | dramatic, peaceful, vibrant, moody, cinematic |
| **Lighting** | golden hour, neon, studio lighting, backlit, soft light |

## Canva — AI-Powered Design

### What is Canva?

**Canva** = Free online design tool. No design skills needed. AI makes it even easier.

### Canva Quick Start

1. Go to **canva.com** → Sign up free
2. Click **"Create a design"**
3. Pick a template size (Instagram Post, Presentation, Resume, etc.)
4. Edit text, swap images, change colors
5. Download or share

### Design Types in Canva

| Type | Use For | Size |
|------|---------|------|
| **Instagram Post** | Social media | 1080 × 1080 |
| **Instagram Story** | Stories, reels cover | 1080 × 1920 |
| **Presentation** | Slides | 1920 × 1080 |
| **Resume** | Job application | A4 |
| **Logo** | Brand identity | 500 × 500 |
| **YouTube Thumbnail** | Video thumbnails | 1280 × 720 |
| **Poster** | Events, ads | A3/A4 |
| **Business Card** | Networking | 3.5 × 2 inches |

### Canva AI Features

| Feature | What It Does |
|---------|-------------|
| **Magic Design** | Describe what you want, AI creates a design |
| **Magic Write** | AI writes text for your designs |
| **Magic Eraser** | Remove unwanted objects from photos |
| **Background Remover** | One-click background removal |
| **Magic Resize** | Resize design for different platforms instantly |
| **Text to Image** | Generate images from text prompts |
| **Magic Animate** | Add animations with one click |

## Practical Exercises

### Exercise 1: Create a Social Media Post

```
1. Open Canva → Instagram Post template
2. Pick a template you like
3. Change the text to: "5 Reasons to Learn Python in 2026"
4. Change colors to match a tech theme (blue + white)
5. Add your logo or brand name
6. Download as PNG
```

### Exercise 2: Generate AI Images

```
1. Open ChatGPT (with DALL-E) or Leonardo AI
2. Try these prompts:
   - "Minimalist icon set for a coding app, flat design, blue and purple"
   - "Student studying at desk with laptop, cozy room, warm lighting, illustration style"
   - "Futuristic classroom with holographic displays, sci-fi, clean design"
3. Save the best results
```

### Exercise 3: Design a Resume

```
1. Open Canva → Search "Resume"
2. Pick a modern template
3. Fill in your info (name, skills, education)
4. Customize colors and fonts
5. Download as PDF
```

## AI Design Tips

| Tip | Why |
|-----|-----|
| Start with templates, don't start from scratch | Faster and better results |
| Keep designs simple — less is more | Clean designs look professional |
| Use consistent colors (2-3 max) | Brand consistency |
| Use high-contrast text | Readability |
| Save designs as PDF for print, PNG for web | Right format for right use |
| Don't overuse AI-generated images | Mix with real photos when possible |
| Always check AI images for errors | AI sometimes generates wrong fingers, text, etc. |
