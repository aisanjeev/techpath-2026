## Advanced Techniques

### 1. Role Prompting

Tell AI to act as a specific expert:

```
"Act as a senior web developer reviewing my code. 
Point out bugs, security issues, and suggest improvements.
Here's my code: [code]"
```

### 2. Chain Prompting

Break complex tasks into steps:

```
Step 1: "List the 5 most important topics to cover in a Python beginner course"
Step 2: "For topic 1, create a detailed lesson plan with examples"  
Step 3: "Now create 5 practice exercises for this lesson"
```

### 3. Format Control

Tell AI exactly how to format output:

```
"Respond in this format:
## Topic Name
**Key Point:** one sentence
**Example:** real-world example
**Common Mistake:** what beginners get wrong"
```

### 4. Context Window

You can paste large documents and ask questions:

```
"Here is a 50-page research paper: [paste content]
1. Summarize the key findings in 5 points
2. What methodology did they use?
3. What are the limitations?"
```

## Common Mistakes to Avoid

| Mistake | Better Approach |
|---------|----------------|
| Asking vague questions | Be specific: who, what, format, length |
| Accepting first answer | Iterate: "Make it simpler" or "Add more examples" |
| Not giving context | Tell AI your skill level and purpose |
| Copy-pasting AI output as-is | Always review, edit, and personalize |
| Using AI without understanding | Use AI to learn, not to skip learning |
| Asking one massive question | Break into smaller step-by-step prompts |

## Summary

- **ChatGPT and Claude** can help with writing, coding, learning, business tasks
- Use **role prompting** for expert-level responses
- **Chain prompting** breaks complex tasks into steps
- **Format control** gets structured, useful output
- Always **review and edit** AI output — don't use as-is
- Use AI to **accelerate learning**, not replace it
