## Prompt Formula

```
Be specific + Give context + Set format + Set length
```

**Bad:** "Write about Python"
**Good:** "Write 5 bullet points explaining Python to beginners. Include one code example."

---

## Prompt Techniques

| Technique | Example |
|-----------|---------|
| Role prompting | "Act as a teacher..." |
| Chain prompting | Step 1, then Step 2, then Step 3 |
| Format control | "Respond as a table" |
| Few-shot | Give 2-3 examples first |

---

## Image Prompt Formula

```
[Subject] + [Style] + [Details] + [Mood] + [Lighting]
```

**Keywords:** photo-realistic, flat design, watercolor, cinematic, bokeh, golden hour, minimalist

| Task | How |

---

## Golden Rules

1. **Always review** AI output before using
2. **Be specific** in your prompts
3. **Iterate** — refine prompts for better results
4. **Verify facts** — AI can hallucinate
5. **Use AI to learn**, not to skip learning
