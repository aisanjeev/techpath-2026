## AI Tools You Should Know

AI tools can save you hours of work every day. Here's a complete guide to the most useful ones.

---

## Text & Writing AI

| Tool | What It Does | Free? | Best For |
|------|-------------|-------|---------|
| **ChatGPT** | Write, summarize, translate, brainstorm | Free (GPT-4o mini), Paid (GPT-4o, GPT-5) | General writing, Q&A |
| **Claude** | Long documents, coding, analysis | Free tier available | Detailed analysis, coding |
| **Gemini** | Google-integrated AI assistant | Free | Google Workspace tasks |
| **Copilot** | Built into Windows & Office | Free with Windows | Word, Excel, PowerPoint help |
| **Grammarly** | Grammar, spelling, tone checking | Free (basic) | Emails, reports, resumes |
| **QuillBot** | Paraphrasing and rewriting | Free (basic) | Academic writing |

### What You Can Do with Text AI

- **Write emails:** "Write a professional email to request leave for 3 days"
- **Summarize:** Paste a long article → "Summarize this in 5 bullet points"
- **Translate:** "Translate this to Hindi: [text]"
- **Brainstorm:** "Give me 10 Instagram caption ideas for a tech education brand"
- **Explain:** "Explain cloud computing to a 10-year-old"
- **Format:** "Convert this into a table: [data]"

| Bad Prompt | Good Prompt |
|-----------|------------|
| "A cat" | "A fluffy orange cat sitting on a windowsill, sunset light, photo-realistic, warm colors" |

### Gamma Example Workflow

```
1. Go to gamma.app
2. Type: "Create a 10-slide presentation about cybersecurity basics for beginners"
3. AI generates complete slides with content and design
4. Edit text, swap images, adjust layout
5. Export as PDF or present online
```

### Perplexity vs ChatGPT

| Feature | ChatGPT | Perplexity |
|---------|---------|-----------|

| Sources/citations | Sometimes | Always shows sources |
| Best for | Writing, creativity | Research, fact-checking |

## How to Pick the Right AI Tool

| Your Need | Best Tool |
|-----------|----------|
| Write an email | ChatGPT or Gemini |
| Create a presentation | Gamma |
| Generate an image | DALL-E or Leonardo AI |
| Research a topic | Perplexity |
| Write/fix code | GitHub Copilot or Claude |
| Edit a video | CapCut |
| Design a social post | Canva |
| Analyze data | ChatGPT Code Interpreter |
| Remove image background | Remove.bg |
| Check grammar | Grammarly |

---

## Summary

- AI tools exist for almost every task: writing, images, code, design, video, research
- Most have **free tiers** — no need to pay to start
- **ChatGPT/Claude** = best for text, writing, coding
- **Gamma** = best for quick presentations
- **Perplexity** = best for research with sources
- **Canva** = best for design without design skills
- Always **verify AI output** and add your own thinking
