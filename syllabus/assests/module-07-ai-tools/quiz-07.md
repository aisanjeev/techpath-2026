# Quiz: AI Tools — Practical Mastery

**Module 07 | 12 Questions | Pass Mark: 60%**

---

## Q1. Which AI tool is best for creating presentations from text?

- A) ChatGPT
- B) Gamma ✅
- C) Remove.bg
- D) ElevenLabs

> **Explanation:** Gamma (gamma.app) is specifically designed for AI-generated presentations. Describe your topic and it creates complete slides.

---

## Q2. What is Perplexity AI best used for?

- A) Generating images
- B) Research with citations and sources ✅
- C) Video editing
- D) Code writing

> **Explanation:** Perplexity is an AI search engine that always provides citations and sources — great for research and fact-checking.

---

## Q3. Which technique tells AI to act as a specific expert?

- A) Chain prompting
- B) Role prompting ✅
- C) Zero-shot
- D) Template prompting

> **Explanation:** Role prompting: "Act as a senior web developer and review my code." Gives AI a specific expertise perspective.

---

## Q4. What is the best format to save a logo designed in Canva?

- A) JPG
- B) PNG
- C) SVG or PNG with transparent background ✅
- D) GIF

> **Explanation:** SVG is best for logos (scalable, never blurry). PNG with transparent background is the next best option.

---

## Q5. What makes a good AI image prompt?

- A) Just the subject name
- B) Subject + style + details + mood + lighting ✅
- C) Very long paragraphs
- D) Only using keywords

> **Explanation:** Good image prompts include: Subject (what), Style (art/photo/3D), Details (specifics), Mood (feeling), and Lighting.

---

## Q6. What is chain prompting?

- A) Sending one very long prompt
- B) Breaking complex tasks into step-by-step prompts ✅
- C) Using multiple AI tools together
- D) Copying prompts from others

> **Explanation:** Chain prompting breaks a complex task into smaller sequential prompts — each step builds on the previous one.

---

## Q7. Which tool removes image backgrounds with one click?

- A) ChatGPT
- B) Canva / Remove.bg ✅
- C) Grammarly
- D) GitHub Copilot

> **Explanation:** Both Canva (Background Remover feature) and Remove.bg can remove image backgrounds with one click.

---

## Q8. What should you always do before submitting AI-generated content?

- A) Nothing, AI is always correct
- B) Review, edit, and personalize it ✅
- C) Add more AI content
- D) Delete it and start over

> **Explanation:** Always review and edit AI output. Add your own voice, check facts, and personalize before using it.

---

## Q9. GitHub Copilot is an AI tool for:

- A) Writing emails
- B) Auto-completing and suggesting code ✅
- C) Creating images
- D) Video editing

> **Explanation:** GitHub Copilot is an AI coding assistant that auto-completes code, suggests functions, and helps write code in VS Code.

---

## Q10. What is Canva's Magic Design feature?

- A) A photo filter
- B) AI that creates a complete design from your description ✅
- C) A drawing tool
- D) An animation feature

> **Explanation:** Magic Design lets you describe what you want and Canva's AI creates a complete design with layout, colors, and images.

---

## Q11. For AI image generation, "bokeh" refers to:

- A) A color style
- B) Blurred background effect in photography ✅
- C) A type of camera
- D) A drawing technique

> **Explanation:** Bokeh is the blurred background effect in photography. Adding "bokeh" to image prompts creates a professional photo look.

---

## Q12. Which is NOT a good practice when using AI tools?

- A) Verifying AI-generated facts
- B) Using AI to learn new concepts
- C) Copy-pasting AI output without reviewing ✅
- D) Breaking tasks into smaller prompts

> **Explanation:** Never copy-paste AI output without reviewing. Always check for errors, add your perspective, and personalize the content.
