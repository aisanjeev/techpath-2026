## ChatGPT vs Claude vs Gemini
| Feature | ChatGPT (OpenAI) | Claude (Anthropic) | Gemini (Google) |
|---------|------------------|-------------------|-----------------|
| Best for | General tasks, DALL-E images | Long documents, coding, safety | Google integration, multimodal |
| Free tier | GPT-4o-mini | Claude Sonnet | Gemini Pro |
| Code | Good | Excellent | Good |
| Context window | 128K tokens | 200K tokens | 1M tokens |
| Image generation | Yes (DALL-E) | No | Yes (Imagen) |

## Prompt Formula
```
[Role] + [Task] + [Context] + [Format] + [Constraints]
```
Example: "You are a Python teacher [Role]. Explain decorators [Task] to a beginner who knows functions [Context]. Use code examples with comments [Format]. Keep it under 200 words [Constraint]."

## AI for Productivity
| Task | AI Approach |
|------|------------|
| Write emails | Give context + tone + length to AI |
| Summarize documents | Paste text + "Summarize in 5 bullet points" |
| Create presentations | Use Gamma.app or prompt + Canva |
| Data analysis | Upload CSV to ChatGPT Code Interpreter |
| Debug code | Paste error + code + "explain and fix" |
| Learn new topics | "Explain X like I'm a complete beginner" |
| Brainstorm ideas | "Give me 10 ideas for..." |
| Translate | Any language pair with context preservation |

## AI Limitations
- **Hallucination** — AI can confidently make up facts. Always verify.
- **Knowledge cutoff** — Training data has a date limit
- **No real-time info** — Can't check live websites (unless given tools)
- **Context limit** — Can't remember previous conversations
- **Bias** — Reflects biases in training data
- **Can't verify** — Doesn't know if its output is correct

## Best Practices
1. Always verify AI outputs (especially facts, numbers, code)
2. Don't share sensitive/personal data with AI
3. Use AI as an assistant, not a replacement for thinking
4. Start with a clear prompt, iterate to improve
5. Combine multiple AI tools for best results
6. Credit AI when appropriate (academic/professional settings)
