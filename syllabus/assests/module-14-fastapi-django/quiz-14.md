# Quiz: FastAPI & Django

**Module 14 | 10 Questions | Pass Mark: 60%**

---

## Q1. What does API stand for?
- A) Application Programming Interface ✅
- B) Advanced Program Integration
- C) Application Process Input
- D) Automated Programming Interface

> **Explanation:** API = Application Programming Interface — how frontend and backend communicate.

---

## Q2. Which HTTP method creates new data?
- A) GET
- B) POST ✅
- C) DELETE
- D) PATCH

> **Explanation:** POST creates. GET reads. PUT/PATCH updates. DELETE removes.

---

## Q3. What does status code 404 mean?
- A) Server error
- B) Unauthorized
- C) Not Found ✅
- D) Success

> **Explanation:** 404 = the resource doesn't exist at that URL.

---

## Q4. What is FastAPI?
- A) A JavaScript framework
- B) A modern Python framework for building APIs ✅
- C) A database tool
- D) A frontend library

> **Explanation:** FastAPI is fast, modern Python framework for REST APIs with auto docs.

---

## Q5. What command runs a FastAPI server?
- A) python run server
- B) fastapi start
- C) uvicorn main:app --reload ✅
- D) flask run

> **Explanation:** `uvicorn main:app --reload` starts FastAPI with hot-reload.

---

## Q6. Main advantage of Django over FastAPI?
- A) Faster performance
- B) Built-in admin panel, ORM, and templates ✅
- C) Better for APIs
- D) Easier to learn

> **Explanation:** Django is batteries-included — admin, ORM, auth, templates all built in.

---

## Q7. What is a JWT used for?
- A) Styling web pages
- B) Token-based user authentication ✅
- C) Database queries
- D) File compression

> **Explanation:** JWT = JSON Web Token for stateless authentication.

---

## Q8. What does the backend handle?
- A) UI design
- B) Database, business logic, and authentication ✅
- C) Browser rendering
- D) CSS styling

> **Explanation:** Backend = server-side: database, auth, API responses, business rules.

---

## Q9. What does GET /students/1 do?
- A) Creates student 1
- B) Gets data of student with ID 1 ✅
- C) Deletes student 1
- D) Updates student 1

> **Explanation:** GET retrieves data. /students/1 targets the student with ID 1.

---

## Q10. What does Pydantic do in FastAPI?
- A) Connects to database
- B) Validates request data using Python type hints ✅
- C) Renders HTML templates
- D) Handles authentication

> **Explanation:** Pydantic models validate incoming data automatically.
