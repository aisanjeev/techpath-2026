## Resume Essentials
**Format:** 1 page, PDF, clean font (Inter/Calibri), no photos (for IT roles)

**Sections (in order):**
1. **Name + Contact** — Phone, Email, LinkedIn, GitHub, Portfolio URL
2. **Summary** — 2 lines about who you are and what you can do
3. **Skills** — grouped: Languages, Frameworks, Tools, Soft Skills
4. **Projects** (most important for freshers) — 3-4 projects with:
   - Project name + one-line description
   - Tech stack used
   - What YOU built (not what the project does)
   - Live link / GitHub link
5. **Education** — Degree, Institute, Year
6. **Certifications** — relevant ones only

**Resume Tips:**
- Use action verbs: Built, Developed, Designed, Implemented, Deployed
- Quantify where possible: "Built an API handling 500+ student records"
- No "I" statements — write in implied first person
- No spelling mistakes — proofread twice
- Tailor for each job application

## Portfolio Website Must-Haves
1. Hero with name and title
2. About section with brief intro
3. Skills section
4. Projects section (3-4 projects with screenshots, descriptions, links)
5. Contact form or email link
6. Responsive design
7. Deployed and live

## GitHub Profile Optimization
- **Profile README** — create a repo named your username
- Pin 4-6 best repositories
- Each repo should have: good README, description, topics
- Consistent commit history (green squares)
- No empty repos or repos named "test123"

## LinkedIn Profile
- Professional headline: "Full Stack Developer | Python | FastAPI | HTML/CSS/JS"
- Summary: 3-4 lines about your skills and goals
- Add projects, certifications, skills
- Get endorsements from batchmates
- Custom URL: linkedin.com/in/yourname

## Interview Preparation

### Common Technical Questions
| Topic | Question |
|-------|----------|
| HTML | What is semantic HTML? Name 5 semantic tags. |
| CSS | Explain the box model. What is `box-sizing: border-box`? |
| CSS | Flexbox vs Grid — when to use which? |
| JS | `let` vs `const` vs `var` — differences? |
| JS | What is the DOM? How do you select elements? |
| Python | List vs Tuple vs Set — differences? |
| Python | What is a decorator? What is `*args` and `**kwargs`? |
| SQL | INNER JOIN vs LEFT JOIN — explain with example. |
| SQL | What is normalization? What is a foreign key? |
| API | What is REST? Explain HTTP methods. |
| API | What status code for: success, created, not found, server error? |
| Git | What is a branch? How do you resolve merge conflicts? |

### HR/Behavioral Questions
- Tell me about yourself (30-second pitch)
- Why should we hire you?
- What is your biggest strength/weakness?
- Describe a challenging project and how you solved it
- Where do you see yourself in 3 years?

### 30-Second Pitch Template
```
"Hi, I'm [Name]. I recently completed my ADCA from TechPath Institute 
where I built [number] real-world projects including [best project name]. 
I specialize in [top 2-3 skills] and I'm looking for opportunities 
where I can apply my skills and grow as a developer."
```

## Job Search Strategy
1. **Job portals:** Naukri.com, LinkedIn, Indeed, Internshala
2. **Direct apply:** Company career pages
3. **Networking:** LinkedIn connections, alumni, meetups
4. **Freelancing:** Fiverr, Upwork while searching
5. **Internships:** Start with internships if no experience
