# Module 16 — Assignment: Career Launch Kit

**Deadline:** End of Week 28 (Final Week)
**Submission:** All links + PDF resume + portfolio URL

---

## Task 1: Professional Resume — 25 marks

Create a 1-page resume as a PDF:

**Must include:**
- Clean, professional layout (no fancy templates with photos)
- Contact: Phone, Email, LinkedIn, GitHub, Portfolio URL
- Summary: 2 lines about skills and goals
- Skills: grouped by category (Languages, Frameworks, Tools)
- Projects: 3-4 with name, description, tech stack, and links
- Education
- Certifications (if any)

**Quality check:**
- No spelling or grammar mistakes
- Action verbs: Built, Developed, Deployed (not "I made")
- Quantified achievements where possible
- Consistent formatting (same font, alignment, spacing)
- File name: `YourName_Resume.pdf`

---

## Task 2: Portfolio Website — 30 marks

Deploy a live portfolio website:

**Must have:**
- Hero with your name and professional title
- About section
- Skills section (tags or progress bars)
- Projects section: at least 3 projects with:
  - Screenshot
  - Description
  - Tech stack badges
  - Live demo link + GitHub link
- Contact section with email or form
- Responsive on mobile
- Deployed to GitHub Pages or Vercel

---

## Task 3: GitHub & LinkedIn Profile — 20 marks

**GitHub:**
- Profile README with intro, skills, and stats
- 4+ pinned repositories with proper READMEs
- Consistent commit activity
- No empty or poorly named repos

**LinkedIn:**
- Professional headline mentioning your skills
- Summary paragraph
- Education section filled
- 3+ projects added
- Skills section with relevant technologies
- Custom URL (linkedin.com/in/yourname)

---

## Task 4: Interview Preparation — 25 marks

Prepare and submit:

**30-second pitch** — written + record a practice video (phone selfie is fine)

**Technical answers** — write answers for 10 questions:
1. What is semantic HTML?
2. Explain CSS Flexbox vs Grid.
3. Difference between `let`, `const`, and `var`.
4. What is an API? Explain REST.
5. Python: list vs tuple vs dictionary.
6. What is SQL JOIN? Types of JOINs.
7. What is Git branching? How do you merge?
8. What is responsive design? How do you implement it?
9. Explain the FastAPI request-response cycle.
10. What is the difference between frontend and backend?

**Mock interview** — pair with a batchmate and practice:
- Each person asks 5 questions
- Record or write feedback for each other
