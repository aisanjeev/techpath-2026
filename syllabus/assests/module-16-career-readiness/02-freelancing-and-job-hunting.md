## Freelancing Platforms

### Where to Start

| Platform | Best For | Getting Started |
|----------|----------|-----------------|
| **Fiverr** | Small gigs, beginners | Create gig, set low price to start |
| **Upwork** | Long-term clients, bigger projects | Apply to jobs with proposals |
| **Freelancer.com** | Contests + projects | Bid on projects |
| **Toptal** | Expert-level (apply later) | Screening process required |
| **LinkedIn** | Direct clients | Post work, connect, pitch |

### Beginner Freelance Services

| Service | You Can Charge |
|---------|---------------|
| WordPress/HTML website | Rs 3,000-10,000 |
| Landing page design (Figma → HTML) | Rs 2,000-5,000 |
| Python data analysis | Rs 2,000-8,000 |
| REST API development | Rs 5,000-15,000 |
| AI chatbot setup | Rs 3,000-10,000 |
| Excel dashboard / automation | Rs 1,000-5,000 |

### Fiverr Gig Tips

1. **Title**: Be specific — "I will build a FastAPI REST API with PostgreSQL"
2. **Description**: What you deliver, timeline, what's included
3. **Price**: Start low (Rs 500-1000) to get first 5 reviews
4. **Portfolio**: Add screenshots of your best projects
5. **Response time**: Reply within 1 hour
6. **Delivery**: Always deliver on time or early

### Upwork Proposal Template

```
Hi [Client Name],

I read your project details carefully. You need [restate their need 
in one line].

I can build this using [tech stack]. Here's my approach:
1. [Step 1]
2. [Step 2]
3. [Step 3]

I've built similar projects before — here's an example: [link]

Timeline: [X days]
Let me know if you'd like to discuss further.

Best,
[Your Name]
```

## Technical Interview Preparation

### Common HR Questions

| Question | How to Answer |
|----------|--------------|
| Tell me about yourself | 60-second pitch: education → skills → projects → what you want |
| Why this company? | Research them, mention specific product/value |
| Strengths? | Pick 2-3 relevant to the role + give examples |
| Weaknesses? | Pick something real + show how you're improving |
| Where in 5 years? | Show ambition aligned with the company |
| Expected salary? | Research market rate, give a range |

### 60-Second Pitch Template

```
"I'm [Name], a recent ADCA graduate from TechPath Institute. 
During my program, I built [number] projects including 
[best project name] using [tech stack]. I'm particularly 
interested in [area], and I'm looking for a role where I can 
[what you want to do]. I'm excited about [company name] because 
[specific reason]."
```

### Common Technical Questions

**Python:**
1. What is the difference between list and tuple?
2. What are decorators?
3. Explain `*args` and `**kwargs`
4. How does a dictionary work?
5. What is a virtual environment?

**Web Development:**
1. What is the difference between GET and POST?
2. What is REST API?
3. Explain the box model in CSS
4. What is responsive design?
5. How does JWT authentication work?

**Database:**
1. What is a primary key?
2. Difference between SQL and NoSQL?
3. What are JOINs? Types?
4. What is normalization?
5. Write a query to find the second highest salary

**General:**
1. What is Git? Why use version control?
2. What is Docker?
3. Explain CI/CD
4. What is the difference between frontend and backend?
5. How does the internet work (DNS, HTTP)?

### Coding Challenge Tips

1. **Read the problem twice** before coding
2. **Think out loud** — explain your approach
3. **Start simple** — brute force first, optimize later
4. **Test with examples** — walk through your solution
5. **Handle edge cases** — empty input, zero, negative numbers
6. **Practice daily** — solve 1-2 problems on HackerRank/LeetCode

### Practice Platforms

| Platform | Level | Best For |
|----------|-------|----------|
| HackerRank | Easy-Hard | Practice + certificates |
| LeetCode | Easy-Hard | Interview prep |
| Codewars | Easy-Medium | Fun challenges |
| FreeCodeCamp | Beginner | Learning + certificates |

## Internship Strategy

### Where to Find Internships

| Source | How |
|--------|-----|
| Internshala | Apply directly |
| LinkedIn | Search + connect |
| College placement | Register with cell |
| Direct approach | Email startups |
| Twitter/X | Follow founders, reply to hiring posts |

### What Makes You Stand Out

| Factor | How to Show It |
|--------|---------------|
| Projects | GitHub portfolio with 3-5 real projects |
| Skills | Match job requirements exactly |
| Communication | Clear resume, good LinkedIn, professional email |
| Initiative | Blog posts, open source contributions, learning |
| Attitude | Be eager, ask questions, show willingness to learn |

## Summary

- **Freelancing**: Start on Fiverr/Upwork with small gigs, build reviews
- **Job hunting**: Apply 5-10 daily, customize resume, follow up
- **LinkedIn**: Post projects, connect with hiring managers
- **Technical prep**: Practice Python, web, SQL, and coding challenges
- **HR interviews**: Prepare 60-second pitch, research the company
- **Stand out**: Projects + skills + communication + initiative
- Start with internships → build experience → move to full-time roles
