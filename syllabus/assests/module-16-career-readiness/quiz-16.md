# Quiz: Career Readiness & Portfolio

**Module 16 | 10 Questions | Pass Mark: 60%**

---

## Q1. How many projects should you pin on your GitHub profile?
- A) 1
- B) 3 to 6 ✅
- C) 10 to 15
- D) All of them

> **Explanation:** Pin 3-6 best projects showing different skills (frontend, backend, AI, data).

---

## Q2. What does ATS stand for?
- A) Advanced Technology System
- B) Applicant Tracking System ✅
- C) Automated Testing Software
- D) Application Transfer Service

> **Explanation:** ATS scans resumes before humans see them. Use keywords from the job post.

---

## Q3. Best format for a fresher's resume?
- A) 3 pages with lots of detail
- B) 1 page, simple format, PDF ✅
- C) Colorful infographic
- D) Video resume only

> **Explanation:** 1 page, simple, PDF, ATS-friendly, keywords matching the job post.

---

## Q4. Best platform for first freelance gig?
- A) Toptal
- B) Fiverr ✅
- C) AngelList
- D) Glassdoor

> **Explanation:** Fiverr is beginner-friendly — create a gig, start cheap, build reviews.

---

## Q5. What should every pinned GitHub project have?
- A) Only source code
- B) README with screenshot, tech stack, and setup instructions ✅
- C) Just a link to the live site
- D) A video tutorial

> **Explanation:** README = title + screenshot + tech stack + setup steps + live demo link.

---

## Q6. Good LinkedIn headline for a developer?
- A) Student
- B) Full-Stack Developer | Python, FastAPI, React | Building AI-powered apps ✅
- C) Looking for job
- D) Hello World

> **Explanation:** Formula: Role | Key Skills | What You Build. Be specific.

---

## Q7. How to describe a project on your resume?
- A) Made a website
- B) Built a REST API with 15+ endpoints using FastAPI and PostgreSQL ✅
- C) Worked on something
- D) Did a project in college

> **Explanation:** Action verb + what + tech + measurable result. Be specific.

---

## Q8. How many jobs to apply to daily?
- A) 1
- B) 5 to 10 ✅
- C) 50+
- D) Only when you feel like it

> **Explanation:** 5-10 daily, customize resume for each, follow up after 3-5 days.

---

## Q9. What should your 60-second pitch include?
- A) Your entire life story
- B) Name, education, key skills, best project, and what you're looking for ✅
- C) Just your name and salary expectation
- D) A joke to break the ice

> **Explanation:** Name → Education → Skills → Best project → What you want. 60 seconds max.

---

## Q10. What makes a fresher stand out?
- A) High marks only
- B) Real projects on GitHub + matching skills + good communication ✅
- C) Expensive certification
- D) Knowing someone important

> **Explanation:** Projects = proof of work. Skills + communication + initiative = hired.
