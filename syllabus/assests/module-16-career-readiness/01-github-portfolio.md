**Module 16 — Career Readiness | Topic 1**

## Why You Need a Portfolio

> Your portfolio is your **proof of work**. Recruiters spend ~6 seconds on a resume but will spend 2 minutes browsing a good GitHub profile.

| What Recruiters Check | Why It Matters |
|----------------------|---------------|
| GitHub profile | Shows you can actually code |
| Pinned projects | Your best work, easily visible |
| README files | Shows communication skills |
| Commit history | Shows consistency and growth |
| Live project links | Proves projects actually work |

## Setting Up Your GitHub Profile

### Step 1: Profile README

Create a repo with your exact GitHub username (e.g., `rahul-sharma/rahul-sharma`). The `README.md` in this repo shows on your profile page.

```markdown
# Hi, I'm Rahul Sharma 👋

## About Me
- 🎓 ADCA Graduate from TechPath Institute
- 💻 Full-stack developer (Python, JavaScript, React)
- 🤖 AI enthusiast — building with Claude & OpenAI APIs
- 📍 Based in India

## Skills
**Languages:** Python, JavaScript, HTML, CSS, SQL
**Frameworks:** FastAPI, Django, React, Bootstrap
**Tools:** Git, Docker, Figma, VS Code
**AI:** ChatGPT, Claude, Prompt Engineering

## Projects
🛒 [E-Commerce API](link) — FastAPI + PostgreSQL
🤖 [AI Chat Bot](link) — Claude API + JavaScript
📊 [Sales Dashboard](link) — Python + Pandas + Charts

## Connect
- 💼 [LinkedIn](your-linkedin-url)
- 📧 your.email@gmail.com
```

### Step 2: Pin Your Best Projects

- Go to your GitHub profile
- Click "Customize your pins"
- Select 3-6 of your best projects
- Choose projects that show **different skills**

### What to Pin (Pick 3-5)

| Project Type | Shows |
|-------------|-------|
| Frontend website | HTML/CSS/JS skills |
| Full-stack app | Backend + frontend + database |
| Python data project | Data analysis + visualization |
| AI-powered app | Modern AI skills |
| UI/UX design | Figma → code workflow |

### Step 3: Write Great READMEs

Every pinned project needs a README with:

1. **Title + one-line description**
2. **Screenshot or demo GIF**
3. **Tech stack used**
4. **How to install and run**
5. **Live demo link** (if deployed)

## LinkedIn Profile Setup

### Headline Formula

```
[Role] | [Key Skills] | [What You Build]
```

Examples:
- "Full-Stack Developer | Python, FastAPI, React | Building AI-powered web apps"
- "Web Developer & UI Designer | HTML, CSS, JavaScript, Figma"
- "Python Developer | Data Analysis, AI Tools | ADCA Graduate"

### About Section (3-4 sentences)

```
I'm a full-stack developer specializing in Python (FastAPI, Django) and 
JavaScript (React). I build AI-powered web applications and have completed 
6 capstone projects during my ADCA program. Currently looking for 
opportunities where I can contribute to building great products.

Skills: Python, JavaScript, FastAPI, Django, React, SQL, Docker, Git, 
AI/GenAI tools, Figma
```

## Resume Writing for IT Jobs

### ATS-Friendly Format

**ATS** (Applicant Tracking System) = software that scans resumes before humans see them.

| Do | Don't |
|----|-------|
| Use standard headings | Use creative section names |
| Plain text, simple format | Fancy graphics or columns |
| Include keywords from job post | Use vague descriptions |
| PDF format | Word doc or image |
| One page (fresher) | Multiple pages |

### Project Description Formula

```
[Action verb] + [what you built] + [tech used] + [measurable result]
```

**Good examples:**
- "Built a REST API with 15+ endpoints using FastAPI and PostgreSQL"
- "Designed a mobile app UI with 5 screens in Figma, converted to responsive HTML"
- "Automated data analysis of 10,000 records using Python and Pandas"

**Bad examples:**
- "Made a website" (too vague)
- "Learned Python" (not an achievement)
- "Worked on a project" (says nothing)

## Summary

- **GitHub profile** = your coding portfolio — pin 3-5 best projects with READMEs
- **LinkedIn** = professional network — custom headline, about section, project posts
- **Resume** = one page, ATS-friendly, keywords from job posts
- **Project descriptions** = action verb + what + tech + result
- Every project needs: screenshot, tech stack, live link, setup instructions
