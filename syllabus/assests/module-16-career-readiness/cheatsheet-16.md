# Cheat Sheet: Career Readiness

**Module 16 — Quick Reference**

---

## GitHub Profile Checklist

- [ ] Profile README (username/username repo)
- [ ] Pin 3-6 best projects
- [ ] Each project has README + screenshot
- [ ] Live demo links where possible
- [ ] Consistent commit history

---

## LinkedIn Checklist

- [ ] Professional photo
- [ ] Custom headline: Role | Skills | What You Build
- [ ] About section (3-4 sentences)
- [ ] All projects listed with descriptions
- [ ] Skills added + endorsements
- [ ] 50+ connections

---

## Resume Format (1 Page)

```
NAME | Role
Contact | GitHub | LinkedIn
━━━━━━━━━━━━━
SKILLS — languages, frameworks, tools
━━━━━━━━━━━━━
PROJECTS (3-4) — action verb + tech + result
━━━━━━━━━━━━━
EDUCATION
━━━━━━━━━━━━━
CERTIFICATIONS
```

---

## Project Description Formula

```
[Action verb] + [what you built] + [tech] + [result]
```

Good: "Built REST API with 15 endpoints using FastAPI"
Bad: "Made a website"

## Interview Prep Topics

- Python: lists vs tuples, decorators, *args/**kwargs
- Web: GET vs POST, REST API, box model, JWT
- DB: primary key, JOINs, normalization
- General: Git, Docker, CI/CD, frontend vs backend
