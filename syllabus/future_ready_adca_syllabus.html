Foundation & Digital Fluency
Build from zero — hardware, software, OS, productivity, and networking. By month 3, students are fully digital-literate and productive.
01
Computer Fundamentals
How computers think, work, and compute
Foundation
History and generations of computers; types of computers (analog, digital, hybrid)
Input → Process → Output → Storage cycle; block diagram of a computer
CPU, RAM, ROM, Storage — roles and differences explained intuitively
Number systems: Binary, Decimal, Octal, Hexadecimal + conversions
Bits, Bytes, KB, MB, GB, TB — data measurement; ASCII & Unicode encoding
Logic gates: AND, OR, NOT, NAND, NOR (concept + truth tables)
Hardware vs Software; System software vs Application software
Theory Diagrams 3 weeks

Keyboard shortcuts (100+ essential shortcuts for productivity)
Task manager, system properties, startup programs, updates
Introduction to Linux: terminal, basic commands (ls, cd, mkdir, chmod, sudo)
Installing and managing software; Windows vs Linux comparison
Hands-on Lab Practice 3 weeks

Cybersecurity basics: threats, firewalls, VPN, HTTPS, 2FA, password hygiene
Theory + Lab Cybersecurity 3 weeks
