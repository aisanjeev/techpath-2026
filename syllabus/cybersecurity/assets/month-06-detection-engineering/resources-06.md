# Month 06 — Resources & Tools

## Detection Rule Tools

### Sigma
- **Sigma GitHub** — Official rule repository (thousands of community rules)
  https://github.com/SigmaHQ/sigma
- **Sigma Rule Converter (pySigma)** — Convert Sigma to Splunk/KQL/Lucene
  https://github.com/SigmaHQ/pySigma
- **Sigma Rule Converter (online)**
  https://sigconverter.io/

### YARA
- **YARA Official Download** — Windows/Linux/Mac binaries
  https://github.com/VirusTotal/yara/releases
- **YARA Rules Repository** (community rules by topic)
  https://github.com/Yara-Rules/rules
- **YARA Documentation**
  https://yara.readthedocs.io/

### SOAR Platforms (Free Tier)
- **Shuffle SOAR** — Open-source SOAR, self-hosted or cloud
  https://shuffler.io/
- **Tines** — Free community tier (no-code automation)
  https://www.tines.com/
- **n8n** — Open-source workflow automation (self-hosted)
  https://n8n.io/
