# Month 03 — Resources & Tools

## Tools to Download / Use

### Cryptography & Security Tools
- **CyberChef** — Browser-based crypto/encoding/hashing tool (no install)
  https://gchq.github.io/CyberChef/
- **OpenSSL** — Command-line cryptography (Windows: Git Bash or WSL)
  https://www.openssl.org/ | Windows: https://slproweb.com/products/Win32OpenSSL.html
- **HashCalc** — GUI hash calculator for Windows
  https://www.slavasoft.com/hashcalc/

### Python Security Libraries
- **Python 3** (if not installed) — https://www.python.org/downloads/
- **requests** — `pip install requests` — HTTP library for security scripts
- **scapy** — `pip install scapy` — packet manipulation / network scanning
- **pycryptodome** — `pip install pycryptodome` — AES, RSA in Python

### Security+ Study Tools
- **Professor Messer's Free Security+ Course** (SY0-701)
  https://www.professormesser.com/security-plus/sy0-701/sy0-701-video/sy0-701-comptia-security-plus-course/
- **Jason Dion Udemy Course** (paid but cheap on sale)
  Search "CompTIA Security+ SY0-701" on Udemy

## Online Tools (No Download)

- **CyberChef** — Encode, decode, hash, encrypt, decrypt anything
  https://gchq.github.io/CyberChef/
- **VirusTotal** — Scan files and URLs for malware (up to 650MB free)
  https://www.virustotal.com/
- **Have I Been Pwned** — Check if your email appeared in data breaches
  https://haveibeenpwned.com/
- **ExplainShell** — Explains any Linux/shell command
  https://explainshell.com/
- **RegexR** — Test regular expressions interactively
  https://regexr.com/
