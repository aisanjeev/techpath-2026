## Copywriting Formulas

### AIDA (Attention → Interest → Desire → Action)
```
A: Bold hook or question (stop the scroll)
I: Relevant info that builds curiosity
D: Paint the outcome / create FOMO
A: Clear CTA (buy/click/DM/follow)
```

### PAS (Problem → Agitate → Solution)
```
P: Name the specific pain
A: Make it feel urgent (what happens if they don't fix it?)
S: Present your product/service as the answer
```

### 4P's (Promise → Picture → Proof → Push)
```
Promise: Bold specific claim
Picture: Help them visualize success
Proof: Data, testimonials, results
Push: Urgency + CTA
```

## Carousel Formula (Instagram/LinkedIn)

```
Slide 1: HOOK — Bold statement + curiosity (stops the scroll)
Slide 2: CONTEXT — Who this is for / why it matters
Slides 3-8: VALUE — One point per slide (actionable)
Slide 9: SUMMARY — Quick recap
Slide 10: CTA — Follow + Save + Introduce yourself
```

**Design Rules:**
- Max 30 words per slide
- Font size 24pt minimum
- One idea per slide
- Consistent colors and fonts
- First slide = most important (determines swipes)

## Hook-Body-CTA Template (Captions)

### Hook Starters (First Line)
- "Stop doing [common mistake]."
- "I spent ₹[X] to learn this so you don't have to."
- "[Number] [things] I wish I knew before [situation]."
- "Nobody talks about this, but..."
- "The truth about [topic] that [audience] needs to hear."
- "This one [thing] changed my [result] completely."

### Body (Value Delivery)
- Keep under 200 words for Instagram
- Use line breaks for readability
- Bold key points with CAPS or emojis
- Include 1 example or mini-story

### CTA Options
- Engagement: "Save this for later"
- Comment: "Drop a [emoji] if you agree"
- Follow: "Follow @handle for daily tips"
- Share: "Tag someone who needs this"
- Link: "Link in bio for the full guide"

## The 4-1-1 Content Rule

For every 6 posts:
```
4 = EDUCATE (tips, how-tos, frameworks, tutorials)
1 = PROMOTE (your service, product, offer, portfolio)
1 = PERSONAL (story, journey, lesson, behind-the-scenes)
```

## E-E-A-T Checklist (Blog Writing)

- [ ] **Experience**: Did I share personal experience or first-hand knowledge?
- [ ] **Expertise**: Did I demonstrate deep understanding with data/specifics?
- [ ] **Authoritativeness**: Do I cite credible sources? Am I qualified to write this?
- [ ] **Trustworthiness**: Is info accurate? No misleading claims? Sources cited?

## Video Script Structure (Reels/Shorts)

```
0-2 sec:  HOOK (text on screen + visual surprise)
2-15 sec: SETUP (context/problem)
15-45 sec: VALUE (tips/tutorial/story)
45-55 sec: TAKEAWAY (summary punch)
55-60 sec: CTA (follow/save/comment)
```

**High-Performing Reel Types:**
1. Tutorial/How-to (highest saves)
2. "Things I wish I knew" (relatable)
3. Before/After (transformation)
4. Trending audio + education overlay
5. POV format (situational)

## Hub-Spoke Content Model

```
PILLAR PAGE (3000-5000 words) = Hub
    ├── Blog Post 1 (spoke) ← links to hub
    ├── Blog Post 2 (spoke) ← links to hub
    ├── Blog Post 3 (spoke) ← links to hub
    ├── Blog Post 4 (spoke) ← links to hub
    └── Blog Post 5 (spoke) ← links to hub

All spokes link to the hub. Hub links to all spokes.
Google sees this cluster = AUTHORITY on the topic.
```

## Crisis Communication (5 Steps)

```
1. ACKNOWLEDGE — Respond quickly, take it seriously
2. APOLOGIZE — Own it (if at fault)
3. ACT — State what you are doing to fix it
4. ADAPT — Change process to prevent recurrence
5. ADVANCE — Follow up and rebuild trust
```

**Rules:** Never delete comments. Never argue publicly. Always respond within 1 hour.

## ASCI Disclosure Rules (India)

- Every paid partnership MUST have disclosure
- Use: #Ad OR #Sponsored OR #PaidPartnership
- Must be VISIBLE (first line, not buried in hashtags)
- Both brand AND influencer are responsible
- Applies to: cash, free products, affiliate commissions
