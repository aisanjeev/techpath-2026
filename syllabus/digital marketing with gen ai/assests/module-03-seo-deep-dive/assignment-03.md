## Task 1: Keyword Research Sheet (30 Marks)

### Brief
Build a comprehensive 100-keyword research sheet for the niche: **"Coaching Classes in Varanasi"**

### Requirements

Create a Google Sheet with the following columns for each keyword:

| Column | Description |
|--------|-------------|
| Keyword | The search term |
| Search Volume | Monthly searches (use Google Keyword Planner or Ubersuggest) |
| Keyword Difficulty (KD) | 0-100 score |
| CPC (₹) | Cost per click in Google Ads |
| Search Intent | Informational / Navigational / Transactional / Commercial |
| SERP Features | What appears (Featured Snippet, PAA, Video, Local Pack, etc.) |
| Topical Cluster | Group name (e.g., "IIT Coaching," "NEET Coaching," "SSC Coaching") |
| Priority | High / Medium / Low (based on opportunity) |
| Target Page Type | Blog, Service Page, Landing Page, FAQ |

### Distribution of 100 Keywords:
- 30 long-tail keywords (4+ words)
- 30 medium-tail keywords (2-3 words)
- 20 question-based keywords ("how to," "what is," "which is best")
- 10 local intent keywords (include "Varanasi," "near me," "in BHU area")
- 10 competitor brand keywords (names of actual coaching institutes in Varanasi)

### Marking Criteria:
- Keyword relevance and variety: 10 marks
- Accuracy of metrics (volume, KD, CPC): 8 marks
- Correct intent classification: 5 marks
- Proper clustering and prioritization: 5 marks
- Clean formatting and presentation: 2 marks

## Task 2: On-Page SEO Audit & Rewrite (25 Marks)

### Brief
Pick any REAL website (preferably a local business or coaching institute in an Indian city). Run a complete on-page SEO audit on 5 pages and rewrite the key elements.

### Requirements

**Step 1: Audit (in a table format for each page)**

For each of the 5 pages, document:
- Current title tag (and character count)
- Current meta description (and character count)
- Current URL structure
- Current heading structure (list all H1-H6 tags)
- Number of images without alt text
- Number of internal links
- Keyword being targeted (your analysis)

**Step 2: Rewrite**

For each of the 5 pages, provide:
- **Optimized title tag** (50-60 chars, include primary keyword, brand name)
- **Optimized meta description** (150-155 chars, include CTA, keyword)
- **Suggested URL** (clean, short, keyword-rich)
- **Optimized heading structure** (H1 + at least 3 H2s + H3s where needed)
- **3 recommended internal links** (to which other pages and with what anchor text)
- **Reasoning** (1-2 sentences explaining why you made each change)

### Marking Criteria:
- Thoroughness of audit (all elements checked): 8 marks
- Quality of rewritten title tags: 5 marks
- Quality of rewritten meta descriptions: 5 marks
- Heading structure logic and keyword usage: 4 marks
- Internal linking recommendations: 3 marks

## Task 3: robots.txt + XML Sitemap Creation (20 Marks)

### Brief
Create a `robots.txt` file and an `XML sitemap` for a hypothetical coaching institute website: **"Gupta Coaching Centre, Varanasi"** (a 20-page website).

### Website Structure (20 pages):
1. Homepage
2. About Us
3. Our Faculty
4. IIT-JEE Coaching (service page)
5. NEET Coaching (service page)
6. SSC/Bank Coaching (service page)
7. Foundation Course (Class 9-10)
8. Study Material (resources page)
9. Results & Toppers
10. Fee Structure
11. Admission Form
12. Blog — "How to Prepare for IIT JEE"
13. Blog — "Best Coaching in Varanasi"
14. Blog — "NEET 2026 Exam Pattern"
15. Contact Us
16. Gallery (photos)
17. Testimonials
18. FAQ
19. Privacy Policy
20. Terms & Conditions

### Requirements:

**Part A: robots.txt** (8 marks)
- Write a complete robots.txt file
- Block pages that should NOT be indexed (admin, internal search, form submissions)
- Allow important pages
- Include sitemap reference
- Add rules for specific bots (Googlebot, Bingbot)
- Write comments explaining each rule

**Part B: XML Sitemap** (8 marks)
- Write a valid XML sitemap including all 20 pages
- Assign appropriate `<priority>` values (homepage = 1.0, service pages = 0.8, blogs = 0.6, legal pages = 0.3)
- Set realistic `<lastmod>` dates
- Set appropriate `<changefreq>` values

**Part C: Explanation** (4 marks)
- In 200 words, explain:
  - Why did you block certain pages in robots.txt?
  - How did you decide priority values in the sitemap?
  - What would happen if you accidentally blocked the blog section in robots.txt?

### Marking Criteria:
- Correct robots.txt syntax and logic: 8 marks
- Valid XML sitemap with proper priorities: 8 marks
- Explanation quality: 4 marks
