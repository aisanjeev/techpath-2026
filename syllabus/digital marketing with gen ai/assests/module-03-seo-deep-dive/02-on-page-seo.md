# On-Page SEO

**Module 03 — SEO Deep Dive | Topic 2**

---

## What is On-Page SEO?

**On-Page SEO** means optimising the elements **on your own web page** to help search engines understand your content and rank it higher. Unlike off-page SEO (backlinks), on-page SEO is 100% in your control.

> **Simple Analogy:** Think of on-page SEO like dressing up for a job interview. You control your outfit, your resume, and how you present yourself. Off-page SEO is like the reference letter someone else writes for you.

---

## 1. Title Tag

The **title tag** is the clickable headline that appears in search results. It is the single most important on-page SEO element.

| Rule | Detail |
|------|--------|
| **Character limit** | 50-60 characters (Google truncates after ~60) |
| **Primary keyword** | Place it near the beginning of the title |
| **Uniqueness** | Every page must have a different title tag |
| **Formula** | Primary Keyword - Secondary Keyword | Brand Name |

**Good Examples:**

| Page | Title Tag |
|------|----------|
| Course page | `Digital Marketing Course in Bhopal - 100% Placement | TechPath` |
| Blog post | `10 SEO Tips for Small Businesses in India - TechPath Academy` |
| Service page | `Web Development Services Jaipur - Custom Websites | DevStudio` |

**Bad Examples:**

| Title Tag | Problem |
|----------|---------|
| `Home` | No keyword, no context |
| `TechPath Academy - The Best Institute for Everything` | Keyword not at the start, vague |
| `Digital Marketing Course Digital Marketing Training Digital Marketing Classes` | Keyword stuffing |

> **Pro Tip:** Add power words to increase click-through rate — numbers ("10 Tips"), urgency ("2026 Guide"), and benefits ("Free", "With Placement").

## 2. Meta Description

The **meta description** is the summary text that appears below the title in search results. It does not directly affect ranking, but it strongly affects **click-through rate (CTR)**.

| Rule | Detail |
|------|--------|
| **Character limit** | 150-155 characters |
| **Include keyword** | Google bolds the matching keyword in the description |
| **Add a CTA** | Tell users what to do — "Learn more", "Enroll now", "Download free guide" |
| **Be specific** | Include numbers, benefits, or unique selling points |

**Example:**
```
Page: Digital Marketing Course page
Meta: Join TechPath's 6-month Digital Marketing course. Learn SEO, Ads & AI tools.
      500+ students placed. Batch starts Aug 2026. Enroll now!
      (Characters: 148)
```

> **Fun Fact:** Google rewrites meta descriptions about 63% of the time, pulling text from your page instead. But a well-written meta description still improves your CTR — so always write one.

## 3. URL Structure

Your URL should tell both users and Google what the page is about.

| Rule | Good Example | Bad Example |
|------|-------------|-------------|
| Use hyphens, not underscores | `/digital-marketing-course/` | `/digital_marketing_course/` |
| Keep it short (3-5 words) | `/seo-tips-beginners/` | `/the-ultimate-complete-guide-to-seo-tips-for-beginners-in-india-2026/` |
| Include primary keyword | `/spoken-english-varanasi/` | `/page?id=4827&cat=12` |
| Lowercase only | `/web-development/` | `/Web-Development/` |
| No special characters | `/courses/python/` | `/courses/python%20course!!/` |
| Reflect site hierarchy | `/blog/seo-tips/` | `/x7gh2/post-47/` |

> **Real Example:** Which URL would you trust more?
> - `techpath.biz/courses/digital-marketing-course-bhopal`
> - `techpath.biz/index.php?page=38&category=courses&id=472`
>
> The first URL tells you exactly what the page is about before you even click.

## 4. Heading Hierarchy (H1-H6)

Headings create a logical structure for your page, like chapters in a textbook.

```
H1: Main Topic (only ONE per page)
  H2: Major Section
    H3: Subsection under H2
      H4: Detail under H3 (rarely needed)
```

| Rule | Explanation |
|------|-------------|
| **One H1 only** | The H1 is your page title — only one per page, include your primary keyword |
| **H2 for sections** | Use H2 for main sections — include secondary keywords naturally |
| **H3 for subsections** | Use H3 under each H2 for subtopics |
| **Never skip levels** | Do not jump from H1 to H3 — always go H1 then H2 then H3 |
| **Keep them descriptive** | Headings should make sense if someone only reads the headings |

**Bad heading structure:**
```
H1: Digital Marketing
H3: What is SEO            ← Skipped H2!
H2: Social Media Marketing
H4: Instagram Tips          ← Skipped H3!
H1: Contact Us              ← Two H1 tags!
```

## 5. Content Optimisation

| Concept | What It Means | How to Apply |
|---------|---------------|--------------|
| **Keyword Density** | Percentage of times your keyword appears vs total words | Keep between 1-2%. For a 1,000-word article, use the keyword 10-20 times naturally |
| **First 100 Words Rule** | Include your primary keyword in the first 100 words | Google pays extra attention to the opening paragraph |
| **LSI Keywords** | Latent Semantic Indexing — related terms Google expects to see | If your keyword is "digital marketing", LSI keywords include "SEO", "social media", "PPC", "content strategy" |
| **Keyword Placement** | Where you place the keyword matters | Title tag, H1, first paragraph, at least one H2, image alt text, and conclusion |
| **Natural Writing** | Write for humans first, search engines second | If the keyword feels forced, rephrase the sentence |

> **Pro Tip:** Use a free tool like SurferSEO or NeuronWriter to check your content optimisation score. It tells you which LSI keywords to add and whether your density is too low or too high.

**Content Length Guidelines:**

| Page Type | Recommended Length |
|----------|-------------------|
| Blog post (informational) | 1,500-2,500 words |
| Product/service page | 500-1,000 words |
| Landing page | 300-800 words |
| Pillar page (comprehensive guide) | 3,000-5,000 words |

## 6. Image SEO

Images can drive traffic through Google Image Search and improve user experience. But unoptimised images also slow your site down.

### File Naming

| Bad | Good |
|-----|------|
| `IMG_2847.jpg` | `digital-marketing-classroom-bhopal.jpg` |
| `screenshot.png` | `google-keyword-planner-dashboard.png` |
| `photo(1).jpeg` | `techpath-students-working-on-seo-project.jpg` |

### Alt Text

Alt text describes the image for screen readers and search engines. It appears if the image fails to load.

| Rule | Example |
|------|---------|
| Describe what is in the image | `alt="Students learning SEO in TechPath Academy classroom"` |
| Include keyword if natural | `alt="Digital marketing course classroom in Bhopal"` |
| Keep it under 125 characters | Do not write a paragraph |
| Do not start with "image of" or "picture of" | Google already knows it is an image |

### Image Format and Performance

| Format | Best For | File Size |
|--------|----------|-----------|
| **WebP** | All web images (best balance of quality and size) | 25-35% smaller than JPEG |
| **JPEG** | Photos and complex images | Medium |
| **PNG** | Images with transparency (logos, icons) | Larger |
| **SVG** | Icons and simple graphics | Very small |
| **AVIF** | Next-gen format, even smaller than WebP | Smallest (limited browser support) |

### Lazy Loading and CLS Prevention

```html
<img src="classroom.webp"
     alt="TechPath digital marketing classroom"
     width="800"
     height="450"
     loading="lazy" />
```

- `loading="lazy"` — Image loads only when the user scrolls to it (saves bandwidth)
- `width` and `height` — Prevents **Cumulative Layout Shift (CLS)** — the page does not jump while images load

## 7. Internal Linking Strategy

Internal links connect one page of your website to another. They help Google understand your site structure and pass authority between pages.

### Hub-Spoke Model

```
                    [Pillar: Digital Marketing Guide]
                   /          |           \
         [SEO Guide]   [Social Media]   [Email Marketing]
         /    \             |                  |
  [On-Page] [Off-Page]  [Instagram]     [Newsletter Tips]
```

The pillar page links to all cluster pages, and every cluster page links back to the pillar page.

### Internal Linking Rules

| Rule | Do This | Not This |
|------|---------|----------|
| **Anchor text** | Use descriptive text: "learn on-page SEO techniques" | "click here" or "read more" |
| **Link count** | 3-5 internal links per page minimum | Zero links (orphan page) |
| **Relevance** | Link to related content only | Link your SEO page to a cooking recipe |
| **Depth** | Every page reachable within 3 clicks from homepage | Important pages buried 6 clicks deep |
| **Distribution** | Link from high-authority pages to new pages | Only link from new pages to old pages |

## 8. Schema Markup / Structured Data

Schema markup is code (in JSON-LD format) added to your page that helps Google understand your content better. It can earn you **rich results** — enhanced search listings with stars, FAQs, prices, and more.

### Common Schema Types for Indian Businesses

| Schema Type | Use Case | What Appears in Search |
|-------------|----------|----------------------|
| **LocalBusiness** | Physical store, office, coaching class | Address, phone, hours, map in Knowledge Panel |
| **Article** | Blog posts, news articles | Author name, date, breadcrumbs |
| **FAQ** | Pages with questions and answers | Expandable Q&A directly in search results |
| **HowTo** | Step-by-step tutorials | Steps with images in search results |
| **Course** | Online/offline courses | Course name, provider, price |
| **Product** | E-commerce products | Price, availability, star ratings |
| **Review** | Customer reviews | Star rating in search results |

### JSON-LD Example: FAQ Schema

```json
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "What is the fee for TechPath Digital Marketing course?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "The 6-month Digital Marketing with Gen AI course costs Rs 45,000 with EMI options."
      }
    },
    {
      "@type": "Question",
      "name": "Is placement guaranteed after the course?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "TechPath offers 100% placement assistance with 500+ hiring partners across India."
      }
    }
  ]
}
```

### JSON-LD Example: LocalBusiness Schema

```json
{
  "@context": "https://schema.org",
  "@type": "EducationalOrganization",
  "name": "TechPath Academy",
  "url": "https://techpath.biz",
  "telephone": "+91-7000-123456",
  "address": {
    "@type": "PostalAddress",
    "streetAddress": "MP Nagar Zone 2",
    "addressLocality": "Bhopal",
    "addressRegion": "Madhya Pradesh",
    "postalCode": "462011",
    "addressCountry": "IN"
  },
  "openingHours": "Mo-Sa 09:00-18:00",
  "priceRange": "$$"
}
```

> **Pro Tip:** Test your schema markup at [Google Rich Results Test](https://search.google.com/test/rich-results). Paste your JSON-LD code and fix any errors until you see a green checkmark.

## Summary

- **Title tag** is the most important on-page element — keep it 50-60 characters with keyword at the start
- **Meta description** (150-155 chars) does not directly affect ranking but drives click-through rate
- **URLs** should be short, lowercase, use hyphens, and include the primary keyword
- Follow proper **heading hierarchy** — one H1 per page, never skip levels (H1 then H2 then H3)
- Keep **keyword density** at 1-2% and include the keyword in the first 100 words
- Optimise **images** with descriptive file names, alt text, WebP format, lazy loading, and width/height attributes
- Use the **hub-spoke model** for internal linking — every page should have 3-5 internal links minimum
- Add **schema markup** (JSON-LD) for rich results — FAQ, LocalBusiness, Article, and Course schemas are most useful for Indian businesses
