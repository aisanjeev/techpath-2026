## Introduction

The Internet is not just about opening websites. It provides many useful **services** that we use every day — from sending emails to attending online classes. In this topic, we will learn about the most important internet services that are covered in the CCC exam.

---

## 1. World Wide Web (WWW)

The **World Wide Web** (or simply **the Web**) is a system of interlinked web pages and websites that you can access using the internet and a web browser.

- **Invented by:** Tim Berners-Lee in 1989
- **How it works:** Web pages are written in HTML and stored on web servers. You access them using a browser (like Chrome) by typing a URL.
- **Key components:**
  - **Web Pages** — Individual pages of information (text, images, videos)
  - **Website** — A collection of related web pages (e.g., www.irctc.co.in has many pages)
  - **Web Server** — The computer that stores and serves web pages
  - **Web Browser** — Software used to view web pages (Chrome, Firefox, Edge)
  - **URL** — The address of a web page (e.g., https://www.google.com)

**Real-life example:** When Sneha opens Chrome and visits www.flipkart.com to shop online, she is using the World Wide Web.

**CCC Exam Tip:** WWW and Internet are NOT the same thing. The Internet is the network infrastructure (cables, routers). WWW is a service that runs on top of the Internet. The exam may ask: "WWW was invented by?" Answer: Tim Berners-Lee.

## 2. Email (Electronic Mail)

**Email** is the service of sending and receiving messages electronically over the internet. It is one of the oldest and most widely used internet services.

### How Email Works:
1. Amit composes an email in Gmail and clicks "Send"
2. Gmail's server uses **SMTP** (Simple Mail Transfer Protocol) to send the email
3. The email reaches the recipient's email server
4. When Priya opens her inbox, her email client uses **POP3** or **IMAP** to download the email

### Email Protocols:
| Protocol | Purpose |
|----------|---------|
| **SMTP** | Sending emails |
| **POP3** | Receiving emails (downloads to device, removes from server) |
| **IMAP** | Receiving emails (keeps emails on server, syncs across devices) |

### Parts of an Email Address:
```
rahul.sharma@gmail.com
|___________|  |_____|
  Username    Domain name
       |
       @ (at symbol)
```

### Popular Email Services in India:
- **Gmail** (Google) — Most popular
- **Outlook/Hotmail** (Microsoft)
- **Yahoo Mail**
- **Rediffmail** — Indian email service
- **NIC Email** — Used by government officials (e.g., name@nic.in)

**CCC Exam Tip:** "Which protocol sends email?" = SMTP. "Who introduced the @ symbol in email?" = Ray Tomlinson (1971). The difference between POP3 and IMAP is often asked.

## 3. FTP (File Transfer Protocol)

**FTP** is used to transfer files between computers over the internet. It allows you to upload files to a server or download files from a server.

- **Upload:** Sending a file from your computer to a server
- **Download:** Getting a file from a server to your computer

### How FTP Works:
1. Ananya connects to an FTP server using an FTP client (like FileZilla)
2. She browses the files on the server
3. She can upload her files to the server or download files from it

### Real-life examples:
- A web developer uploading website files to a hosting server
- A student downloading study materials from a college server
- Government uploading forms to the NIC server for public access

**CCC Exam Tip:** "Full form of FTP?" = File Transfer Protocol. "What is FTP used for?" = Transferring files between computers.

## 4. Telnet

**Telnet** is a service that allows you to remotely access and control another computer over the internet. It works as if you are sitting in front of that remote computer.

- **How it works:** You use a Telnet client to connect to a remote computer. Once connected, you can type commands and the remote computer executes them.
- **Port number:** 23
- **Limitation:** Telnet sends data (including passwords) in plain text — it is **not secure**
- **Modern replacement:** **SSH (Secure Shell)** — does the same thing but with encryption

**Real-life example:** An IT administrator in Delhi remotely managing a server located in Mumbai using Telnet or SSH.

**CCC Exam Tip:** Telnet is used for remote access. It is NOT secure because data is sent in plain text. SSH is the secure alternative.

## 5. Chat and Instant Messaging

**Chat** or **Instant Messaging (IM)** allows real-time text communication between two or more people over the internet.

### Types of Chat:
| Type | Description | Example |
|------|-------------|---------|
| **Text Chat** | Real-time text messages | WhatsApp, Telegram |
| **Voice Chat** | Real-time voice communication | WhatsApp call, Discord |
| **Group Chat** | Multiple people chatting together | WhatsApp Groups, Slack |
| **Chatbot** | Automated chat with AI/bot | IRCTC chatbot, bank chatbots |

### Popular Chat Apps in India:
- **WhatsApp** — Most popular messaging app in India
- **Telegram** — Popular for groups and channels
- **Signal** — Known for privacy and security
- **Google Chat** — Used in workplaces
- **Slack/Microsoft Teams** — Used in companies and organizations

**Real-life example:** Rahul uses WhatsApp to send a message to his study group about tomorrow's exam schedule. The message is delivered instantly.

## 6. Video Conferencing

**Video Conferencing** allows people in different locations to have face-to-face meetings over the internet using audio and video.

### Popular Video Conferencing Tools:

| Tool | Developer | Key Feature |
|------|-----------|-------------|
| **Zoom** | Zoom Video Communications | Most popular for online classes |
| **Google Meet** | Google | Free with Google account |
| **Microsoft Teams** | Microsoft | Used in offices and schools |
| **Cisco Webex** | Cisco | Enterprise-grade meetings |
| **Jio Meet** | Reliance Jio | Indian video calling platform |

### Features of Video Conferencing:
- **Screen Sharing** — Show your screen to others (useful for presentations)
- **Recording** — Record the meeting for later viewing
- **Chat** — Send text messages during the meeting
- **Virtual Background** — Change your background during a call
- **Breakout Rooms** — Split participants into smaller groups

### How It Works:
1. A host creates a meeting and shares the meeting link/ID
2. Participants click the link or enter the meeting ID
3. Audio and video data is transmitted over the internet in real-time
4. Everyone can see and hear each other

**Real-life example:** During COVID-19, Sneha's college in Bhopal conducted all classes on Zoom. The teacher shared her screen to show presentations, and students could ask questions using the chat feature.

**CCC Exam Tip:** Video conferencing became very important during COVID-19. Know the names of popular tools — Zoom, Google Meet, Microsoft Teams.

## 7. Other Important Internet Services

### VoIP (Voice over Internet Protocol)
- Making phone calls using the internet instead of traditional phone lines
- Examples: WhatsApp call, Skype, Google Voice, JioCall
- Much cheaper than regular phone calls, especially for international calls

### Cloud Storage
- Storing files on the internet instead of your computer's hard drive
- Examples: Google Drive, OneDrive, Dropbox, iCloud
- You can access your files from any device, anywhere

### Social Networking
- Platforms for connecting with people, sharing updates, and socializing
- Examples: Facebook, Instagram, Twitter (X), LinkedIn, Koo (Indian platform)

### E-Commerce
- Buying and selling products/services online
- Examples: Amazon.in, Flipkart, Myntra, Meesho, JioMart
- Payments via UPI, credit/debit cards, or COD (Cash on Delivery)

### E-Governance
- Government services available online for citizens
- Examples: DigiLocker, UMANG app, Passport Seva, Income Tax e-filing
- Part of the Digital India initiative
