## Tools to Explore (Hands-on Practice)

| Tool | What to Practice |
|------|-----------------|
| **Command Prompt (cmd)** | Run `ipconfig`, `ping`, `tracert`, `nslookup` commands |
| **Windows Network Settings** | Check your IP address, WiFi details, DNS settings |
| **Chrome Browser** | Inspect URL structure, check HTTPS padlock, view site certificate |
| **Gmail** | Send emails with CC and BCC, add attachments, check spam folder |
| **Google Search** | Practice advanced search operators (quotes, site:, filetype:) |
| **DigiLocker** | Create account, explore documents |
| **UMANG App** | Install and explore government services |
