## File Extensions

| Extension | Format | Opens As |
|-----------|--------|----------|
| **.pptx** | PowerPoint Presentation | Editable |
| **.ppsx** | PowerPoint Show | Slide show directly |
| .ppt | Old PowerPoint (97-2003) | Editable |
| .potx | PowerPoint Template | Template |
| .pdf | PDF export | Non-editable |

## PowerPoint Views

| View | Shows | Best For |
|------|-------|----------|
| **Normal** | Slide + panel + notes | Editing (DEFAULT) |

| **Outline** | Text only | Content structure |

| **Ctrl + A** | Arrow pointer |
| **Alt + F5** | Presenter View |

## Transition vs Animation

| | Transition | Animation |
|-|-----------|-----------|
| **Applied to** | **Between slides** | **Objects within a slide** |
| **Tab** | Transitions | Animations |
| **Example** | Fade from slide 1 to 2 | Title flying into slide |

---

## Transition Types

| Category | Examples |
|----------|---------|
| **Subtle** | None, Cut, Fade, Push, Wipe, Split |
| **Exciting** | Dissolve, Checkerboard, Blinds, Clock |
| **Dynamic** | Pan, Cube, Doors, Rotate |

**Apply to All** = same transition on every slide

---

## Animation Types

| Type | Effect | Color Code |
|------|--------|------------|
| **Entrance** | Object appears | Green |
| **Emphasis** | Object highlighted | Yellow |
| **Exit** | Object disappears | Red |
| **Motion Path** | Object moves | Blue |

### Start Options
| Option | When It Plays |
|--------|--------------|
| **On Click** | When mouse clicked |
| **With Previous** | Same time as previous |
| **After Previous** | After previous finishes |
