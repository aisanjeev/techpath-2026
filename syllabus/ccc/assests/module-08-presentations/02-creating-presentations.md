## Creating a Presentation from Blank

When you open PowerPoint and select **Blank Presentation**, you get a fresh presentation with one slide using the **Title Slide** layout.

### Steps to Create a Simple Presentation

1. Open **Microsoft PowerPoint**
2. Click **Blank Presentation**
3. On the first slide (Title Slide layout):
   - Click "Click to add title" and type your presentation title
   - Click "Click to add subtitle" and type your name or description
4. Add more slides as needed (explained below)
5. Save your presentation (**Ctrl + S**)

---

## Creating from a Template

Templates are pre-designed presentations with professional themes, colors, fonts, and layouts. Using templates saves time and gives your presentation a polished look.

### Steps to Create from Template
1. Open PowerPoint
2. On the Start Screen, you will see template categories
3. Search for a template by typing in the search box (e.g., "Education", "Business Report")
4. Click on a template to preview it
5. Click **Create**
6. Replace the placeholder text and images with your own content

### Template vs Blank Comparison

| Feature | Blank Presentation | Template |
|---------|-------------------|----------|
| Design | No design — plain white | Pre-designed with colors and fonts |
| Slides | One empty slide | Multiple pre-arranged slides |
| Time to create | Longer (design from scratch) | Faster (just replace content) |
| Customization | Full control | Modify existing design |
| Best for | Custom designs | Quick professional presentations |

## Entering and Editing Text

### Adding Text to a Slide
- Click on any **text placeholder** (the dotted-border boxes that say "Click to add text")
- Start typing your content
- Use the **Home** tab to format text (font, size, color, bold, italic, etc.)

### Text Formatting Options

| Formatting | How to Apply | Shortcut |
|-----------|-------------|----------|
| **Bold** | Home → B button | Ctrl + B |
| *Italic* | Home → I button | Ctrl + I |
| Underline | Home → U button | Ctrl + U |
| Font size | Home → Font size dropdown | Ctrl + ] (increase), Ctrl + [ (decrease) |
| Font color | Home → Font Color dropdown | — |
| Text alignment | Home → Align Left/Center/Right | Ctrl + L / E / R |
| Bullet list | Home → Bullets button | — |
| Numbered list | Home → Numbering button | — |

### Adding a Text Box
If you need text outside the placeholders:
1. Go to **Insert** tab → **Text Box**
2. Click and drag on the slide to create a text box
3. Type your text inside it

## Working with Slides

### Inserting a New Slide

| Method | Steps |
|--------|-------|
| **Ribbon** | Home tab → **New Slide** button |
| **Keyboard** | **Ctrl + M** |
| **Right-click** | Right-click in Slide Panel → **New Slide** |

When you click the **dropdown arrow** on the New Slide button, you can choose a specific layout for the new slide.

### Deleting a Slide
1. Click on the slide in the **Slide Panel** (left side)
2. Press the **Delete** key on your keyboard
3. Or right-click the slide → **Delete Slide**

**Warning:** Deleting a slide cannot be undone once you save the file. Use **Ctrl + Z** (Undo) immediately if you delete by mistake.

### Duplicating a Slide
- Right-click on a slide in the Slide Panel → **Duplicate Slide**
- Or select the slide and press **Ctrl + D**
- This creates an exact copy of the slide right after the original
- Useful when you want to create similar slides with minor changes

### Rearranging Slides
You can change the order of slides in two ways:

**Method 1: Drag and Drop (Normal View)**
1. In the Slide Panel (left side), click and hold on a slide thumbnail
2. Drag it up or down to the desired position
3. Release the mouse button

**Method 2: Slide Sorter View**
1. Go to **View** tab → **Slide Sorter**
2. All slides appear as thumbnails in a grid
3. Drag and drop slides to rearrange them
4. This is the easiest way to rearrange multiple slides

**CCC Exam Tip:** "Which view is best for rearranging slides?" — Answer: **Slide Sorter View**. You can drag and drop slides in this view to change their order.

## Slide Master

### What is Slide Master?
The **Slide Master** is a special slide that controls the appearance of all slides in your presentation. Think of it as a "template within a template."

Changes made to the Slide Master are automatically applied to **all slides** that use that layout.

### What Can You Set in Slide Master?
- Background color or image
- Font styles and sizes for titles and body text
- Logo or image that appears on every slide
- Footer text, date, and slide number position
- Color scheme for the entire presentation

### How to Access Slide Master
1. Go to **View** tab → **Slide Master**
2. The Slide Master appears at the top of the slide panel (larger thumbnail)
3. Below it are the individual layout masters
4. Make your changes (e.g., add a logo, change font)
5. Click **Close Master View** when done

### Example Use Case
**Scenario:** Priya is creating a presentation for TechPath Institute. She wants the TechPath logo on every slide.

**Solution:** She opens Slide Master, inserts the logo in the top-right corner, and closes Master View. Now the logo appears on every slide automatically!

**CCC Exam Tip:** "Slide Master is used to ___" — Answer: **Apply uniform formatting to all slides**. Changes in Slide Master affect all slides using that layout.

## Copy, Cut, and Paste Operations

### Within a Presentation

| Operation | Shortcut | What It Does |
|-----------|----------|-------------|
| **Copy** | Ctrl + C | Copies selected text/object to clipboard |
| **Cut** | Ctrl + X | Removes and copies to clipboard |
| **Paste** | Ctrl + V | Pastes from clipboard |
| **Undo** | Ctrl + Z | Undoes the last action |
| **Redo** | Ctrl + Y | Redoes the undone action |
| **Select All** | Ctrl + A | Selects everything on the current slide |

### Copying Slides Between Presentations
1. Open both presentations
2. In the source presentation, right-click the slide → **Copy**
3. In the destination presentation, right-click where you want it → **Paste**
4. Choose paste option:
   - **Use Destination Theme** — matches the new presentation's design
   - **Keep Source Formatting** — keeps the original design

## Spell Check

PowerPoint automatically checks spelling as you type:
- Words with **red wavy underlines** have spelling errors
- Right-click the underlined word to see suggestions
- To run a full spell check: **Review** tab → **Spelling** (or press **F7**)

---

## Undo and Redo

- **Ctrl + Z** — Undo (goes back one step). You can press it multiple times to undo several actions.
- **Ctrl + Y** — Redo (restores the action you just undid)
- The Quick Access Toolbar also has Undo and Redo buttons (curved arrows)
