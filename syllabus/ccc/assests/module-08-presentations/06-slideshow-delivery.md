## Running a Slide Show

The **Slide Show** is the final output of your presentation — it displays your slides in full screen mode for the audience. This is the most important section for the CCC exam, with several frequently asked questions.

### Starting a Slide Show

| Method | Shortcut/Steps | What It Does |
|--------|---------------|-------------|
| **From Beginning** | **F5** | Starts from the **first slide** |
| **From Current Slide** | **Shift + F5** | Starts from the **currently selected slide** |
| **From Ribbon** | Slide Show tab → From Beginning | Starts from the first slide |
| **From Ribbon** | Slide Show tab → From Current Slide | Starts from current slide |
| **From Status Bar** | Click the slide show icon (bottom-right) | Starts from current slide |

**CCC Exam Tip:** This is the MOST frequently asked question from this module. "F5 in PowerPoint does ___" — Answer: **Starts slide show from the beginning**. "Shift+F5 does ___" — Answer: **Starts slide show from the current slide**. Memorize these shortcuts!

### Navigating During a Slide Show

| Action | Method |
|--------|--------|
| **Next slide** | Click mouse, Enter, Space, Right arrow, Down arrow, Page Down, N |
| **Previous slide** | Backspace, Left arrow, Up arrow, Page Up, P |
| **Go to specific slide** | Type slide number + Enter (e.g., 5 + Enter = go to slide 5) |
| **First slide** | Home key |
| **Last slide** | End key |
| **End slide show** | **Esc** key or right-click → End Show |
| **Black screen** | Press **B** (press again to return) |
| **White screen** | Press **W** (press again to return) |

### Pointer/Pen Options During Slide Show
During a slide show, you can use your mouse as a pointer or pen:
- Right-click → **Pointer Options** or press **Ctrl + P** for pen
- **Laser Pointer** — Red dot that follows your mouse (Ctrl + L)
- **Pen** — Draw on slides with a colored pen (Ctrl + P)
- **Highlighter** — Highlight text with a semi-transparent color
- **Eraser** — Erase pen/highlighter marks (Ctrl + E)
- **Arrow** — Normal mouse pointer (Ctrl + A)

After the show ends, PowerPoint asks if you want to **keep or discard** pen annotations.

## Presenter View

### What is Presenter View?
**Presenter View** is a special mode where the presenter sees additional information on their screen while the audience sees only the slide show.

### What the Presenter Sees (on their screen):
- Current slide (large)
- Next slide preview
- Speaker notes for the current slide
- Elapsed time / timer
- Slide navigation buttons
- Pointer/pen tools

### What the Audience Sees (on projector/screen):
- Only the current slide in full screen

### How to Enable Presenter View
1. Go to **Slide Show** tab
2. Check **Use Presenter View** in the Monitors group
3. Start the slide show
4. Presenter View requires **two displays** (laptop screen + projector)

### Presenter View Keyboard Shortcuts
| Shortcut | Action |
|----------|--------|
| Alt + F5 | Start Presenter View (even with one monitor) |
| Ctrl + S | Show All Slides (thumbnail grid to jump to any slide) |

**CCC Exam Tip:** Presenter View shows the current slide, next slide, speaker notes, and timer to the presenter while the audience sees only the current slide.

## Rehearse Timings

### What is Rehearse Timings?
**Rehearse Timings** allows you to practice your presentation while PowerPoint records how long you spend on each slide. This helps you:
- Estimate the total presentation time
- Set automatic slide advancement timings
- Practice staying within time limits

### How to Use Rehearse Timings
1. Go to **Slide Show** tab → **Rehearse Timings**
2. The slide show starts with a **Recording toolbar** in the top-left corner showing:
   - Current slide time
   - Total presentation time
   - Pause button
   - Repeat button (restart current slide timer)
   - Next button (advance to next slide)
3. Present your content as you would to an audience
4. Click through slides naturally
5. When finished, PowerPoint asks: **"Do you want to save the slide timings?"**
   - Click **Yes** to save (slides will auto-advance based on your rehearsal)
   - Click **No** to discard timings

### Viewing Saved Timings
- Switch to **Slide Sorter View** to see the timing displayed below each slide
- Example: Slide 1 (00:15), Slide 2 (00:30), Slide 3 (00:20)

## Set Up Slide Show

The **Set Up Show** dialog provides advanced options for controlling how your presentation runs.

### Accessing Set Up Show
Go to **Slide Show** tab → **Set Up Slide Show**

### Show Type Options

| Show Type | Description | Audience Control |
|-----------|-------------|-----------------|
| **Presented by a speaker (full screen)** | Normal full-screen presentation | Speaker controls navigation |
| **Browsed by an individual (window)** | Presentation runs in a window (like Reading View) | Individual controls navigation |
| **Browsed at a kiosk (full screen)** | Self-running, full-screen, loops continuously | No manual control — automatic |

### Kiosk Mode
**Kiosk mode** is a special self-running presentation mode:
- The presentation runs in **full screen** and **loops continuously**
- The audience **cannot manually advance** slides — only automatic timings work
- Press **Esc** to exit kiosk mode
- Perfect for: exhibition displays, lobby screens, trade show booths, information kiosks

**CCC Exam Tip:** "Kiosk mode in PowerPoint is used for ___" — Answer: **Self-running, looping presentations at public displays**. The presentation loops back to slide 1 after the last slide.

### Other Set Up Show Options

| Option | Description |
|--------|-------------|
| **Show slides:** | Choose all slides or a range (e.g., slides 3-8) |
| **Loop continuously until 'Esc'** | Presentation restarts after the last slide |
| **Show without animation** | Disables all animations |
| **Show without narration** | Disables recorded narration |
| **Pen color** | Choose the color for the pen tool |

## Automating a Slide Show

You can make your presentation run automatically without any clicks:

### Method 1: Set Transition Timings
1. Go to **Transitions** tab
2. In the Timing group, uncheck **On Mouse Click**
3. Check **After:** and set the time (e.g., 5 seconds)
4. Click **Apply to All**
5. Now slides advance automatically every 5 seconds

### Method 2: Use Rehearse Timings
1. Use **Rehearse Timings** (explained above) to set individual slide timings
2. Save the timings
3. Slides will advance based on your rehearsal

### Method 3: Record Slide Show
1. Go to **Slide Show** tab → **Record Slide Show**
2. This records your narration, timings, and pen annotations
3. The recorded show can play automatically with your voice-over

## Printing Presentations

PowerPoint offers several printing options to create different types of handouts.

### Accessing Print Options
Go to **File** → **Print** (or press **Ctrl + P**)

### Print Layout Options

| Layout | What It Prints | Best For |
|--------|---------------|----------|
| **Full Page Slides** | One slide per page (full size) | Projector slides, posters |
| **Notes Pages** | One slide + speaker notes per page | Presenter reference |
| **Outline** | Text-only outline of all slides | Content review |
| **Handouts (1 slide)** | 1 slide per page with borders | Detailed handouts |
| **Handouts (2 slides)** | 2 slides per page | Compact handouts |
| **Handouts (3 slides)** | 3 slides per page + lines for notes | Student handouts (most popular) |
| **Handouts (4 slides)** | 4 slides per page | Quick reference |
| **Handouts (6 slides)** | 6 slides per page | Compact overview |
| **Handouts (9 slides)** | 9 slides per page | Maximum slides per page |

**CCC Exam Tip:** "To print 3 slides per page with lines for notes, use ___" — Answer: **Handouts (3 slides per page)**. This is very frequently asked. The 3-slides-per-page handout includes ruled lines next to each slide for students to write notes.

### Print Settings

| Setting | Options |
|---------|---------|
| **Printer** | Select your printer |
| **Print Range** | All slides, current slide, custom range (e.g., 1-5, 8) |
| **Copies** | Number of copies |
| **Color/Grayscale** | Color, Grayscale, or Pure Black and White |
| **Collated** | Print complete sets (1,2,3... 1,2,3...) vs grouped (1,1... 2,2...) |

### Print Preview
- The Print dialog in PowerPoint shows a **preview** of what will be printed
- Use the navigation arrows to preview each page
- Verify the layout before clicking **Print**

## Exporting Presentations

### Export as PDF
1. Go to **File** → **Export** → **Create PDF/XPS Document**
2. Click **Create PDF/XPS**
3. Choose save location and click **Publish**
4. The PDF preserves your slide design and can be opened on any device

Alternative: **File → Save As → choose PDF** from the file type dropdown

### Export as Video
1. Go to **File** → **Export** → **Create a Video**
2. Choose quality:
   - Full HD (1080p) — Best quality, larger file
   - HD (720p) — Good quality
   - Standard (480p) — Smallest file
3. Set timing (use recorded timings or set default seconds per slide)
4. Click **Create Video**
5. Save as `.mp4` or `.wmv`

### Export as Images
1. **File → Save As** → Choose **JPEG** or **PNG** from file type dropdown
2. Choose:
   - **All Slides** — Each slide becomes a separate image file
   - **Just This One** — Only the current slide

### Export Options Summary

| Format | Extension | Use Case |
|--------|-----------|----------|
| PDF | .pdf | Sharing (non-editable, any device) |
| Video | .mp4 / .wmv | Self-playing presentations, YouTube |
| Images | .jpg / .png | Using slides in documents, social media |
| PowerPoint Show | .ppsx | Auto-play without editing |
