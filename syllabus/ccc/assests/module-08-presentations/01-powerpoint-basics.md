## What is Microsoft PowerPoint?

**Microsoft PowerPoint** is a presentation software developed by Microsoft. It is part of the Microsoft Office suite and is used to create visual presentations made up of individual **slides**. These presentations are used for:

- Classroom teaching and lectures
- Business meetings and project reports
- Conference talks and seminars
- Personal projects like photo albums and event planning

PowerPoint files are saved with the extension **`.pptx`** (in modern versions). Older versions used **`.ppt`**.

**CCC Exam Tip:** "The file extension of a PowerPoint presentation is ___" is a very frequently asked question. Answer: **`.pptx`** (or `.ppt` for older versions). This appears in almost every CCC exam.

## Starting Microsoft PowerPoint

### Method 1: From Start Menu
1. Click the **Start** button (Windows icon)
2. Search for **PowerPoint** in the search bar
3. Click **Microsoft PowerPoint** to open it

### Method 2: From Desktop Shortcut
- Double-click the PowerPoint icon on your Desktop (if available)

### Method 3: From File Explorer
- Right-click on empty space → **New** → **Microsoft PowerPoint Presentation**

When PowerPoint opens, you see the **Start Screen** where you can choose:
- **Blank Presentation** — Start from scratch
- **Templates** — Pre-designed layouts (business, education, etc.)
- **Recent files** — Previously opened presentations

## The PowerPoint Interface

When you open a blank presentation, you see the main PowerPoint window with these components:

### Key Parts of the PowerPoint Window

| Component | Location | Purpose |
|-----------|----------|---------|
| **Title Bar** | Top | Shows filename and "PowerPoint" |
| **Ribbon** | Below title bar | Contains all tools organized in tabs |
| **Slide Panel** | Left side | Thumbnail view of all slides |
| **Slide Area** | Center (large) | Main editing area for current slide |
| **Notes Panel** | Below slide area | Add speaker notes for each slide |
| **Status Bar** | Bottom | Slide number, view buttons, zoom slider |
| **Quick Access Toolbar** | Top-left | Common commands (Save, Undo, Redo) |

### The Ribbon

The **Ribbon** is the main toolbar in PowerPoint. It is organized into **tabs**, and each tab contains related tools grouped into **sections**.

| Tab | What It Contains |
|-----|-----------------|
| **File** | Open, Save, Save As, Print, Export, Close |
| **Home** | Clipboard, Slides, Font, Paragraph, Drawing, Editing |
| **Insert** | Table, Images, Shapes, SmartArt, Chart, Text, Media |
| **Design** | Themes, Variants, Slide Size, Format Background |
| **Transitions** | Transition effects between slides |
| **Animations** | Animation effects for objects on slides |
| **Slide Show** | Start show, Set up, Rehearse timings |
| **Review** | Spelling, Comments, Compare |
| **View** | Presentation views, Master views, Zoom |

**CCC Exam Tip:** The Ribbon contains all the tools you need. Know which tab each feature belongs to — for example, Transitions tab is for slide-to-slide effects, Animations tab is for object effects within a slide.

## PowerPoint Views

PowerPoint provides different ways to view your presentation. This is one of the most frequently tested topics in the CCC exam.

### 1. Normal View (Default)
- The **default view** when you open PowerPoint
- Shows the slide panel (left), main slide editing area (center), and notes panel (bottom)
- Used for **creating and editing** slides
- Most of your work happens in this view

### 2. Slide Sorter View
- Shows **all slides as small thumbnails** in a grid layout
- Useful for **rearranging slides** (drag and drop to reorder)
- Useful for **overview** — see the entire presentation at a glance
- You **cannot edit slide content** in this view, only rearrange/delete slides

### 3. Reading View
- Shows the presentation like a slide show but **within the PowerPoint window** (not full screen)
- Useful for **previewing** your presentation without going full screen
- You can still see the Windows taskbar

### 4. Slide Show View
- Shows the presentation in **full screen mode** — this is what the audience sees
- Press **F5** to start from the **first slide**
- Press **Shift + F5** to start from the **current slide**
- Press **Esc** to exit the slide show

### 5. Notes Page View
- Shows one slide per page with a large area for **speaker notes** below
- Useful for preparing detailed speaking notes for each slide
- Access from: **View tab → Notes Page**

### 6. Outline View
- Shows only the **text content** of slides in an outline format
- No images, shapes, or formatting visible
- Useful for focusing on the content structure

### View Comparison Table

| View | What You See | Best For |
|------|-------------|----------|
| **Normal** | Slide + panel + notes | Editing slides (default) |
| **Slide Sorter** | All slides as thumbnails | Rearranging slides |
| **Reading View** | Slide show in window | Quick preview |
| **Slide Show** | Full screen presentation | Presenting to audience |
| **Notes Page** | Slide + large notes area | Preparing speaker notes |
| **Outline** | Text-only outline | Content structure |

**CCC Exam Tip:** "Which view shows slides as thumbnails for rearranging?" — Answer: **Slide Sorter View**. "Which view is used for presenting to the audience?" — Answer: **Slide Show View**. These are very frequently asked.

## Opening, Saving, and Closing Presentations

### Opening a Presentation
1. **File → Open** (or **Ctrl + O**)
2. Browse to the location of your file
3. Select the `.pptx` file and click **Open**

### Saving a Presentation

| Action | Keyboard Shortcut | What It Does |
|--------|-------------------|-------------|
| **Save** | Ctrl + S | Saves to current location |
| **Save As** | F12 or Ctrl + Shift + S | Save with new name or location |

### Save Formats

| Format | Extension | Use |
|--------|-----------|-----|
| PowerPoint Presentation | **.pptx** | Default format (editable) |
| PowerPoint 97-2003 | .ppt | Old format (backward compatible) |
| PDF | .pdf | For sharing (non-editable) |
| PowerPoint Show | **.ppsx** | Opens directly in slide show mode |
| PowerPoint Template | .potx | Reusable template |
| JPEG/PNG | .jpg / .png | Save slides as images |

**CCC Exam Tip:** `.pptx` is the editable presentation format. `.ppsx` opens directly as a slide show (no editing view). `.pdf` is for sharing non-editable copies.

### Closing a Presentation
- **File → Close** (or **Ctrl + W**) — closes the file but keeps PowerPoint open
- **Alt + F4** — closes PowerPoint completely

## Slide Layouts

A **slide layout** is a pre-designed arrangement of placeholders for text, images, and other content. PowerPoint offers several built-in layouts.

### Common Slide Layouts

| Layout | Description |
|--------|-------------|
| **Title Slide** | Large title + subtitle (used for first slide) |
| **Title and Content** | Title + one large content area (most common) |
| **Section Header** | Section title + description (used to divide sections) |
| **Two Content** | Title + two side-by-side content areas |
| **Comparison** | Title + two labeled content areas for comparing |
| **Title Only** | Only a title placeholder |
| **Blank** | Completely empty slide |
| **Content with Caption** | Content area + caption text on the side |

### How to Change Slide Layout
1. Right-click on a slide in the slide panel
2. Select **Layout**
3. Choose the desired layout from the options

**CCC Exam Tip:** Know the common slide layouts. "Title Slide" is used for the first slide of a presentation. "Title and Content" is the most commonly used layout for regular slides.

## Creating a New Presentation

### From Blank
1. Open PowerPoint
2. Click **Blank Presentation**
3. The first slide (Title Slide layout) appears
4. Click on "Click to add title" and type your title
5. Click on "Click to add subtitle" and type your subtitle

### From Template
1. Open PowerPoint
2. Instead of Blank, search for a template (e.g., "Education", "Business")
3. Click on a template → Click **Create**
4. The template provides pre-designed slides with colors, fonts, and layouts
