## 1. PowerPoint Fundamentals

### What is PowerPoint?
Microsoft PowerPoint is presentation software used to create slide-based visual presentations. It is part of the Microsoft Office suite.

### File Extensions
| Extension | Format | Purpose |
|-----------|--------|---------|
| **.pptx** | PowerPoint Presentation | Default editable format |
| .ppt | PowerPoint 97-2003 | Old format (backward compatible) |
| **.ppsx** | PowerPoint Show | Opens directly in slide show |
| .potx | PowerPoint Template | Reusable template |
| .pdf | PDF | Non-editable sharing format |

**Key exam fact:** `.pptx` = editable presentation. `.ppsx` = opens directly as slide show.

### PowerPoint Interface
| Component | Location | Purpose |
|-----------|----------|---------|
| Title Bar | Top | Filename and "PowerPoint" |
| Ribbon | Below title bar | All tools in organized tabs |
| Slide Panel | Left side | Thumbnail previews of slides |
| Slide Area | Center | Main editing area |
| Notes Panel | Below slide area | Speaker notes |
| Status Bar | Bottom | Slide number, views, zoom |
| Quick Access Toolbar | Top-left | Save, Undo, Redo |

### Ribbon Tabs
| Tab | Contains |
|-----|----------|
| File | Open, Save, Print, Export |
| Home | Font, Paragraph, Slides, Drawing |
| Insert | Table, Pictures, Shapes, SmartArt, Chart, Media |
| Design | Themes, Variants, Background |
| Transitions | Slide transition effects |
| Animations | Object animation effects |
| Slide Show | Start show, Set up, Rehearse |
| Review | Spelling, Comments |
| View | Presentation views, Master views, Zoom |

## 2. PowerPoint Views

This is one of the most frequently tested areas. Know every view.

| View | What You See | Best For | Access |
|------|-------------|----------|--------|
| **Normal** | Slide + panel + notes | Editing (default view) | View tab |
| **Slide Sorter** | All slides as thumbnails in grid | Rearranging slides | View tab |
| **Reading View** | Slide show in window (not full screen) | Quick preview | View tab |
| **Slide Show** | Full screen presentation | Presenting to audience | F5 / Shift+F5 |
| **Notes Page** | Slide + large notes area | Preparing speaker notes | View tab |
| **Outline** | Text-only outline | Content structure | View tab |

**Key exam facts:**
- "Which view shows slides as thumbnails?" → **Slide Sorter View**
- "Default view in PowerPoint?" → **Normal View**
- "Which view is used for presenting?" → **Slide Show View**
- "Slide Sorter is best for?" → **Rearranging slides**

## 3. Creating and Managing Slides

### Creating Presentations
- **Blank Presentation** — Start from scratch
- **Template** — Pre-designed with themes, colors, fonts, layouts

### Slide Layouts
| Layout | Description |
|--------|-------------|
| Title Slide | Title + subtitle (first slide) |
| Title and Content | Title + content area (most common) |
| Two Content | Title + two side-by-side areas |
| Blank | Empty slide |
| Section Header | Section divider |
| Comparison | Two labeled areas for comparing |

### Slide Operations
| Operation | Method |
|-----------|--------|
| Insert new slide | Ctrl + M or Home → New Slide |
| Delete slide | Select → Delete key |
| Duplicate slide | Ctrl + D |
| Rearrange | Drag in Slide Panel or Slide Sorter View |
| Copy slide | Ctrl + C → Ctrl + V |

### Slide Master
- Controls appearance of ALL slides using that layout
- Set background, fonts, logos, colors once — applies everywhere
- Access: View tab → Slide Master
- Changes propagate to all slides automatically

## 4. Inserting Objects

All objects are inserted from the **Insert** tab.

### Tables
- Insert tab → Table → Select grid size
- Can also insert Word tables (Insert → Object → Microsoft Word Document)

### Pictures and Images
- Insert → Pictures → This Device (from computer)
- Insert → Pictures → Online Pictures (from internet)
- Resize: Drag corner handles (hold Shift for proportions)
- Format: Picture Format tab (crop, corrections, effects, borders)

### Shapes
- Insert → Shapes → Choose shape category
- Categories: Lines, Rectangles, Basic Shapes, Block Arrows, Flowchart, Callouts, Stars
- Can add text to shapes: Right-click → Add Text
- Format: Shape Format tab (fill, outline, effects)

### SmartArt
- Insert → SmartArt → Choose type
- Types: List, Process, Cycle, Hierarchy, Relationship, Matrix, Pyramid, Picture
- Used for graphical representations of information

### WordArt
- Insert → WordArt → Choose style
- Decorative text with special effects (shadow, glow, 3D)

### Charts
- Insert → Chart → Choose chart type
- Excel-like data sheet opens for entering data
- Types: Column, Line, Pie, Bar, Area, Scatter

### Object Manipulation
| Action | Method |
|--------|--------|
| Resize proportionally | Drag corner handle + Shift |
| Move | Click and drag |
| Nudge | Arrow keys |
| Align | Format tab → Align options |
| Group | Select multiple → Right-click → Group |
| Bring to Front | Format tab → Arrange → Bring to Front |
| Send to Back | Format tab → Arrange → Send to Back |

## 5. Slide Design and Themes

### Themes
- Coordinated set of colors, fonts, effects, and backgrounds
- Applied from Design tab
- Right-click theme → Apply to All Slides or Selected Slides

### Variants
- Color variations of the same theme
- Design tab → Variants section

### Background
- Design tab → Format Background
- Types: Solid fill, Gradient fill, Picture/texture fill, Pattern fill

### Headers and Footers
- Insert tab → Header & Footer
- Options: Date/time, Slide number, Footer text
- Can hide on title slide

### Color Schemes
- Set of coordinated colors for text, background, and accents
- Design tab → Variants → Colors

### Font Formatting
| Shortcut | Action |
|----------|--------|
| Ctrl + B | Bold |
| Ctrl + I | Italic |
| Ctrl + U | Underline |
| Ctrl + ] | Increase font size |
| Ctrl + [ | Decrease font size |

## 6. Transitions vs Animations

**This is the most critical distinction in this module.**

| Feature | Transition | Animation |
|---------|-----------|-----------|
| Applied to | **Between slides** | **Objects within a slide** |
| Affects | How slides change | How text/images/shapes behave |
| Tab | Transitions tab | Animations tab |
| Example | Fade between slide 1 and 2 | Title text flying into slide 1 |

### Transitions
- Visual effect when moving from one slide to the next
- Categories: Subtle (Fade, Push, Wipe), Exciting (Dissolve, Checkerboard), Dynamic (Cube, Doors)
- **Apply to All** button applies same transition to every slide
- Timing options: On Mouse Click, After (set seconds), or Both
- Sound can be added to transitions

### Animations — Four Types
| Type | Effect | Color |
|------|--------|-------|
| **Entrance** | Object appears | Green |
| **Emphasis** | Object draws attention | Yellow |
| **Exit** | Object disappears | Red |
| **Motion Path** | Object moves along path | Blue |

### Animation Controls
- **On Click** — Plays when mouse clicked
- **With Previous** — Plays simultaneously with previous animation
- **After Previous** — Plays after previous animation finishes
- **Animation Pane** — Shows all animations in order, allows reordering
- **Add Animation** — Adds additional animation (without replacing existing)
- **Duration** — How long animation takes
- **Delay** — Wait time before animation starts

## 7. Slide Show and Delivery

### Starting Slide Show
| Method | What It Does |
|--------|-------------|
| **F5** | **Start from FIRST slide** |
| **Shift + F5** | **Start from CURRENT slide** |
| Slide Show tab → From Beginning | Same as F5 |
| Slide Show tab → From Current | Same as Shift + F5 |

### Navigation During Show
| Key | Action |
|-----|--------|
| Click / Enter / Space / N | Next slide |
| Backspace / P | Previous slide |
| Number + Enter | Jump to specific slide |
| Home | First slide |
| End | Last slide |
| Esc | End show |
| B | Black screen |
| W | White screen |

### Pointer Tools During Show
| Shortcut | Tool |
|----------|------|
| Ctrl + P | Pen |
| Ctrl + L | Laser pointer |
| Ctrl + A | Arrow (normal pointer) |
| Ctrl + E | Eraser |

### Presenter View
- Shows current slide, next slide, notes, and timer to presenter
- Audience sees only the current slide
- Requires two displays (laptop + projector)
- Enable: Slide Show tab → Use Presenter View

### Rehearse Timings
- Slide Show tab → Rehearse Timings
- Records time spent on each slide
- Saved timings can auto-advance slides
- View timings in Slide Sorter View

### Set Up Show — Show Types
| Type | Description |
|------|-------------|
| Presented by speaker | Normal full-screen (default) |
| Browsed by individual | Runs in a window |
| **Browsed at kiosk** | Self-running, loops, no manual control |

**Key exam fact:** Kiosk mode = self-running + looping + no manual navigation.

### Automating Slide Show
1. Set transition timing (Transitions tab → After: seconds → Apply to All)
2. Use Rehearse Timings (records your practice timings)
3. Record Slide Show (records narration + timings)

## 8. Printing and Exporting

### Print Layouts
| Layout | Slides Per Page | Notes |
|--------|----------------|-------|
| Full Page Slides | 1 | Full size |
| Notes Pages | 1 + notes | With speaker notes |
| Outline | Text only | Content structure |
| **Handouts (3 per page)** | 3 + lines | Most popular for students |
| Handouts (6 per page) | 6 | Compact reference |

**Key exam fact:** "Print 3 slides per page with note lines" = **Handouts (3 slides per page)**.

### Print shortcut: **Ctrl + P**

### Export Formats
| Format | Extension | Use |
|--------|-----------|-----|
| PDF | .pdf | Non-editable sharing |
| Video | .mp4 / .wmv | Self-playing |
| Images | .jpg / .png | Individual slide images |
| Show | .ppsx | Auto-play presentation |
