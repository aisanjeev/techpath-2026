# Inserting Objects in Slides

**Module 08 — CCC Exam Preparation | Topic 3**

---

## Overview

PowerPoint slides can contain much more than just text. You can insert various objects to make your presentations visually engaging and informative. All insertion tools are found in the **Insert** tab of the Ribbon.

Objects you can insert:
- Tables (from Word or directly)
- Excel Worksheets/Charts
- Pictures and Clip Art
- Shapes and Lines
- SmartArt Graphics
- WordArt (decorative text)

---

## Inserting a Table

Tables are used to present data in organized rows and columns.

### Method 1: Insert a PowerPoint Table
1. Go to **Insert** tab → **Table**
2. Move your mouse over the grid to select the number of rows and columns (e.g., 4x3 = 4 columns, 3 rows)
3. Click to insert the table
4. Click inside each cell to type data
5. Use the **Table Design** tab to change colors, borders, and styles

### Method 2: Insert a Word Table
1. Go to **Insert** tab → **Object**
2. Select **Microsoft Word Document**
3. A Word editing area appears on the slide
4. Create your table in Word (Insert → Table)
5. Click outside the Word area to return to PowerPoint

## Inserting an Excel Worksheet

You can insert live Excel data into your PowerPoint slides.

### Method 1: Insert an Excel Object
1. Go to **Insert** tab → **Object**
2. Select **Microsoft Excel Worksheet**
3. An Excel editing area appears on the slide
4. Enter your data and create formulas
5. Click outside the Excel area to return to PowerPoint

### Method 2: Copy-Paste from Excel
1. Open your Excel file
2. Select the cells you want to copy
3. Press **Ctrl + C** (Copy)
4. Switch to PowerPoint
5. Press **Ctrl + V** (Paste)
6. Choose a paste option:
   - **Keep Source Formatting** — looks like the original Excel data
   - **Use Destination Theme** — matches the PowerPoint design
   - **Embed** — embeds a live Excel object (double-click to edit)
   - **Picture** — pastes as an image (cannot edit data)
   - **Keep Text Only** — pastes as plain text

### Method 3: Insert an Excel Chart
1. Go to **Insert** tab → **Chart**
2. Select a chart type (Column, Pie, Line, Bar, etc.)
3. An Excel-like data sheet opens
4. Enter your data in the sheet
5. Close the data sheet — the chart appears on the slide

**CCC Exam Tip:** You can insert both Word tables and Excel worksheets into PowerPoint slides. The Insert tab is used for adding all types of objects.

## Inserting Pictures and Clip Art

### Inserting a Picture from Your Computer
1. Go to **Insert** tab → **Pictures** → **This Device**
2. Browse to the folder containing your image
3. Select the image file and click **Insert**
4. Resize the image by dragging the corner handles (hold **Shift** to maintain proportions)

### Inserting Online Pictures
1. Go to **Insert** tab → **Pictures** → **Online Pictures**
2. Search for an image using keywords
3. Select an image and click **Insert**

### Inserting Clip Art
In older versions of PowerPoint, Clip Art was a separate feature. In modern versions (2016+), it is integrated into **Online Pictures**.

1. Go to **Insert** tab → **Pictures** → **Online Pictures**
2. Search for clip art style images
3. Select and insert

### Image Formatting Options
After inserting a picture, the **Picture Format** tab appears with these options:

| Option | What It Does |
|--------|-------------|
| **Corrections** | Adjust brightness and contrast |
| **Color** | Change color tone or make grayscale |
| **Artistic Effects** | Apply effects like blur, paint, sketch |
| **Crop** | Cut unwanted parts of the image |
| **Picture Border** | Add a border around the image |
| **Picture Effects** | Shadow, reflection, glow, 3D rotation |
| **Remove Background** | Remove the background of an image |

## Inserting Shapes

Shapes are basic geometric objects used to create diagrams, flowcharts, and visual elements.

### How to Insert a Shape
1. Go to **Insert** tab → **Shapes**
2. Choose from categories:
   - **Lines** — Straight line, arrow, curved line
   - **Rectangles** — Square, rounded rectangle
   - **Basic Shapes** — Circle, triangle, diamond, heart, star
   - **Block Arrows** — Large directional arrows
   - **Flowchart** — Process, decision, terminator shapes
   - **Callouts** — Speech bubbles and annotations
   - **Stars and Banners** — Decorative elements
3. Click and drag on the slide to draw the shape
4. Use the **Shape Format** tab to change color, border, and effects

### Formatting Shapes
- **Shape Fill** — Change the interior color or add a gradient/pattern
- **Shape Outline** — Change border color, thickness, and style
- **Shape Effects** — Add shadow, reflection, glow, 3D effects
- **Add Text** — Right-click on a shape → **Add Text** (or just start typing while shape is selected)

## Inserting SmartArt

**SmartArt** provides pre-designed graphical representations of information. It is used to create professional-looking diagrams quickly.

### How to Insert SmartArt
1. Go to **Insert** tab → **SmartArt**
2. Choose from categories:

| Category | Best For | Example |
|----------|----------|---------|
| **List** | Bulleted information | Simple list with icons |
| **Process** | Step-by-step procedures | Flowchart of steps |
| **Cycle** | Repeating processes | Water cycle, product lifecycle |
| **Hierarchy** | Organization charts | Company structure |
| **Relationship** | Connections between items | Venn diagram |
| **Matrix** | Four-quadrant layout | SWOT analysis |
| **Pyramid** | Proportional relationships | Food pyramid |
| **Picture** | Image-based layouts | Photo gallery |

3. Select a SmartArt type and click **OK**
4. Click on each text box in the SmartArt and type your content
5. Use the **SmartArt Design** tab to change colors and styles

### Example: Process SmartArt
Create a "How to Send an Email" process diagram:
```
Step 1: Open Gmail → Step 2: Click Compose → Step 3: Enter To address →
Step 4: Type message → Step 5: Click Send
```

**CCC Exam Tip:** SmartArt is used to create **graphical representations** of information. Know the SmartArt categories — especially Process (steps), Hierarchy (org charts), and Cycle (repeated processes).

## Inserting WordArt

**WordArt** creates decorative text with special effects like shadows, outlines, and gradients.

### How to Insert WordArt
1. Go to **Insert** tab → **WordArt**
2. Select a WordArt style from the gallery
3. A text box appears — type your decorative text
4. Use the **Shape Format** tab to modify:
   - Text Fill (color, gradient)
   - Text Outline (border)
   - Text Effects (shadow, reflection, glow, 3D)

### When to Use WordArt
- Slide titles that need visual impact
- Headings and section dividers
- Decorative text elements
- Logo text

## Resizing, Moving, and Aligning Objects

### Resizing Objects
- Click on the object to select it (handles appear around it)
- Drag a **corner handle** to resize proportionally (hold **Shift** for exact proportions)
- Drag a **side handle** to stretch horizontally or vertically
- Use the **Size** options in the Format tab for exact dimensions

### Moving Objects
- Click and drag the object to any position on the slide
- Use **arrow keys** for precise small movements (nudging)
- Hold **Ctrl + arrow keys** for even finer movement

### Aligning Objects
To align multiple objects perfectly:
1. Select multiple objects (hold **Ctrl** and click each one, or **Ctrl + A** for all)
2. Go to **Shape Format** tab → **Align**
3. Choose alignment options:
   - **Align Left** — All objects line up on the left
   - **Align Center** — All objects center horizontally
   - **Align Right** — All objects line up on the right
   - **Align Top** — All objects line up at the top
   - **Align Middle** — All objects center vertically
   - **Align Bottom** — All objects line up at the bottom
   - **Distribute Horizontally** — Equal spacing between objects
   - **Distribute Vertically** — Equal spacing top to bottom

### Arranging Object Order
When objects overlap, you can control which one appears on top:
- **Bring to Front** — Move object to the top layer
- **Send to Back** — Move object to the bottom layer
- **Bring Forward** — Move one layer up
- **Send Backward** — Move one layer down

Access from: **Shape Format** tab → **Arrange** group

## Grouping Objects

You can **group** multiple objects together so they behave as a single object.

1. Select multiple objects (hold **Ctrl** and click each)
2. Right-click → **Group** → **Group**
3. Now all selected objects move, resize, and rotate as one unit
4. To ungroup: Right-click → **Group** → **Ungroup**

## Key Terms to Remember

| Term | Meaning |
|------|---------|
| Table | Rows and columns for organized data |
| Picture | Image file inserted into a slide |
| Clip Art | Pre-made illustrations (now part of Online Pictures) |
| Shape | Geometric object (rectangle, circle, arrow, etc.) |
| SmartArt | Pre-designed graphical diagram |
| WordArt | Decorative text with special effects |
| Resize | Change the size of an object |
| Align | Line up objects precisely |
| Group | Combine multiple objects into one unit |
| Crop | Cut unwanted parts of an image |
