# Slide Design and Themes

**Module 08 — CCC Exam Preparation | Topic 4**

## What are Themes?

A **theme** in PowerPoint is a coordinated set of design elements that gives your presentation a consistent and professional look. A theme includes:

- **Colors** — A palette of coordinated colors for text, backgrounds, and accents
- **Fonts** — A pair of fonts (one for headings, one for body text)
- **Effects** — Visual effects for shapes and objects (shadows, reflections, etc.)
- **Background styles** — Slide background design

When you apply a theme, all slides in your presentation automatically update to match the theme's design.

---

## Applying a Theme

### Method 1: From the Design Tab
1. Go to the **Design** tab in the Ribbon
2. You will see a gallery of available themes
3. Hover over a theme to see a **live preview** on your slide
4. Click the theme to apply it to your entire presentation

### Method 2: Right-Click Options
1. In the Design tab, right-click on any theme
2. Choose:
   - **Apply to All Slides** — Changes the theme for every slide
   - **Apply to Selected Slides** — Changes only the currently selected slide(s)

### Built-in Theme Examples
PowerPoint comes with many built-in themes. Some popular ones include:
- Office (default clean theme)
- Facet (modern geometric design)
- Integral (professional with accent bars)
- Ion (bold and contemporary)
- Retrospect (classic professional look)

---

## Theme Variants

After selecting a theme, you can choose **Variants** — different color schemes for the same theme design.

1. In the **Design** tab, look at the **Variants** section (to the right of themes)
2. You will see 4 color variations of the current theme
3. Click any variant to apply it
4. Click the **dropdown arrow** on Variants for more options:
   - **Colors** — Change the color palette
   - **Fonts** — Change the font pair
   - **Effects** — Change shape effects
   - **Background Styles** — Change the background

## Color Schemes

### What is a Color Scheme?
A **color scheme** is a set of coordinated colors used throughout the presentation. It typically includes:
- **Background colors** (light or dark)
- **Text colors** (contrasting with background)
- **Accent colors** (for shapes, charts, and highlights)
- **Hyperlink colors** (for clickable links)

### Changing the Color Scheme
1. **Design** tab → **Variants** dropdown → **Colors**
2. Choose from built-in color schemes or create a custom one
3. Click **Customize Colors** to create your own color scheme

### Tips for Good Color Choices
- Use **high contrast** between text and background (dark text on light background or vice versa)
- Limit accent colors to 2-3 for a clean look
- Avoid red text on green background (difficult for colorblind viewers)
- Use consistent colors throughout the presentation

## Font Formatting

### Changing Fonts
You can format text using the **Home** tab or the **mini toolbar** (appears when you select text).

| Property | How to Change | Location |
|----------|-------------|----------|
| **Font family** | Select from font dropdown | Home tab |
| **Font size** | Select from size dropdown or type | Home tab |
| **Bold** | Click B button or Ctrl + B | Home tab |
| **Italic** | Click I button or Ctrl + I | Home tab |
| **Underline** | Click U button or Ctrl + U | Home tab |
| **Font color** | Click Font Color dropdown (A icon) | Home tab |
| **Text shadow** | Click Shadow button (S icon) | Home tab |
| **Strikethrough** | Click Strikethrough button | Home tab |
| **Character spacing** | Font dialog → Character Spacing tab | Home tab (dialog launcher) |
| **Superscript** | Select text → Home → Superscript | Home tab |
| **Subscript** | Select text → Home → Subscript | Home tab |

### Font Size Shortcuts

| Shortcut | Action |
|----------|--------|
| Ctrl + ] | Increase font size |
| Ctrl + [ | Decrease font size |
| Ctrl + Shift + > | Increase to next standard size |
| Ctrl + Shift + < | Decrease to next standard size |

### Recommended Font Sizes

| Element | Recommended Size |
|---------|-----------------|
| Slide title | 36-44 pt |
| Subtitle | 24-32 pt |
| Body text | 18-24 pt |
| Footnotes/captions | 14-16 pt |

**CCC Exam Tip:** Text should be large enough to read from the back of a room. Minimum body text size for presentations is generally **18 pt**.

## Background Styles

### Changing Slide Background
1. Go to **Design** tab → **Format Background** (right side)
2. A panel opens on the right with these options:

| Background Type | Description |
|----------------|-------------|
| **Solid fill** | Single solid color |
| **Gradient fill** | Gradual blend between two or more colors |
| **Picture or texture fill** | Image or texture as background |
| **Pattern fill** | Repeating geometric pattern |

### Applying Background
- **Apply to All** — Changes background for every slide
- **Close** — Changes only the current slide

### Tips for Good Backgrounds
- Keep backgrounds simple — they should not distract from content
- Ensure text is readable against the background
- Avoid busy images as backgrounds (they make text hard to read)
- Use the same background style throughout for consistency

## Slide Design Consistency

### Why Consistency Matters
A professional presentation should have a **consistent design** throughout. This means:
- Same theme and color scheme on all slides
- Same font family for titles and body text
- Same style of bullet points
- Consistent placement of titles and content
- Same background on all slides (or intentional variations)

### Using Slide Master for Consistency
The best way to ensure consistency is to use the **Slide Master** (View → Slide Master):
- Set fonts, colors, and backgrounds once in the master
- All slides automatically follow the master design
- Changes to the master update all slides instantly

## Headers and Footers

### What are Headers and Footers?
**Headers and footers** are text that appears at the top (header) or bottom (footer) of every slide. Common uses:
- Slide numbers
- Date and time
- Company name or presentation title
- Confidentiality notice

### Inserting Headers and Footers
1. Go to **Insert** tab → **Header & Footer**
2. A dialog box appears with these options:

| Option | Description |
|--------|-------------|
| **Date and time** | Shows current date (auto-update) or a fixed date |
| **Slide number** | Shows the slide number on each slide |
| **Footer** | Custom text at the bottom of each slide |
| **Don't show on title slide** | Hides the footer on the first (title) slide |

3. Check the options you want
4. Click **Apply to All** (all slides) or **Apply** (current slide only)

### Example Footer Setup for CCC Presentation
- Date and time: Fixed → "July 2026"
- Slide number: Checked (appears as 1, 2, 3...)
- Footer text: "TechPath Institute — CCC Exam Preparation"
- Don't show on title slide: Checked

## Slide Numbering

### Adding Slide Numbers
1. **Insert** tab → **Slide Number** (or Insert → Header & Footer → check Slide Number)
2. Click **Apply to All**
3. Slide numbers appear on every slide (except the title slide if you chose to hide them)

### Changing Starting Slide Number
By default, slide numbering starts at 1. To change:
1. Go to **Design** tab → **Slide Size** → **Custom Slide Size**
2. Change the **Number slides from:** value
3. Click **OK**

**CCC Exam Tip:** Slide numbering is inserted from the **Insert** tab using **Header & Footer**. You can choose to hide slide numbers on the title slide.

## Slide Size

### Changing Slide Size
1. Go to **Design** tab → **Slide Size**
2. Choose:
   - **Standard (4:3)** — Traditional screen ratio (older projectors)
   - **Widescreen (16:9)** — Modern widescreen ratio (default in newer PowerPoint)
   - **Custom Slide Size** — Set exact dimensions

### When to Use Each Size
| Size | Ratio | Best For |
|------|-------|----------|
| Standard | 4:3 | Older projectors, printing |
| Widescreen | 16:9 | Modern laptops, LCD projectors, TVs |

## Key Terms to Remember

| Term | Meaning |
|------|---------|
| Theme | Coordinated design (colors, fonts, effects, background) |
| Variant | Color variation of a theme |
| Color Scheme | Set of coordinated colors for the presentation |
| Background | The base design behind slide content |
| Font | The typeface used for text (e.g., Calibri, Arial) |
| Header | Text at the top of slides |
| Footer | Text at the bottom of slides (date, slide number, custom text) |
| Slide Number | Sequential number on each slide |
| Slide Master | Master slide controlling design of all slides |
| Gradient | Gradual blend between two or more colors |
| Consistency | Uniform design throughout the presentation |
