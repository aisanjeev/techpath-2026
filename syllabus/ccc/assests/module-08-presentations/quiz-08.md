# Quiz: Making Small Presentations

**Module 08 — CCC Exam Preparation**

---

### Q1. Pressing F5 in PowerPoint starts the slide show from ___.

- A) The current slide
- B) The last slide
- C) The first slide ✅
- D) A random slide

> **Explanation:** F5 starts the slide show from the very first slide (beginning of the presentation). To start from the current slide, use Shift+F5.

---

### Q2. Pressing Shift+F5 in PowerPoint starts the slide show from ___.

- A) The first slide
- B) The current slide ✅
- C) The last slide
- D) Slide number 5

> **Explanation:** Shift+F5 starts the slide show from the currently selected (active) slide. F5 starts from the first slide.

---

### Q3. Which view in PowerPoint shows all slides as small thumbnails for rearranging?

- A) Normal View
- B) Slide Sorter View ✅
- C) Reading View
- D) Outline View

> **Explanation:** Slide Sorter View displays all slides as small thumbnails in a grid layout, making it easy to rearrange slides by dragging and dropping.

---

### Q4. A slide transition is applied between ___.

- A) Objects on a slide
- B) Text and images
- C) Two slides ✅
- D) Paragraphs in text

> **Explanation:** A transition is a visual effect that occurs when moving from one slide to the next. It is applied between two slides, not to objects within a slide.

---

### Q5. An animation in PowerPoint is applied to ___.

- A) Slides
- B) The entire presentation
- C) Objects within a slide ✅
- D) The slide background

> **Explanation:** Animations are applied to individual objects (text boxes, images, shapes, charts) within a slide. Transitions are applied between slides.

---

### Q6. To print 3 slides per page with lines for notes, you should use ___.

- A) Full Page Slides
- B) Notes Pages
- C) Outline
- D) Handouts ✅

> **Explanation:** Handouts with 3 slides per page include three slide thumbnails on the left and ruled lines on the right for the audience to write notes. This is the most popular handout format.

---

### Q7. The file extension of a PowerPoint presentation is ___.

- A) .docx
- B) .xlsx
- C) .pptx ✅
- D) .pdf

> **Explanation:** PowerPoint presentations are saved with the .pptx extension. .docx is for Word, .xlsx is for Excel, and .pdf is a portable document format.

---

### Q8. Which PowerPoint view is the default editing view?

- A) Slide Sorter View
- B) Slide Show View
- C) Normal View ✅
- D) Reading View

> **Explanation:** Normal View is the default view in PowerPoint. It shows the slide panel on the left, the main editing area in the center, and the notes panel at the bottom.

---

### Q9. Which type of animation makes an object appear on the slide?

- A) Exit
- B) Emphasis
- C) Motion Path
- D) Entrance ✅

> **Explanation:** Entrance animations make objects appear on the slide (e.g., Fly In, Fade, Zoom). Exit animations make objects disappear. Emphasis animations draw attention to objects already on the slide.

---

### Q10. The Slide Master is used to ___.

- A) Delete all slides at once
- B) Apply uniform formatting to all slides ✅
- C) Convert presentation to PDF
- D) Start the slide show

> **Explanation:** The Slide Master controls the appearance (fonts, colors, backgrounds, logos) of all slides that use its layout. Changes to the Slide Master are automatically applied to all slides.

---

### Q11. A .ppsx file opens directly in ___ mode.

- A) Normal editing
- B) Slide Sorter
- C) Slide Show ✅
- D) Outline

> **Explanation:** A .ppsx (PowerPoint Show) file opens directly in Slide Show mode, showing the presentation full screen without the editing interface. A .pptx file opens in editing mode.

---

### Q12. What does pressing 'B' during a slide show do?

- A) Goes back to the previous slide
- B) Makes the screen black ✅
- C) Opens the browser
- D) Applies bold formatting

> **Explanation:** Pressing 'B' during a slide show turns the screen black (useful for pausing the presentation to talk without visual distraction). Press 'B' again to return to the slide. 'W' turns the screen white.

---

### Q13. SmartArt in PowerPoint is used to create ___.

- A) Spreadsheet formulas
- B) Graphical representations of information ✅
- C) Email messages
- D) Web pages

> **Explanation:** SmartArt provides pre-designed graphical layouts for presenting information visually, such as process flows, hierarchies, cycles, and lists.

---

### Q14. Which keyboard shortcut inserts a new slide in PowerPoint?

- A) Ctrl + N
- B) Ctrl + M ✅
- C) Ctrl + S
- D) Ctrl + D

> **Explanation:** Ctrl + M inserts a new slide in PowerPoint. Ctrl + N creates a new blank presentation, Ctrl + S saves, and Ctrl + D duplicates the selected slide.

---

### Q15. Kiosk mode in PowerPoint is used for ___.

- A) Editing slides quickly
- B) Printing handouts
- C) Self-running presentations that loop continuously ✅
- D) Recording narration

> **Explanation:** Kiosk mode (Set Up Show - Browsed at a kiosk) creates a self-running, full-screen presentation that loops continuously. The audience cannot manually advance slides — only automatic timings work.
