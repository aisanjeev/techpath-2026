# Animations and Transitions

**Module 08 — CCC Exam Preparation | Topic 5**

---

## Understanding the Difference: Transitions vs Animations

This is one of the most important distinctions in the CCC exam. Many students confuse transitions with animations.

| Feature | Transition | Animation |
|---------|-----------|-----------|
| **Applied to** | Between slides (slide-to-slide) | Objects within a slide |
| **What it affects** | How one slide changes to the next | How text, images, shapes move on a slide |
| **Tab in Ribbon** | Transitions tab | Animations tab |
| **Example** | Fade, Push, Wipe between slides | Text flying in, image zooming, shape bouncing |

**CCC Exam Tip:** This is VERY frequently asked. "A transition is applied between ___" — Answer: **Slides**. "An animation is applied to ___" — Answer: **Objects within a slide**. Remember: Transition = between slides, Animation = within a slide.

## Slide Transitions

### What is a Slide Transition?
A **slide transition** is a visual effect that occurs when you move from one slide to the next during a presentation. It controls **how** the current slide exits and the next slide enters.

### Types of Transitions

PowerPoint groups transitions into three categories:

#### 1. Subtle Transitions (Professional, minimal)
| Transition | Effect |
|-----------|--------|
| **None** | No effect — instant change |
| **Cut** | Instant switch (like cutting a film) |
| **Fade** | Current slide fades out, next fades in |
| **Push** | Next slide pushes current slide off screen |
| **Wipe** | Next slide wipes over the current slide |
| **Split** | Slide splits open to reveal the next one |
| **Reveal** | Current slide moves away to reveal the next |

#### 2. Exciting Transitions (More dramatic)
| Transition | Effect |
|-----------|--------|
| **Dissolve** | Slide dissolves into small pieces |
| **Checkerboard** | Slide changes in a checkerboard pattern |
| **Blinds** | Like opening window blinds |
| **Clock** | Circular wipe like a clock hand |
| **Ripple** | Water ripple effect |
| **Honeycomb** | Hexagonal pattern transition |
| **Glitter** | Sparkle effect |

#### 3. Dynamic Content Transitions
| Transition | Effect |
|-----------|--------|
| **Pan** | Slides pan across like a camera |
| **Ferris Wheel** | Rotation effect |
| **Conveyor** | Slides move like a conveyor belt |
| **Rotate** | 3D rotation effect |
| **Cube** | 3D cube rotation |
| **Doors** | Slide opens like doors |

### How to Apply a Transition
1. Select the slide in the Slide Panel (or select multiple slides)
2. Go to the **Transitions** tab
3. Click on a transition effect to apply it
4. You will see a preview of the transition
5. To preview again, click **Preview** on the left side of the Transitions tab

### Transition Options

| Option | What It Does |
|--------|-------------|
| **Effect Options** | Change direction (top, bottom, left, right) |
| **Sound** | Add sound during transition (Applause, Breeze, etc.) |
| **Duration** | How long the transition takes (in seconds) |
| **Apply to All** | Apply the same transition to every slide |

### Applying Transition to All Slides
- Select any slide
- Choose a transition
- Click **Apply to All** button in the Transitions tab
- Now every slide will use the same transition

**CCC Exam Tip:** "To apply the same transition to all slides, click ___" — Answer: **Apply to All** button in the Transitions tab. This is frequently asked.

### Transition Timing

You can control how slides advance:

| Option | Description |
|--------|-------------|
| **On Mouse Click** | Advance to next slide when you click the mouse |
| **After:** | Advance automatically after a set time (e.g., 00:05.00 = 5 seconds) |
| **Both** | Either click or wait for the timer |

To set automatic timing:
1. In the **Transitions** tab → **Timing** group
2. Uncheck **On Mouse Click** (if you want automatic only)
3. Check **After:** and set the time (e.g., 5 seconds)
4. Click **Apply to All** for all slides

## Animations

### What is an Animation?
An **animation** is a visual effect applied to an **object** (text, image, shape, chart) **within a slide**. Animations control how objects appear, move, or disappear on the slide.

### Four Types of Animations

| Type | What It Does | Icon Color | Example |
|------|-------------|------------|---------|
| **Entrance** | Object appears on the slide | Green | Text flies in from left |
| **Emphasis** | Object draws attention while on slide | Yellow | Text grows bigger, changes color |
| **Exit** | Object leaves/disappears from the slide | Red | Image fades out |
| **Motion Path** | Object moves along a defined path | Blue | Shape moves from corner to center |

**CCC Exam Tip:** Know the four types of animations. "Entrance animations" make objects appear, "Exit animations" make them disappear, "Emphasis" highlights objects, and "Motion Path" moves objects along a path.

### Common Animation Effects

#### Entrance Animations
| Effect | Description |
|--------|-------------|
| **Appear** | Object suddenly appears (no effect) |
| **Fade** | Object gradually fades in |
| **Fly In** | Object flies in from a direction |
| **Float In** | Object floats gently into position |
| **Split** | Object appears by splitting open |
| **Wipe** | Object is revealed by a wipe effect |
| **Zoom** | Object zooms in from small to normal size |
| **Bounce** | Object bounces into position |

#### Emphasis Animations
| Effect | Description |
|--------|-------------|
| **Pulse** | Object briefly gets larger then returns |
| **Spin** | Object rotates |
| **Grow/Shrink** | Object changes size |
| **Change Font Color** | Text color changes |
| **Bold Flash** | Text becomes bold briefly |

#### Exit Animations
| Effect | Description |
|--------|-------------|
| **Disappear** | Object suddenly vanishes |
| **Fade** | Object gradually fades out |
| **Fly Out** | Object flies off the slide |
| **Float Out** | Object floats away |
| **Zoom** | Object shrinks and disappears |

#### Motion Path Animations
| Effect | Description |
|--------|-------------|
| **Lines** | Move in a straight line |
| **Arcs** | Move in a curved path |
| **Turns** | Move with turns |
| **Shapes** | Move in shape patterns (circle, star) |
| **Custom Path** | Draw your own path |

## Applying Animations

### Adding an Animation
1. Select the object you want to animate (text box, image, shape)
2. Go to the **Animations** tab
3. Click on an animation effect from the gallery
4. A number appears on the object showing the animation order
5. Click **Preview** to see the animation

### Animation Options

| Option | What It Does |
|--------|-------------|
| **Effect Options** | Change direction, sequence, or style |
| **Trigger** | Start animation on click of a specific object |
| **Duration** | How long the animation takes |
| **Delay** | Wait time before animation starts |

### Start Options for Animations

| Start Option | Description |
|-------------|-------------|
| **On Click** | Animation plays when you click the mouse |
| **With Previous** | Animation plays at the same time as the previous animation |
| **After Previous** | Animation plays automatically after the previous one finishes |

## Animation Pane

The **Animation Pane** is a panel that shows all animations on the current slide in order. It is essential for managing complex animations.

### Opening Animation Pane
1. Go to **Animations** tab → **Animation Pane** (in the Advanced Animation group)
2. A panel opens on the right side showing all animations

### What You Can Do in Animation Pane
- See the **order** of all animations (numbered list)
- **Reorder** animations by dragging them up or down
- **Change timing** — adjust start, duration, and delay
- **Play** all animations to preview
- **Delete** animations by selecting and pressing Delete
- See animation **type** by icon color (green = entrance, yellow = emphasis, red = exit)

### Reordering Animations
1. Open the Animation Pane
2. Click on an animation in the list
3. Use the **up/down arrow** buttons (Move Earlier / Move Later) to change order
4. Or drag the animation to a new position

## Adding Multiple Animations to One Object

By default, adding a new animation replaces the existing one. To add multiple animations to the same object:

1. Select the object
2. Apply the first animation normally
3. For the second animation, click **Add Animation** (in the Animations tab → Advanced Animation group)
4. Choose the additional animation
5. Both animations will now be listed in the Animation Pane

**Example:** A text box could have:
- Entrance animation: Fly In (to appear)
- Emphasis animation: Pulse (to draw attention)
- Exit animation: Fade (to disappear)

## Custom Animation Settings

### Duration
Controls how fast/slow the animation plays:
- **Very Fast:** 0.5 seconds
- **Fast:** 1 second
- **Medium:** 2 seconds (default)
- **Slow:** 3 seconds
- **Very Slow:** 5 seconds

### Delay
Adds a pause before the animation starts:
- Set in seconds (0.00, 0.25, 0.50, 1.00, etc.)
- Useful for creating timed sequences

### Repeat
- Set an animation to repeat a specific number of times
- Options: None, 2, 3, 4, 5, 10, Until next click, Until end of slide

## Practical Tips for Transitions and Animations

### Do's
- Use **one consistent transition** for the entire presentation
- Use animations **sparingly** — only when they add value
- Keep transitions **subtle** (Fade and Push are professional choices)
- Use **Entrance** animations for important points to reveal them one by one
- Test your animations before presenting

### Don'ts
- Do not use too many different transitions (looks unprofessional)
- Do not use loud transition sounds in formal presentations
- Do not animate every object on every slide (distracting)
- Do not use very slow animations (audience gets impatient)
- Avoid spinning, bouncing, and flying effects in professional settings

## Key Terms to Remember

| Term | Meaning |
|------|---------|
| Transition | Visual effect between two slides |
| Animation | Visual effect on an object within a slide |
| Entrance | Animation type — object appears |
| Emphasis | Animation type — object draws attention |
| Exit | Animation type — object disappears |
| Motion Path | Animation type — object moves along a path |
| Duration | How long the effect takes |
| Delay | Pause before effect starts |
| Apply to All | Apply same transition to every slide |
| Animation Pane | Panel showing all animations in order |
| On Click | Effect starts when mouse is clicked |
| After Previous | Effect starts after the previous one ends |
| With Previous | Effect plays simultaneously with previous |
