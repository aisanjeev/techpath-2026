# Assignment — Module 08: Making Small Presentations

**CCC Exam Preparation — Practical Exercises**

---

## Assignment Overview

Complete the following four tasks to build hands-on PowerPoint skills. This module carries 14-16 marks in the CCC exam — practice is essential.

**Submission:** Save each completed presentation as a `.pptx` file and submit to your trainer.

---

## Task 1: Create a 6-Slide Presentation on "My City"

**Objective:** Practice creating a complete presentation with text, images, themes, and slide layouts.

### Requirements:

Create a PowerPoint presentation about your city (e.g., Bhopal, Delhi, Pune) with the following 6 slides:

#### Slide 1: Title Slide
- **Title:** Name of your city (e.g., "Bhopal — The City of Lakes")
- **Subtitle:** Your Name, CCC Batch 2026, TechPath Institute
- **Layout:** Title Slide

#### Slide 2: About My City
- **Title:** "About [City Name]"
- **Content:** 5-6 bullet points about your city (location, state, population, famous for, language spoken)
- **Layout:** Title and Content
- **Add:** One picture of your city

#### Slide 3: Famous Places
- **Title:** "Famous Places to Visit"
- **Content:** List 4-5 famous tourist spots with brief descriptions
- **Layout:** Two Content (text on left, image on right)
- **Add:** A picture of a famous landmark

#### Slide 4: Food and Culture
- **Title:** "Food and Culture"
- **Content:** Famous local food items, festivals, and cultural traditions
- **Layout:** Title and Content
- **Add:** Use a SmartArt graphic (List type) for food items

#### Slide 5: Why Visit My City?
- **Title:** "Why You Should Visit [City Name]"
- **Content:** Create a SmartArt (Process type) showing the top 5 reasons
- **Layout:** Title and Content

#### Slide 6: Thank You
- **Title:** "Thank You!" (use WordArt)
- **Subtitle:** "Presented by [Your Name] | TechPath Institute"
- **Layout:** Title Slide or Blank

### Design Requirements:
- Apply a **Theme** from the Design tab (choose one you like)
- Add **slide numbers** on all slides except the title slide (Insert → Header & Footer)
- Add a **footer:** "CCC Assignment 08 — TechPath Institute"
- Save the file as: `MyCity_YourName.pptx`

## Task 2: Apply Transitions and Animations

**Objective:** Practice adding transitions between slides and animations to objects.

### Part A: Apply Transitions
1. Open the "My City" presentation from Task 1
2. Select **Slide 1** and apply the **Fade** transition
3. Select **Slide 2** and apply the **Push** transition from the right
4. Select **Slide 3** and apply the **Wipe** transition from the bottom
5. Set the **duration** of all transitions to **1.5 seconds**
6. Now click **Apply to All** to apply the **Fade** transition uniformly to all slides
7. Set transition timing: **After 5 seconds** (automatic advance)
8. Preview the transitions by running the slide show (F5)

### Part B: Apply Animations
1. Go to **Slide 2** (About My City)
2. Select the **title text** and apply the **Fly In** entrance animation (from top)
3. Select the **bullet point text** and apply the **Fade** entrance animation
   - Set the text to appear **one paragraph at a time** (Effect Options → By Paragraph)
4. Select the **picture** and apply the **Zoom** entrance animation
5. Open the **Animation Pane** (Animations tab → Animation Pane)
6. Reorder the animations so the title appears first, then text, then the picture
7. Set all animations to start **After Previous** with a 0.5 second delay

### Part C: Add Emphasis and Exit Animations
1. Go to **Slide 5** (Why Visit My City)
2. Select the SmartArt and add an **Entrance** animation: **Fly In**
3. Then click **Add Animation** and add an **Emphasis** animation: **Pulse**
4. Set the Pulse to start **After Previous** with 1 second delay
5. Preview all animations on Slide 5

### Save the file as: `MyCity_Animated_YourName.pptx`

- Animation Pane for Slide 2 showing the order of animations
- Slide Sorter View showing transition timing below each slide

## Task 3: Run Slide Show and Print as Handouts

**Objective:** Practice slide show delivery options and printing.

### Part A: Slide Show Practice
1. Open your animated presentation from Task 2
2. Press **F5** — verify the show starts from Slide 1
3. Navigate through all slides and observe transitions and animations
4. Press **Esc** to end the show
5. Go to **Slide 3** in Normal View
6. Press **Shift + F5** — verify the show starts from Slide 3
7. During the slide show, try these:
   - Press **B** to turn the screen black, press **B** again to return
   - Press **W** to turn the screen white, press **W** again to return
   - Press **Ctrl + P** to activate the pen tool, draw on the slide
   - Press **Ctrl + A** to go back to the normal arrow pointer
   - Press **Esc** to end the show

### Part B: Rehearse Timings
1. Go to **Slide Show** tab → **Rehearse Timings**
2. The slide show starts with a timer
3. Speak about each slide for 15-20 seconds, then advance to the next
4. After all slides, click **Yes** to save timings
5. Switch to **Slide Sorter View** and verify the timing appears below each slide

### Part C: Print as Handouts
1. Go to **File → Print** (or Ctrl + P)
2. Under **Settings**, click the layout dropdown (default: Full Page Slides)
3. Select **Handouts → 3 Slides** per page
4. Preview the printout — notice the lines for notes next to each slide
5. If you have a printer, print one copy. Otherwise, **save as PDF:**
   - Change printer to **Microsoft Print to PDF**
   - Click **Print** and save as `MyCity_Handouts_YourName.pdf`
6. Repeat with **6 Slides** per page — save as another PDF

### Submission:
- `MyCity_Handouts_YourName.pdf` (3 slides per page)
- `MyCity_Handouts6_YourName.pdf` (6 slides per page)

## Task 4: Create a "CCC Exam Topics" Presentation with Advanced Features

**Objective:** Apply all learned skills in a comprehensive presentation.

### Requirements:

Create a new presentation with the following specifications:

#### Content (5 slides):
1. **Title Slide:** "CCC Exam Topics Overview" | Your Name, TechPath Institute
2. **Modules Overview:** Use a **table** with columns: Module No., Module Name, Expected Questions
3. **Study Plan:** Use a **SmartArt Process** diagram showing: Syllabus → Notes → Practice → Revision → Exam
4. **Key Tips:** Use **shapes** (rectangles with text) arranged as tip cards
5. **Thank You:** WordArt title with your details

#### Design Requirements:
- Apply a **professional theme** (not the default Office theme)
- Use **consistent fonts:** Title in 36pt, body in 20pt
- Add **slide numbers** and **date** in the footer
- Set slide size to **Widescreen (16:9)**

#### Transitions and Animations:
- Apply **Fade** transition to all slides (Apply to All)
- Transition duration: 1 second
- Add **Fly In** entrance animation to the table on Slide 2
- Add **Wipe** entrance animation to the SmartArt on Slide 3
- Add **Zoom** entrance animation to each shape on Slide 4

#### Delivery:
- Set automatic advance: **After 8 seconds** per slide
- Export as **PDF** (File → Export → Create PDF)

### Save as: `CCC_Overview_YourName.pptx`
### Export as: `CCC_Overview_YourName.pdf`
