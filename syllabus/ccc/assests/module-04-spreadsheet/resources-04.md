## Practice Exercise Ideas

### Exercise 1: Personal Monthly Budget
Create a spreadsheet tracking your monthly expenses:
- Column A: Expense categories (Rent, Food, Transport, Phone, Entertainment, Savings)
- Column B: Budgeted amount in Rs.
- Column C: Actual spent amount in Rs.
- Column D: Difference (=B-C for each row)
- Use SUM at the bottom to total each column
- Use formatting: bold headers, currency format, borders
- Create a Pie chart showing the budget allocation

### Exercise 2: Student Marksheet
Create a marksheet for 10 students with 5 subjects:
- Include student names (use Indian names), roll numbers
- Calculate Total using SUM
- Calculate Average using AVERAGE
- Find Highest and Lowest marks using MAX and MIN
- Count the number of students using COUNT
- Add a Pass/Fail column using the IF function: =IF(Average>=33,"Pass","Fail")
- Format with colors: green for Pass, red for Fail

### Exercise 3: Cell Reference Practice
- Create a price list with items and prices in Rs.
- Add a GST rate in a separate cell (18%)
- Use absolute reference ($A$1) to calculate GST for each item
- Copy the formula down and observe how absolute references stay fixed while relative references change

### Exercise 4: Chart Creation Practice
Using any data (sales, marks, temperatures):
- Create a Column chart comparing categories
- Create a Pie chart showing proportions
- Create a Line chart showing trends
- Practice adding chart titles, axis labels, and legends
- Try changing chart types after creation

### Exercise 5: Sorting and Filtering
Create a table of 20 Indian cities with columns for Name, State, Population, and Area:
- Sort by population (descending)
- Sort by state (ascending), then by city name within each state
- Apply filters to show only cities from a specific state
- Use Number Filter to show cities with population above 10 lakhs

### Exercise 6: AutoFill Practice
Practice AutoFill with:
- Months (January, February, ...)
- Days of the week (Monday, Tuesday, ...)
- Number sequences (2, 4, 6, 8, ...)
- Dates (1-Jan-2026, 2-Jan-2026, ...)
- Quarters (Q1, Q2, Q3, Q4)
- Custom series (Week 1, Week 2, ...)

### Exercise 7: Print Setup Practice
- Set a print area for a portion of your marksheet
- Add a header with your name and the date
- Add a footer with page numbers (Page 1 of 3)
- Use Page Break Preview to adjust page breaks
- Practice Fit to Page scaling
- Set Print Titles to repeat the header row on every page

## Software for Practice

### Microsoft Excel
- If you have Microsoft Office installed on your computer, use Excel directly for practice.
- Microsoft 365 (subscription) includes the latest version of Excel.

### Free Alternatives
- **LibreOffice Calc** — Free and open-source spreadsheet application. Download from https://www.libreoffice.org/. Works very similarly to Excel and is suitable for CCC exam practice.
- **Google Sheets** — Free online spreadsheet available at https://sheets.google.com/. Requires a Google account. Supports most Excel features.
- **Excel Online** — Free web version of Excel available at https://www.office.com/. Requires a Microsoft account. Has fewer features than the desktop version but sufficient for basic practice.

## Tips for Self-Study

1. **Practice daily** — Open Excel (or a free alternative) and spend 15-20 minutes practicing what you learned.
2. **Type formulas yourself** — Do not just read about SUM, AVERAGE, etc. Type them in Excel and see the results.
3. **Experiment** — Try changing values and see how formulas update automatically.
4. **Create real-world examples** — Make your own marksheet, budget, or attendance tracker.
5. **Learn shortcuts** — Practice keyboard shortcuts until they become automatic. This saves time in the exam.
6. **Take mock tests** — After studying each topic, take a mock test to identify weak areas.
