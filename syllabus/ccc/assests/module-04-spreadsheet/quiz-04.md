# Quiz: Spreadsheet / MS Excel

**Module 04 — CCC Exam Preparation**

---

### Q1. The intersection of a row and a column in a spreadsheet is called a ___.

- A) Cell  <<
- B) Workbook
- C) Formula
- D) Range

> **Explanation:** A cell is the basic unit of a spreadsheet, formed at the intersection (meeting point) of a row and a column. Each cell has a unique address like A1, B5, etc.

---

### Q2. What is the correct formula to add the values in cells A1 to A10 in Excel?

- A) =ADD(A1:A10)
- B) =SUM(A1:A10)  <<
- C) =TOTAL(A1:A10)
- D) =SUM(A1-A10)

> **Explanation:** The SUM function is used to add values in Excel. The correct syntax is =SUM(A1:A10), where the colon (:) defines the range from A1 to A10. There is no ADD or TOTAL function in Excel.

---

### Q3. Absolute cell reference in Excel is written as ___.

- A) A1
- B) #A#1
- C) $A$1  <<
- D) @A@1

> **Explanation:** An absolute cell reference uses the dollar sign ($) before both the column letter and row number: $A$1. This reference does not change when the formula is copied to another cell.

---

### Q4. Which chart type is best for showing parts of a whole?

- A) Line chart
- B) Bar chart
- C) Pie chart  <<
- D) Scatter chart

> **Explanation:** A Pie chart is best for showing parts of a whole. It displays data as slices of a circle, where each slice represents a proportion (percentage) of the total.

---

### Q5. What is the default file extension for an Excel 2007 and later workbook?

- A) .xls
- B) .xlsx  <<
- C) .xlsm
- D) .csv

> **Explanation:** The default file extension for Excel 2007 and later versions is .xlsx. The older format used .xls, .xlsm is for macro-enabled workbooks, and .csv is for comma-separated values.

---

### Q6. AutoFill can create a series of ___.

- A) Months and weekdays only
- B) Numbers only
- C) Months, weekdays, numbers, and dates  <<
- D) Formulas only

> **Explanation:** AutoFill can create series of months (January, February...), weekdays (Mon, Tue...), numbers (1, 2, 3...), dates, quarters (Q1, Q2...), and more. It uses the Fill Handle (small black cross at the bottom-right corner of a cell).

---

### Q7. By default, text entered in an Excel cell is aligned to the ___.

- A) Right
- B) Center
- C) Left  <<
- D) Top

> **Explanation:** By default, text (labels) in Excel is left-aligned, while numbers and dates are right-aligned. This default alignment helps users quickly identify the type of data in a cell.

---

### Q8. Which function returns the largest value in a range of cells?

- A) =MIN()
- B) =LARGE()
- C) =MAX()  <<
- D) =HIGH()

> **Explanation:** The MAX function returns the largest (maximum) value from a range of cells. For example, =MAX(A1:A10) returns the highest value among cells A1 to A10. There is no HIGH function in Excel.

---

### Q9. What does the error #DIV/0! indicate in Excel?

- A) Formula is misspelled
- B) Cell reference is invalid
- C) Division by zero  <<
- D) Column is too narrow

> **Explanation:** The #DIV/0! error occurs when a formula attempts to divide a number by zero or by an empty cell. To fix it, ensure the divisor cell contains a non-zero value.

---

### Q10. Which keyboard shortcut opens the Format Cells dialog box in Excel?

- A) Ctrl + F
- B) Ctrl + 1  <<
- C) Ctrl + D
- D) Ctrl + Shift + F

> **Explanation:** Ctrl + 1 opens the Format Cells dialog box, which provides detailed formatting options for number format, alignment, font, border, fill, and protection.

---

### Q11. In the cell reference $A1, which part remains fixed when the formula is copied?

- A) Row number (1)
- B) Column letter (A)  <<
- C) Both row and column
- D) Neither row nor column

> **Explanation:** In the mixed reference $A1, the dollar sign before A means the column is fixed (locked). The row number (1) is free and will change when the formula is copied to different rows.

---

### Q12. Freeze Panes feature in Excel is found under which tab?

- A) Home
- B) Insert
- C) Page Layout
- D) View  <<

> **Explanation:** Freeze Panes is found under the View tab. It allows you to lock certain rows or columns in place so they remain visible while scrolling through large datasets.

---

### Q13. What is the maximum number of rows in an Excel worksheet?

- A) 65,536
- B) 2,56,000
- C) 10,48,576  <<
- D) 16,384

> **Explanation:** An Excel worksheet (2007 and later) can have a maximum of 10,48,576 rows (from row 1 to row 1048576). The older .xls format supported only 65,536 rows. 16,384 is the maximum number of columns.

---

### Q14. Which Excel function counts only the cells that contain numbers in a range?

- A) COUNTA()
- B) COUNTIF()
- C) COUNT()  <<
- D) SUM()

> **Explanation:** The COUNT function counts only cells that contain numeric values. COUNTA counts all non-empty cells (including text), COUNTIF counts cells meeting a specific condition, and SUM adds values rather than counting them.

---

### Q15. Filtering data in Excel ___.

- A) Permanently deletes hidden rows
- B) Temporarily hides rows that do not match criteria  <<
- C) Sorts the data in ascending order
- D) Merges matching cells together

> **Explanation:** Filtering temporarily hides rows that do not match the specified criteria. The hidden data is NOT deleted -- it can be shown again by clearing the filter. Filter is found under the Data tab (shortcut: Ctrl + Shift + L).
