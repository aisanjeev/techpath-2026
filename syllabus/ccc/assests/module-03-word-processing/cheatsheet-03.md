# Cheatsheet: MS Word Keyboard Shortcuts and Quick Reference

**Module 03 — CCC Exam Preparation**

---

## File Operations

| Shortcut | Action |
|----------|--------|
| **Ctrl + N** | Create a new blank document |
| **Ctrl + O** | Open an existing document |
| **Ctrl + S** | Save the current document |
| **F12** | Save As (new name/location/format) |
| **Ctrl + W** | Close the current document |
| **Alt + F4** | Exit MS Word completely |
| **Ctrl + P** | Print / Print Preview |

---

## Text Editing

| Shortcut | Action |
|----------|--------|
| **Ctrl + C** | Copy selected text |
| **Ctrl + X** | Cut selected text (move) |
| **Ctrl + V** | Paste from clipboard |
| **Ctrl + Z** | Undo last action |
| **Ctrl + Y** | Redo (reverse an undo) |
| **Ctrl + A** | Select entire document |
| **Ctrl + F** | Find text |
| **Ctrl + H** | Find and Replace |
| **Ctrl + G** or **F5** | Go To (page, section, line) |
| **Delete** | Delete character to the right |
| **Backspace** | Delete character to the left |
| **Ctrl + Delete** | Delete word to the right |
| **Ctrl + Backspace** | Delete word to the left |
| **Insert** key | Toggle Insert / Overtype mode |

## Text Formatting

| Shortcut | Action |
|----------|--------|
| **Ctrl + B** | Bold |
| **Ctrl + I** | Italic |
| **Ctrl + U** | Underline |
| **Ctrl + D** | Open Font dialog box |
| **Ctrl + ]** | Increase font size by 1 point |
| **Ctrl + [** | Decrease font size by 1 point |
| **Ctrl + Shift + >** | Increase font to next preset size |
| **Ctrl + Shift + <** | Decrease font to next preset size |

| **Ctrl + Shift + C** | Copy formatting |
| **Ctrl + Shift + V** | Paste formatting |
| **Shift + F3** | Change text case (Sentence/UPPER/lower) |

## Error Indicators

| Indicator | Meaning |
|-----------|---------|
| Red wavy underline | Spelling error |
| Blue wavy underline | Grammar / contextual error |
| Green wavy underline | Grammar error (older Word versions) |

## Table Operations Quick Reference

| Task | How To |
|------|--------|
| Insert table | Insert tab → Table |
| Add row at end | Press Tab in last cell |
| Merge cells | Select cells → Layout tab → Merge Cells |
| Split cells | Click cell → Layout tab → Split Cells |
| Delete row/column | Layout tab → Delete |
| Sort table | Layout tab → Sort |
| Add borders | Table Design tab → Borders |
| Add shading | Table Design tab → Shading |
| Cell alignment | Layout tab → 9 alignment options |
| AutoFit | Layout tab → AutoFit |
| Convert text to table | Insert tab → Table → Convert Text to Table |

## File Format Reference

| Extension | Format | When to Use |
|-----------|--------|-------------|
| .docx | Word 2007+ Document | Default — use for normal documents |
| .doc | Word 97-2003 | When sharing with someone using an older version |
| .pdf | Portable Document Format | When you want the layout preserved and no editing |
| .rtf | Rich Text Format | When sharing across different word processors |
| .txt | Plain Text | When you only need the text, no formatting |
| .dotx | Word Template | When creating reusable document templates |
