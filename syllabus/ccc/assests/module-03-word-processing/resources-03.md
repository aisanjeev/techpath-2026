## Practice Exercises

Practice is the key to mastering MS Word. Try these exercises on your computer:

### Exercise 1: Basic Document Operations
1. Open MS Word and create a new blank document
2. Type your name, address, and a short paragraph about yourself
3. Save the document as "MyProfile.docx" on your Desktop
4. Close the document
5. Reopen it using Ctrl + O
6. Save it again with a different name using F12 (Save As) as "MyProfile_v2.docx"

### Exercise 2: Text Formatting Practice
1. Type the following text: "TechPath Institute offers the best CCC exam preparation course in Bhopal."
2. Make "TechPath Institute" **Bold**
3. Make "CCC exam preparation" *Italic*
4. Underline the word "best"
5. Change the font of the entire sentence to Arial, 14pt
6. Center-align the text
7. Change the text colour to dark blue

### Exercise 3: Keyboard Shortcuts Drill
Practice these shortcuts 10 times each until they become automatic:
- Ctrl + B (Bold), Ctrl + I (Italic), Ctrl + U (Underline)
- Ctrl + C (Copy), Ctrl + X (Cut), Ctrl + V (Paste)
- Ctrl + Z (Undo), Ctrl + Y (Redo)
- Ctrl + L (Left), Ctrl + E (Center), Ctrl + R (Right), Ctrl + J (Justify)
- Ctrl + S (Save), Ctrl + N (New), Ctrl + O (Open), Ctrl + P (Print)
- Ctrl + F (Find), Ctrl + H (Replace)

### Exercise 4: Table Creation
1. Create a table with 5 columns and 6 rows
2. Add headers: Roll No, Name, Hindi, English, Maths
3. Fill in data for 5 students with Indian names
4. Merge the cells in the first row and type "Class 10 — Exam Results"
5. Add borders and shading to the header
6. Sort the table by the "Name" column

### Exercise 5: Find and Replace
1. Type a paragraph that mentions "computer" at least 5 times
2. Use Ctrl + H to replace all occurrences of "computer" with "PC"
3. Try using Find (Ctrl + F) to search for specific words

### Exercise 6: Headers, Footers, and Page Numbers
1. Create a 3-page document by typing enough text
2. Add a header with the text "TechPath Institute — CCC Notes"
3. Add a footer with your name
4. Insert page numbers at the bottom center
5. Add a page border from the Design tab

### Exercise 7: Mail Merge (Conceptual)
1. Create a letter template with placeholders for Name, Course, and City
2. Understand how the Mailings tab works
3. Practice the steps: Start Mail Merge → Select Recipients → Insert Merge Fields → Preview → Finish

| Setting | Default Value |
|---------|--------------|
| Font (Word 2007+) | Calibri, 11 pt |
| Font (Word 2003) | Times New Roman, 12 pt |
| Alignment | Left |

| Orientation | Portrait |
| Paper Size | A4 |
| View | Print Layout |
