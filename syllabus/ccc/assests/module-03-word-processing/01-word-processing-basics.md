# Word Processing Basics

**Module 03 — CCC Exam Preparation | Topic 1**

## What is Word Processing?

**Word processing** means using a computer to create, edit, format, save, and print text documents. A **word processor** is the software that lets you do this.

The most popular word processor in the world is **Microsoft Word** (commonly called MS Word). It is part of the **Microsoft Office** suite. Other word processors include LibreOffice Writer, Google Docs, and WordPad, but the CCC exam focuses almost entirely on MS Word.

**CCC Exam Tip:** You may be asked: *"Which of the following is a word processor?"* — The answer is **MS Word**. Excel is a spreadsheet, PowerPoint is for presentations, and Access is a database.

## Opening Microsoft Word

There are several ways to open MS Word on a Windows computer:

| Method | Steps |
|--------|-------|
| Start Menu | Click **Start** → **All Programs** → **Microsoft Office** → **Microsoft Word** |
| Search | Click Start and type **"Word"** in the search box, then press Enter |
| Desktop Shortcut | Double-click the **MS Word icon** on the desktop (if available) |
| Run Command | Press **Win + R**, type **winword**, and press Enter |

When MS Word opens, you see a blank document ready for typing.

## The MS Word Interface (Screen Layout)

When you open MS Word, you will see several important parts on the screen. Understanding each part is critical for the CCC exam.

### Title Bar

The **Title Bar** is at the very top of the window. It shows:
- The **name of the document** (new documents show "Document1")
- The **program name** (Microsoft Word)
- **Minimize**, **Maximize/Restore**, and **Close** buttons on the right side

### Menu Bar / Ribbon

In older versions of Word (2003 and earlier), there was a **Menu Bar** with options like File, Edit, View, Insert, Format, Tools, Table, Window, Help.

In Word 2007 and later, the menu bar was replaced by the **Ribbon** — a wide toolbar at the top organized into **tabs**:

| Tab | What It Contains |
|-----|-----------------|
| **File** (Backstage View) | New, Open, Save, Save As, Print, Close, Info |
| **Home** | Clipboard, Font, Paragraph, Styles, Editing |
| **Insert** | Tables, Pictures, Shapes, Header/Footer, Page Number |
| **Design** | Document formatting themes and page background |
| **Layout** (or Page Layout) | Page Setup, Margins, Orientation, Size, Columns |
| **References** | Table of Contents, Footnotes, Citations, Bibliography |
| **Mailings** | Mail Merge, Envelopes, Labels |
| **Review** | Spelling & Grammar, Comments, Track Changes |
| **View** | Document views, Zoom, Window arrangement |

**CCC Exam Tip:** Questions about which tab contains a specific feature are very common. Remember: Tables are in **Insert** tab, Margins are in **Layout** tab, Spelling check is in **Review** tab.

### Quick Access Toolbar

The **Quick Access Toolbar** is a small toolbar above or below the ribbon. By default, it contains:
- **Save** button
- **Undo** button
- **Redo** button

You can customize it by adding frequently used commands.

### Ruler

The **Ruler** appears below the ribbon (horizontal) and on the left side (vertical). It helps you:
- Set **margins** and **indents**
- Adjust **tab stops**
- See the **page width**

To show or hide the ruler: Go to **View** tab → check/uncheck **Ruler**.

### Scroll Bars

- **Vertical Scroll Bar** (right side) — scrolls the document up and down
- **Horizontal Scroll Bar** (bottom) — scrolls left and right (visible when the document is wider than the screen)

### Status Bar

The **Status Bar** is at the very bottom of the Word window. It shows:
- **Page number** and total pages (e.g., Page 1 of 5)
- **Word count**
- **Language** (e.g., English (India))
- **View buttons** (Read Mode, Print Layout, Web Layout)
- **Zoom slider**

**CCC Exam Tip:** The Status Bar shows the word count and page number. This is frequently asked in the exam.

## Creating a New Document

To create a new blank document:

| Method | Steps |
|--------|-------|
| Keyboard shortcut | Press **Ctrl + N** |
| File menu | Click **File** → **New** → **Blank Document** |
| From template | Click **File** → **New** → choose a template |

**Ctrl + N** is the fastest way and is commonly asked in exams.

## Opening an Existing Document

To open a document that you have already saved:

| Method | Steps |
|--------|-------|
| Keyboard shortcut | Press **Ctrl + O** |
| File menu | Click **File** → **Open** → browse to the file location |
| Recent files | Click **File** → **Open** → **Recent** to see recently opened files |

## Saving a Document

### Save (Ctrl + S)

- **Saves changes** to the current file
- If the file has never been saved before, it opens the "Save As" dialog box
- If the file was already saved, it updates the existing file silently

### Save As (F12 or File → Save As)

- Lets you save the file with a **new name**, in a **different location**, or in a **different format**
- Always opens a dialog box where you can choose the file name and location

### Save vs Save As — Key Difference

| Feature | Save (Ctrl + S) | Save As (F12) |
|---------|-----------------|---------------|
| Purpose | Update existing file | Save with new name/location/format |
| Dialog box | Only appears for new files | Always appears |
| Original file | Gets overwritten | Remains unchanged |
| Shortcut | Ctrl + S | F12 |

**CCC Exam Tip:** "What is the difference between Save and Save As?" is one of the most frequently asked questions. Save overwrites the existing file; Save As creates a new copy.

### Default File Format

- MS Word 2007 and later saves files in **.docx** format
- Older versions used **.doc** format
- You can also save as **.pdf**, **.txt**, **.rtf**, and other formats using Save As

## Closing a Document

| Method | Steps |
|--------|-------|
| Keyboard shortcut | Press **Ctrl + W** (closes the document but keeps Word open) |
| Close button | Click the **X** button in the top-right corner |
| File menu | Click **File** → **Close** |
| Exit Word | Press **Alt + F4** (closes Word completely) |

If you have unsaved changes, Word will ask if you want to save before closing.

## Page Setup

Page Setup controls how the document will look when printed. You can find it in the **Layout** tab (or **Page Layout** tab in older versions).

### Margins

Margins are the blank spaces around the edges of the page.

| Margin Type | Default Size |
|-------------|-------------|
| Top | 1 inch (2.54 cm) |
| Bottom | 1 inch (2.54 cm) |
| Left | 1 inch (2.54 cm) |
| Right | 1 inch (2.54 cm) |

To change margins: **Layout** → **Margins** → choose a preset or click **Custom Margins**.

### Orientation

- **Portrait** — page is taller than it is wide (default)
- **Landscape** — page is wider than it is tall

To change: **Layout** → **Orientation**.

### Paper Size

The default paper size is **A4** (21 cm x 29.7 cm) in India. Other sizes include Letter, Legal, and A3.

To change: **Layout** → **Size**.

**CCC Exam Tip:** Default paper size in India is **A4**. Default orientation is **Portrait**. Default margins are **1 inch** on all sides.

## Print Preview and Printing

### Print Preview

Print Preview shows you exactly how the document will look when printed, before you actually print it.

To access Print Preview: Press **Ctrl + P** or go to **File** → **Print**.

In the Print Preview screen, you can see:
- How the pages look
- The total number of pages
- A zoom slider to see the document closer or farther

### Printing a Document

To print: Press **Ctrl + P** → choose your printer → click **Print**.

Print options include:
- **Number of copies**
- **Print all pages**, current page, or a range of pages
- **Printer selection**
- **Page orientation** and **paper size**

---

## Document Views

MS Word offers several ways to view your document:

| View | Purpose |
|------|---------|
| **Print Layout** | Default view — shows the page as it will be printed (with margins, headers, footers) |
| **Read Mode** | For reading — hides the ribbon and shows text in a book-like format |
| **Web Layout** | Shows how the document would look as a web page |
| **Outline** | Shows document structure with headings and subheadings |
| **Draft** | Shows only the text without page margins — good for fast typing |

**CCC Exam Tip:** The default view in MS Word is **Print Layout**. Questions about views and what each view shows are common.
