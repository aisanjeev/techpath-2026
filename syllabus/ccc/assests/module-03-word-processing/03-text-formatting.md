# Text Formatting

**Module 03 — CCC Exam Preparation | Topic 3**

---

## What is Formatting?

**Formatting** means changing the appearance of text to make it look better, easier to read, or more professional. Formatting does not change the content of the text — only how it looks.

In MS Word, most formatting options are found on the **Home** tab in the ribbon.

---

## Font Formatting

Font formatting changes the appearance of individual characters (letters, numbers, symbols).

### Font Type (Font Family)

A **font** (also called a typeface) is the design style of letters. Examples:

| Font | Style | Use |
|------|-------|-----|
| **Calibri** | Modern, clean | Default font in Word 2007+ |
| **Times New Roman** | Traditional, serif | Default in older versions; formal documents |
| **Arial** | Clean, sans-serif | Business documents, presentations |
| **Comic Sans MS** | Casual, playful | Informal documents (avoid in professional work) |

To change the font: Select the text → go to the **Home** tab → click the **Font dropdown** → choose a font.

**CCC Exam Tip:** The default font in MS Word 2007 and later is **Calibri** with a default size of **11 points**. In older versions (Word 2003), the default was **Times New Roman, 12 points**. This is frequently asked.

### Font Size

Font size is measured in **points** (pt). Common sizes:

| Size | Typical Use |
|------|-------------|
| 8-10 pt | Fine print, footnotes |
| 11-12 pt | Normal body text |
| 14-16 pt | Subheadings |
| 18-24 pt | Headings |
| 28-72 pt | Titles, banners |

To change font size:
- Select the text → change the number in the **Font Size** box
- Or use shortcuts: **Ctrl + ]** (increase size) and **Ctrl + [** (decrease size)
- **Ctrl + Shift + >** increases size to next preset; **Ctrl + Shift + <** decreases

### Bold (Ctrl + B)

**Bold** makes text thicker and darker: **This is bold text.**

- Select the text → press **Ctrl + B** or click the **B** button on the Home tab
- Press Ctrl + B again to remove bold

### Italic (Ctrl + I)

**Italic** makes text slanted: *This is italic text.*

- Select the text → press **Ctrl + I** or click the **I** button
- Used for emphasis, book titles, foreign words

### Underline (Ctrl + U)

**Underline** adds a line below the text: The text appears underlined.

- Select the text → press **Ctrl + U** or click the **U** button
- Click the small arrow next to U to choose different underline styles (double, dotted, wavy, etc.)

### Strikethrough

**Strikethrough** draws a line through the middle of text: ~~This text is struck through.~~

- Found in the **Home** tab → **Font** group → click the **abc** with a line through it
- Used to show deleted or outdated content

### Subscript and Superscript

| Style | Shortcut | Example | Use |
|-------|----------|---------|-----|
| **Subscript** | Ctrl + = | H₂O | Chemical formulas |
| **Superscript** | Ctrl + Shift + + | x² | Mathematical exponents |

### Font Colour

To change the colour of text:
- Select the text → click the **Font Color** dropdown (the A with a coloured bar) on the Home tab
- Choose from the colour palette
- The default font colour is **Automatic (Black)**

### Text Highlight

To highlight text (like using a highlighter pen):
- Select the text → click the **Text Highlight Color** button (looks like a marker pen)
- Choose a highlight colour (yellow is most common)

### Changing Multiple Font Settings at Once

Open the **Font dialog box** by pressing **Ctrl + D** (or clicking the small arrow at the bottom-right of the Font group). Here you can change:
- Font type, style, size
- Font colour
- Underline style
- Effects (strikethrough, superscript, subscript, small caps, all caps)
- Character spacing

**CCC Exam Tip:** Know all three shortcuts: **Ctrl + B** (Bold), **Ctrl + I** (Italic), **Ctrl + U** (Underline). These appear in almost every CCC exam. Also remember **Ctrl + D** opens the Font dialog box.

## Text Alignment

Text alignment controls how text is positioned between the left and right margins.

### Four Types of Alignment

| Alignment | Shortcut | Description | Appearance |
|-----------|----------|-------------|------------|
| **Left Align** | **Ctrl + L** | Text is aligned to the left margin; right edge is uneven | Most common for body text |
| **Center Align** | **Ctrl + E** | Text is centered between margins | Used for titles, headings |
| **Right Align** | **Ctrl + R** | Text is aligned to the right margin; left edge is uneven | Used for dates, signatures |
| **Justify** | **Ctrl + J** | Text is aligned to both left and right margins | Used in newspapers, books |

**Example:**

- **Left Aligned:** This line starts from the left margin.
- **Center Aligned:** This line is in the middle of the page.
- **Right Aligned:** This line touches the right margin.
- **Justified:** This text stretches from the left margin to the right margin, adding extra spaces between words to make both edges even.

**CCC Exam Tip:** Remember the shortcuts using this memory trick:
- Ctrl + **L** = **L**eft
- Ctrl + **E** = C**e**nter (think of the "E" in Center)
- Ctrl + **R** = **R**ight
- Ctrl + **J** = **J**ustify

These four shortcuts are asked very frequently. The default alignment is **Left**.

## Line Spacing

**Line spacing** is the vertical space between lines of text within a paragraph.

### Common Line Spacing Options

| Spacing | Description |
|---------|-------------|
| **1.0 (Single)** | Lines are close together |
| **1.15** | Default spacing in Word 2007+ |
| **1.5** | More space between lines |
| **2.0 (Double)** | Twice the normal space — often required for assignments |
| **3.0 (Triple)** | Three times the normal space |

### How to Change Line Spacing

1. Select the text (or press Ctrl + A for the entire document)
2. Go to **Home** tab → **Paragraph** group → click the **Line and Paragraph Spacing** button (icon with up/down arrows)
3. Choose the spacing you want

**Keyboard shortcuts:**
- **Ctrl + 1** = Single spacing
- **Ctrl + 2** = Double spacing
- **Ctrl + 5** = 1.5 line spacing

**CCC Exam Tip:** The default line spacing in MS Word 2007 and later is **1.15** (not single spacing). **Ctrl + 2** sets double spacing. These are commonly asked.

---

## Paragraph Spacing

**Paragraph spacing** is the space before and after a paragraph (not between lines within the paragraph).

- **Before** spacing: Space above the paragraph
- **After** spacing: Space below the paragraph

The default paragraph spacing in Word 2007+ is:
- Before: **0 pt**
- After: **8 pt** (or 10 pt depending on the style)

To change: Select the paragraph → go to **Home** tab → **Paragraph** group → click the small arrow to open the Paragraph dialog box → adjust "Before" and "After" values under Spacing.

Or use: **Layout** tab → **Spacing** section → change Before/After values.

## Format Painter

The **Format Painter** is a powerful tool that copies formatting from one piece of text and applies it to another.

### How to Use Format Painter

1. Select the text that has the formatting you want to copy
2. Click the **Format Painter** button (paintbrush icon) on the Home tab
3. Select the text you want to apply the formatting to

**Tip:** Double-click the Format Painter button to keep it active and apply the same formatting to multiple sections. Press **Esc** to turn it off.

**Keyboard shortcut:** There is no direct keyboard shortcut for Format Painter, but you can use:
- **Ctrl + Shift + C** to copy formatting
- **Ctrl + Shift + V** to paste formatting

**CCC Exam Tip:** Format Painter is found on the **Home** tab. Remember **Ctrl + Shift + C** copies formatting and **Ctrl + Shift + V** pastes formatting.

---

## Clearing Formatting

To remove all formatting from selected text and return it to plain default text:

- Select the text → click the **Clear All Formatting** button (letter A with an eraser) on the Home tab
- Or press **Ctrl + Spacebar** to clear character formatting (font, bold, etc.)
