## Task 1: Type and Format a Professional Letter

**Objective:** Practice document creation, text formatting, alignment, and page setup.

### Instructions

1. Open Microsoft Word and create a new blank document (Ctrl + N).

2. Set the page margins to **1.5 inches** on all sides (Layout tab → Margins → Custom Margins).

3. Type the following letter (replace the placeholders with your details):

```
[Your Name]
[Your Address]
[City, Pin Code]
[Date]

The Director
TechPath Institute
Bhopal - 462001
Madhya Pradesh

Subject: Application for Admission to CCC Course

Respected Sir/Madam,

I am writing to apply for admission to the CCC (Course on Computer Concepts) 
program at TechPath Institute. I am a [your qualification] graduate and wish 
to improve my computer literacy to meet the growing demands of the job market.

I am particularly interested in learning about word processing, spreadsheets, 
and internet applications. I am confident that the CCC certification from 
NIELIT will help me in my career.

I have enclosed copies of my educational certificates and a passport-size 
photograph for your reference. I am ready to pay the course fee of Rs. 3,000 
and can join the upcoming batch.

I request you to kindly consider my application and grant me admission at 
the earliest.

Thanking you,
Yours faithfully,

[Your Name]

Enclosures:
1. Educational Certificates
2. Passport-size Photograph
3. Aadhar Card Copy
```

4. Apply the following formatting:
   - **Your name** at the top: Font = Arial, Size = 14pt, Bold
   - **Subject line**: Bold and Underlined
   - **"Respected Sir/Madam"**: Italic
   - **Body text**: Font = Times New Roman, Size = 12pt
   - **"TechPath Institute"** wherever it appears: Bold
   - **"Rs. 3,000"**: Bold and coloured red
   - **Entire letter**: Justify alignment (Ctrl + J)
   - **Date and closing**: Right-aligned (Ctrl + R)

5. Add a **header** with the text "Application Letter" (Insert tab → Header).

6. Add a **footer** with the page number centered (Insert tab → Page Number → Bottom of Page).

7. Run **Spelling and Grammar check** (press F7).

8. Save the document as **"CCC_Letter_[YourName].docx"**.

### Submission
- Submit the .docx file
- Ensure all formatting is applied correctly

## Task 3: Practice Find & Replace and Document Formatting

**Objective:** Practice Find & Replace (Ctrl + H), text case change, bullets, numbering, and paragraph formatting.

### Instructions

1. Create a new document and type the following text (type it exactly as shown, including the deliberate mistakes):

```
Introduction to Computers at techpath institute

computers are electronic devices that process data into useful information. 
at techpath institute in bhopal, we teach students how to use computers 
effectively. the ccc course covers topics like word processing, spreadsheets, 
and internet applications.

benefits of learning computers at techpath institute:
better job opportunities in government and private sector
improved productivity in daily tasks  
access to online services like banking and shopping
ability to communicate through email and social media
digital literacy for the modern world

the ccc exam is conducted by nielit. students need to score at least 50 out 
of 100 marks to pass. the exam has 100 multiple choice questions and the 
time limit is 90 minutes. at techpath institute, our pass rate is over 95 
percent. techpath institute provides practice tests and study materials 
to help students succeed.
```

2. Use **Find and Replace** (Ctrl + H) to make the following replacements:
   - Replace "techpath institute" with "TechPath Institute" (all occurrences)
   - Replace "computers" with "Computers" (all occurrences)
   - Replace "ccc" with "CCC" (all occurrences)
   - Replace "nielit" with "NIELIT" (all occurrences)
   - Replace "bhopal" with "Bhopal" (all occurrences)

3. Note down: How many replacements were made for each word? (Write this at the bottom of the document)

4. Apply **Sentence Case** to the heading using **Shift + F3**.

5. Convert the 5 benefits into a **bulleted list** (Home tab → Bullets).

6. Convert the paragraph about the exam into a **numbered list** with each sentence as a separate point.

7. Apply the following paragraph formatting:
   - **First paragraph**: First Line Indent of 0.5 inches
   - **Bulleted list**: Hanging indent of 0.25 inches
   - **Entire document**: Line spacing = 1.5 (Ctrl + 5)
   - **Heading**: Center-aligned, Bold, 16pt, Underlined

8. Add **Headers and Footers**:
   - Header: "CCC Study Material — TechPath Institute" (right-aligned)
   - Footer: Page number in "Page X of Y" format (center-aligned)

9. Add a **Page Border** (Design tab → Page Borders → choose a Box border with double-line style).

10. Save the document as **"CCC_FindReplace_[YourName].docx"**.

### Submission
- Submit the .docx file
- Include the replacement count at the bottom of the document
