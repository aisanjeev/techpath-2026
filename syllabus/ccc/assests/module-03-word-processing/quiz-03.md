# Quiz: Elements of Word Processing

**Module 03 — CCC Exam Preparation**

---

### Q1. What is the keyboard shortcut to make selected text Bold in MS Word?

- A) Ctrl + A
- B) Ctrl + B ✔
- C) Ctrl + D
- D) Ctrl + G

> **Explanation:** Ctrl + B is the shortcut for Bold in MS Word. Ctrl + A selects all text, Ctrl + D opens the Font dialog box, and Ctrl + G opens the Go To dialog.

---

### Q2. What is the shortcut key for 'Save As' in MS Word?

- A) Ctrl + S
- B) Ctrl + Shift + S
- C) F12 ✔
- D) F7

> **Explanation:** F12 is the shortcut for Save As, which lets you save a document with a new name, location, or format. Ctrl + S is for Save (overwrites the current file).

---

### Q3. Which shortcut key is used for Find and Replace in MS Word?

- A) Ctrl + F
- B) Ctrl + R
- C) Ctrl + H ✔
- D) Ctrl + G

> **Explanation:** Ctrl + H opens the Find and Replace dialog box. Ctrl + F opens Find only. Ctrl + R is for Right alignment. Ctrl + G is for Go To.

---

### Q4. What is the default file extension for documents saved in MS Word 2007 and later?

- A) .doc
- B) .docx ✔
- C) .pdf
- D) .txt

> **Explanation:** MS Word 2007 and later versions save documents in .docx format by default. The .doc format was used in Word 2003 and earlier versions.

---

### Q5. What does the shortcut Ctrl + E do in MS Word?

- A) Exit Word
- B) Center align text ✔
- C) Open Edit menu
- D) Select all text

> **Explanation:** Ctrl + E is used to Center align the selected text or paragraph in MS Word. Remember the memory trick: the 'E' in cEnter.

---

### Q6. Which tab in MS Word contains the option to insert a Table?

- A) Home
- B) Insert ✔
- C) Layout
- D) Design

> **Explanation:** Tables are inserted from the Insert tab. The Insert tab also contains options for Pictures, Shapes, Header/Footer, and Page Numbers.

---

### Q7. What is the default font in MS Word 2007 and later versions?

- A) Times New Roman, 12pt
- B) Arial, 11pt
- C) Calibri, 11pt ✔
- D) Verdana, 10pt

> **Explanation:** The default font in MS Word 2007 and later is Calibri with a size of 11 points. Times New Roman, 12pt was the default in Word 2003 and earlier.

---

### Q8. To add a new row at the end of a table in MS Word, you should:

- A) Press Enter in the last cell
- B) Press Tab in the last cell ✔
- C) Press Ctrl + Enter
- D) Right-click and select Add Row

> **Explanation:** Pressing the Tab key when the cursor is in the last cell of the last row automatically adds a new row at the end of the table.

---

### Q9. Which keyboard shortcut opens the Spelling and Grammar checker in MS Word?

- A) F5
- B) F7 ✔
- C) F1
- D) F12

> **Explanation:** F7 opens the Spelling and Grammar checker. F5 opens Go To, F1 opens Help, and F12 opens Save As.

---

### Q10. What is the shortcut to Undo the last action in MS Word?

- A) Ctrl + Y
- B) Ctrl + Z ✔
- C) Ctrl + U
- D) Ctrl + X

> **Explanation:** Ctrl + Z is the shortcut for Undo, which reverses the last action. Ctrl + Y is for Redo. Ctrl + U is for Underline. Ctrl + X is for Cut.

---

### Q11. In MS Word, where are Page Borders found?

- A) Home tab
- B) Insert tab
- C) Design tab ✔
- D) Layout tab

> **Explanation:** Page Borders are found in the Design tab under the Page Background group. This is different from paragraph borders, which are in the Home tab.

---

### Q12. What does a red wavy underline indicate in MS Word?

- A) Grammar error
- B) Formatting error
- C) Spelling error ✔
- D) Auto-save reminder

> **Explanation:** A red wavy underline indicates a spelling error — the word is not recognized by Word's dictionary. A blue (or green in older versions) wavy underline indicates a grammar error.

---

### Q13. Which shortcut key changes the text case (uppercase/lowercase) in MS Word?

- A) Ctrl + F3
- B) Alt + F3
- C) Shift + F3 ✔
- D) Ctrl + Shift + A

> **Explanation:** Shift + F3 cycles through text case options: Sentence case, UPPERCASE, and lowercase. It can be pressed repeatedly to toggle between these options.

---

### Q14. In Mail Merge, the file containing names, addresses, and other data is called:

- A) Main Document
- B) Merge Field
- C) Data Source ✔
- D) Template

> **Explanation:** The Data Source is the file (usually an Excel spreadsheet or database) that contains the actual data like names and addresses. The Main Document is the template letter with merge fields.

---

### Q15. What is the default view in MS Word?

- A) Draft View
- B) Read Mode
- C) Print Layout ✔
- D) Web Layout

> **Explanation:** Print Layout is the default view in MS Word. It shows the document exactly as it will appear when printed, including margins, headers, footers, and page breaks.
