## 1. Introduction to Word Processing

**Word processing** is the use of a computer application to create, edit, format, store, and print text documents. **Microsoft Word** (MS Word) is the most widely used word processor and is part of the Microsoft Office suite.

MS Word allows you to:
- Create professional documents (letters, reports, resumes)
- Format text with fonts, colours, sizes, and alignment
- Insert tables, images, and shapes
- Check spelling and grammar
- Print and share documents

> **Exam Tip:** When the exam asks "Which of the following is a word processor?", the answer is **MS Word**. Excel = spreadsheet, PowerPoint = presentation, Access = database.

## 2. MS Word Interface

When you open MS Word, the screen contains the following components:

| Component | Location | Purpose |
|-----------|----------|---------|
| **Title Bar** | Top of window | Shows document name and program name |
| **Quick Access Toolbar** | Above/below ribbon | Save, Undo, Redo buttons |
| **Ribbon** | Below title bar | Main toolbar with tabs (Home, Insert, Layout, etc.) |
| **Ruler** | Below ribbon | Shows margins, indents, tab stops |
| **Document Area** | Center | Where you type and edit text |
| **Scroll Bars** | Right and bottom | Navigate through the document |
| **Status Bar** | Bottom | Page number, word count, view buttons, zoom slider |

### Important Ribbon Tabs

| Tab | Contains |
|-----|----------|
| **Home** | Clipboard, Font, Paragraph, Styles, Editing |
| **Insert** | Tables, Pictures, Shapes, Header/Footer, Page Number |
| **Design** | Themes, Page Borders, Watermarks |
| **Layout** | Margins, Orientation, Size, Columns, Indents |
| **References** | TOC, Footnotes, Citations |
| **Mailings** | Mail Merge, Envelopes, Labels |
| **Review** | Spelling, Grammar, Comments, Track Changes, Word Count |
| **View** | Document views, Zoom, Ruler |

> **Exam Tip:** Know which tab contains which feature. Tables = **Insert**. Margins = **Layout**. Spelling = **Review**. Page Borders = **Design**. Mail Merge = **Mailings**. This is one of the most commonly asked question types.

## 3. Document Operations

### Creating, Opening, Saving, and Closing Documents

| Operation | Shortcut | Alternative |
|-----------|----------|-------------|
| New document | **Ctrl + N** | File → New |
| Open document | **Ctrl + O** | File → Open |
| Save | **Ctrl + S** | File → Save |
| Save As | **F12** | File → Save As |
| Close document | **Ctrl + W** | File → Close |
| Exit Word | **Alt + F4** | File → Exit |
| Print / Preview | **Ctrl + P** | File → Print |

### Save vs Save As

| Save (Ctrl + S) | Save As (F12) |
|-----------------|---------------|
| Updates the existing file | Creates a new copy with different name/location/format |
| No dialog box (for previously saved files) | Always shows dialog box |
| Overwrites original | Original remains unchanged |

> **Exam Tip:** "What is the difference between Save and Save As?" is one of the most commonly asked questions. **Save** overwrites the existing file. **Save As** saves a new copy.

### File Formats

| Format | Extension | Description |
|--------|-----------|-------------|
| Word Document | **.docx** | Default format (Word 2007+) |
| Word 97-2003 | **.doc** | Older format |
| PDF | **.pdf** | Universal, preserves layout |
| Rich Text | **.rtf** | Cross-platform compatible |
| Plain Text | **.txt** | No formatting |
| Template | **.dotx** | Reusable template |

> **Exam Tip:** Default file format for MS Word 2007 and later is **.docx** (not .doc). The .docx format uses XML-based storage and is smaller in file size.

## 4. Text Editing

### Insert Mode vs Overtype Mode

- **Insert Mode** (default): New text is inserted at the cursor; existing text moves right.
- **Overtype Mode**: New text replaces existing text character by character.
- Toggle with the **Insert** key on the keyboard.

### Text Selection

| Action | Mouse | Keyboard |
|--------|-------|----------|
| Select a word | Double-click | Ctrl + Shift + Right Arrow |
| Select a line | Click left margin | Shift + End (from start) |
| Select a paragraph | Triple-click | — |
| Select all | — | **Ctrl + A** |
| Select to start of doc | — | Ctrl + Shift + Home |
| Select to end of doc | — | Ctrl + Shift + End |

### Cut, Copy, Paste

| Operation | Shortcut | What Happens |
|-----------|----------|-------------|
| **Copy** | **Ctrl + C** | Copies text to clipboard (original stays) |
| **Cut** | **Ctrl + X** | Moves text to clipboard (original is removed) |
| **Paste** | **Ctrl + V** | Inserts clipboard content at cursor |

**Copy = Duplicate, Cut = Move**

### Undo and Redo

| Operation | Shortcut | Purpose |
|-----------|----------|---------|
| **Undo** | **Ctrl + Z** | Reverses the last action |
| **Redo** | **Ctrl + Y** | Reverses an undo |

> **Exam Tip:** The shortcuts Ctrl+C, Ctrl+X, Ctrl+V, Ctrl+Z, and Ctrl+Y appear in virtually every CCC exam. Memorize them perfectly.

## 5. Text Formatting

### Font Formatting

| Feature | Shortcut | Location |
|---------|----------|----------|
| **Bold** | **Ctrl + B** | Home → Font |
| **Italic** | **Ctrl + I** | Home → Font |
| **Underline** | **Ctrl + U** | Home → Font |
| Subscript | Ctrl + = | Home → Font |
| Superscript | Ctrl + Shift + + | Home → Font |
| Font dialog box | **Ctrl + D** | Home → Font (small arrow) |
| Increase font size | Ctrl + ] | Home → Font |
| Decrease font size | Ctrl + [ | Home → Font |

- **Default font** (Word 2007+): Calibri, 11 pt
- **Default font** (Word 2003): Times New Roman, 12 pt

### Text Alignment

| Alignment | Shortcut | Description |
|-----------|----------|-------------|
| **Left** | **Ctrl + L** | Default alignment |
| **Center** | **Ctrl + E** | Centered between margins |
| **Right** | **Ctrl + R** | Aligned to right margin |
| **Justify** | **Ctrl + J** | Aligned to both margins |

> **Exam Tip:** Memory trick for alignment shortcuts: **L**eft, c**E**nter, **R**ight, **J**ustify. These four shortcuts are asked in almost every exam.

### Line Spacing

| Spacing | Shortcut |
|---------|----------|
| Single (1.0) | Ctrl + 1 |
| 1.5 lines | Ctrl + 5 |
| Double (2.0) | Ctrl + 2 |

Default line spacing in Word 2007+: **1.15** (not single spacing)

### Change Case (Shift + F3)

Cycles through: Sentence case → UPPERCASE → lowercase

Also available: Home → Font → Change Case (Aa button) for Title Case and tOGGLE cASE options.

## 6. Paragraph Formatting

### Indenting

| Type | Description |
|------|-------------|
| **Left Indent** | Entire paragraph moves right from left margin |
| **Right Indent** | Entire paragraph moves left from right margin |
| **First Line Indent** | Only the first line is indented |
| **Hanging Indent** | All lines except the first are indented |

Set indents using the ruler, the Paragraph dialog box (Home → Paragraph → small arrow), or the Tab key.

### Bullets and Numbering

- **Bullets**: Unordered lists (Home → Paragraph → Bullets)
- **Numbering**: Ordered/sequential lists (Home → Paragraph → Numbering)
- Press **Tab** to demote a list item (create sub-level); **Shift + Tab** to promote

### Headers and Footers

- **Header**: Text at the top of every page (Insert tab)
- **Footer**: Text at the bottom of every page (Insert tab)
- **Page Numbers**: Insert → Page Number (formats: 1,2,3 or i,ii,iii or a,b,c)

> **Exam Tip:** Headers and footers are inserted from the **Insert** tab. Page numbers can appear in headers or footers. The "Page X of Y" format is commonly asked about.

### Find and Replace

| Feature | Shortcut |
|---------|----------|
| **Find** | **Ctrl + F** |
| **Replace** | **Ctrl + H** |
| **Go To** | **Ctrl + G** or **F5** |

> **Exam Tip:** **Ctrl + H** for Find and Replace is one of the most frequently asked shortcuts in the CCC exam. Remember: **H** = Hunt and Replace.

## 7. Tables

### Creating Tables

- **Insert tab → Table** → choose rows/columns from the grid
- Or click **Insert Table** for exact specifications
- Or use **Draw Table** for custom table structures

### Table Operations

| Operation | How To |
|-----------|--------|
| Add row at end | Press **Tab** in last cell |
| Insert row above/below | Layout tab → Insert Above/Below |
| Insert column left/right | Layout tab → Insert Left/Right |
| Delete row/column | Layout tab → Delete (not keyboard Delete key) |
| **Merge Cells** | Select cells → Layout tab → Merge Cells |
| **Split Cells** | Click cell → Layout tab → Split Cells |
| Sort data | Layout tab → Sort |
| Convert text to table | Insert tab → Table → Convert Text to Table |

### Text Alignment in Cells

There are **9 alignment options** in table cells: 3 vertical (Top, Middle, Bottom) x 3 horizontal (Left, Center, Right). Found in the Layout tab.

> **Exam Tip:** To add a new row at the end of a table, press **Tab** in the last cell. Merge Cells combines multiple cells into one; Split Cells divides one cell into multiple. Both are in the **Layout** tab.

## 8. Spelling, Grammar, and AutoCorrect

- **F7** opens the Spelling and Grammar checker (also in Review tab)
- **Red wavy underline** = spelling error
- **Blue wavy underline** = grammar error
- **AutoCorrect** (File → Options → Proofing) automatically fixes common typos as you type

### Word Count

- Visible on the **Status Bar** (bottom of screen)
- Also available: Review tab → Word Count
- Shows pages, words, characters (with/without spaces), paragraphs, lines

> **Exam Tip:** **F7** = Spelling and Grammar check. Red underline = spelling error. Word count is shown on the Status Bar.

## 9. Mail Merge

Mail Merge creates personalized mass documents by combining:
1. **Main Document** — the template with merge fields
2. **Data Source** — the data (Excel file, Word table, database)
3. **Merge Fields** — placeholders like <<Name>>, <<Address>>

Steps: Mailings tab → Start Mail Merge → Select Recipients → Insert Merge Fields → Preview Results → Finish & Merge.

> **Exam Tip:** Mail Merge is in the **Mailings** tab. The data source is often an Excel file. Know the three components: Main Document, Data Source, and Merge Fields.

## 10. Additional Features

### Page Setup (Layout Tab)

| Setting | Default |
|---------|---------|
| Margins | 1 inch on all sides |
| Orientation | Portrait |
| Paper Size | A4 (21 cm x 29.7 cm) |

### Document Views (View Tab)

| View | Description |
|------|-------------|
| **Print Layout** | Default view — shows page as it will print |
| **Read Mode** | Book-like reading view |
| **Web Layout** | How page looks as a web page |
| **Outline** | Document structure with headings |
| **Draft** | Text only, no margins — fast editing |

### Page Borders and Watermarks (Design Tab)

- **Page Borders**: Decorative borders around the entire page. Art borders available.
- **Watermarks**: Faint text/image behind content (CONFIDENTIAL, DRAFT, etc.)

### Columns (Layout Tab)

- Split text into newspaper-style columns (Two, Three, or custom)
- Found in Layout tab → Columns

### Inserting Images (Insert Tab)

- Pictures, Online Pictures, Shapes, Icons
- Text wrapping options: In Line with Text (default), Square, Tight, Behind Text, In Front of Text

### Saving as PDF

- File → Save As → choose PDF format
- Or File → Export → Create PDF/XPS Document

> **Exam Tip:** Page Borders and Watermarks are in the **Design** tab. Columns are in the **Layout** tab. Default view is **Print Layout**. Default margins are **1 inch** on all sides.
