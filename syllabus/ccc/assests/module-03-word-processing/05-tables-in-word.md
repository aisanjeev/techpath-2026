## What is a Table?

A **table** is a grid of rows and columns used to organize data in a structured format. Each box in the table is called a **cell**. Tables are one of the most important features in MS Word and are heavily tested in the CCC exam.

### Table Terminology

| Term | Meaning |
|------|---------|
| **Row** | A horizontal line of cells (goes left to right) |
| **Column** | A vertical line of cells (goes top to bottom) |
| **Cell** | A single box where a row and column meet |
| **Border** | The lines that form the edges of cells |
| **Gridlines** | Light lines that show cell boundaries (visible on screen but may not print) |

**Example:** A table with 3 rows and 4 columns has 3 x 4 = **12 cells**.

## Creating a Table

There are several ways to insert a table in MS Word:

### Method 1: Using the Grid (Quick Method)

1. Place the cursor where you want the table
2. Go to **Insert** tab → **Tables** group → click **Table**
3. A grid appears — move your mouse to select the number of rows and columns
4. Click to insert (maximum 10 x 8 through the grid)

### Method 2: Insert Table Dialog Box

1. Go to **Insert** tab → **Table** → click **Insert Table**
2. Enter the number of rows and columns
3. Choose AutoFit behavior:
   - **Fixed column width** — you set the width
   - **AutoFit to contents** — columns resize to fit the text
   - **AutoFit to window** — table stretches to fill the page width
4. Click OK

### Method 3: Draw Table

1. Go to **Insert** tab → **Table** → click **Draw Table**
2. The cursor becomes a pencil
3. Draw the outer border first, then draw inner lines to create rows and columns
4. This method gives you full control over table structure

### Method 4: Convert Text to Table

If you already have text separated by tabs, commas, or other characters:
1. Select the text
2. Go to **Insert** tab → **Table** → **Convert Text to Table**
3. Choose the separator (tabs, commas, paragraphs, or other)
4. Click OK

**CCC Exam Tip:** Tables are inserted from the **Insert** tab. The "Convert Text to Table" feature is sometimes asked about. Remember that you can also convert a table back to text (**Layout** tab → **Convert to Text**).

## Selecting Parts of a Table

| What to Select | How to Do It |
|---------------|-------------|
| A **cell** | Click inside the cell near the left edge (cursor becomes a small black arrow) |
| A **row** | Click to the left of the row (outside the table) |
| A **column** | Position the cursor at the top border of the column (cursor becomes a downward arrow) and click |
| **Multiple cells** | Click and drag across the cells |
| **Entire table** | Click the **table move handle** (small square with arrows at the top-left corner of the table) |
| **Entire table** | Place cursor in table → press **Alt + Shift + 5** (on the numeric keypad with Num Lock OFF) |

## Table Design and Layout Tabs

When you click inside a table, two new tabs appear on the ribbon:

### Table Design Tab
- **Table Styles** — pre-made designs with colours and formatting
- **Borders** — add/remove borders, choose border styles
- **Shading** — add background colour to cells

### Table Layout Tab
- **Insert** rows/columns
- **Delete** rows/columns/table
- **Merge/Split** cells
- **Cell size** — row height, column width
- **Alignment** — text alignment within cells
- **Sort** — sort table data
- **Convert to Text** — convert table back to plain text

## Adding and Deleting Rows and Columns

### Inserting Rows

| Action | Steps |
|--------|-------|
| Insert row **above** | Click in a row → **Layout** tab → **Insert Above** |
| Insert row **below** | Click in a row → **Layout** tab → **Insert Below** |
| Quick add at end | Place cursor in the last cell of the last row → press **Tab** |

### Inserting Columns

| Action | Steps |
|--------|-------|
| Insert column to **left** | Click in a column → **Layout** tab → **Insert Left** |
| Insert column to **right** | Click in a column → **Layout** tab → **Insert Right** |

### Deleting Rows, Columns, or the Entire Table

1. Select the row(s), column(s), or entire table
2. Go to **Layout** tab → click **Delete**
3. Choose: Delete Cells, Delete Columns, Delete Rows, or Delete Table

**Important:** Pressing the **Delete** key on the keyboard only deletes the content inside the cells, not the cells themselves. To delete the structure, you must use the **Layout** tab → **Delete** option.

**CCC Exam Tip:** To add a new row at the end of a table, press **Tab** in the last cell. This is a frequently asked shortcut. Also remember: pressing Delete only clears content, not the row/column itself.

## Merging and Splitting Cells

### Merge Cells

**Merging** combines two or more cells into one larger cell. This is commonly used for table headings.

**How to merge cells:**
1. Select the cells you want to merge
2. Go to **Layout** tab → click **Merge Cells**

**Example:** Amit is creating a student report card. He wants "Student Details" as a heading spanning across 4 columns. He selects all 4 cells in the first row and clicks Merge Cells.

| Student Details (merged across 4 columns) ||||
|------|------|------|------|
| Name | Class | Subject | Marks |
| Rahul | 10th | Mathematics | 85 |

### Split Cells

**Splitting** divides one cell into multiple cells.

**How to split cells:**
1. Click inside the cell you want to split
2. Go to **Layout** tab → click **Split Cells**
3. Enter the number of columns and rows
4. Click OK

### Split Table

To split one table into two separate tables:
1. Place the cursor in the row that should become the first row of the new table
2. Go to **Layout** tab → click **Split Table**

**CCC Exam Tip:** **Merge Cells** combines multiple cells into one. **Split Cells** divides one cell into many. Both are found in the **Layout** tab. These operations are commonly asked about.

## Adjusting Cell Width and Height

### Column Width

- **Drag** the column border to resize manually
- Go to **Layout** tab → enter a value in the **Width** box
- **Double-click** a column border to auto-fit to the widest content

### Row Height

- **Drag** the row border to resize manually
- Go to **Layout** tab → enter a value in the **Height** box

### Distribute Rows/Columns Evenly

To make all rows equal height or all columns equal width:
- Select the rows/columns
- Go to **Layout** tab → click **Distribute Rows** or **Distribute Columns**

### AutoFit

- **AutoFit Contents** — columns adjust to fit the text inside
- **AutoFit Window** — table stretches to fit the page width
- **Fixed Column Width** — columns stay at a fixed width

Found in: **Layout** tab → **AutoFit** dropdown.

## Text Alignment in Cells

Text inside table cells can be aligned in **9 different positions** (combination of horizontal and vertical alignment):

| Top Left | Top Center | Top Right |
|----------|------------|-----------|
| Middle Left | Middle Center | Middle Right |
| Bottom Left | Bottom Center | Bottom Right |

To change alignment:
1. Select the cell(s)
2. Go to **Layout** tab → **Alignment** group → click the desired alignment button

The default alignment is **Top Left**.

**CCC Exam Tip:** There are **9 alignment options** for text in table cells (3 horizontal x 3 vertical positions). This is sometimes asked.

## Borders and Shading

### Adding Borders

1. Select the cells, rows, or entire table
2. Go to **Table Design** tab → **Borders** group
3. Click the **Borders** dropdown → choose a border option:
   - **All Borders** — adds borders to all cells
   - **Outside Borders** — adds borders only around the outer edge
   - **No Border** — removes all borders
   - **Borders and Shading** — opens a dialog box with more options (line style, colour, width)

### Adding Shading (Background Colour)

1. Select the cells
2. Go to **Table Design** tab → click the **Shading** dropdown
3. Choose a colour

**Example:** Sneha is creating a price list for TechPath Institute. She adds a dark blue background with white text to the header row to make it stand out.

| Course | Duration | Fee |
|--------|----------|-----|
| CCC | 3 Months | Rs. 3,000 |
| ADCA | 12 Months | Rs. 15,000 |
| Tally | 3 Months | Rs. 5,000 |

## Sorting Table Data

You can sort the data in a table alphabetically, numerically, or by date:

1. Click inside the table
2. Go to **Layout** tab → click **Sort**
3. Choose the column to sort by
4. Choose **Ascending** (A-Z, 1-9) or **Descending** (Z-A, 9-1)
5. Click OK

You can sort by up to 3 columns (primary, secondary, tertiary sort).

## Practical Example: Creating a Student Marks Table

Ananya needs to create a marks table for her class:

1. Go to **Insert** tab → **Table** → select 5 columns and 6 rows
2. Type the headers: Roll No, Name, Hindi, English, Maths
3. Enter the student data
4. Select the header row → apply **Bold** formatting
5. Select the header row → add **Shading** (light blue)
6. Select the entire table → add **All Borders**
7. Merge the first row to create a title "Class 10 — Term 1 Results"
8. Center-align all cells with numbers
