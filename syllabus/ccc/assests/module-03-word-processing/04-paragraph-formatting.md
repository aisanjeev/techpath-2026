## Paragraph Indenting

**Indenting** means adding extra space between the margin and the text of a paragraph. Indenting helps organize text and makes documents look professional.

### Types of Indents

| Indent Type | Description | How It Looks |
|------------|-------------|-------------|
| **Left Indent** | Moves the entire paragraph away from the left margin | All lines shift right |
| **Right Indent** | Moves the entire paragraph away from the right margin | All lines shift left |
| **First Line Indent** | Only the first line of the paragraph is indented | Common in books and letters |
| **Hanging Indent** | All lines except the first line are indented | Used in bibliographies and references |

### How to Set Indents

**Method 1: Using the Ruler**
- Drag the **First Line Indent** marker (top triangle on the left ruler) to set first line indent
- Drag the **Hanging Indent** marker (bottom triangle on the left ruler) to set hanging indent
- Drag the **Left Indent** marker (small rectangle below the triangles) to move the entire paragraph

**Method 2: Using the Paragraph Dialog Box**
1. Select the paragraph
2. Go to **Home** tab → **Paragraph** group → click the small arrow in the bottom-right corner
3. Under **Indentation**, set Left, Right, and Special (First Line or Hanging)

**Method 3: Using the Tab Key**
- Press **Tab** at the beginning of a paragraph to indent the first line by 0.5 inches (default tab stop)

**Method 4: Using the Increase/Decrease Indent Buttons**
- **Home** tab → **Paragraph** group → use the **Increase Indent** and **Decrease Indent** buttons

**CCC Exam Tip:** Know the difference between **First Line Indent** (only first line moves right) and **Hanging Indent** (all lines except first move right). This is commonly asked.

## Bullets and Numbering

Bullets and numbering help create organized lists in your document.

### Bullets

Bullets create an unordered list (no sequence):
- Each item starts with a symbol (dot, arrow, square, etc.)
- Used when the order of items does not matter

**How to add bullets:**
1. Select the text (each paragraph becomes a bullet point)
2. Go to **Home** tab → **Paragraph** group → click the **Bullets** button
3. Click the dropdown arrow to choose different bullet styles

### Numbering

Numbering creates an ordered list (sequential):
1. Each item starts with a number (1, 2, 3 or a, b, c or I, II, III)
2. Used when the order of items matters (steps, instructions)

**How to add numbering:**
1. Select the text
2. Go to **Home** tab → **Paragraph** group → click the **Numbering** button
3. Click the dropdown arrow to choose different numbering styles

### Multilevel Lists

Multilevel lists have sub-items under main items:
1. Main Item
   a. Sub-item
   b. Sub-item
2. Another Main Item
   a. Sub-item

To create: Click the **Multilevel List** button in the Paragraph group.

To change the level of an item: Place the cursor at the beginning and press **Tab** to demote (go deeper) or **Shift + Tab** to promote (go up a level).

**CCC Exam Tip:** Bullets are used for unordered lists, Numbering for ordered lists. Both are found in the **Paragraph** group on the **Home** tab.

## Changing Text Case

MS Word can quickly change the case (uppercase/lowercase) of selected text.

### Case Options

| Case | Example | Description |
|------|---------|-------------|
| **Sentence case** | This is a sentence. | First letter of first word is capital |
| **lowercase** | this is lowercase | All letters are small |
| **UPPERCASE** | THIS IS UPPERCASE | All letters are capital |
| **Capitalize Each Word** | This Is Title Case | First letter of each word is capital |
| **tOGGLE cASE** | tHIS iS tOGGLE | Reverses each letter's case |

### How to Change Case

**Method 1:** Select the text → go to **Home** tab → **Font** group → click the **Change Case** button (Aa icon) → choose the option.

**Method 2:** Select the text → press **Shift + F3** to cycle through Sentence case → UPPERCASE → lowercase.

**CCC Exam Tip:** **Shift + F3** is the shortcut to change text case. It cycles through three options: Sentence case, UPPERCASE, and lowercase. This is a frequently asked question.

## Headers and Footers

**Headers** and **Footers** are areas at the top and bottom of every page where you can add text, page numbers, dates, or other information that repeats on every page.

### Header
- Appears at the **top** of every page
- Common uses: document title, chapter name, company name, date

### Footer
- Appears at the **bottom** of every page
- Common uses: page numbers, author name, filename, copyright notice

### How to Add Headers and Footers

**Method 1:** Go to **Insert** tab → **Header & Footer** group → click **Header** or **Footer** → choose a style.

**Method 2:** **Double-click** at the top of the page (for header) or bottom of the page (for footer).

To exit the header/footer area: **Double-click** on the main document area, or click **Close Header and Footer** in the ribbon.

**CCC Exam Tip:** Headers and Footers are found in the **Insert** tab. They repeat on every page of the document. You can have different headers/footers for the first page and for odd/even pages.

## Page Numbering

Page numbers help readers navigate multi-page documents.

### How to Add Page Numbers

1. Go to **Insert** tab → **Header & Footer** group → click **Page Number**
2. Choose the position:
   - **Top of Page** — page number appears in the header
   - **Bottom of Page** — page number appears in the footer
   - **Page Margins** — page number appears on the side
   - **Current Position** — inserts page number at the cursor location

### Page Number Formats

You can choose different formats:
- **1, 2, 3** (Arabic numerals — most common)
- **i, ii, iii** (Roman numerals — used for preface/introduction)
- **a, b, c** (Alphabetical)
- **Page X of Y** format (e.g., "Page 3 of 10")

To change format: Click **Page Number** → **Format Page Numbers** → choose the number format.

**CCC Exam Tip:** Page numbers are inserted from the **Insert** tab → **Page Number**. The "Page X of Y" format is commonly asked about.

## Find and Replace

**Find and Replace** is one of the most useful features in MS Word. It lets you quickly search for specific text and optionally replace it with different text.

### Find (Ctrl + F)

- Opens the **Navigation Pane** on the left side
- Type the word or phrase you want to find
- Word highlights all matches in the document and shows them in the navigation pane
- Use the up/down arrows to jump between matches

### Replace (Ctrl + H)

- Opens the **Find and Replace** dialog box
- **Find what:** Enter the text you want to find
- **Replace with:** Enter the text you want to replace it with
- **Replace:** Replaces the current match
- **Replace All:** Replaces all matches at once (be careful — review first!)
- **Find Next:** Finds the next match without replacing

### Go To (Ctrl + G or F5)

The "Go To" tab in the Find and Replace dialog lets you jump directly to:
- A specific **page number**
- A specific **section**, **line**, **bookmark**, **comment**, or **footnote**

### Practical Example

Priya has written a 20-page report for TechPath Institute. She realizes she spelled "programme" throughout the document but the correct spelling should be "program". Instead of manually changing each one:

1. She presses **Ctrl + H** to open Find and Replace
2. In "Find what" she types: **programme**
3. In "Replace with" she types: **program**
4. She clicks **Replace All**
5. Word reports: "Word has completed 47 replacements"

This saves her a huge amount of time!

**CCC Exam Tip:** **Ctrl + F** = Find, **Ctrl + H** = Replace, **Ctrl + G** or **F5** = Go To. The shortcut **Ctrl + H** is one of the most frequently asked questions in the CCC exam. Remember: H for Hunt and replace.

## Borders and Shading (for Paragraphs)

You can add borders and shading to paragraphs to make them stand out.

### Paragraph Borders
1. Select the paragraph
2. Go to **Home** tab → **Paragraph** group → click the **Borders** dropdown
3. Choose a border style (Bottom Border, All Borders, Outside Borders, etc.)
4. For more options, click **Borders and Shading** at the bottom of the dropdown

### Paragraph Shading
1. Select the paragraph
2. Go to **Home** tab → **Paragraph** group → click the **Shading** dropdown (paint bucket icon)
3. Choose a background colour for the paragraph
