## Creating a New Document

When you open MS Word, a blank document appears automatically. You can also create new documents at any time:

| Method | How to Do It |
|--------|-------------|
| Keyboard shortcut | Press **Ctrl + N** |
| File menu | Click **File** → **New** → **Blank Document** |
| Template | Click **File** → **New** → select a template (letter, resume, etc.) |

The blinking vertical line you see is called the **cursor** (or insertion point). Whatever you type will appear at the cursor position.

---

## Typing Text

Simply start typing to enter text into your document. MS Word automatically wraps text to the next line when you reach the right margin — you do not need to press Enter at the end of every line.

Press **Enter** only when you want to start a **new paragraph**.

**CCC Exam Tip:** Word wrapping is automatic in MS Word. Pressing Enter creates a new paragraph, not just a new line. To create a new line within the same paragraph, press **Shift + Enter** (this inserts a line break, not a paragraph break).

---

## Insert Mode vs Overtype Mode

MS Word has two typing modes:

### Insert Mode (Default)

In Insert mode, new text is **inserted** at the cursor position, and existing text moves to the right to make room. This is the default mode.

**Example:** If you have the text "Hello World" and place your cursor between "Hello" and "World", typing "Beautiful " gives you "Hello Beautiful World".

### Overtype Mode

In Overtype mode, new text **replaces** (overwrites) existing text character by character.

**Example:** If you have "Hello World" and place your cursor at "W", typing "Earth" replaces "World" with "Earth".

### Switching Between Modes

- Press the **Insert** key on your keyboard to toggle between Insert and Overtype mode
- You can also enable/disable it from **File** → **Options** → **Advanced** → check/uncheck "Use overtype mode"

**CCC Exam Tip:** The default typing mode in MS Word is **Insert mode**. The **Insert key** toggles between Insert and Overtype mode. This is a frequently asked question.

## Moving the Cursor

You can move the cursor using the mouse (click where you want to go) or the keyboard:

### Arrow Keys

| Key | Movement |
|-----|----------|
| ← (Left Arrow) | One character to the left |
| → (Right Arrow) | One character to the right |
| ↑ (Up Arrow) | One line up |
| ↓ (Down Arrow) | One line down |

### Ctrl + Arrow Keys (Move Faster)

| Key Combination | Movement |
|----------------|----------|
| **Ctrl + ←** | One word to the left |
| **Ctrl + →** | One word to the right |
| **Ctrl + ↑** | One paragraph up |
| **Ctrl + ↓** | One paragraph down |

### Home and End Keys

| Key Combination | Movement |
|----------------|----------|
| **Home** | Beginning of the current line |
| **End** | End of the current line |
| **Ctrl + Home** | Beginning of the document |
| **Ctrl + End** | End of the document |

### Page Up and Page Down

| Key | Movement |
|-----|----------|
| **Page Up** | One screen up |
| **Page Down** | One screen down |

**CCC Exam Tip:** **Ctrl + Home** goes to the beginning of the document and **Ctrl + End** goes to the end. These shortcuts are commonly asked.

## Selecting Text

Before you can format, copy, or delete text, you must first **select** it. Selected text appears highlighted (usually in blue).

### Selection Using Mouse

| What to Select | Mouse Action |
|---------------|-------------|
| A word | **Double-click** the word |
| A sentence | Hold **Ctrl** and **click** anywhere in the sentence |
| A line | Click in the **left margin** next to the line (cursor becomes a right-pointing arrow) |
| A paragraph | **Triple-click** anywhere in the paragraph |
| A block of text | Click at the start, hold **Shift**, and click at the end |
| Entire document | **Ctrl + A** |

### Selection Using Keyboard

| Key Combination | What Gets Selected |
|----------------|-------------------|
| **Shift + →** | One character to the right |
| **Shift + ←** | One character to the left |
| **Shift + ↓** | To the same position on the next line |
| **Shift + ↑** | To the same position on the previous line |
| **Ctrl + Shift + →** | One word to the right |
| **Ctrl + Shift + ←** | One word to the left |
| **Shift + Home** | From cursor to beginning of line |
| **Shift + End** | From cursor to end of line |
| **Ctrl + Shift + Home** | From cursor to beginning of document |
| **Ctrl + Shift + End** | From cursor to end of document |
| **Ctrl + A** | Select entire document |

**CCC Exam Tip:** **Ctrl + A** selects the entire document. **Double-click** selects a word. **Triple-click** selects a paragraph. These are frequently asked.

## Cut, Copy, and Paste

These are the most important editing operations in MS Word.

### Copy (Ctrl + C)

- **Copies** the selected text to the **clipboard** (a temporary storage area in memory)
- The original text remains in place
- You can then paste it somewhere else

### Cut (Ctrl + X)

- **Removes** the selected text from its current location and places it on the **clipboard**
- The original text disappears
- You can then paste it in a new location (this is how you "move" text)

### Paste (Ctrl + V)

- **Inserts** whatever is on the clipboard at the current cursor position
- You can paste the same content multiple times

### How to Use Cut/Copy/Paste

1. **Select** the text you want to cut or copy
2. Press **Ctrl + C** (copy) or **Ctrl + X** (cut)
3. Place the cursor where you want the text to go
4. Press **Ctrl + V** (paste)

### Paste Options

When you paste, a small **Paste Options** icon appears near the pasted text. It lets you choose:
- **Keep Source Formatting** — keeps the original formatting
- **Merge Formatting** — matches the surrounding text formatting
- **Keep Text Only** — pastes plain text without any formatting

### Cut vs Copy — Key Difference

| Feature | Cut (Ctrl + X) | Copy (Ctrl + C) |
|---------|---------------|-----------------|
| Original text | **Removed** from original location | **Remains** in original location |
| Clipboard | Text placed on clipboard | Text placed on clipboard |
| Purpose | **Move** text | **Duplicate** text |

**CCC Exam Tip:** This is extremely important for the exam. Remember: Cut = Move, Copy = Duplicate. The shortcut keys (Ctrl+C, Ctrl+X, Ctrl+V) are asked in almost every CCC exam.

## Undo and Redo

### Undo (Ctrl + Z)

**Undo** reverses the last action you performed. If you accidentally deleted some text, pressing Ctrl + Z brings it back.

- You can undo multiple actions by pressing Ctrl + Z repeatedly
- Each press undoes one more previous action
- You can also click the **Undo** button on the Quick Access Toolbar

### Redo (Ctrl + Y)

**Redo** reverses an undo. If you undid something by mistake, press Ctrl + Y to redo it.

- Redo is only available after you have used Undo
- You can also click the **Redo** button on the Quick Access Toolbar

**Example:** Rahul is typing a letter. He accidentally deletes a paragraph. He presses **Ctrl + Z** and the paragraph comes back. Then he realizes he actually wanted to delete it, so he presses **Ctrl + Y** to redo the deletion.

**CCC Exam Tip:** **Ctrl + Z = Undo** and **Ctrl + Y = Redo**. These are among the most frequently asked shortcuts in the CCC exam.

---

## Clipboard

The **Clipboard** is a temporary storage area in memory that holds text or images you have cut or copied.

Key facts about the clipboard:
- MS Word can store up to **24 items** on the clipboard at once
- You can view the clipboard by clicking the small arrow at the bottom-right of the **Clipboard group** on the Home tab
- The clipboard is cleared when you close all Office applications
- You can paste any item from the clipboard, not just the most recent one

## Deleting Text

| Key | Action |
|-----|--------|
| **Delete** (or Del) | Deletes the character **to the right** of the cursor |
| **Backspace** | Deletes the character **to the left** of the cursor |
| **Ctrl + Delete** | Deletes the word to the right of the cursor |
| **Ctrl + Backspace** | Deletes the word to the left of the cursor |
| Select text + **Delete** | Deletes all selected text |

**CCC Exam Tip:** Know the difference between Delete key (removes character to the right) and Backspace (removes character to the left).
