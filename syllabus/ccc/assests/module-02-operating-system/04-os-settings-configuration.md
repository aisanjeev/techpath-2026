# OS Settings and Configuration

**Module 02 — CCC Exam Preparation | Topic 4**

---

## Introduction

Windows allows you to customize and configure many settings to suit your needs. These settings are available through two main locations:

1. **Settings App** (Modern — Windows 10/11)
2. **Control Panel** (Classic — available in all Windows versions)

Both let you change system settings, but the Settings app is newer and more visual, while the Control Panel is the traditional way with more detailed options.

---

## Control Panel

The **Control Panel** is the classic settings manager in Windows. It has been part of Windows since the earliest versions.

### How to Open Control Panel:
- Press **Windows key**, type "Control Panel", press Enter
- Or: Windows + R > type `control` > press Enter

### Control Panel Categories:

| Category | What You Can Change |
|----------|-------------------|
| **System and Security** | Windows Firewall, Windows Update, Power Options, System info |
| **User Accounts** | Add/remove users, change passwords, account type |
| **Network and Internet** | Wi-Fi settings, network sharing, internet options |
| **Hardware and Sound** | Printers, sound, power plan, device manager |
| **Programs** | Install/uninstall programs, default programs, Windows features |
| **Appearance and Personalization** | Desktop background, screen resolution, fonts, taskbar |
| **Clock and Region** | Date/time, language, region format (Indian date format) |
| **Ease of Access** | Accessibility features for people with disabilities |

**CCC Exam Tip:** Control Panel is the central place to change system settings. This concept is asked frequently. Know the main categories.

## Date and Time Settings

### How to Change Date and Time:
**Method 1:**
1. Right-click the **clock** in the system tray (bottom-right)
2. Click **Adjust date/time**
3. Toggle "Set time automatically" OFF
4. Click **Change** under "Set the date and time manually"
5. Set the correct date and time
6. Click **Change**

**Method 2 — Control Panel:**
1. Open Control Panel > Clock and Region > Date and Time
2. Click **Change date and time**
3. Set the values and click OK

### Time Zone:
- India's time zone is **IST (Indian Standard Time)** = UTC + 5:30
- To change: Settings > Time & Language > Date & Time > Time Zone
- Select "(UTC+05:30) Chennai, Kolkata, Mumbai, New Delhi"

**CCC Exam Tip:** India follows IST (Indian Standard Time) = GMT/UTC + 5:30.

## Display Settings

### Changing Screen Resolution:
1. Right-click on Desktop > **Display settings**
2. Scroll to **Display resolution**
3. Select the desired resolution (e.g., 1920 x 1080 for Full HD)
4. Click **Keep changes** if it looks good

### Common Resolutions:
| Resolution | Name | Usage |
|-----------|------|-------|
| 1366 x 768 | HD | Basic laptops |
| 1920 x 1080 | Full HD (1080p) | Most monitors and laptops |
| 2560 x 1440 | 2K/QHD | High-end monitors |
| 3840 x 2160 | 4K/UHD | Premium displays |

### Changing Desktop Background (Wallpaper):
1. Right-click on Desktop > **Personalize**
2. Click **Background**
3. Choose:
   - **Picture** — select an image
   - **Solid colour** — choose a single colour
   - **Slideshow** — rotate through multiple images
4. Click **Browse** to select your own photo

### Screen Saver:
- A screen saver is an animation that appears when the computer is idle
- Settings > Personalization > Lock Screen > Screen saver settings
- Choose a screen saver type and set the wait time (e.g., 5 minutes)
- Originally designed to prevent screen burn-in on CRT monitors

## Mouse Settings

### How to Change Mouse Settings:
1. Open Settings > Devices > Mouse
2. Or: Control Panel > Hardware and Sound > Mouse

### Settings You Can Change:

| Setting | What It Does |
|---------|-------------|
| **Primary Button** | Swap left and right buttons (useful for left-handed users) |
| **Cursor Speed** | How fast the mouse pointer moves on screen |
| **Scroll Speed** | How many lines scroll per mouse wheel click |
| **Double-click Speed** | How fast you need to double-click |
| **Pointer Style** | Change the look of the mouse cursor |
| **Pointer Trails** | Show a trail behind the cursor (helps find it on screen) |

## Sound Settings

### How to Change Sound Settings:
1. Click the **Volume icon** in the system tray
2. Adjust the volume slider
3. For more options: Right-click volume icon > **Sound settings**

### What You Can Change:
- **Master Volume** — overall volume level
- **App Volume** — individual volume for each program
- **Output Device** — speakers or headphones
- **Input Device** — microphone settings
- **System Sounds** — sounds for notifications, errors, startup

## Adding and Removing Printers

### Adding a Printer:
1. Open Settings > Devices > Printers & Scanners
2. Click **Add a printer or scanner**
3. Windows will search for available printers
4. Select the printer and click **Add device**
5. If the printer is not found, click "The printer that I want isn't listed" for manual setup

### Setting Default Printer:
1. Go to Settings > Devices > Printers & Scanners
2. Click on the printer you want as default
3. Click **Manage** > **Set as default**

### Removing a Printer:
1. Go to Settings > Devices > Printers & Scanners
2. Click on the printer
3. Click **Remove device**

## Installing and Removing Programs

### Installing a Program:
1. Download the installer file (usually `.exe` or `.msi`)
2. Double-click the installer file
3. Follow the installation wizard (Next > Next > Install > Finish)
4. The program is now available in the Start Menu

### Removing (Uninstalling) a Program:
**Method 1 — Settings:**
1. Open Settings > Apps > Apps & Features
2. Find the program in the list
3. Click on it > Click **Uninstall**
4. Follow the uninstall wizard

**Method 2 — Control Panel:**
1. Open Control Panel > Programs > Programs and Features
2. Find the program
3. Right-click > **Uninstall**

**CCC Exam Tip:** To uninstall a program, use Settings > Apps or Control Panel > Programs and Features. Never just delete the program's folder — use the proper uninstall method.

## Task Manager

**Task Manager** shows you all running programs and system performance. It is essential for troubleshooting.

### How to Open Task Manager:
- Press **Ctrl + Shift + Esc** (fastest method)
- Or: Right-click taskbar > Task Manager
- Or: Press **Ctrl + Alt + Delete** > Task Manager

### Task Manager Tabs:

| Tab | Shows |
|-----|-------|
| **Processes** | All running programs and background processes |
| **Performance** | CPU, Memory, Disk, Network usage graphs |
| **App History** | Resource usage history by app |
| **Startup** | Programs that run automatically when Windows starts |
| **Users** | Currently logged-in users |
| **Details** | Detailed information about all processes |
| **Services** | System services and their status |

### Using Task Manager:
- **End a frozen program:** Select the program > Click **End Task**
- **Check CPU usage:** Go to Performance tab > CPU
- **Disable startup programs:** Go to Startup tab > Select program > Click **Disable**

**CCC Exam Tip:** **Ctrl + Shift + Esc** opens Task Manager directly. **Ctrl + Alt + Delete** shows a menu where Task Manager is one option. Both are frequently asked.

## Power Options

### Power Plans:
| Plan | Description |
|------|-------------|
| **Balanced** | Good balance between performance and energy saving (default) |
| **Power Saver** | Saves battery by reducing performance |
| **High Performance** | Maximum performance but uses more power |

### Power Options:
- **Shut Down** — Turns off the computer completely
- **Restart** — Turns off and turns on again (needed after updates)
- **Sleep** — Low-power state; computer wakes up quickly; RAM stays powered
- **Hibernate** — Saves current state to hard disk and turns off; uses no power; slower to wake up
- **Lock** (Windows + L) — Locks the screen; requires password to unlock

**CCC Exam Tip:** Sleep keeps data in RAM (uses some power). Hibernate saves data to disk (uses no power). This difference is commonly asked.

## Windows Update

Windows Update downloads and installs improvements, security patches, and new features.

### How to Check for Updates:
1. Open Settings > Windows Update (or Update & Security in Windows 10)
2. Click **Check for updates**
3. If updates are found, click **Download and install**
4. Some updates require a restart

**Why Updates are Important:**
- Fix security vulnerabilities (protect against hackers and viruses)
- Fix bugs (problems in the software)
- Add new features
- Improve performance
