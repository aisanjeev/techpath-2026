## Key Definitions

| Term | Definition |
|------|-----------|
| Operating System | System software that manages hardware and software resources |
| GUI | Graphical User Interface — visual interaction with computer |
| CLI | Command Line Interface — text-based commands |
| WIMP | Windows, Icons, Menus, Pointer — elements of GUI |
| Booting | Process of starting computer and loading the OS |
| Cold Boot | Starting a computer that is OFF (power button) |
| Warm Boot | Restarting a running computer (Ctrl+Alt+Del / Restart) |
| Kernel | Core of the OS that talks directly to hardware |
| Driver | Software that lets OS communicate with a hardware device |
| File | Collection of related data stored with a name and extension |
| Folder | Container that holds files and other folders (also called directory) |

## File Operations

| Operation | Shortcut | Result |
|-----------|----------|--------|
| Copy | Ctrl + C, then Ctrl + V | Original stays, duplicate created |
| Move | Ctrl + X, then Ctrl + V | Original removed, placed at new location |
| Rename | F2 | Change name of file/folder |
| Delete | Delete key | Goes to Recycle Bin (recoverable) |
| Permanent Delete | Shift + Delete | Gone forever (NOT recoverable) |
| Select All | Ctrl + A | Select everything in current folder |

---

## Recycle Bin

| Action | How |
|--------|-----|
| Delete to Recycle Bin | Press Delete key |
| Bypass Recycle Bin | Press Shift + Delete |
| Restore file | Open Recycle Bin > Right-click file > Restore |
| Empty Recycle Bin | Right-click Recycle Bin > Empty Recycle Bin |

**Remember:** Shift + Delete = permanent = NO recovery
