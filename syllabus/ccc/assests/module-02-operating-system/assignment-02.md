## Task 2: Explore and Change Windows Settings

**Objective:** Practice navigating Windows Settings and Control Panel.

**What to Do:**

**Part A — Display Settings:**
1. Right-click on the Desktop > **Display settings**
2. Note your current screen resolution: ___________
3. Change the desktop wallpaper:
   - Right-click Desktop > **Personalize** > **Background**
   - Choose a different picture or solid colour
   - Take a screenshot of the new wallpaper
4. Change it back to the original after taking the screenshot

**Part B — Date and Time:**
1. Right-click the clock in the system tray > **Adjust date/time**
2. Note the current time zone: ___________
3. Verify it is set to "(UTC+05:30) Chennai, Kolkata, Mumbai, New Delhi"
4. Check if "Set time automatically" is ON or OFF: ___________

**Part C — Mouse Settings:**
1. Open Settings > Devices > Mouse (or Control Panel > Mouse)
2. Note the current pointer speed
3. Change the pointer speed to a different level — notice the difference
4. Change it back to the original setting

**Part D — Sound Settings:**
1. Click the Volume icon in the system tray
2. Note the current volume level: ___________
3. Mute the volume by clicking the speaker icon
4. Unmute it again

**What to Submit:**
- A written record of all the settings you observed and changed
- Screenshot of the new wallpaper you selected
- Answers to all the blanks above

## Task 3: Use Task Manager and System Tools

**Objective:** Learn to use Task Manager and other system tools for monitoring and troubleshooting.

**What to Do:**

**Part A — Task Manager:**
1. Open Task Manager using **Ctrl + Shift + Esc**
2. Go to the **Processes** tab:
   - How many processes are running? ___________
   - Which process is using the most CPU? ___________
   - Which process is using the most memory? ___________
3. Go to the **Performance** tab:
   - What is your CPU usage? ___________
   - How much RAM is in use out of total? ___________
   - What is the uptime (how long has the PC been running)? ___________
4. Go to the **Startup** tab:
   - How many startup programs are listed? ___________
   - How many are enabled? ___________
   - How many are disabled? ___________

**Part B — System Information:**
1. Press Windows + R to open the Run dialog
2. Type `msinfo32` and press Enter
3. Note down:
   - OS Name: ___________
   - Processor: ___________
   - Total Physical Memory (RAM): ___________
   - BIOS Version: ___________

**Part C — Disk Cleanup:**
1. Press Windows key and type "Disk Cleanup"
2. Select your C: drive and click OK
3. Note how much space can be freed: ___________
4. Check the boxes for Temporary files and Recycle Bin
5. Click OK > Delete Files (only if your trainer approves)

**Part D — Recycle Bin Test:**
1. Create a test file on your Desktop called `delete-test.txt`
2. Delete it using the **Delete** key
3. Open the Recycle Bin — can you see the file? ___________
4. Right-click the file > **Restore** — it goes back to the Desktop
5. Now delete it again, but this time use **Shift + Delete**
6. Open the Recycle Bin — can you see the file now? ___________

**What to Submit:**
- All filled-in answers from above
- A screenshot of the Task Manager Performance tab
- A screenshot of the System Information window

## Task 4: File Types and Properties Exploration

**Objective:** Identify different file types by their extensions and explore file properties.

**What to Do:**

**Part A — Show File Extensions:**
1. Open File Explorer (Windows + E)
2. Click the **View** tab
3. Check **File name extensions** (if not already checked)
4. Now you can see the extensions of all files

**Part B — Identify File Types:**
Navigate to different folders on your computer and find one example of each file type. Write down the file name and location:

| File Type | Extension | File Name | Location Found |
|-----------|-----------|-----------|---------------|
| Text file | .txt | ___________ | ___________ |
| Word document | .docx | ___________ | ___________ |
| Image | .jpg or .png | ___________ | ___________ |
| Music | .mp3 | ___________ | ___________ |
| Video | .mp4 | ___________ | ___________ |
| Executable | .exe | ___________ | ___________ |
| PDF | .pdf | ___________ | ___________ |

**Part C — Explore File Properties:**
1. Choose any file on your computer
2. Right-click > **Properties** (or select and press Alt + Enter)
3. On the **General** tab, note:
   - File name: ___________
   - Type of file: ___________
   - Opens with: ___________
   - Location: ___________
   - Size: ___________
   - Created date: ___________
   - Modified date: ___________

**Part D — Change File Association:**
1. Right-click on a `.txt` file
2. Click **Open with** > **Choose another app**
3. See the list of programs that can open text files
4. Select **Notepad** and close
5. Write down at least 3 programs that can open .txt files: ___________

**What to Submit:**
