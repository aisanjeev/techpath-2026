# Quiz: Introduction to GUI Based Operating System

**Module 02 — CCC Exam Preparation**

---

### Q1. What is the full form of GUI?

- A) General User Interface
- B) Graphical Unified Interface
- C) Graphical User Interface ✅
- D) General Utility Interface

> **Explanation:** GUI stands for Graphical User Interface. It allows users to interact with the computer using visual elements like windows, icons, menus, and a pointer (WIMP) instead of typing text commands.

---

### Q2. What happens when you press Shift + Delete on a file?

- A) File goes to Recycle Bin
- B) File is permanently deleted ✅
- C) File is copied
- D) File is renamed

> **Explanation:** Shift + Delete permanently deletes a file without sending it to the Recycle Bin. The file cannot be recovered through normal means. The regular Delete key sends files to the Recycle Bin.

---

### Q3. The shortcut key to open Task Manager directly is:

- A) Ctrl + Alt + Delete
- B) Ctrl + Shift + Esc ✅
- C) Alt + F4
- D) Ctrl + Alt + Esc

> **Explanation:** Ctrl + Shift + Esc opens Task Manager directly. Ctrl + Alt + Delete opens a security screen where Task Manager is one of the options. Ctrl + Shift + Esc is the faster method.

---

### Q4. Which of the following is the function of the Recycle Bin?

- A) Permanently deletes files
- B) Stores deleted files temporarily ✅
- C) Compresses files
- D) Scans for viruses

> **Explanation:** The Recycle Bin temporarily stores files that have been deleted using the Delete key. Files can be restored to their original location from the Recycle Bin, or permanently deleted by emptying it.

---

### Q5. The file extension .exe represents:

- A) A text file
- B) An image file
- C) An executable (program) file ✅
- D) A compressed file

> **Explanation:** The .exe extension stands for Executable. It is a program file that runs when double-clicked. Examples include setup files for installing software and application programs.

---

### Q6. The keyboard shortcut to open File Explorer in Windows is:

- A) Windows + D
- B) Windows + E ✅
- C) Windows + F
- D) Windows + R

> **Explanation:** Windows + E opens File Explorer (formerly called Windows Explorer). Windows + D shows the desktop, Windows + R opens the Run dialog, and Windows + F was used for search in older Windows versions.

---

### Q7. Linux Operating System is an example of:

- A) Proprietary software
- B) Open source software ✅
- C) Application software
- D) Firmware

> **Explanation:** Linux is open source software — its source code is freely available for anyone to view, modify, and distribute. It was created by Linus Torvalds in 1991. In contrast, Windows is proprietary (paid, closed source).

---

### Q8. Which power option saves the current state to the hard disk and uses no power?

- A) Sleep
- B) Hibernate ✅
- C) Shut Down
- D) Lock

> **Explanation:** Hibernate saves all open programs and data to the hard disk, then turns off the computer completely (using no power). Sleep keeps data in RAM and uses a small amount of power for faster wake-up.

---

### Q9. What does the keyboard shortcut Ctrl + Z do?

- A) Zoom in
- B) Close the program
- C) Undo the last action ✅
- D) Select all

> **Explanation:** Ctrl + Z undoes the last action. For example, if you accidentally delete text, pressing Ctrl + Z will bring it back. It works in most Windows applications.

---

### Q10. The shortcut key F2 is used to:

- A) Delete a file
- B) Open a file
- C) Rename a file ✅
- D) Copy a file

> **Explanation:** Pressing F2 when a file or folder is selected allows you to rename it. You can type the new name and press Enter to confirm.

---

### Q11. Which of the following is NOT a type of operating system?

- A) Batch Operating System
- B) Real-Time Operating System
- C) Microsoft Word ✅
- D) Network Operating System

> **Explanation:** Microsoft Word is application software (a word processor), not an operating system. Batch, Real-Time, and Network are all types of operating systems.

---

### Q12. The Indian Linux distribution developed by C-DAC is called:

- A) Ubuntu
- B) Red Hat
- C) BOSS ✅
- D) Fedora

> **Explanation:** BOSS (Bharat Operating System Solutions) is an Indian Linux distribution developed by C-DAC (Centre for Development of Advanced Computing). It was developed as part of India's push for open source and self-reliance in IT.

---

### Q13. Ctrl + Shift + N is used to:

- A) Open a new window
- B) Create a new folder ✅
- C) Create a new file
- D) Open Notepad

> **Explanation:** Ctrl + Shift + N creates a new folder in the current location in File Explorer. Ctrl + N opens a new window in most applications.

---

### Q14. Which of the following file extensions is associated with Microsoft Excel?

- A) .docx
- B) .pptx
- C) .xlsx ✅
- D) .txt

> **Explanation:** .xlsx is the file extension for Microsoft Excel spreadsheets. .docx is for Word documents, .pptx is for PowerPoint presentations, and .txt is for plain text files.

---

### Q15. What is the shortcut to lock the Windows computer screen?

- A) Windows + D
- B) Windows + L ✅
- C) Windows + E
- D) Ctrl + L

> **Explanation:** Windows + L locks the computer screen. You will need to enter your password or PIN to unlock it. This is useful when you leave your computer temporarily and want to protect your work.
