# Windows GUI Components

**Module 02 — CCC Exam Preparation | Topic 2**

---

## What is a GUI?

**GUI** stands for **Graphical User Interface**. It allows users to interact with the computer using visual elements like windows, icons, buttons, and menus — instead of typing text commands.

Before GUI, users had to type commands in a text-based interface (like DOS). GUI made computers easy enough for anyone to use — even absolute beginners.

**CCC Exam Tip:** GUI = Graphical User Interface. WIMP = Windows, Icons, Menus, Pointer — these are the four elements of a GUI. Both are frequently asked.

## The Desktop

The **Desktop** is the main screen you see after Windows starts up. Think of it as your computer's work table — you keep your most-used items here for quick access.

### Desktop Components:

| Component | Description |
|-----------|------------|
| **Desktop Background (Wallpaper)** | The image displayed on the desktop. Can be changed in Settings > Personalization |
| **Desktop Icons** | Small pictures representing files, folders, or programs |
| **Taskbar** | The horizontal bar at the bottom of the screen |
| **Start Button** | The Windows logo button at the left end of the taskbar |
| **System Tray** | The area at the right end of the taskbar (clock, volume, network) |
| **Recycle Bin** | Where deleted files go temporarily |

### Default Desktop Icons:

| Icon | Purpose |
|------|---------|
| **This PC** | Access all drives (C:, D:), folders, and devices |
| **Recycle Bin** | Stores deleted files until you empty it |
| **Network** | Access shared computers and resources on a network |
| **Control Panel** | Change system settings |
| **User's Files** | Quick access to your Documents, Pictures, Music folders |

**CCC Exam Tip:** To show or hide desktop icons: Right-click on Desktop > View > Show desktop icons.

## The Taskbar

The **Taskbar** is the horizontal bar at the bottom of the screen. It is always visible (unless hidden) and helps you switch between open programs.

### Parts of the Taskbar:

| Part | Location | Purpose |
|------|----------|---------|
| **Start Button** | Far left | Opens the Start Menu |
| **Search Box** | Next to Start | Search for files, apps, settings |
| **Task View** | Next to Search | Shows all open windows and virtual desktops |
| **Pinned Apps** | Centre-left area | Quick-launch buttons for your favourite programs |
| **Running Apps** | Centre area | Shows buttons for all currently open programs |
| **System Tray (Notification Area)** | Far right | Shows clock, volume, network, battery, and background apps |
| **Show Desktop Button** | Very far right corner | Click to minimize all windows and show desktop |

### Taskbar Tips:
- **Right-click the taskbar** to access Taskbar Settings
- **Drag the taskbar** to move it to the top, left, or right side of the screen
- **Pin an app:** Right-click on an app > Pin to taskbar
- **Unpin an app:** Right-click a pinned app on taskbar > Unpin from taskbar

**CCC Exam Tip:** The taskbar is located at the **bottom** of the screen by default. It shows running programs and provides quick access to the Start Menu.

## The Start Menu

The **Start Menu** opens when you click the **Start Button** (Windows logo) or press the **Windows key** on the keyboard.

### What the Start Menu Contains:

| Section | What It Shows |
|---------|--------------|
| **Pinned Apps** | Apps you use frequently, pinned for quick access |
| **Recommended / Recent** | Recently opened files and newly installed apps |
| **All Apps** | Complete alphabetical list of all installed programs |
| **Power Button** | Shut Down, Restart, Sleep options |
| **User Account** | Your name and profile picture; sign out option |
| **Settings** | Opens Windows Settings |

### How to Open a Program from Start Menu:
1. Click the **Start Button** (or press Windows key)
2. If the app is pinned, click it directly
3. If not, click **All Apps** and scroll to find it
4. Or simply **type the app name** in the search box

**CCC Exam Tip:** The Start Menu provides access to all programs, settings, and power options. The Windows key on the keyboard opens the Start Menu.

## System Tray (Notification Area)

The **System Tray** is located at the far right of the taskbar. It shows small icons for background programs and system status.

### Common System Tray Items:

| Icon | Purpose |
|------|---------|
| **Clock** | Shows current date and time |
| **Volume** | Control speaker volume; mute/unmute |
| **Network** | Shows Wi-Fi or Ethernet connection status |
| **Battery** | Shows battery percentage (laptops only) |
| **Action Centre** | Shows notifications and quick settings |
| **Antivirus** | Status of Windows Defender or installed antivirus |
| **Hidden Icons Arrow (^)** | Click to see more hidden system tray icons |
| **Language/Keyboard** | Shows current input language (ENG for English) |

## Icons

**Icons** are small pictures that represent files, folders, programs, or shortcuts.

### Types of Icons:

| Type | Description | How to Identify |
|------|-------------|----------------|
| **Program Icon** | Represents an installed application | Has the app's logo (e.g., Chrome circle, Word "W") |
| **File Icon** | Represents a document, image, or other file | Shows the file type logo |
| **Folder Icon** | Represents a folder containing files | Yellow folder shape |
| **Shortcut Icon** | A link to a file, folder, or program elsewhere | Has a small **arrow** at the bottom-left corner |
| **System Icon** | System items like This PC, Recycle Bin | Special system shapes |

### Working with Icons:
- **Single click** — Select the icon (highlights it)
- **Double click** — Open the file, folder, or program
- **Right click** — Open the context menu (options like Open, Copy, Delete, Properties)
- **Drag and drop** — Move or copy the icon to another location

**CCC Exam Tip:** A shortcut icon has a **small arrow** at the bottom-left corner. Deleting a shortcut does NOT delete the original file.

## Windows (Application Windows)

A **window** is a rectangular area on the screen where a program runs or files are displayed. You can have multiple windows open at the same time.

### Parts of a Window:

| Part | Location | Purpose |
|------|----------|---------|
| **Title Bar** | Top of the window | Shows the name of the program or file |
| **Menu Bar** | Below title bar | Contains menus (File, Edit, View, Help) |
| **Toolbar/Ribbon** | Below menu bar | Quick access buttons for common actions |
| **Minimize Button (—)** | Top-right corner | Hides the window to the taskbar (does NOT close) |
| **Maximize Button (□)** | Top-right corner | Makes the window fill the entire screen |
| **Restore Button (⧉)** | Top-right corner | Returns a maximized window to its previous size |
| **Close Button (X)** | Top-right corner | Closes the window and exits the program |
| **Scroll Bar** | Right side / Bottom | Scroll through content that does not fit in the window |
| **Status Bar** | Very bottom | Shows information about the content (page number, zoom) |
| **Address Bar** | Top (in File Explorer) | Shows the current folder path |

### Window Operations:

| Action | How to Do It |
|--------|-------------|
| **Minimize** | Click the (—) button or press Windows + D (minimize all) |
| **Maximize** | Click the (□) button or double-click the title bar |
| **Restore** | Click the restore button (⧉) when maximized |
| **Close** | Click the (X) button or press Alt + F4 |
| **Move** | Click and drag the title bar |
| **Resize** | Drag any edge or corner of the window |
| **Snap Left** | Drag window to left edge or press Windows + Left Arrow |
| **Snap Right** | Drag window to right edge or press Windows + Right Arrow |
| **Switch Between Windows** | Press Alt + Tab |

**CCC Exam Tip:** 
- Minimize (—) = hides window, program keeps running
- Maximize (□) = full screen
- Close (X) = exits the program
- Alt + Tab = switch between open windows
- Alt + F4 = close the current window

## Dialog Boxes

A **Dialog Box** is a small window that appears asking for user input or providing information. It requires you to take action before you can continue.

### Common Dialog Box Elements:

| Element | Purpose |
|---------|---------|
| **Text Box** | Type text (e.g., file name) |
| **Drop-down List** | Select one option from a list |
| **Check Box** | Select multiple options (tick/untick) |
| **Radio Button** | Select only one option from a group |
| **OK Button** | Accept and close the dialog |
| **Cancel Button** | Discard changes and close |
| **Apply Button** | Apply changes without closing |
| **Tabs** | Switch between different sections in the dialog |
| **Slider** | Adjust a value by sliding (e.g., volume) |

**Example:** When you press Ctrl + S in Word for the first time, a "Save As" dialog box appears asking you to choose a file name and location.

## Context Menu (Right-Click Menu)

When you **right-click** on any item (desktop, file, folder, taskbar), a **Context Menu** appears with relevant options.

### Common Context Menu Options:

| Right-Click On | Options Available |
|---------------|-------------------|
| **Desktop** | View, Sort by, New (folder/file), Display settings, Personalize |
| **File** | Open, Edit, Copy, Cut, Delete, Rename, Properties, Send to |
| **Folder** | Open, Copy, Cut, Delete, Rename, Properties |
| **Taskbar** | Taskbar settings, Task Manager, Show desktop |
