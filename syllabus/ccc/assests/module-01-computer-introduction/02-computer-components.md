## Overview: Parts of a Computer System

A computer system is made up of several components that work together. These components can be grouped into four main categories:

1. **Central Processing Unit (CPU)** — the brain of the computer
2. **Input Devices** — devices used to enter data into the computer
3. **Output Devices** — devices used to display or produce results
4. **Memory/Storage** — where data and instructions are stored

---

## Central Processing Unit (CPU)

The CPU is called the **"Brain of the Computer"**. It performs all the processing — calculations, comparisons, and decision-making. The CPU has three main parts:

### 1. Arithmetic Logic Unit (ALU)

The ALU performs two types of operations:
- **Arithmetic operations:** Addition (+), Subtraction (−), Multiplication (×), Division (÷)
- **Logical operations:** Comparisons like greater than (>), less than (<), equal to (=), AND, OR, NOT

**Example:** When Rahul uses a calculator app to add ₹500 + ₹300, the ALU performs this addition.

**CCC Exam Tip:** "ALU performs arithmetic and logical operations" is a very common exam question. Remember: ALU = Arithmetic + Logic.

### 2. Control Unit (CU)

The Control Unit is the manager of the CPU. It does not process data itself, but it controls and coordinates all parts of the computer. It:
- Fetches instructions from memory
- Decodes (interprets) the instructions
- Directs the ALU, memory, and I/O devices to execute the instructions

Think of it like a traffic police officer directing vehicles at a busy crossing in Delhi — the officer does not drive the vehicles but tells them where to go.

### 3. Registers

Registers are very small, very fast memory locations inside the CPU. They temporarily hold data and instructions that the CPU is currently working on. Types include:
- **Accumulator** — stores results of ALU operations
- **Program Counter** — keeps track of the next instruction to execute
- **Instruction Register** — holds the current instruction being executed

**CCC Exam Tip:** The full form of CPU is **Central Processing Unit**. This is asked almost every year in the CCC exam.

## Input Devices

Input devices are used to **enter data and instructions** into the computer. Here are the most important ones:

### Keyboard
- The most common input device
- Standard keyboard has **104 keys** (101 for older models)
- Key types: Alphabet keys, Number keys, Function keys (F1–F12), Special keys (Enter, Shift, Ctrl, Alt, Caps Lock, Tab, Backspace, Delete, Escape)

**CCC Exam Tip:** Function keys F1–F12 are frequently asked. F1 = Help in most programs.

### Mouse
- A **pointing device** used to move the cursor on the screen
- Operations: Left click, Right click, Double click, Drag and drop, Scroll
- Types: Mechanical mouse (with ball), Optical mouse (with LED/laser)
- Invented by **Douglas Engelbart** in 1964

### Scanner
- Converts physical documents (paper) into digital format
- Works like a photocopy machine but creates a digital image
- Used in offices, banks, and Aadhaar centres across India
- Types: Flatbed scanner, Handheld scanner, Drum scanner

### Microphone (Mic)
- Converts voice/sound into digital signals
- Used for voice calls, voice typing, recording, video conferencing

### Other Input Devices

| Device | Purpose |
|--------|---------|
| **Joystick** | Used for gaming — controls movement in games |
| **Light Pen** | Pen-shaped device to select items on screen |
| **Trackball** | Like an upside-down mouse — the ball is on top |
| **Touchscreen** | Screen that responds to finger touch (smartphones, ATMs) |
| **Webcam** | Captures video images — used for video calls |
| **Barcode Reader** | Reads barcodes on products (seen in Big Bazaar, D-Mart) |
| **OCR (Optical Character Reader)** | Reads printed/handwritten text and converts to digital text |
| **MICR (Magnetic Ink Character Recognition)** | Reads special magnetic ink characters — used on bank cheques |
| **OMR (Optical Mark Reader)** | Reads pencil marks on answer sheets — used in competitive exams |

**CCC Exam Tip:** OMR, OCR, and MICR are very commonly asked. Remember:
- OMR = reads marks (exam answer sheets)
- OCR = reads text (printed characters)
- MICR = reads magnetic ink (bank cheques)

## Output Devices

Output devices **display or produce results** from the computer.

### Monitor
- The primary output device — displays visual output on screen
- Types:
  - **CRT (Cathode Ray Tube)** — old, bulky monitors (like old TVs)
  - **LCD (Liquid Crystal Display)** — flat, thin screens
  - **LED (Light Emitting Diode)** — improved LCD with better brightness
  - **OLED** — best quality, used in premium smartphones and TVs

### Printer
Printers produce **hard copy** (output on paper).

| Type | How It Works | Speed | Quality |
|------|-------------|-------|---------|
| **Dot Matrix** | Pins strike ink ribbon onto paper | Slow | Low |
| **Inkjet** | Sprays tiny ink droplets | Medium | Good |
| **Laser** | Uses laser beam and toner powder | Fast | Excellent |
| **Thermal** | Uses heat on special paper | Fast | Good (for receipts) |

**CCC Exam Tip:** Hard copy = printed output on paper. Soft copy = output displayed on screen.

### Speaker
- Produces audio output (music, system sounds, voice)
- Converts digital signals into sound waves

### Other Output Devices

| Device | Purpose |
|--------|---------|
| **Projector** | Displays output on a large screen/wall — used in classrooms and offices |
| **Headphones** | Personal audio output device |
| **Plotter** | Prints large drawings, blueprints, maps — used by architects and engineers |

## Memory (Storage)

Memory is where the computer stores data and instructions. There are two main categories:

### Primary Memory (Main Memory)

Primary memory is directly accessible by the CPU. It is fast but limited in size.

#### RAM (Random Access Memory)
- **Volatile** — data is lost when the computer is turned off
- Used to store data and programs that are currently in use
- More RAM = computer runs faster
- Types: SRAM (Static RAM) — faster, expensive; DRAM (Dynamic RAM) — slower, cheaper
- Common sizes: 4 GB, 8 GB, 16 GB, 32 GB

**CCC Exam Tip:** "RAM is volatile" is one of the most frequently asked questions. Volatile means data disappears when power is off.

#### ROM (Read Only Memory)
- **Non-volatile** — data is NOT lost when the computer is turned off
- Contains permanent instructions written by the manufacturer
- Stores the **BIOS (Basic Input Output System)** — instructions to start the computer
- Types: PROM, EPROM, EEPROM

**CCC Exam Tip:** RAM is volatile, ROM is non-volatile. This comparison is asked in almost every CCC exam.

| Feature | RAM | ROM |
|---------|-----|-----|
| Full form | Random Access Memory | Read Only Memory |
| Volatile? | Yes (data lost on power off) | No (data stays) |
| Speed | Faster | Slower |
| User can write? | Yes | No (read only) |
| Purpose | Temporary storage during use | Permanent storage of startup instructions |
| Example | 8 GB RAM stick | BIOS chip on motherboard |

### Cache Memory
- Very fast memory located between the CPU and RAM
- Stores frequently used data for quick access
- Smaller than RAM but much faster
- Levels: L1 (fastest, smallest), L2, L3 (largest, slowest)

### Secondary Memory (Storage Devices)

Secondary memory stores data permanently, even when the computer is turned off.

| Device | Type | Capacity | Usage |
|--------|------|----------|-------|
| **Hard Disk Drive (HDD)** | Magnetic | 500 GB to 4 TB | Main storage in desktops |
| **Solid State Drive (SSD)** | Flash | 128 GB to 2 TB | Faster alternative to HDD |
| **Pen Drive (USB Flash Drive)** | Flash | 8 GB to 128 GB | Portable data transfer |
| **CD (Compact Disc)** | Optical | 700 MB | Music, small files |
| **DVD (Digital Versatile Disc)** | Optical | 4.7 GB (single layer) | Movies, software |
| **Blu-ray Disc** | Optical | 25 GB (single layer) | HD movies |
| **Memory Card (SD Card)** | Flash | 4 GB to 512 GB | Cameras, smartphones |
