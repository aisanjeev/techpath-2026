## 1. What is a Computer?

A **computer** is an electronic device that accepts data (input), processes it according to a set of instructions (program), and produces useful information (output). It can also store data for future use.

**Key definition keywords for exam:** Electronic + Data + Processing + Output + Storage

**Charles Babbage** is called the **Father of Computer** because he designed the **Analytical Engine** (1837), which had all the basic components of a modern computer — input, processing, memory, and output.

**ENIAC** (Electronic Numerical Integrator and Computer) was the first general-purpose electronic computer, built in 1946 by Eckert and Mauchly.

## 3. Characteristics of a Computer

| Characteristic | Meaning |
|---------------|---------|
| **Speed** | Performs millions of calculations per second (measured in nanoseconds) |
| **Accuracy** | Always gives correct results if input and program are correct |
| **Storage** | Can store vast amounts of data (GB, TB) |
| **Diligence** | Never gets tired — works continuously without losing accuracy |
| **Versatility** | Can perform many different types of tasks |
| **Automation** | Runs tasks automatically once programmed |
| **No IQ** | Has no intelligence of its own — follows instructions only |

**GIGO (Garbage In, Garbage Out):** If wrong data is entered, the output will also be wrong. The computer does not correct your mistakes.

## 5. CPU — The Brain of the Computer

**CPU** = **Central Processing Unit**

Three parts of the CPU:

| Part | Full Form | Function |
|------|-----------|----------|
| **ALU** | Arithmetic Logic Unit | Performs arithmetic (+, −, ×, ÷) and logical (>, <, =, AND, OR) operations |
| **CU** | Control Unit | Fetches, decodes, and coordinates execution of instructions |
| **Registers** | — | Very fast temporary storage inside CPU |

## 8. Memory

### Primary Memory (Main Memory)

| Type | Volatile? | Purpose | Exam Fact |
|------|-----------|---------|-----------|
| **RAM** | Yes (data lost on power off) | Temporary storage during use | Volatile memory |
| **ROM** | No (data stays) | Permanent startup instructions | Non-volatile, stores BIOS |
| **Cache** | Yes | Very fast CPU-side storage | L1, L2, L3 levels |

**Most Important Exam Point:** RAM is **volatile** (temporary). ROM is **non-volatile** (permanent).

### Secondary Memory (Storage)

## 9. Hardware vs Software

| Hardware | Software |
|----------|----------|
| Physical parts (touchable) | Programs (not touchable) |
| Gets worn out | Becomes outdated |
| Keyboard, Monitor, CPU | Windows, Word, Chrome |

### Types of Software

**System Software** — manages hardware:
- Operating System (Windows, Linux)
- Language Translators (Compiler, Interpreter, Assembler)
- Utility Programs (Antivirus, Disk Cleanup)

**Application Software** — user tasks:
- General: Word, Excel, PowerPoint, Chrome, Tally
- Special: AutoCAD, Photoshop
- Customized: IRCTC reservation system

**Compiler vs Interpreter:**
- Compiler = translates entire program at once
- Interpreter = translates line by line

## 11. Data Representation

### Bits and Bytes
- **1 Bit** = 0 or 1 (smallest unit)
- **1 Byte** = 8 Bits (stores 1 character)
- **1 KB** = 1,024 Bytes
- **1 MB** = 1,024 KB
- **1 GB** = 1,024 MB
- **1 TB** = 1,024 GB

**Conversion factor is always 1,024** (not 1,000).

### ASCII
- **ASCII** = American Standard Code for Information Interchange
- A = 65, a = 97, 0 = 48
- Total 128 characters (7-bit), Extended ASCII = 256 (8-bit)
- **Unicode** supports all world languages (Hindi, Tamil, etc.)

### Number Systems
| System | Base | Digits |
|--------|------|--------|
| Decimal | 10 | 0–9 |
| Binary | 2 | 0, 1 |
| Octal | 8 | 0–7 |
| Hexadecimal | 16 | 0–9, A–F |

**Decimal to Binary:** Divide by 2, note remainders bottom-to-top.
**Binary to Decimal:** Multiply each bit by its power of 2, add all.
