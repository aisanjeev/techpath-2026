**CCC Exam Quick Reference | TechPath Institute**

## Key Definitions

| Term | Definition |
|------|-----------|
| Computer | Electronic device that processes data into information |
| Hardware | Physical parts you can touch (keyboard, monitor, CPU) |
| Software | Programs and instructions (Windows, Word, Chrome) |
| Data | Raw facts and figures (unprocessed) |
| Information | Processed, meaningful data |
| Program | Set of instructions for the computer |
| GIGO | Garbage In, Garbage Out — wrong input = wrong output |

## RAM vs ROM

| Feature | RAM | ROM |
|---------|-----|-----|
| Full form | Random Access Memory | Read Only Memory |
| Volatile? | YES (lost on power off) | NO (stays permanently) |
| Writable? | Yes | No (read only) |
| Purpose | Temporary storage during use | Stores BIOS/startup instructions |
| Speed | Faster | Slower |

## Memory Size Table

| Unit | Abbreviation | Equals |
|------|-------------|--------|
| Bit | b | 0 or 1 |
| Nibble | — | 4 bits |
| Byte | B | **8 bits** |
| Kilobyte | KB | **1,024 Bytes** |
| Megabyte | MB | **1,024 KB** |
| Gigabyte | GB | **1,024 MB** |
| Terabyte | TB | **1,024 GB** |
| Petabyte | PB | 1,024 TB |
