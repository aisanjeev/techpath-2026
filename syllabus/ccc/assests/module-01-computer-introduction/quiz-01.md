# Quiz: Introduction to Computer

**Module 01 — CCC Exam Preparation**

---

### Q1. Who is known as the 'Father of Computer'?

- A) Bill Gates
- B) Charles Babbage ✅
- C) Tim Berners-Lee
- D) Steve Jobs

> **Explanation:** Charles Babbage is called the Father of Computer because he designed the Analytical Engine, which had all the basic components of a modern computer.

---

### Q2. What is the full form of CPU?

- A) Computer Processing Unit
- B) Central Processing Unit ✅
- C) Central Program Utility
- D) Computer Program Unit

> **Explanation:** CPU stands for Central Processing Unit. It is the brain of the computer that processes all data and instructions.

---

### Q3. Which memory is volatile?

- A) ROM
- B) Hard Disk
- C) RAM ✅
- D) Pen Drive

> **Explanation:** RAM (Random Access Memory) is volatile, meaning all data stored in it is lost when the computer is turned off. ROM, Hard Disk, and Pen Drive are non-volatile.

---

### Q4. How many bits are in one byte?

- A) 2
- B) 4
- C) 8 ✅
- D) 16

> **Explanation:** 1 Byte = 8 Bits. A byte is the basic unit of data storage and can represent one character (like the letter 'A').

---

### Q5. First generation computers used which technology?

- A) Transistors
- B) Integrated Circuits
- C) Vacuum Tubes ✅
- D) Microprocessors

> **Explanation:** First generation computers (1940-1956) used Vacuum Tubes. They were large in size, generated a lot of heat, and consumed huge electricity.

---

### Q6. Which part of the CPU performs arithmetic and logical operations?

- A) Control Unit
- B) Register
- C) ALU ✅
- D) Cache

> **Explanation:** ALU (Arithmetic Logic Unit) performs all arithmetic operations (addition, subtraction, multiplication, division) and logical operations (comparisons like greater than, less than, equal to).

---

### Q7. How many bytes are in 1 Kilobyte (KB)?

- A) 100
- B) 1000
- C) 1024 ✅
- D) 512

> **Explanation:** 1 KB = 1024 Bytes. In computing, the conversion factor is always 1024 (which is 2 raised to the power 10), not 1000.

---

### Q8. Which of the following is an input device?

- A) Printer
- B) Monitor
- C) Speaker
- D) Scanner ✅

> **Explanation:** A Scanner is an input device that converts physical documents (paper) into digital format. Printer, Monitor, and Speaker are all output devices.

---

### Q9. MICR is used to read characters on which of the following?

- A) Exam answer sheets
- B) Bank cheques ✅
- C) Barcodes on products
- D) Printed books

> **Explanation:** MICR (Magnetic Ink Character Recognition) is used to read the special magnetic ink characters printed on bank cheques. OMR is used for exam sheets, and Barcode Reader is for product barcodes.

---

### Q10. What does GIGO stand for?

- A) Get In, Get Out
- B) Garbage In, Garbage Out ✅
- C) Go In, Go Out
- D) General Input, General Output

> **Explanation:** GIGO stands for Garbage In, Garbage Out. It means that if incorrect or poor-quality data is entered into a computer, the output will also be incorrect.

---

### Q11. Which of the following translates a high-level language program line by line?

- A) Assembler
- B) Compiler
- C) Interpreter ✅
- D) Linker

> **Explanation:** An Interpreter translates and executes a high-level language program one line at a time. A Compiler translates the entire program at once before execution.

---

### Q12. What is the ASCII value of the character 'A'?

- A) 55
- B) 65 ✅
- C) 97
- D) 48

> **Explanation:** The ASCII value of uppercase 'A' is 65. Uppercase letters A-Z have values 65-90. Lowercase 'a' has the value 97.

---

### Q13. The binary number system has a base of:

- A) 2 ✅
- B) 8
- C) 10
- D) 16

> **Explanation:** The binary number system uses base 2 with only two digits: 0 and 1. Computers use binary because electronic circuits have two states — ON (1) and OFF (0).

---

### Q14. Which of the following is an example of system software?

- A) MS Word
- B) Google Chrome
- C) Windows 10 ✅
- D) Tally

> **Explanation:** Windows 10 is an Operating System, which is a type of system software. MS Word, Chrome, and Tally are all application software designed for specific user tasks.

---

### Q15. What is the full form of ICT?

- A) Indian Computer Technology
- B) Information and Communication Technology ✅
- C) International Computer Technology
- D) Internet and Computer Technology

> **Explanation:** ICT stands for Information and Communication Technology. It refers to all technologies used for handling, processing, and communicating information, including computers, internet, and mobile phones.
