## Task 1: Identify Your Computer's Parts

**Objective:** Identify the physical components (hardware) of a desktop or laptop computer.

**What to Do:**
1. Look at the computer in your lab or at home.
2. Identify and list the following parts:
   - Monitor (screen)
   - Keyboard (count the total number of keys)
   - Mouse (is it wired or wireless? optical or mechanical?)
   - CPU cabinet (or laptop body)
   - Speakers (built-in or external?)
   - Any other connected devices (printer, pen drive, headphones)
3. Open the CPU cabinet (with your trainer's help, if desktop) or look at laptop ports and identify:
   - USB ports — how many?
   - HDMI port — present or not?
   - Headphone jack — present or not?
   - SD card slot — present or not?

**What to Submit:**
- A written list of all parts you identified with their type (input/output/storage)
- A simple hand-drawn diagram showing how the parts connect to each other

## Task 2: Explore System Properties

**Objective:** Find out the specifications (configuration) of your computer using System Properties.

**What to Do:**
1. Right-click on **This PC** (or My Computer) on the desktop
2. Click **Properties**
3. Note down the following information:
   - **Processor (CPU):** What is the name and speed? (e.g., Intel Core i5, 2.4 GHz)
   - **RAM:** How much RAM is installed? (e.g., 8 GB)
   - **System Type:** Is it 32-bit or 64-bit?
   - **Operating System:** Which Windows version? (e.g., Windows 10, Windows 11)
   - **Computer Name:** What is the computer's name?

4. Open **Task Manager** (press Ctrl + Shift + Esc) and go to the **Performance** tab:
   - CPU usage — what percentage is being used right now?
   - Memory usage — how much RAM is currently in use?
   - Disk — what type of storage does your computer have (HDD or SSD)?

5. Open **File Explorer** and check:
   - Total storage capacity of C: drive
   - How much space is used and how much is free?

**What to Submit:**
- A written table with all the specifications you found
- A screenshot of the System Properties window (optional, if you can print it)

## Task 3: Practice Keyboard Skills

**Objective:** Learn the different types of keys on the keyboard and practice typing.

**What to Do:**

**Part A — Identify Key Types:**
1. On your keyboard, identify and mark (on paper) the location of:
   - All 12 Function keys (F1 to F12)
   - Number keys (top row and numpad)
   - Caps Lock, Num Lock, Scroll Lock
   - Enter, Backspace, Delete, Tab, Escape
   - Ctrl, Alt, Shift, Windows key
   - Arrow keys (Up, Down, Left, Right)
   - Print Screen, Home, End, Page Up, Page Down

2. Write down what each of these keys does:
   - Caps Lock
   - Num Lock
   - Backspace vs Delete
   - Tab
   - Enter
   - Escape
   - Print Screen

**Part B — Typing Practice:**
1. Open **Notepad** (Start Menu > search "Notepad")
2. Type the following paragraph exactly as shown:

```
My name is [Your Name]. I am learning computers at TechPath Institute.
Today I learned that a computer has 4 main parts: Input, Processing,
Output, and Storage. The CPU is the brain of the computer. RAM is
volatile memory and ROM is non-volatile memory. 1 byte = 8 bits, and
1 KB = 1024 bytes. Charles Babbage is the Father of Computer.
```

3. Save the file as `typing-practice.txt` on your Desktop

4. Visit a free typing practice website and practice for 15 minutes

**What to Submit:**
- Your list of key functions
- The `typing-practice.txt` file (email or pen drive)
- Your typing speed result (words per minute)

## Task 4: Number System Conversion Practice

**Objective:** Practice converting numbers between decimal and binary number systems.

**What to Do:**

**Part A — Decimal to Binary (by hand):**
Convert the following decimal numbers to binary using the division-by-2 method. Show all your steps.

1. Convert **5** to binary
2. Convert **12** to binary
3. Convert **25** to binary
4. Convert **100** to binary

**Part B — Binary to Decimal (by hand):**
Convert the following binary numbers to decimal. Show all your steps.

1. Convert **1010** to decimal
2. Convert **1100** to decimal
3. Convert **11011** to decimal
4. Convert **10000** to decimal

**Part C — Memory Size Calculations:**
Answer the following without using a calculator:

1. How many bytes are in 3 KB?
2. How many KB are in 2 MB?
3. How many bits are in 5 bytes?
4. If a photo is 3 MB, how many such photos can fit in 1 GB?

**Part D — Verify with a Tool:**
1. Open the Number System Converter tool provided in this module (the HTML file)
2. Verify all your answers from Part A and Part B
3. Note down any answers you got wrong and understand why

**What to Submit:**
- A handwritten sheet showing all conversions with steps
- Answers to the memory size calculations
- A list of any mistakes you found when verifying
