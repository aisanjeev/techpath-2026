# Printing and Saving Web Content

**Module 06 — CCC Exam Preparation | Topic 5**

---

## Introduction

Sometimes you need to print information from a website — a train ticket from IRCTC, an admit card from NIELIT, a form from a government website, or study notes for exam preparation. In this topic, you will learn how to print web pages, save them for offline use, and use important browser keyboard shortcuts.

---

## Printing Web Pages

### How to Print a Web Page in Chrome:

**Method 1: Keyboard Shortcut**
1. Open the web page you want to print
2. Press **Ctrl + P**
3. The Print dialog box opens

**Method 2: Using Menu**
1. Click the three dots (menu) in the top-right corner
2. Click **Print**

### Understanding the Print Dialog Box

When you press Ctrl + P, you see several options:

| Option | Description |
|--------|-------------|
| **Destination/Printer** | Select your printer or "Save as PDF" |
| **Pages** | Print all pages, or specific pages (e.g., 1-3, 5) |
| **Copies** | Number of copies to print |
| **Layout** | Portrait (vertical) or Landscape (horizontal) |
| **Color** | Color or Black and White |
| **Paper Size** | A4 (most common in India), Letter, Legal |
| **Margins** | Default, None, Minimum, Custom |
| **Scale** | Fit to page width or custom percentage |
| **Headers and Footers** | Show/hide page title, URL, date on printout |
| **Background Graphics** | Include/exclude background colors and images |

**CCC Exam Tip:** Ctrl + P opens the print dialog. You can print to a physical printer or save as PDF.

## Print Preview

**Print preview** shows you exactly how the printed page will look before you actually print it. This helps you avoid wasting paper.

### Using Print Preview:
In Chrome, print preview is built into the Print dialog (Ctrl + P). The left side shows options, and the right side shows a preview of how each page will look.

### Things to Check in Print Preview:
1. Is all the important content visible?
2. Are images showing correctly?
3. Is the text readable (not too small)?
4. How many pages will it print?
5. Is the orientation correct (portrait vs. landscape)?
6. Are headers and footers needed?

**Tip:** If a web page has a "Printer-friendly version" link, use that instead — it removes ads, navigation menus, and other clutter.

## Selecting Print Area

Sometimes you do not want to print the entire web page — just a specific section (like a table or a paragraph).

### How to Print Only a Selection:
1. **Select the text** you want to print by clicking and dragging your mouse over it
2. Press **Ctrl + P** to open Print dialog
3. In the "Pages" option, select **Selection only** (or the equivalent option)
4. Only the selected text will be printed

### Alternative: Copy and Paste Method
1. Select the content you want to print
2. Press **Ctrl + C** to copy
3. Open a Word document or Notepad
4. Press **Ctrl + V** to paste
5. Print from the document instead

## Fit to Page

When a web page is too wide for the paper, you can use the **Scale** option to fit it on one page.

### How to Fit to Page:
1. Press **Ctrl + P** to open Print dialog
2. Click on **More settings** (if available)
3. Under **Scale**, choose:
   - **Default** — Normal size
   - **Fit to page width** — Shrinks or stretches to fit paper width
   - **Custom** — Enter a percentage (e.g., 80% to make smaller, 120% to make larger)

**Tip for wide tables:** If a web page has a wide table that gets cut off, try:
1. Changing layout from Portrait to **Landscape**
2. Reducing the scale to 70-80%
3. Setting margins to **Minimum** or **None**

## Saving Web Pages

### Method 1: Save as HTML (Ctrl + S)
1. Press **Ctrl + S** while on the web page
2. Choose save location
3. Select format:
   - **Webpage, Complete** — Saves with all images (creates a folder)
   - **Webpage, HTML Only** — Text only, no images
   - **Webpage, Single File (.mhtml)** — Everything in one file
4. Click Save

### Method 2: Save as PDF (Ctrl + P > Save as PDF)
1. Press **Ctrl + P**
2. Change Destination to **Save as PDF**
3. Click **Save**
4. Choose location and file name

**When to use which method:**
| Method | Best For |
|--------|----------|
| HTML Complete | Saving a full page with images for offline reading |
| HTML Only | Saving text content quickly |
| PDF | Sharing, printing later, official documents |
| MHTML | Single-file backup of entire page |

**Real-life example:** Amit needs to save his IRCTC train ticket. He presses Ctrl + P, selects "Save as PDF," and saves it. He can now show this PDF on his phone or print it at the railway station.

## Copying Text and Images from Websites

### Copying Text:
1. Click at the beginning of the text you want to copy
2. Hold the mouse button and drag to select the text (highlighted in blue)
3. Press **Ctrl + C** to copy
4. Open any application (Word, Notepad, email)
5. Press **Ctrl + V** to paste

### Copying Images:
1. Right-click on the image
2. Select **Copy image**
3. Open an application (Word, Paint, email)
4. Press **Ctrl + V** to paste the image

### Select All:
- Press **Ctrl + A** to select all content on the page
- Then Ctrl + C to copy everything

**Note:** Some websites disable right-click or text selection to protect their content. This is their way of preventing copying.

## Browser Keyboard Shortcuts

Knowing keyboard shortcuts makes you faster and more efficient. These shortcuts work in most browsers (Chrome, Firefox, Edge).

### Navigation Shortcuts

| Shortcut | Action |
|----------|--------|
| **Ctrl + T** | Open a new tab |
| **Ctrl + W** | Close the current tab |
| **Ctrl + Shift + T** | Reopen the last closed tab |
| **Ctrl + Tab** | Switch to the next tab |
| **Ctrl + Shift + Tab** | Switch to the previous tab |
| **Ctrl + L** or **F6** | Select the address bar (to type a URL) |
| **Alt + Left Arrow** | Go back to the previous page |
| **Alt + Right Arrow** | Go forward to the next page |
| **F5** or **Ctrl + R** | Refresh the current page |
| **Ctrl + Shift + Delete** | Clear browsing data |
| **F11** | Toggle full-screen mode |
| **Ctrl + N** | Open a new browser window |

### Bookmark Shortcuts

| Shortcut | Action |
|----------|--------|
| **Ctrl + D** | Bookmark the current page |
| **Ctrl + Shift + B** | Show/hide the bookmarks bar |
| **Ctrl + Shift + O** | Open Bookmark Manager |

### Page Shortcuts

| Shortcut | Action |
|----------|--------|
| **Ctrl + P** | Print the page |
| **Ctrl + S** | Save the page |
| **Ctrl + F** | Find text on the page |
| **Ctrl + +** | Zoom in (make text bigger) |
| **Ctrl + -** | Zoom out (make text smaller) |
| **Ctrl + 0** | Reset zoom to default (100%) |
| **Ctrl + A** | Select all content |
| **Ctrl + C** | Copy selected content |
| **Ctrl + V** | Paste content |
| **Ctrl + U** | View page source code (HTML) |
| **Ctrl + J** | Open Downloads page |
| **Ctrl + H** | Open History page |

### Special Shortcuts

| Shortcut | Action |
|----------|--------|
| **Ctrl + Shift + N** | Open Incognito/Private window |
| **Ctrl + Shift + P** | Open Private window (Firefox) |
| **Ctrl + Enter** | Add "www." and ".com" to text in address bar |
| **Spacebar** | Scroll down the page |
| **Shift + Spacebar** | Scroll up the page |
| **Home** | Go to the top of the page |
| **End** | Go to the bottom of the page |

**CCC Exam Tip:** The most commonly asked shortcuts in CCC exam are:
- Ctrl + D = Add bookmark
- Ctrl + P = Print
- Ctrl + T = New tab
- Ctrl + W = Close tab
- Ctrl + H = History
- Ctrl + F = Find on page
- Ctrl + Shift + N = Incognito mode
- F5 = Refresh
