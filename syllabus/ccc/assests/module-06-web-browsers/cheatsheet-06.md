## Search Engine Operators

| Operator | Purpose | Example |
|----------|---------|---------|
| `"..."` | Exact phrase | `"CCC exam syllabus"` |
| `-word` | Exclude word | `apple -fruit` |
| `site:` | Search one website | `site:irctc.co.in` |
| `filetype:` | Specific file type | `notes filetype:pdf` |
| `OR` | Either term | `CCC OR BCC` |
| `*` | Wildcard | `"Father of *"` |
| `define:` | Definition | `define:modem` |

## Incognito Mode Quick Facts

| What It DOES | What It Does NOT Do |
|-------------|-------------------|
| Does not save history | Does NOT hide from ISP |
| Does not save cookies | Does NOT hide from employer |
| Does not save form data | Does NOT make you anonymous |
| Does not save passwords | Does NOT protect from malware |

**Shortcut:** Ctrl + Shift + N (Chrome, Edge) / Ctrl + Shift + P (Firefox)

## URL Anatomy

```
https://www.irctc.co.in/nget/train-search?date=today
|_____| |_| |____|__|__| |________________| |_________|
  |      |     |   |  |          |               |
Protocol Sub  Name TLD CC       Path           Query
```

| Part | Example | Meaning |
|------|---------|---------|
| Protocol | https:// | Secure connection |
| Subdomain | www | World Wide Web |
| Domain | irctc | Website name |
| TLD | .co | Commercial |
| Country Code | .in | India |
| Path | /nget/train-search | Specific page |
| Query | ?date=today | Parameters |

## Most Frequently Asked CCC Questions (Module 06)

1. Which is NOT a web browser? **Google** (it is a search engine)
2. Ctrl + D does what in browser? **Adds bookmark**
3. Which shows encrypted connection? **HTTPS / padlock icon**
4. Most used search engine worldwide? **Google**
5. What are cookies in a browser? **Small text files that store preferences**
6. Default browser in Windows 10/11? **Microsoft Edge**
7. Safari is made by? **Apple** (only for Apple devices)
8. Internet Explorer was replaced by? **Microsoft Edge**
9. Shortcut for Incognito mode? **Ctrl + Shift + N**
10. Shortcut to print a page? **Ctrl + P**
11. How to search exact phrase in Google? **Use double quotes**
12. URL stands for? **Uniform Resource Locator**
13. WWW was invented by? **Tim Berners-Lee (1989)**
14. Shortcut to refresh page? **F5 or Ctrl + R**
15. Shortcut to open history? **Ctrl + H**
