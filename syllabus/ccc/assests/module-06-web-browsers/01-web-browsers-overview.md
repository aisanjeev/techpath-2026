## What is a Web Browser?

A **web browser** is a software application that allows you to access and view websites on the internet. It reads the code (HTML, CSS, JavaScript) that makes up a web page and displays it as text, images, videos, and interactive elements on your screen.

**Simple Definition:** A web browser is a program that lets you visit websites by typing their address (URL) or clicking links.

Think of it like this: The internet is like a giant library with billions of books (websites). A web browser is the librarian who finds the book you want and shows it to you in a readable format.

**CCC Exam Tip:** A web browser is software used to access and display web pages. It is NOT the same as a search engine. Chrome is a browser; Google is a search engine. The exam often tests this distinction.

## Popular Web Browsers

### 1. Google Chrome

- **Developer:** Google
- **Release Year:** 2008
- **Market Share:** Most popular browser worldwide (over 65%)
- **Key Features:**
  - Very fast page loading
  - Syncs bookmarks, history, and passwords across devices (via Google account)
  - Huge library of extensions (add-ons)
  - Built-in translation for foreign language websites
  - Incognito mode for private browsing
  - Built-in PDF viewer
- **Used in India:** Most widely used browser in India on both desktop and mobile

### 2. Mozilla Firefox

- **Developer:** Mozilla Foundation (non-profit organization)
- **Release Year:** 2004
- **Key Features:**
  - Strong focus on privacy and security
  - Open-source (free and community-developed)
  - Customizable with themes and extensions
  - Enhanced Tracking Protection (blocks trackers by default)
  - Does not collect as much data as Chrome
- **Best for:** Users who care about privacy

### 3. Microsoft Edge

- **Developer:** Microsoft
- **Release Year:** 2015 (replaced Internet Explorer in 2020)
- **Key Features:**
  - Built into Windows 10 and Windows 11 (comes pre-installed)
  - Based on the same engine as Chrome (Chromium)
  - Integration with Microsoft services (Outlook, OneDrive, Office)
  - Collections feature — save and organize web content
  - Reading mode for distraction-free reading
  - Built-in AI assistant (Copilot)
- **CCC Exam Note:** Internet Explorer was discontinued in 2022. Edge is its replacement.

### 4. Opera

- **Developer:** Opera Software
- **Release Year:** 1995
- **Key Features:**
  - Built-in free VPN (Virtual Private Network)
  - Built-in ad blocker
  - Sidebar with quick access to messaging apps (WhatsApp, Telegram)
  - Data saving mode (Opera Mini for mobile)
  - Speed Dial — visual bookmarks on new tab page
- **Popular in India:** Opera Mini was very popular on feature phones for saving mobile data

### 5. Safari

- **Developer:** Apple
- **Release Year:** 2003
- **Key Features:**
  - Default browser on all Apple devices (iPhone, iPad, Mac)
  - Excellent performance on Apple hardware
  - Strong privacy features (Intelligent Tracking Prevention)
  - Energy efficient — saves battery on MacBooks
  - Not available on Windows or Android
- **CCC Exam Note:** Safari is Apple's browser and only works on Apple devices

**CCC Exam Tip:** "Which is NOT a web browser?" is a common question. Remember: Google, Yahoo, and Bing are search engines, NOT browsers. Chrome, Firefox, Edge, Opera, and Safari are browsers.

## Default Browser

The **default browser** is the browser that opens automatically when you click a link in an email, document, or other application.

- On Windows 10/11, the default browser is **Microsoft Edge** (pre-installed)
- On iPhone/iPad, the default browser is **Safari**
- On Android phones, the default browser is usually **Chrome**

### How to Change Default Browser in Windows:
1. Open **Settings** > **Apps** > **Default Apps**
2. Under "Web browser," click the current browser name
3. Select your preferred browser from the list (e.g., Chrome)
4. Close Settings — your new default browser is now set

## Browser Interface (Parts of a Browser Window)

When you open a web browser, you see several important parts:

### 1. Title Bar
- Shows the title of the current web page
- Located at the very top of the browser window

### 2. Address Bar (URL Bar / Omnibox)
- Where you type the website address (URL)
- Also works as a search bar — type any query and it searches using the default search engine
- Shows the padlock icon for secure (HTTPS) websites
- Located below the title bar

### 3. Tabs
- Allow you to open multiple web pages in the same browser window
- Each tab shows a different web page
- Click the **+** button to open a new tab
- Right-click a tab for options (close, duplicate, pin, mute)
- **Keyboard shortcut:** Ctrl + T (new tab), Ctrl + W (close tab)

### 4. Navigation Buttons
- **Back button** (left arrow): Go to the previous page
- **Forward button** (right arrow): Go to the next page (after going back)
- **Refresh button** (circular arrow): Reload the current page
- **Home button**: Go to your homepage
- **Keyboard shortcuts:** Alt + Left (back), Alt + Right (forward), F5 (refresh)

### 5. Bookmarks Bar
- A toolbar that shows your saved bookmarks (favorite websites)
- Located below the address bar
- You can show/hide it using Ctrl + Shift + B

### 6. Menu Button (Three Dots / Three Lines)
- Usually in the top-right corner
- Opens browser settings, history, downloads, bookmarks, extensions, and more
- Three dots (Chrome, Edge) or three lines (Firefox — called "hamburger menu")

### 7. Status Bar
- Located at the bottom of the browser window
- Shows the URL of a link when you hover over it
- Shows loading progress of a web page

### 8. Scroll Bar
- On the right side of the browser window
- Allows you to scroll up and down on long web pages
