## Keyboard Shortcuts Quick Reference Card

Print this section and keep it at your desk for practice:

| Shortcut | What It Does |
|----------|-------------|
| Ctrl + T | New tab |
| Ctrl + W | Close tab |
| Ctrl + D | Bookmark page |
| Ctrl + H | Open history |
| Ctrl + J | Open downloads |
| Ctrl + P | Print page |
| Ctrl + S | Save page |
| Ctrl + F | Find on page |
| Ctrl + + / - | Zoom in / out |
| Ctrl + Shift + N | Incognito window |
| Ctrl + Shift + T | Reopen closed tab |
| Ctrl + Shift + B | Toggle bookmarks bar |
| F5 | Refresh page |
| F11 | Full screen |
