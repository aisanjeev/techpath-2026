# Quiz: WWW and Web Browsers

**Module 06 — CCC Exam Preparation**

---

### Q1. Which of the following is NOT a web browser?

- A) Google Chrome
- B) Mozilla Firefox
- C) Google ✅
- D) Microsoft Edge

> **Explanation:** Google is a search engine, not a web browser. Chrome, Firefox, and Edge are web browsers (software used to view websites). Google is a website used to search for information.

---

### Q2. What does the keyboard shortcut Ctrl + D do in a web browser?

- A) Downloads the current page
- B) Deletes the current tab
- C) Adds the current page as a bookmark ✅
- D) Opens the browser settings

> **Explanation:** Ctrl + D adds the current web page as a bookmark (favorite). This saves a shortcut to the page so you can access it quickly later.

---

### Q3. Which of the following indicates that a website connection is encrypted and secure?

- A) HTTP in the URL
- B) HTTPS and a padlock icon in the address bar ✅
- C) The website loads fast
- D) The website has colorful images

> **Explanation:** HTTPS (HyperText Transfer Protocol Secure) and the padlock icon in the address bar indicate that the connection between your browser and the website is encrypted. Always look for this before entering sensitive information like passwords or bank details.

---

### Q4. Which search engine is the most widely used worldwide?

- A) Yahoo
- B) Bing
- C) Google ✅
- D) DuckDuckGo

> **Explanation:** Google is the most widely used search engine worldwide with over 90% market share. It was founded in 1998 by Larry Page and Sergey Brin.

---

### Q5. What are cookies in a web browser?

- A) Viruses that harm your computer
- B) Small text files stored by websites to remember your preferences ✅
- C) Images downloaded from websites
- D) Browser extensions

> **Explanation:** Cookies are small text files that websites store on your computer. They remember information like login status, language preference, and shopping cart items to provide a better browsing experience.

---

### Q6. What is the default web browser in Windows 10 and Windows 11?

- A) Google Chrome
- B) Mozilla Firefox
- C) Microsoft Edge ✅
- D) Internet Explorer

> **Explanation:** Microsoft Edge is the default web browser in Windows 10 and Windows 11. It replaced Internet Explorer, which was discontinued in 2022. Edge is based on the Chromium engine, the same engine used by Chrome.

---

### Q7. Which browser is developed by Apple and only available on Apple devices?

- A) Chrome
- B) Firefox
- C) Opera
- D) Safari ✅

> **Explanation:** Safari is developed by Apple and is the default browser on all Apple devices (Mac, iPhone, iPad). It is not available on Windows or Android devices.

---

### Q8. What does the keyboard shortcut Ctrl + Shift + N do in Chrome?

- A) Opens a new regular window
- B) Opens an Incognito (private) window ✅
- C) Opens a new tab
- D) Opens the settings page

> **Explanation:** Ctrl + Shift + N opens an Incognito (private) window in Chrome and Edge. In Incognito mode, your browsing history, cookies, and form data are not saved. In Firefox, the shortcut is Ctrl + Shift + P.

---

### Q9. How do you search for an exact phrase in Google?

- A) Type the phrase normally
- B) Put the phrase in double quotes ✅
- C) Put the phrase in parentheses
- D) Add an exclamation mark before the phrase

> **Explanation:** To search for an exact phrase in Google, enclose it in double quotes. For example, searching for "Domain Name System" will only show results containing those exact words in that exact order.

---

### Q10. What does URL stand for?

- A) Universal Resource Link
- B) Uniform Resource Locator ✅
- C) United Resource Location
- D) Uniform Reference Link

> **Explanation:** URL stands for Uniform Resource Locator. It is the address of a web page on the internet. For example, https://www.google.com is a URL.

---

### Q11. Which keyboard shortcut is used to print a web page?

- A) Ctrl + S
- B) Ctrl + D
- C) Ctrl + P ✅
- D) Ctrl + F

> **Explanation:** Ctrl + P opens the Print dialog box. From here, you can print to a physical printer or save the page as a PDF by selecting "Save as PDF" as the destination.

---

### Q12. What keyboard shortcut opens the browser history?

- A) Ctrl + H ✅
- B) Ctrl + J
- C) Ctrl + B
- D) Ctrl + D

> **Explanation:** Ctrl + H opens the browser history, which shows a list of all websites you have visited with dates and times. Ctrl + J opens Downloads, Ctrl + D adds a bookmark.

---

### Q13. In Incognito mode, which of the following is TRUE?

- A) Your ISP cannot see your activity
- B) Your employer cannot track your browsing
- C) Your browsing history is not saved locally ✅
- D) You are completely anonymous online

> **Explanation:** Incognito mode does NOT save your browsing history, cookies, or form data on your local computer. However, your ISP, employer, and network admin can still see your activity. Incognito mode does NOT make you anonymous.

---

### Q14. Which keyboard shortcut refreshes (reloads) the current web page?

- A) F1
- B) F3
- C) F5 ✅
- D) F7

> **Explanation:** F5 (or Ctrl + R) refreshes the current web page. This reloads the page from the server, which is useful when you want to see updated content or fix a loading problem.

---

### Q15. What replaced Internet Explorer as Microsoft's web browser?

- A) Google Chrome
- B) Mozilla Firefox
- C) Microsoft Edge ✅
- D) Opera

> **Explanation:** Microsoft Edge replaced Internet Explorer, which was officially discontinued in June 2022. Edge was first released in 2015 and is now based on the Chromium engine (the same open-source project used by Chrome).
