## Task 1: Advanced Search with Google

2. **Exclude Words:**

3. **Search Within a Website:**

5. **Other Operators:**

   - What definition did Google show? _______________
   - Search for: `100 USD to INR`
   - How many rupees? _______________
   - Search for: `weather Bhopal`
   - What is today's temperature? _______________

## Task 3: Download and Save Web Pages

**Objective:** Practice downloading files, saving web pages, and using the download manager.

### Steps:

1. **Save a Web Page as PDF:**
   - Open: https://www.nielit.gov.in
   - Press **Ctrl + P** to open Print dialog
   - Change Destination to **Save as PDF**
   - Click **Save** and save to your Desktop
   - File name: `NIELIT_Homepage.pdf`
   - Did it save successfully? _______________

2. **Save a Web Page as HTML:**
   - Open: https://www.google.com
   - Press **Ctrl + S**
   - Select **Webpage, Complete**
   - Save to your Desktop
   - Notice: it creates both an HTML file AND a folder with images
   - File name: `Google_Homepage`

3. **Download a File:**
   - Search Google for: `CCC syllabus filetype:pdf`
   - Download one PDF file from the results
   - Open the Download Manager: **Ctrl + J**
   - Take a screenshot of the download manager showing your download

4. **Save an Image:**
   - Go to https://www.google.com
   - Right-click on the Google logo
   - Click **Save image as...**
   - Save to your Desktop as `google_logo.png`

5. **Check Your Downloads Folder:**
   - Open File Explorer
   - Navigate to: `C:\Users\YourName\Downloads`
   - How many files are in your Downloads folder? _______________
   - What file types do you see? (PDF, JPG, EXE, etc.) _______________

### Questions to Answer:
- What is the keyboard shortcut to open Download Manager?
- What is the difference between saving as PDF and saving as HTML?
- Why should you be careful when downloading .exe files?
- What is the default download location on Windows?

## Task 4: Browser Settings and Printing Practice

**Objective:** Configure browser settings and practice printing web content.

### Steps:

1. **Check Browser Settings:**
   - Open Chrome Settings (three dots > Settings)
   - Find and record:
     - Your current homepage: _______________
     - Your default search engine: _______________
     - Is Safe Browsing enabled? _______________
     - Are third-party cookies blocked? _______________

2. **Set a Custom Homepage:**
   - Go to Settings > On startup
   - Select "Open a specific page"
   - Add: `https://www.google.com`
   - Close and reopen Chrome
   - Did Google open as your homepage? _______________

3. **Try Incognito Mode:**
   - Press **Ctrl + Shift + N** to open Incognito window
   - Notice the dark theme and the "You've gone incognito" message
   - Visit 3 websites in Incognito mode
   - Close the Incognito window
   - Press **Ctrl + H** to open History
   - Are the 3 websites you visited in Incognito showing in history? _______________
   - Why or why not? _______________

4. **Printing Practice:**
   - Open any website with content (e.g., a news article)
   - Press **Ctrl + P**
   - In the Print dialog, practice these settings:
     - Change Layout from Portrait to **Landscape**
     - Change Paper size to **A4**
     - Try **Save as PDF** instead of printing
     - Save the PDF to your Desktop

5. **Zoom Practice:**
   - Open any website
   - Press **Ctrl + +** (plus) three times to zoom in
   - What zoom level are you at now? _______________
   - Press **Ctrl + -** (minus) twice to zoom out
   - Press **Ctrl + 0** to reset to 100%

### Questions to Answer:
- What is the keyboard shortcut for Incognito mode in Chrome?
- Does Incognito mode hide your browsing from your ISP?
- What is the difference between Portrait and Landscape printing?
- How do you reset zoom back to normal (100%)?
