## Section 1: Web Browsers

### What is a Web Browser?
A web browser is a software application used to access, view, and interact with websites on the internet. It reads HTML code and displays it as formatted text, images, and interactive elements. A browser is NOT a search engine — Chrome is a browser, Google is a search engine.

### Popular Web Browsers

**Google Chrome** (by Google, 2008)
- Most popular browser worldwide with over 65% market share
- Syncs data across devices via Google account
- Extensive extension library (Chrome Web Store)
- Built-in translation, PDF viewer, and Incognito mode
- Uses the Blink rendering engine

**Mozilla Firefox** (by Mozilla Foundation, 2004)
- Open-source and privacy-focused
- Enhanced Tracking Protection blocks trackers by default
- Customizable with themes and add-ons
- Does not collect user data like commercial browsers
- Uses the Gecko rendering engine

**Microsoft Edge** (by Microsoft, 2015)
- Pre-installed in Windows 10 and Windows 11
- Replaced Internet Explorer (discontinued in 2022)
- Based on Chromium (same engine as Chrome)
- Integrated with Microsoft services (Office, OneDrive)
- Features Collections for organizing web content and Copilot AI

**Opera** (by Opera Software, 1995)
- Built-in free VPN for private browsing
- Built-in ad blocker
- Sidebar with messaging app shortcuts
- Opera Mini version for mobile saves data
- Speed Dial feature for visual bookmarks

**Safari** (by Apple, 2003)
- Default browser on all Apple devices (Mac, iPhone, iPad)
- Only available on Apple devices
- Intelligent Tracking Prevention for privacy
- Energy efficient on MacBook devices
- Uses the WebKit rendering engine

### Browser Interface Components
1. **Title Bar** — Shows the current page title
2. **Address Bar / Omnibox** — Type URLs or search queries; shows padlock for HTTPS
3. **Tabs** — Open multiple pages in one window; Ctrl + T for new tab
4. **Navigation Buttons** — Back, Forward, Refresh, Home
5. **Bookmarks Bar** — Quick access to saved websites; Ctrl + Shift + B to toggle
6. **Menu Button** — Three dots (Chrome/Edge) or three lines (Firefox); access settings
7. **Status Bar** — Bottom of window; shows link URLs on hover
8. **Scroll Bar** — Right side; scroll through long pages

### Default Browser
- The browser that opens automatically when you click a link outside any browser
- Windows default: Microsoft Edge
- Android default: Chrome
- iPhone/iPad default: Safari
- Change in Windows: Settings > Apps > Default Apps > Web browser

## Section 2: Browser Configuration

### Homepage
- The first page displayed when you open the browser
- Set in: Settings > On startup > Open a specific page
- Common choices: Google, Gmail, organization website, news site

### Privacy Settings
- **Safe Browsing:** Protects from dangerous websites and downloads
- **Do Not Track:** Requests websites not to track your activity
- **Site Settings:** Control camera, microphone, location, and notification permissions

### Cookies
- Small text files stored on your computer by websites
- **Session Cookies:** Temporary, deleted when browser closes (e.g., shopping cart items)
- **Persistent Cookies:** Stay for days/months (e.g., login remembrance)
- **Third-party Cookies:** Placed by advertisers to track you across websites
- Manage: Settings > Privacy and Security > Cookies
- Delete: Settings > Clear browsing data > Cookies and site data

### Browser History
- Record of all websites visited with date and time
- View: Ctrl + H
- Clear: Ctrl + Shift + Delete
- Clearing history frees storage and protects privacy

### Incognito / Private Browsing
- Does NOT save: history, cookies, form data, passwords
- Does NOT hide from: ISP, employer, school network
- Shortcuts: Ctrl + Shift + N (Chrome/Edge/Opera), Ctrl + Shift + P (Firefox)
- NOT the same as being anonymous or invisible online

### Extensions / Add-ons
- Small programs that add features to your browser
- Install from official store (Chrome Web Store, Firefox Add-ons)
- Popular: AdBlock Plus, Grammarly, LastPass, Dark Reader
- Only install from trusted sources to avoid malware

## Section 3: Search Engines

### What is a Search Engine?
A website that helps you find information on the internet by searching through billions of web pages. It is NOT a browser.

### Major Search Engines
- **Google** (1998, by Larry Page & Sergey Brin) — 90%+ market share, most popular worldwide
- **Bing** (2009, by Microsoft) — Default in Edge, AI-powered Copilot
- **Yahoo** (1994) — One of the oldest, now uses Bing's search engine
- **DuckDuckGo** — Privacy-focused, does not track users

### How Search Engines Work (3 Steps)
1. **Crawling:** Bots/spiders/crawlers visit web pages and follow links to discover new content. Google's crawler = Googlebot.
2. **Indexing:** Content of discovered pages is stored in a massive database (index).
3. **Ranking:** When you search, an algorithm ranks pages by relevance, quality, links, speed, and mobile-friendliness.

### Advanced Search Operators

| Operator | Purpose | Example |
|----------|---------|---------|
| `"phrase"` | Exact phrase match | `"Domain Name System"` |
| `-word` | Exclude a word | `apple -fruit` |
| `site:domain` | Search within one site | `site:irctc.co.in refund` |
| `filetype:ext` | Find specific file types | `CCC syllabus filetype:pdf` |
| `OR` | Either of two terms | `CCC OR BCC exam` |
| `*` | Wildcard placeholder | `"Father of *"` |
| `define:word` | Get definition | `define:protocol` |
| `intitle:word` | Search in page titles | `intitle:CCC exam` |

## Section 4: Bookmarks and Downloads

### Bookmarks (Favorites)
- Saved shortcuts to web pages for quick access
- **Add bookmark:** Ctrl + D (or click star icon in address bar)
- **Bookmark Manager:** Ctrl + Shift + O
- **Show/Hide Bookmarks Bar:** Ctrl + Shift + B
- Organize bookmarks in folders (Study Material, Government Sites, Shopping, etc.)
- Export as HTML file when switching browsers

### Downloading Files
- Downloading = copying a file from the internet to your computer
- **Default download location:** C:\Users\YourName\Downloads
- **Download Manager:** Ctrl + J — view, pause, resume, cancel downloads
- Change download location in Settings > Downloads
- Common download types: PDF, DOCX, XLSX, JPG, PNG, MP3, MP4, ZIP, EXE

### Saving Web Pages
- **Save as HTML:** Ctrl + S — choose Complete, HTML Only, or Single File
- **Save as PDF:** Ctrl + P > Destination: Save as PDF
- **Useful for:** Saving IRCTC tickets, admit cards, study material for offline use

### Saving Images
- Right-click image > Save image as
- Or right-click > Copy image > Paste (Ctrl + V) in Word/Paint

### Common File Types

| Extension | Type | Used For |
|-----------|------|----------|
| .pdf | Document | Forms, tickets, e-books |
| .doc/.docx | Word | Reports, assignments |
| .xls/.xlsx | Excel | Data, spreadsheets |
| .ppt/.pptx | PowerPoint | Presentations |
| .jpg/.png | Image | Photos, screenshots |
| .mp4 | Video | Tutorials, movies |
| .zip | Compressed | Multiple files in one |
| .exe | Executable | Software (Windows) |

## Section 5: Printing and Saving Web Content

### Printing Web Pages
- **Shortcut:** Ctrl + P
- Print dialog options: Printer/Destination, Pages, Copies, Layout (Portrait/Landscape), Color, Paper Size, Margins, Scale
- **Save as PDF:** Change destination to "Save as PDF" in print dialog
- **Print selection only:** Select text first, then Ctrl + P > Selection only

### Print Preview
- Built into the Print dialog in Chrome (right side shows preview)
- Check: content visibility, image quality, page count, orientation

### Fit to Page
- In Print dialog > More settings > Scale
- Options: Default, Fit to page width, Custom percentage
- For wide tables: use Landscape orientation + reduced scale + minimum margins

### Copying Content
- **Copy text:** Select text > Ctrl + C > Ctrl + V to paste
- **Copy image:** Right-click > Copy image > Ctrl + V to paste
- **Select all:** Ctrl + A

## CCC Exam Tips Summary

1. Browser vs Search Engine: Chrome/Firefox/Edge = browsers; Google/Bing/Yahoo = search engines
2. "Which is NOT a web browser?" = Google (it is a search engine)
3. Ctrl + D = Add bookmark (very frequently asked)
4. Ctrl + P = Print page
5. Ctrl + T = New tab; Ctrl + W = Close tab
6. Ctrl + H = History; Ctrl + J = Downloads
7. Ctrl + Shift + N = Incognito mode (Chrome/Edge)
8. Cookies = small text files stored by websites to remember preferences
9. Incognito mode does NOT make you anonymous — ISP can still see
10. "Which shows encrypted connection?" = HTTPS / padlock icon
11. "Most used search engine?" = Google
12. Default browser in Windows 10/11 = Edge
13. Safari works only on Apple devices
14. Internet Explorer was replaced by Edge
15. Search engines work by: Crawl > Index > Rank
16. "Exact phrase search in Google?" = Use double quotes
17. Homepage = first page when browser opens
18. URL = Uniform Resource Locator
19. Tim Berners-Lee invented WWW (1989)
20. F5 = Refresh page
