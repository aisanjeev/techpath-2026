## What are Bookmarks?

A **bookmark** (also called a **favorite** in some browsers) is a saved shortcut to a web page. Instead of typing the full URL every time you want to visit a website, you can simply click the bookmark.

**Simple Analogy:** A bookmark in a browser works just like a bookmark in a physical book — it marks a page so you can quickly find it again later.

---

## Adding Bookmarks

### Method 1: Using Keyboard Shortcut (Fastest)
1. Open the website you want to bookmark
2. Press **Ctrl + D**
3. A dialog box appears where you can:
   - Edit the bookmark name
   - Choose which folder to save it in
4. Click **Done**

### Method 2: Using the Star Icon
1. Open the website you want to bookmark
2. Click the **star icon** in the address bar (right side)
3. Edit the name and folder if needed
4. Click **Done**

### Method 3: Drag and Drop
1. Open the website
2. Click the padlock/info icon in the address bar
3. Drag it to the Bookmarks Bar

**CCC Exam Tip:** "Ctrl + D does what in browser?" = Adds a bookmark (saves the current page as a favorite). This is a very frequently asked question.

## Organizing Bookmarks in Folders

As you add more bookmarks, they can become messy. Organizing them into folders helps you find things quickly.

### How to Create Bookmark Folders in Chrome:
1. Press **Ctrl + Shift + O** to open the Bookmark Manager
2. Click the **three dots** (menu) at the top
3. Click **Add new folder**
4. Give the folder a meaningful name (e.g., "Study Material," "Government Sites," "Shopping")
5. Drag existing bookmarks into the folder

## Bookmarks Bar

The **Bookmarks Bar** is a toolbar that appears just below the address bar. It shows your most-used bookmarks for quick access.

### Show/Hide Bookmarks Bar:
- **Keyboard shortcut:** Ctrl + Shift + B
- Or: Menu (three dots) > Bookmarks > Show bookmarks bar

### Tips for Using Bookmarks Bar:
- Keep only your most-used websites (5-10 bookmarks)
- Remove the bookmark names to save space — just the icon is enough to recognize the site
- Create folders in the bookmarks bar to organize more links

## Managing Bookmarks

### Editing a Bookmark:
1. Open Bookmark Manager (Ctrl + Shift + O)
2. Right-click the bookmark
3. Click **Edit**
4. Change the name or URL
5. Click **Save**

### Deleting a Bookmark:
1. Open Bookmark Manager (Ctrl + Shift + O)
2. Right-click the bookmark
3. Click **Delete**

### Exporting Bookmarks:
- You can export all your bookmarks as an HTML file
- Menu > Bookmarks > Bookmark Manager > Three dots > Export bookmarks
- Useful when switching to a new browser or computer

### Importing Bookmarks:
- You can import bookmarks from another browser or an HTML file
- Menu > Bookmarks > Import bookmarks and settings

## Downloading Files from the Internet

**Downloading** means copying a file from the internet (a server) to your computer's storage.

### Common Things People Download:
- PDF documents (exam syllabus, admit cards, study materials)
- Images and photos
- Software and apps
- Music and videos
- Forms and applications (government forms, bank forms)

### How to Download a File:
1. Find the download link on a website
2. Click the link
3. The browser may ask where to save the file — choose a folder
4. The file starts downloading — progress shows at the bottom of the browser
5. Once complete, you can find the file in your Downloads folder

### Default Download Location:
- **Windows:** `C:\Users\YourName\Downloads`
- You can change this in browser settings

### How to Change Download Location in Chrome:
1. Go to Settings > Downloads
2. Click **Change** next to the download location
3. Select your preferred folder
4. Optionally, turn on "Ask where to save each file before downloading"

## Saving Web Pages

You can save an entire web page to your computer to read later (even without internet).

### Method 1: Save as HTML File
1. Open the web page you want to save
2. Press **Ctrl + S**
3. Choose the save location
4. Select format:
   - **Webpage, Complete** — Saves the page with all images and formatting
   - **Webpage, HTML Only** — Saves only the text (smaller file size)
   - **Webpage, Single File (MHTML)** — Saves everything in one file
5. Click **Save**

### Method 2: Save as PDF
1. Open the web page
2. Press **Ctrl + P** (Print dialog)
3. Change the destination/printer to **Save as PDF**
4. Click **Save**
5. Choose location and click **Save**

This is very useful for saving IRCTC tickets, admit cards, and government documents.

## Saving Images from Websites

### Method 1: Right-click and Save
1. Right-click on the image you want to save
2. Click **Save image as...**
3. Choose the location and file name
4. Click **Save**

### Method 2: Drag and Drop
1. Click and hold the image
2. Drag it to your desktop or a folder
3. Release the mouse button

### Image File Types:

| Format | Description | Best For |
|--------|-------------|----------|
| **JPG/JPEG** | Compressed photo format | Photographs, images with many colors |
| **PNG** | Supports transparency | Logos, icons, screenshots |
| **GIF** | Supports animation | Animated images, simple graphics |
| **SVG** | Scalable vector graphics | Logos, icons that need to scale |
| **WebP** | Modern format, smaller size | Web images (newer format) |

## Download Manager

The **download manager** is a built-in feature of every browser that tracks and manages your downloads.

### How to Open Download Manager:
- **Keyboard shortcut:** Ctrl + J
- Or: Menu (three dots) > Downloads

### Download Manager Features:
- Shows all current and past downloads
- Displays download progress (percentage, speed, time remaining)
- Allows you to pause and resume downloads
- Shows download location (click "Show in folder")
- Allows you to cancel downloads
- Clear download history

### Download Manager Actions:

| Action | How |
|--------|-----|
| View downloads | Ctrl + J |
| Pause a download | Click pause button in download bar |
| Resume a download | Click resume button |
| Cancel a download | Click X (cancel) button |
| Open downloaded file | Click the file name |
| Open file location | Click "Show in folder" |

## Common File Types Downloaded from the Web

| Extension | Type | Used For |
|-----------|------|----------|
| **.pdf** | Document | Admit cards, forms, e-books, study material |
| **.doc/.docx** | Word Document | Reports, assignments |
| **.xls/.xlsx** | Excel Spreadsheet | Data, mark sheets |
| **.ppt/.pptx** | PowerPoint | Presentations |
| **.jpg/.png** | Image | Photos, screenshots |
| **.mp3** | Audio | Music, recordings |
| **.mp4** | Video | Movies, tutorials |
| **.zip/.rar** | Compressed | Multiple files packed into one |
| **.exe** | Executable | Software installers (Windows) |
| **.apk** | Android Package | Android app installers |

**Safety Warning:** Be very careful when downloading **.exe** files. Only download software from official websites. Malicious .exe files can contain viruses.
