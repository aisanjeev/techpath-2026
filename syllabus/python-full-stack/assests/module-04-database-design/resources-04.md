### Python Packages
```bash

pip install pymysql                       # MySQL driver for Python
pip install alembic                       # Database migrations
pip install pymongo                       # MongoDB driver
pip install redis                         # Redis driver
pip install aiosqlite                     # Async SQLite (for development)
```
