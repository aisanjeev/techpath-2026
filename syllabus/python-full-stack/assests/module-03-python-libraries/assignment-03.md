## Task 4: Automated File Organizer with Logging (Advanced)

**Objective:** Build a Python tool that organizes files in a directory by type, with full logging and scheduling.

**Requirements:**
1. The tool should:
   - Scan a given directory for files
   - Organize files into subfolders by type:
     - `Images/` — .jpg, .png, .gif, .svg
     - `Documents/` — .pdf, .doc, .docx, .txt, .md
     - `Spreadsheets/` — .csv, .xlsx, .xls
     - `Code/` — .py, .js, .html, .css, .json
     - `Archives/` — .zip, .rar, .tar, .gz
     - `Other/` — everything else
   - Handle duplicate filenames (add _1, _2, etc.)
   - Track file sizes and generate a summary
2. Use `pathlib` for all file operations
3. Use `shutil` for moving/copying files
4. Use Python `logging` module:
   - Log every file move to both console and a log file
   - Use appropriate log levels (INFO for moves, WARNING for duplicates, ERROR for failures)
5. Generate a JSON report with:
   - Total files processed
   - Files per category
   - Total size per category
   - Any errors encountered
6. Add a `--dry-run` mode that shows what would happen without actually moving files
7. Use `argparse` or simple input to accept the target directory path

**Deliverables:**
- `file_organizer.py` — The main tool
- `test_organizer.py` — A script that creates sample test files and runs the organizer on them
- The tool should create a `organize_report.json` and `organizer.log` when run

**Bonus challenge:** Add a `--watch` mode using `schedule` that re-organizes every 5 minutes.
