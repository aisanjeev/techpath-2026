# Module 01: Python Core — Resources

## Official Documentation
- [Python Official Tutorial](https://docs.python.org/3/tutorial/) — The best starting point from Python itself
- [Python Standard Library Reference](https://docs.python.org/3/library/) — Complete reference for built-in modules
- [Python Built-in Functions](https://docs.python.org/3/library/functions.html) — All built-in functions like `print()`, `len()`, `range()`
- [PEP 8 Style Guide](https://peps.python.org/pep-0008/) — Official Python coding style guide
- [Python re Module Docs](https://docs.python.org/3/library/re.html) — Regular expressions reference

- [LeetCode — Easy Problems](https://leetcode.com/problemset/?difficulty=EASY&topicSlugs=array%2Cstring%2Chash-table) — Start with Easy string and array problems
