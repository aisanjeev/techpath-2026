## Recommended Reading Order for Beginners

1. Start with **FastAPI docs** -- build a basic API first
2. Read **ChromaDB docs** -- understand how vector search works
3. Follow **Anthropic prompt engineering guide** -- learn to write good prompts
4. Try the **OpenAI Cookbook** RAG examples -- build your first RAG pipeline
5. Watch the **freeCodeCamp RAG Chatbot** video -- see everything come together
6. Read **RAGAS docs** -- learn how to measure chatbot quality
7. Explore **LangChain docs** -- once you understand the basics, use the framework
