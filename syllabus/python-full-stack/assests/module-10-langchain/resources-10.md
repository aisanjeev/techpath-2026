# Module 10 -- Resources & Links

## Installation

- **Python 3.10+** -- https://www.python.org/downloads/
- **LangChain** -- `pip install langchain langchain-openai langchain-community langchain-core`
- **Vector Stores** -- `pip install faiss-cpu chromadb pymilvus langchain-milvus`
- **Document Loaders** -- `pip install pypdf beautifulsoup4`
- **Tokenizer** -- `pip install tiktoken`
- **Environment Variables** -- `pip install python-dotenv`
- **OpenAI API Key** -- https://platform.openai.com/api-keys (free tier available)
