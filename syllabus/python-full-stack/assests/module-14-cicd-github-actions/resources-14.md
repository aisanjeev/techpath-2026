## CI/CD Tools Comparison

| Tool | Free Tier | Best For | Runs On |
|------|-----------|----------|---------|
| **GitHub Actions** | 2,000 min/month (free repos unlimited) | GitHub-hosted projects | Cloud (GitHub runners) |
| **GitLab CI/CD** | 400 min/month | GitLab-hosted projects | Cloud or self-hosted |
| **Jenkins** | Fully free (self-hosted) | Enterprise, custom pipelines | Self-hosted only |
| **CircleCI** | 6,000 min/month | Fast builds, Docker support | Cloud or self-hosted |
| **Travis CI** | Free for open source | Open source projects | Cloud |
