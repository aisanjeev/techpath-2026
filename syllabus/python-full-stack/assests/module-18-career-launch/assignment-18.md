# Module 18 — Assignment: Career Launch Portfolio

**Deadline:** End of Week 18 (Final submission)
**Submission:** GitHub profile link, resume PDF, LinkedIn profile link

## Task 1: GitHub Portfolio Setup (25 marks)

Set up a professional GitHub profile with pinned projects:

- [ ] **GitHub Profile README** — Create a repository with your username as the name (e.g., `rahulsharma/rahulsharma`) with a README.md that includes:
  - Your name and a one-line introduction
  - Tech stack (list of technologies you know)
  - A table of 3-5 featured projects with links and descriptions
  - Contact information (email, LinkedIn)

- [ ] **5 Pinned Repositories** — Pin exactly 5 repos on your profile:
  - At least 1 must be your capstone project
  - At least 1 must have a live deployment link
  - At least 3 must have professional READMEs with:
    - Project description
    - Tech stack table
    - Setup instructions (clone, install, run)
    - At least 1 screenshot
    - CI badge (if applicable)

- [ ] **Clean commit history** — At least 20 commits across your pinned repos with meaningful messages (not "update" or "fix")

- [ ] **Contribution graph** — Show activity in the last 30 days (at least 10 green squares)

**Verification:** Share your GitHub profile URL (e.g., `https://github.com/rahulsharma`)

## Task 2: ATS-Friendly Resume (25 marks)

Create a one-page resume optimized for ATS:

- [ ] **Format**: Single page, clean layout, no tables/columns/graphics
- [ ] **Sections** (in this order):
  1. Name + contact info (email, phone, GitHub link, LinkedIn link, city)
  2. Skills (comma-separated list of technologies)
  3. Projects (at least 3 projects with tech stack, bullet points, and live/GitHub links)
  4. Education
  5. Certifications (optional)

- [ ] **Project descriptions** must:
  - Start each bullet with an action verb (Built, Developed, Implemented, Deployed)
  - Include at least one quantified result per project (e.g., "reduced manual work by 80%")
  - List the tech stack for each project
  - Include live demo link or GitHub link

- [ ] **Keywords**: Your resume must include these terms (if applicable):
  Python, FastAPI or Django, PostgreSQL, REST API, Git, GitHub,
  CI/CD, Docker, HTML, CSS, JavaScript, SQL, AI, LangChain

- [ ] **ATS Test**: Upload your resume to https://resumeworded.com or https://jobscan.co and score at least 60% match against a sample Python developer job description

**Submission:** Resume as PDF file (named `YourName-Resume-2026.pdf`)

## Task 3: LinkedIn Profile (25 marks)

Set up or optimize your LinkedIn profile:

- [ ] **Professional photo** — Clear face photo, neutral background (no selfies)
- [ ] **Headline** — Include role + key technologies + "Open to Opportunities"
  - Example: "Python Full-Stack Developer | FastAPI | Django | AI/ML | Open to Opportunities"

- [ ] **About section** — 3-5 sentences covering:
  - Who you are (background)
  - What you build (technologies and project types)
  - What you are looking for (job type, location preference)
  - Key technologies listed

- [ ] **Experience section** — Add at least 2 entries:
  - Your capstone project as "Full-Stack Developer (Capstone Project)" at TechPath Institute
  - Another project or internship

- [ ] **Skills section** — Add at least 10 relevant skills and get endorsements from classmates

- [ ] **Projects section** — Add at least 2 projects with descriptions and links

- [ ] **Education** — Add TechPath Institute course

- [ ] **1 LinkedIn post** — Write and publish at least one post about your learning journey or a project. Include:
  - What you built
  - What you learned
  - Live demo or GitHub link
  - At least 3 relevant hashtags

**Verification:** Share your LinkedIn profile URL

## Task 4: Interview Preparation Evidence (25 marks)

Demonstrate interview readiness:

### DSA Practice (10 marks)
- [ ] Solve at least 20 problems on LeetCode or HackerRank
- [ ] Share your profile link showing completed problems
- [ ] Categories covered: Arrays (5), Strings (5), Hashmaps (5), Other (5)

### Mock Interview (10 marks)
Complete one of the following:
- [ ] **Option A**: Record yourself answering these 5 questions (2-3 minutes per answer):
  1. "Tell me about yourself"
  2. "Walk me through your capstone project"
  3. "What is REST API and how did you design yours?"
  4. "What was the hardest bug you fixed in your project?"
  5. "Where do you see yourself in 3 years?"

- [ ] **Option B**: Complete a mock interview on Pramp (https://pramp.com) and share the feedback/rating

### Technical Q&A Document (5 marks)
- [ ] Write answers to 10 technical interview questions in a document:
  - 3 Python questions (e.g., "What are decorators?", "List vs Tuple")
  - 3 Framework questions (e.g., "What is middleware?", "What is ORM?")
  - 2 Database questions (e.g., "What is normalization?", "Explain JOIN types")
  - 2 System design questions (e.g., "What is caching?", "REST vs GraphQL")

**Submission:** LeetCode/HackerRank profile link, mock interview recording or Pramp feedback, technical Q&A document
