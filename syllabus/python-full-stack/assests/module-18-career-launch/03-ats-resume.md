## What Is ATS and Why Should You Care?

Imagine you are a security guard at a building entrance. Your job is to check if each visitor has the right ID and clearance. If they do not match, you turn them away -- no matter how qualified they actually are. That is exactly what an ATS (Applicant Tracking System) does for job applications.

An ATS is software that companies use to filter resumes before a human ever sees them. In India, over 90% of large IT companies (TCS, Infosys, Wipro, HCL, Cognizant) and most startups use an ATS. If your resume does not pass the ATS, a recruiter will never read it.

| ATS Name | Used By |
|---|---|
| Workday | Large enterprises, MNCs |
| Greenhouse | Startups, mid-size companies |
| Lever | Tech companies |
| Taleo (Oracle) | TCS, Infosys, large IT firms |
| Naukri RMS | Indian companies using Naukri.com |

## Why Fancy Resumes Get Rejected

Here is a harsh truth: that beautifully designed resume with colors, icons, charts, and creative layouts is probably getting thrown out by the ATS.

**Things that break ATS parsing:**

| Feature | Why It Fails |
|---|---|
| Tables and columns | ATS reads left-to-right, top-to-bottom; columns get mixed up |
| Images and icons | ATS cannot read images at all |
| Headers and footers | Many ATS systems skip header/footer content entirely |
| Fancy fonts | Non-standard fonts may render as gibberish |
| PDF with graphics | Complex PDFs may not parse correctly |
| Infographic resumes | ATS sees blank page |

**What works:**

- Simple, single-column layout.
- Standard fonts (Arial, Calibri, Times New Roman).
- Clear section headings (Education, Skills, Projects, Experience).
- Plain text or simple PDF format.
- Standard date formats (Month Year or MM/YYYY).

## The 1-Page Format Rules

For a fresher with 0-2 years of experience, your resume must be exactly 1 page. Not 2 pages, not 1.5 pages. One page.

### Page Layout

| Element | Specification |
|---|---|
| Paper size | A4 |
| Margins | 0.5 to 0.75 inches on all sides |
| Font | Arial or Calibri, 10-11pt for body, 12-14pt for name |
| Line spacing | 1.0 to 1.15 |
| Section spacing | 6-8pt between sections |
| File format | PDF (unless company specifically asks for .docx) |

### What to Exclude to Save Space

- Photo (not needed for most tech jobs unless explicitly asked)
- "Objective" or "Career Objective" section (replace with Summary)
- Hobbies (reading, traveling, music -- they add no value)
- "References available on request" (obvious, wastes space)
- Full address (city and state is enough)
- Date of birth, gender, marital status (not required)

## Keyword Matching from Job Descriptions

ATS systems score your resume based on how well it matches the job description. This is called keyword matching. Think of it like a search engine -- if the job asks for "FastAPI" and your resume says "fast api" or does not mention it at all, you lose points.

### How to Match Keywords

**Step 1:** Copy the job description into a text file.

**Step 2:** Highlight all technical skills, tools, and technologies mentioned.

**Step 3:** Make sure every highlighted keyword appears in your resume (if you genuinely have that skill).

### Example: Matching a Real Job Description

**Job Description says:** "Looking for a Python developer with experience in FastAPI, REST APIs, PostgreSQL, Docker, and CI/CD. Knowledge of React and cloud deployment is a plus."

**Your Skills section should include:** Python, FastAPI, REST APIs, PostgreSQL, Docker, CI/CD, React, Cloud Deployment.

**Common keyword mismatches to avoid:**

| Job Description Says | Your Resume Says | Fix |
|---|---|---|
| REST APIs | Web APIs | Use "REST APIs" |
| PostgreSQL | Postgres | Use "PostgreSQL" |
| CI/CD | Continuous Integration | Use "CI/CD" |
| Docker | Containerization | Use "Docker" |
| React.js | ReactJS | Use "React.js" or "React" |

## Action Verbs That Work

Start every bullet point with a strong action verb. These verbs tell the ATS and the recruiter exactly what you did.

| Strong Verbs | Weak Alternatives (Avoid) |
|---|---|
| Built | Was responsible for |
| Designed | Helped with |
| Deployed | Worked on |
| Optimized | Was involved in |
| Implemented | Assisted in |
| Developed | Participated in |
| Automated | Did some work on |
| Integrated | Contributed to |
| Reduced | Tried to improve |
| Achieved | Was part of |

### Example Bullet Points

**Bad:** "Worked on a web application using Python and React."

**Good:** "Built a full-stack web application using FastAPI and React, serving 100+ users with 20 REST API endpoints and JWT authentication."

**Bad:** "Was responsible for database work."

**Good:** "Designed and optimized PostgreSQL database schema with 15 tables, reducing query response time by 35% through proper indexing."

## Common Mistakes That Get Resumes Rejected

| Mistake | Why It Hurts | Fix |
|---|---|---|
| Spelling errors | Shows carelessness | Proofread 3 times, use Grammarly |
| Generic objective | Wastes space, adds nothing | Replace with targeted summary |
| No projects section | No proof of skills | Add 3-4 projects with links |
| Missing GitHub/LinkedIn | Recruiter cannot verify skills | Always include profile links |
| Listing every skill ever | Looks unfocused | List only relevant skills (15-20) |
| Using "I" or "my" | Not resume style | Start with verbs: Built, Designed, Deployed |
| More than 1 page | Fresher does not need 2 pages | Cut ruthlessly, keep only strong content |
| Inconsistent formatting | Looks unprofessional | Same font, spacing, and bullet style throughout |
