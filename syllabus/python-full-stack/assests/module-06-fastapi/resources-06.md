# Module 06 — Resources & Links

## Installation

- **Python 3.10+** — https://www.python.org/downloads/
- **pip** (included with Python)
- **Key packages to install:**
```bash
pip install fastapi uvicorn sqlalchemy aiosqlite python-jose passlib[bcrypt] httpx pytest
```
